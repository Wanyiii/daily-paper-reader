## 摘要
我们提出了FlexSplat，一个用于从未标定的、以物体为中心的多视图图像集合进行新视图合成(NVS)的前馈框架。近期一类基于查询的方法通过将三维高斯视为Transformer查询，并用多视图可变形注意力进行细化，来重建紧凑的三维高斯集合；然而，这些方法假设相机位姿是给定的。FlexSplat去除了这一假设：一个几何Transformer与高斯解码器联合训练，以预测每张图像的相机参数和深度，进而为深度引导的高斯参数化以及多视图可变形交叉注意力提供基础，该注意力将所有输入视图的证据聚合为单一、视图一致的基元集合。一个不确定性加权的深度一致性目标使得联合训练的几何适应重建任务，而解码过程中形成的跨视图共识吸收了估计相机和深度的残差误差。该表示采用紧凑的高斯预算，且与输入分辨率解耦——与像素对齐方法不同，其基元数量不随图像网格增长——也不由视图数量决定。在ShapeNet-SRN和Google Scanned Objects (GSO)上，FlexSplat在不需要相机位姿或真实深度的情况下，匹配或接近有位姿的最先进重建器，并在GSO上达到所比较方法中最佳的感知质量(LPIPS)。我们的结果表明，联合训练的几何前端足以使基于查询的高斯重建实现无标定操作，同时其PSNR保持在有位姿方法的0.7 dB以内，并匹配其感知质量。

## Abstract
We present FlexSplat, a feed-forward framework for novel view synthesis (NVS) from uncalibrated, object-centric multi-view image collections. A recent line of query-based methods reconstructs a compact set of 3D Gaussians by treating them as transformer queries that are refined with multi-view deformable attention; these methods, however, assume that camera poses are given. FlexSplat removes this assumption: a geometry transformer is trained jointly with the Gaussian decoder to predict per-image camera parameters and depth, which in turn ground a depth-guided Gaussian parameterization and a multi-view deformable cross-attention that aggregates evidence across all input views into a single, view-consistent set of primitives. An uncertainty-weighted depth-consistency objective lets the jointly trained geometry adapt to the reconstruction task, while the cross-view consensus formed during decoding absorbs the residual error of the estimated cameras and depth. The representation uses a compact Gaussian budget that is decoupled from the input resolution - unlike pixel-aligned methods, the primitive count does not grow with the image grid - and is not dictated by the number of views. On ShapeNet-SRN and Google Scanned Objects (GSO), FlexSplat matches or approaches posed state-of-the-art reconstructors while requiring neither camera poses nor ground-truth depth, and matches the best perceptual (LPIPS) quality among the compared methods on GSO. Our results indicate that a jointly trained geometry front-end is sufficient to bring calibration-free operation to query-based Gaussian reconstruction while staying within 0.7 dB PSNR of posed methods and matching their perceptual quality.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- **核心问题**：现有基于查询（query-based）的前馈 3D 高斯重建方法（如 LeanGaussian、UniGS）虽然摆脱了像素/点云对应（correspondence-free）的限制，但仍**强依赖已知相机位姿**作为输入，这恰好是前馈新视图合成（NVS）框架本应规避的预处理环节。
- **研究缺口**：大规模的 NVS 方法要么需要位姿（pixel-aligned 或 point-based 方法），要么针对场景级数据（如 RealEstate10K）而非物体级；而物体级、免标定、查询式高斯重建的方案尚属空白。
- **整体意义**：FlexSplat 首次将**免标定（calibration-free）** 操作引入查询式高斯重建，通过联合训练几何 Transformer 预测相机和深度，使前馈重建器在**没有位姿、没有真实深度**的情况下逼近甚至匹配有位姿的最先进方法（SOTA），缩小了免标定方法与有标定方法之间的差距。

## 2. 论文提出的方法论

### 核心思想
- 用一个**联合训练的几何 Transformer（VGGT）** 替代显式输入的相机位姿，预测每张图像的相机参数和深度图。
- 将预测的深度用于 **深度引导的高斯参数化**（depth-guided Gaussian parameterization），作为高斯中心初始化的锚点。
- 用**多视图可变形交叉注意力（MV-DFA）** 将所有视图的特征聚合到一个**单一、视图一致**的 3D 高斯集合中，通过“跨视图共识”吸收相机和深度的估计误差。

### 关键技术细节
1. **几何 Transformer 前端**：采用 VGGT（Visual Geometry Grounded Transformer）作为骨干，附带两个 head：
   - 相机头（Camera Head）：回归每张图像的内参和外参。
   - 深度头（Depth Head）：回归稠密深度图并输出不确定性（置信度）。
   - 关键设计：VGGT 与高斯解码器**联合微调**，让几何预测适应重建任务，而非作为固定的前置模块。
2. **深度引导的高斯参数化**：
   - 高斯中心不直接回归，而是通过预测深度加上可学习的偏移量进行反投影（back-projection）得到，增强训练稳定性。
3. **几何初始化**：随机初始化高斯在多视图下会导致投影点落在图像外、特征消失、梯度消失；因此将初始高斯放置在**估计的场景中心**（通过相机光轴最小二乘交点计算）。
4. **多视图可变形交叉注意力**：
   - 每个 3D 高斯投影到 N 个视图上得到 N 个 2D 参考点，在参考点周围用可学习偏移采样特征。
   - 注意力权重在所有视图和采样点上联合归一化，形成跨视图共识。
5. **解码器**：L=3 层迭代细化，每层包含 MV-DFA、自注意力、FFN，以及一个 Splat Head 输出增量更新。
6. **损失函数**（由四项组成）：
   - 特征提取器输出上的 RGB MSE 重建损失；
   - 每个解码器层渲染图像上的 RGB MSE 损失；
   - **不确定性加权深度一致性损失**：将渲染深度与几何头预测的深度对齐，用置信度 U 加权，同时正则化高斯和几何预测；
   - LPIPS 感知损失。
7. **紧凑表示**：高斯数量 N_G 是自由超参数，与输入分辨率解耦，也不由视图数量决定——4 视图 256×256 输入下约用 2×10⁴ 个高斯，而像素对齐方法需约 2.6×10⁵ 个。

## 6. 论文的主要结论与发现

1. **免标定可行**：联合训练的几何前端（VGGT）足以支撑查询式高斯重建的无标定操作，且与有姿态方法的 PSNR 差距在 **0.7 dB 以内**。
2. **感知质量相当**：在 GSO 四视图任务上，FlexSplat 以 **0.041 LPIPS** 达到所比较方法中的**最佳感知质量**（超过 UniGS 的 0.042）。
3. **具体性能**（GSO 四视图）：PSNR 29.73 dB、SSIM 0.949，对比有姿态 SOTA UniGS（30.42 dB / 0.961 / 0.042），差距分别为 0.69 dB 和 0.012 SSIM。
4. **视图数量影响**：1→2 视图增益最大（+5.17 dB），2→4 视图继续提升（+2.63 dB），呈边际递减。
5. **鲁棒性**：对相机旋转扰动呈**优雅退化**——5° 扰动仅损失 1.32 dB；10° 以上退化加速。
6. **紧凑性**：10K–20K 高斯即可达到与像素对齐方法（~260K 高斯）相当甚至更好的质量，且预算与分辨率/视图数解耦。

## 7. 优点

- **问题定位精准**：填补了物体级、免标定、查询式高斯重建的空白，动机明确且有实际应用价值（资产创建、image-to-3D、机器人操作）。
- **方法设计优雅**：
  - 用联合训练代替固定前端，使几何预测“适应任务而非孤立正确”；
  - 跨视图共识机制是吸收位姿误差的巧妙设计，将“不完美几何”转化为可容忍的噪声而非灾难性失败；
  - 深度引导参数化显著提升训练稳定性。

- **代码开源**：提供了 GitHub 链接，可复现性强。

## 8. 不足与局限

### 实验覆盖局限
- **仅限物体级/中心化场景**：未在背景丰富的大规模场景（如 RealEstate10K、DL3DV）上验证，泛化性存疑。
- **平移灵敏度未分析**：位姿扰动实验仅覆盖旋转噪声（σ=0°–20°），没有测试相机中心平移噪声的影响。
- **训练时长未报告**：算力成本信息不完整，难以评估可复现成本。

### 方法局限
- **PSNR 仍落后于有姿态方法** 0.7 dB，在要求精确几何的应用（如测量、严格重建）中可能不够。
- **大几何误差场景脆弱**：在密集或不一致的捕获条件下，几何 Transformer 的大误差仍可能传播到重建结果，跨视图共识的容错有上限。
- **视图数量上限未探索**：实验只到 4 视图，对于更多视图（如 8–12 视图）的表现和预算扩展策略未测试。
- **与场景级方法不做对比**：虽然作者解释合理（不是同类比较），但这意味着无法判断该方法在通用场景中的相对位置。

### 潜在偏差风险
- 训练数据为 Objaverse-LVIS 子集，与 GSO 评测集分布较近（都是物体扫描），跨域泛化（如真实拍摄照片、非白背景）未经检验。
- 单视图 GSO 实验中基线使用扩散模型生成多视图的做法，存在轻微的对比不公平。
