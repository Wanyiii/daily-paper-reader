## 摘要
学习具有不完整标注的多标签图像分类是一项具有挑战性的任务，因其在大规模数据集上兼具高效性和较少人工消耗的优越权衡而得到广泛研究。主流方法依赖强先验假设从部分标注中恢复缺失语义。然而，这些统计先验容易遭受不稳定的语义错误，从而导致灾难性过拟合。为此，我们提出了一种语言驱动的稠密语义适配器（LDSA），从多模态预训练CLIP模型中挖掘先验自适应关系。在我们的方法中，首先提出稠密对比适配器以构建稠密视觉对比约束，将任务特定知识迁移到视觉域。接着，借助类特定提示调优，我们提出一种语言驱动的交互式解码器，使语言代理与视觉域相适应。通过所提模块的协同学习，实验结果表明，我们提出的LDSA在公开的多标签分类基准上达到了新的最先进水平，且可解释性分析揭示我们的LDSA通过先验自适应学习方案发现了隐式语义关系。

## Abstract
Learning multi-label image classification with incomplete annotations is a challenging task that has been widely studied for its superior trade-off between high efficiency and less labor consumption on large-scale datasets. Predominant methods rely on strong prior assumptions to recover the missing semantics from partial annotations. However, these statistic priors suffer from unstable semantic mistakes and thus lead to catastrophic overfitting. Toward this end, we propose a Language-driven Dense Semantic Adaptor (LDSA) that excavates prior-adaptive relationships from multimodal pretrained CLIP models. In our approach, the densely contrastive adaptor is first proposed to construct dense visual contrastive constraints, transferring the task-specific knowledge to visual domains. We then propose a language-driven interactive decoder with the help of class-specific prompt tuning, which adapts language proxies with visual domains. With the collaborative learning of proposed modules, experimental results demonstrate our proposed LDSA achieves a new state of the art on public multi-label classification benchmarks, and interpretable analyses reveal that our LDSA discovers implicit semantic relationships with the prior-adaptive learning scheme.

  - 统计先验高度依赖训练数据分布，在不同下游场景下容易产生语义错误，进而导致**灾难性过拟合**。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

论文提出 **语言驱动的稠密语义适配器（Language-driven Dense Semantic Adaptor，LDSA）**，整体框架包含两个主要模块：

### 2.1 稠密对比适配器（Densely Contrastive Adaptor）

- **从稀疏到稠密**：放弃 CLIP 传统的池化操作（将特征压缩为单一向量），改为保留密集空间特征 `Vd ∈ R^{W×H×D}`，以保留不同对象的空间位置和细粒度信息。
- **隐式语义对比关系**：对同一图像施加弱增强 `Aw(·)` 和强增强 `As(·)`，构成联合批次 `Bcl = {As(xi), Aw(xi)}`。通过双视角联合优化，隐式地构造正样本对（同一图像的两个增广视图）和负样本对（批次内不同图像的补丁），实现类似对比学习的语义聚类效果。
- **适配器结构**：
  - 采用权重共享的稠密编码器（Squeeze-and-Excitation 式通道降维），加上残差连接；
  - 后接两层标准 Transformer 编码器，使用可学习位置编码；
  - 使用**稠密批归一化（Dense BN）**：在空间分辨率和联合双视角统计上计算均值和方差，促使强弱视图形成紧凑统一的语义分布。
- 视觉编码器 `fV` 保持冻结，仅训练适配器，避免直接微调导致的特征坍塌。

### 2.2 语言驱动的交互式解码器（Language-driven Interactive Decoder）

- **类特定上下文提示（Class-specific Context Prompts）**：冻结文本编码器 `fT`，为每个类别构造可学习提示词 `ti = [zi,1,...,zi,M, cls]`，通过提示学习得到语言原型 `Ti = fT(ti; θfix)`，以适应下游数据集。
- **跨模态交互解码**：以语言原型作为查询（Query），稠密视觉特征作为键（Key）和值（Value），通过 Transformer 风格解码器构建类别-空间区域的关联矩阵，实现细粒度的跨模态交互。
- **语义感知紧凑预测（Semantic-aware Compact Prediction）**：对每个类别使用独立的轻量网络 `τc: R^D → R^1` 进行预测，参数总量仅为传统全连接层的 `1/C`，有效正则化特征表示，防止过拟合。

### 2.3 隐式语义对比学习与损失函数

- 论文从正样本 L1 约束和 InfoNCE 出发，推导出统一的隐式语义对比损失 `LISC`：
  - 结合非对称损失（ASL），仅对已知正/负标签施加约束，忽略未知标签；
  - 同时优化双视图预测与部分标签分类误差，实现分类与语义对比约束的联合学习；
  - 最终训练目标仅为 `Ltotal = LISC`。
- 算法流程（Algorithm 1）概括为：构造联合增强批次 → 视觉编码与稠密适配 → 文本提示与语言原型生成 → 跨模态交互解码 → 紧凑预测 → 计算联合损失并更新可学习参数（仅适配器、解码器和提示参数更新）。

## 6. 论文的主要结论与发现

- 提出的 LDSA 通过“视觉稠密对比适配 + 语言提示引导解码”双路协作，能够从 CLIP 中挖掘**先验自适应的语义关系**，有效缓解部分标签学习中的过拟合和语义错误问题。
- 在 MS-COCO、PASCAL VOC、VG-200 三个基准上均达到新最优水平，尤其在 VG-200 上提升幅度高达 9.3%。
- 消融实验表明：
  - 稠密特征分辨率、稠密适配器、语言引导和紧凑预测头均对性能有正向贡献；
  - 强弱增强与适配器存在协同效应，脱离适配器时强增强反而有害；
  - 隐式对比学习优于显式 InfoNCE 和正 L1 约束，因为多标签图像语义不一致，图像级负对会破坏模型；
  - 语义感知紧凑预测用更少参数获得更好性能，说明参数高效正则化在部分标签任务中非常重要。
- 可视化显示 LDSA 能关注到对象交互和场景信息（如区分滑板与冲浪板），学习到的语义关系既有共现关系（如花瓶与盆栽），也有语义借用（如熊与泰迪熊）和粗粒度颜色相似关系（如胡萝卜与橙子）。
- Few-shot 实验表明 LDSA 在极低标注下仍具竞争力，泛化能力良好。
