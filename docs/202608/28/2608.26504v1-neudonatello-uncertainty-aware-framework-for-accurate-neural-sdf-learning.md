## 摘要
神经表面重建已成为从多视图图像恢复高质量3D表面的强大范式。然而，仅从RGB图像恢复精确几何依然具有挑战性，因为纹理缺失区域、遮挡以及场景固有的模糊性会带来不确定性。现有方法常常忽略这些不确定性，导致符号距离函数（SDF）的估计不准确。我们提出了NeuDonatello，一种新颖的框架，它建模并利用SDF不确定性来改善表面重建。我们方法的核心是使用蒙特卡洛采样策略来建模空间变化的不确定性。利用这种不确定性，我们开发了一种自适应正则化，在RGB监督不可靠的地方选择性地加强几何约束，避免错误的表面重建。我们进一步为SDF到密度的转换引入了一个不确定性感知的尺度参数。以不确定性为条件，这种设计能够更准确地建模空间变化的密度。大量实验表明，NeuDonatello仅使用带位姿的RGB图像即可在多种场景下实现最先进的重建精度和稳健性能。

## Abstract
Neural surface reconstruction has emerged as a powerful paradigm for recovering high-quality 3D surfaces from multi-view images. However, recovering accurate geometry solely from RGB images remains challenging due to uncertainties arising from textureless regions, occlusions, and inherent scene ambiguities. Existing methods often overlook such uncertainties, leading to inaccurate estimates of the signed distance function (SDF). We introduce NeuDonatello, a novel framework that models and leverages SDF uncertainty to improve surface reconstruction. Central to our approach is to model spatially varying uncertainty using a Monte Carlo sampling strategy. Using this uncertainty, we develop an adaptive regularization that selectively strengthens geometric constraints where RGB supervision is unreliable, avoiding incorrect surface reconstruction. We further introduce an uncertainty-aware scale parameter for the SDF-to-density conversion. Conditioned on uncertainty, this design enables more accurate modeling of spatially varying densities. Extensive experiments demonstrate that NeuDonatello achieves state-of-the-art reconstruction accuracy, with robust performance across diverse scenes using only posed RGB images.

- 仅凭有限数量的带位姿 RGB 图像进行重建是一个**欠约束的逆问题**：多个不同的表面可能产生相似的渲染结果。
- 在**纹理缺失区域、光照变化区域、遮挡区域、稀疏观测区域**，RGB 监督信号本身不可靠，导致 SDF 估计存在显著的不确定性。
- 现有方法（Neuralangelo、NeuRodin、VolSDF 等）大多忽略这种空间变化的不确定性，**对全场景施加统一的正则化强度**，无法在真正需要几何约束的模糊区域进行有效引导，从而产生错误表面或伪影。

### 论文主张
- 显式建模并利用 SDF 不确定性，将其作为 RGB-only 逆渲染问题的内在属性，形成闭环优化，是提升神经表面重建精度的关键。

## 2. 方法论

### 2.1 总体框架
NeuDonatello 包含三个核心不确定性感知模块：
1. **蒙特卡洛 SDF 不确定性估计**（蓝色模块）
2. **不确定性感知的自适应几何正则化**（绿色模块）
3. **不确定性感知的 SDF-to-Density 转换**（橙色模块）

整体采用两阶段训练策略（借鉴 NeuRodin）：初始阶段学习不确定性，精化阶段在不确定性指导下优化几何。

### 2.2 SDF 不确定性建模（蒙特卡洛采样）
- 将 SDF 建模为高斯分布：$N(\bar{f}(r(t)), \beta_f^2(r(t)))$，其中 $\bar{f}$ 为几何网络 $\phi_g$ 预测的均值，$\beta_f^2$ 为不确定性网络 $\phi_u$ 预测的方差。
- 由于 SDF 体积渲染高度非线性，解析传播不确定性不可行，因此提出**蒙特卡洛采样策略**：
  - 对每条射线上每个采样点，从上述高斯分布中抽取 $N_{mc}=10$ 个独立同分布样本；
  - 每个样本经 SDF-to-density 转换和体积渲染，得到 $N_{mc}$ 个像素颜色估计；
  - 颜色不确定性 $\beta_C^2$ 由这些颜色估计的样本方差计算。
- 训练损失采用**稳定化的负对数似然（NLL）损失**：
  - $L_{NLL} = \beta_C^\gamma \left[ \frac{\|\hat{C}(r) - C(r)\|_1}{\beta_C(r) + \epsilon} + \log(\beta_C(r) + \epsilon) \right]$
  - 该损失使梯度同时流过 SDF 均值和方差，实现端到端的不确定性学习。

### 2.3 不确定性感知的自适应几何正则化
- 对批内 SDF 不确定性做 min-max 归一化得到 $\tilde{\beta}_f^2 \in [0,1]$。
- 定义自适应权重函数（Sigmoid 形式）：
  - $w(r(t)) = \mu + \frac{\eta}{1 + \exp(-k(\tilde{\beta}_f^2(r(t)) - \tau))}$
- 将该权重应用于 **eikonal 损失**和**平滑损失**：
  - $L^w_{eik} = \frac{1}{N}\sum_i w(r(t_i))(\|\nabla f(r(t_i))\| - 1)^2$
  - $L^w_{smooth} = \frac{1}{N}\sum_i w(r(t_i))(n(r(t_i)) \cdot n(r(t_i)+\epsilon) - 1)^2$
- 效果：在不确定区域施加更强正则化以防止错误表面收敛，在可靠区域保持较弱正则化以保留细节。

### 2.4 不确定性感知的 SDF-to-Density 转换
- 标准转换 $\sigma = \Phi_s(f)$ 中尺度参数 $s$ 控制密度过渡的锐度：$s$ 小则表面边界锐利，$s$ 大则体积带更平滑。
- 现有方法仅使用全局或位置相关的尺度参数，无法刻画视角相关纹理变化和几何不确定性。
- 本文提出由**尺度网络 $\phi_s$**（单层线性层）同时以**位置特征、视角方向、SDF 不确定性**为条件预测尺度：
  - $s_u = \phi_s(z(r(t)), d, \beta_f^2(r(t)))$
- 不确定性高的区域自动获得较大的 $s$，防止错误表面定位；确定性高的区域获得较小的 $s$，保留锐利细节。
- 初始阶段使用 VolSDF 转换（含不确定性感知尺度），精化阶段改用无偏的 TUVR 转换。

### 2.5 两阶段优化
- **初始阶段**：$L_{init} = L_{RGB} + \lambda_{NLL}L_{NLL} + \lambda_{eik}L_{eik}(\hat{\nabla}f) + \lambda_{bias}L_{bias}$（采用随机步长数值梯度估计与显式偏置校正）
- **精化阶段**：移除 NLL 损失并冻结不确定性网络，加入不确定性感知的自适应几何正则化和平滑约束，以及 PermutoSDF 的 Lipschitz 颜色正则化：
  - $L_{refine} = L_{RGB} + \lambda_{eik}L^w_{eik}(\nabla f) + \lambda_{smooth}L^w_{smooth} + \lambda_{Lipschitz}L_{Lipschitz}$

## 6. 主要结论与发现

1. **SDF 不确定性是可学习的且与几何误差高度相关**：通过稀疏化分析证实，预测的不确定性能够准确定位重建困难区域（纹理缺失、遮挡、光照变化），且性能优于随机基线、接近集成方法但速度快得多。
2. **自适应正则化有效**：在不确定区域强化几何约束、在可靠区域松开约束，比统一正则化更利于在模糊区域保持表面完整性（如天花板孔洞、地板塌陷问题被解决）。
3. **不确定性条件化的尺度参数有效**：相比仅位置/方向条件化，加入不确定性显著提升密度建模精度，减少近零水平集的密度偏置。
4. **RGB-only 可以达到甚至超越带先验方法**：NeuDonatello 在 ScanNet++ 上超越使用单目深度/法线先验的 MonoSDF，表明显式建模不确定性可以替代部分外部先验的作用。

## 7. 方法亮点与优点

1. **问题定位准确**：抓住了现有方法"统一正则化"忽略空间变化不确定性这一关键缺陷，动机清晰。
2. **不确定性建模方式轻量实用**：采用高斯似然 + 单次前向传播 + 蒙特卡洛采样，避免了变分推断或深度集成的高计算开销，训练仅比基线增加约 27% 时间、47% 显存。
3. **闭环优化设计**：不确定性不仅用于事后分析，而是作为主动训练信号驱动正则化权重和密度尺度参数，形成"估计—利用—再估计"的闭环。
4. **模块化程度高**：三个不确定性模块（估计、正则化、密度转换）可独立消融验证，设计清晰、可复现性强。
5. **不依赖外部先验**：仅需带位姿 RGB 图像，适用范围广。
6. **翔实的补充分析**：对尺度参数可视化、不确定性−深度误差对应关系、蒙特卡洛样本数影响等均有深入分析。

## 8. 不足与局限

1. **对初始阶段质量敏感**：如果早期几何估计严重偏离真实表面，精化阶段可能无法完全恢复正确几何。
2. **训练成本增加**：蒙特卡洛采样（$N_{mc}=10$）虽比集成方法高效，但仍比无不确定性建模的基线增加约 27% 的每迭代耗时。
3. **超参数敏感**：自适应权重函数（$\mu, \eta, k, \tau$）、NLL 损失的 $\gamma$、两阶段损失权重等均需仔细调节，调参成本较高。
4. **实验覆盖的局限**：未在 DTU 等经典 benchmark 上验证；Tanks and Temples 部分场景无增益；未涉及稀疏视角（如 3-view/6-view）的极限场景；主要面向静态场景，动态场景和非位姿输入留作未来工作。
5. **潜在偏差风险**：ScanNet++ 上对比的多个基线（特别是 MonoSDF）表现远低于其

其（MonoSDF 等）在各自论文中报告的水平，这提示 ScanNet++ 的版本差异（v1→v2）或评估口径可能对比较公平性产生潜在影响，读者在解读跨论文数值对比时需谨慎。此外，论文未提供随机种子或多次运行的标准差，无法评估方法在统计意义上的稳定性；代码与预训练模型也未明确说明是否公开，可复现性有待验证。

总体而言，NeuDonatello 在不确定性建模与神经 SDF 重建的结合上做出了有价值的探索，但其性能提升的稳健性、训练复杂度和评估公平性仍需在更广泛的场景中进一步验证。
