## 摘要
预训练的视觉-语言模型（如CLIP）在零样本识别方面表现出色，但在组合性（尤其是属性-对象和关系结构）方面常常失败。近期研究通过使用由大型语言模型和文本到图像模型级联生成的合成困难负样本增强训练来缓解这一问题，但这带来了大量的流水线开销。我们转而提出MLLMCLIP，一种异构蒸馏框架，直接将多模态知识从生成式多模态大语言模型（MLLM）教师迁移到判别式CLIP学生，完全绕过了合成数据。为弥合两种范式之间的架构不匹配，我们引入了基于注意力的逐层令牌选择以及基于CKA的蒸馏损失。与先前的CLIP增强方法相比，MLLMCLIP在组合准确率上达到了最先进的水平，同时在标准零样本分类和图像-文本检索上取得了持续改进，表明特征级蒸馏同时增强了组合性和通用视觉-语言表征能力。

## Abstract
Pretrained vision-language models such as CLIP excel at zero-shot recognition but often fail at compositionality, particularly attribute-object and relational structures. Recent studies mitigate this issue by augmenting training with synthetic hard negatives generated by a cascade of large language models and text-to-image models, which incurs substantial pipeline overhead. We instead propose MLLMCLIP, a heterogeneous distillation framework that transfers multimodal knowledge directly from a generative Multimodal Large Language Model (MLLM) teacher into a discriminative CLIP student, bypassing synthetic data entirely. To bridge the architectural mismatch between the two paradigms, we introduce an attention-based per-layer token selection and a CKA-based distillation loss. Compared to prior CLIP-enhancement methods, MLLMCLIP achieves state-of-the-art compositional accuracy while delivering consistent gains on standard zero-shot classification and image-text retrieval, showing that feature-level distillation strengthens both compositional and general vision-language representation capability.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题起点**：CLIP 等预训练视觉-语言模型在零样本分类和检索上表现出色，但存在严重的 **"词袋"行为（bag-of-words）**，无法真正理解组合性结构，尤其是属性-对象、关系结构等。例如难以区分"马正在吃草"与"草正在吃马"。
- **现有方案的局限**：已有工作（如 NegCLIP、TripletCLIP）通过 **数据级蒸馏** 来缓解——即用大型语言模型（LLM）生成难负样本文本，再用文生图模型生成对应负样本图像。这种级联管线存在两个关键问题：
  - (1) 依赖"分离专家"而缺乏统一的多模态理解；
  - (2) 顺序式数据生成流水线效率低下，带来大量计算和时间开销。
- **论文的立场转换**：作者提出从 **数据级蒸馏** 转向 **特征级蒸馏**——不再将教师知识表达为额外训练样本，而是通过统一 MLLM 的隐藏状态特征直接迁移到 CLIP 学生，**完全绕开合成数据管线**。整体含义是：通过异构蒸馏，在不引入额外数据合成开销的前提下，同时增强 CLIP 的组合性与通用视觉-语言表征能力。

## 2. 方法论

### 2.1 核心思想
- 提出 **MLLMCLIP**，一种异构知识蒸馏框架：以生成式 MLLM 解码器为教师，以判别式 CLIP 双编码器为学生，在单次前向传播中完成特征级知识迁移。
- 关键前提（pilot study）：论文先验证了基础 MLLM 本身具备强组合性理解能力（如 Qwen3-VL-2B 在 SugarCrepe 上平均达 94.5），而经过 embedding 微调的 MLLM 变体（如 VLM2Vec）组合能力显著退化（平均仅约 64.6～83.0），因此直接从基础 MLLM 蒸馏是合理选择。

### 2.2 架构设计
- **学生模型（CLIP）**：
  - 分别包含图像编码器 f_I 和文本编码器 f_T，均为多层 Transformer。
  - 层间隐藏状态 h_l^I、h_l^T 经辅助层（Aux_I、Aux_T，线性投影+LayerNorm）映射到统一维度 D，用于对齐教师特征。
  - 最终层表示经投影头（Proj_I、Proj_T，单层线性层）映射到公共嵌入空间，用于对比学习。
- **教师模型（MLLM）**：
  - 图像 patch 经视觉编码器处理，文本注入特定模板（见下），两者拼接为统一序列输入解码器。
  - 提取每个解码器层的隐藏状态序列 [h_{l,1}, ..., h_{l,N}]。

### 2.3 关键技术与公式

**(a) 基于注意力的逐层令牌选择（Attention-based Token Selection）**
- 对每个解码器层 l，先将各注意力头矩阵求平均： Ā_l = (1/K) Σ_k A_l^(k)；
- 计算每个 token 作为 key 时接收到的最大注意力： a_{l,n} = max_i Ā_l[i,n]；
- 选择接收注意力最大的 token 作为该层教师信号： n*_l = argmax_n a_{l,n}，h_Teach_l = h_{l,n*_l}。
- 层选择采用 **stride 均匀跨层采样**（如取 1, 4, 7, ...），实验证明优于取连续块（下、中、上区块）。

**(b) 损失函数**
- **对比损失**：标准 CLIP InfoNCE 损失（式 8-9），分别以图像和文本为锚点求均值。
- **蒸馏损失（CKA-based）**：
  - 对批量 B 个样本的特征矩阵 X_l 与 Y_sl 进行中心化（式 11），计算 Gram 矩阵（式 12）；
  - CKA 相似度 = 归一化 Frobenius 内积（式 13）；
  - 损失定义为 ℓ_CKA = 1 − √(CKA)（式 14），在图像和文本两个模态上跨层求平均（式 15）。
  - 总损失：L_total = L_contrast + λ·L_distill（式 16），默认 λ=1。

## 3. 实验设计

### 3.1 数据集 / Benchmark
- **预训练数据**：CC3M（Conceptual Captions，约 330 万图文对）。
- **组合性评估**：11 个基准——ARO、CREPE、EQBEN、ImageCoDE、SugarCrepe、SVO-Probes、VALSE、VL-Checklist、WhatsUp、Winoground、SPEC。
- **零样本分类**：13 个数据集——Caltech101、CIFAR-10/100、DTD、EuroSAT、FER-2013、Flower102、Food101、ImageNet-1K、KITTI-Distance、Oxford-IIIT Pet、RESISC45、PASCAL VOC2007。
- **图文检索**：MSCOCO 和 Flickr-30K（双向检索）。

### 3.2 对比方法
- **数据级蒸馏基线**：
  - **LaCLIP**：LLaMA-7B 生成正样本改写；
  - **NegCLIP**：Qwen3-4B 生成难负样本文本；
  - **FSC-CLIP**：Qwen3-4B 生成硬负样本（基于 WordNet 风格）；
  - **TripletCLIP**：Qwen3-4B 生成负文本 + SDXL-Turbo 生成负图像。
- **MLLM embedding 模型**：VLM2Vec-v1/v2、Qwen3-VL-Embedding-2B。
- **教师多样性**：5 种 MLLM 教师——LLaVA-1.6-Mistral-7B、Qwen3-VL-2B、Qwen3.5-2B、InternVL3-2B、InternVL3.5-2B。

### 3.3 训练细节
- 学生模型：CLIP Base（ViT-B/32 图像编码器 + 12 层 Transformer 文本编码器），**从零开始训练**于 CC3M。
- 全局 batch size 4096，30 epochs，AdamW，初始学习率 5e-4，权重衰减 0.5，余弦学习率调度 + 第一轮线性 warmup，bfloat16 精度。

## 4. 资源与算力

- **硬件**：8 张 NVIDIA A100 GPU。
- **训练规模**：全局 batch size 4096，30 epochs，bfloat16 混合精度。

## 6. 主要结论与发现

1. **特征级蒸馏显著优于数据级蒸馏**：在控制教师身份一致的条件下，MLLMCLIP（特征级）在组合性、零样本分类和检索上全面超过 NegCLIP/TripletCLIP（数据级），且差距在分类上尤其明显（如 Comp. 40.0 vs. 38.5；Zero-shot Cls. 31.3 vs. 25.6）。
2. **基础 MLLM 是比 embedding 微调模型更好的教师**：pilot study 显示 embedding 化微调会显著损害组合理解（如 VLM2Vec-v2 平均 72.7 vs. 其底座 Qwen2-VL-2B 平均 92.2），因此直接蒸馏基础 MLLM 更有价值。
3. **CKA 结构对齐损失优于逐点直接相似度损失**：MSE 在异构架构下导致性能崩溃（Zero-shot Cls. 仅 7.00），CKA 在所有指标上全面胜出。
4. **注意力引导的 token 选择优于固定位置**：自适应找出每层最具信息量的 token，比 [Image End] 或 [Text End] 等固定位置更强。
5. **strided 层选择优于连续块选择**：均匀跨层采样覆盖更全面的教师信息。
6. **性能与效率的平衡**：MLLMCLIP 以约 1/11 的推理延迟达到接近或优于部分 MLLM embedding 模型的组合精度（SugarCrepe 71.3 vs. VLM2Vec-v2 72.7），展示了轻量化落地的潜力。

## 7. 优点

- **范式创新**：首次系统提出并验证了从生成式 MLLM 解码器到判别式 CLIP 编码器的 **异构特征级蒸馏**，跳过了合成数据级联管线，具有明确的方法论价值。
- **方法设计巧妙**：
  - 注意力选 token 有效解决了异构架构间"层不对齐、token 不对齐"的关键难题；
  - CKA 损失天然适合跨架构结构对齐，避免特征维度/分布不匹配问题；
  - 教师侧特征可离线预提取，训练时仅需学生前向+读取特征，大幅降低训练开销。
- **教师无关性**：在 LLaVA、Qwen、InternVL 三个模型家族 5 种规模上验证一致提升，泛化性令人信服。
- **实验严谨**：26 个基准 + 5 教师 + 多组消融，且做了教师身份对照实验，证据链完整；在评估 MLLM 时注意位置偏差处理。
- **效率优势明确**：预处理时间降低至数据级管线的约 1/3.6，推理参数与延迟远低于 embedding 型 MLLM。

## 8. 不足与局限

- **教师能力上限**：学生性能受教师天花板约束，教师的偏见或推理错误会随蒸馏迁移到学生；论文也承认"最优教师可能随下游任务而变化"。
- **教师选择成本**：虽然框架本身教师无关，但不同教学任务上如何选出最优教师仍需人工评估，缺乏自动选择准则。
- **实验覆盖面有限**：
  - 仅在 CC3M（约 330 万）这一中小规模数据集上预训练，未在更大规模（如 LAION、DataComp-1B）上验证；
  - 学生仅使用 CLIP Base（ViT-B/32），未测试更大学生规模（如 ViT-L/14）；
  - 训练只报告单 seed（single-seed），虽在 5 个教师间一致，但缺少多次运行统计方差。
- **CLIP 训练 epoch 数量较少**：30 epochs on CC3M 可能未充分挖掘 CLIP 本身潜力，教师蒸馏的增益上限可能因此被低估或高估（需谨慎解读）。
- **MSE 失败的分析不够深入**：论文指出 MSE 导致性能崩溃归因于架构不匹配，但未进一步剖析具体机理（如梯度爆炸、维度方向不匹配等）。
- **应用限制**：依赖可获得的高质量 MLLM（开源模型），若使用闭源模型 API 则难以提取层间隐藏状态，实用性受限。
