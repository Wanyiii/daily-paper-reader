## 摘要
视觉-语言模型（VLM）能够回答空间问题，但对象定位与空间推理之间的连接机制仍鲜为人知。目前尚未充分探究空间推理在内部是否严格要求精确的对象定位，还是可以通过全局布局线索绕过显式定位。在本工作中，我们使用一套机制性可解释性工具，包括词元消融、逐层探测、注意力剔除和因果中介分析，研究了两个代表性模型家族：LLaVA-1.5和Qwen2.5-VL。我们发现空间关系预测遵循一个分阶段的“定位到推理”过程，其中对象对齐的词元建立粗略的目标-参照锚点，而精确的边界框并不需要。位置信息在关系决策出现之前就已可解码，少量注意力头中介了定位与空间推理的因果效应。这两个任务共享早期与定位相关的处理，但最终依赖于部分不同的专门通路。通过严格的实验，我们从词元、层和头部层面阐述了VLM如何将对象定位转化为空间关系，表明知道对象在哪里并不等同于知道它们如何关联。

## Abstract
Vision-language models (VLMs) can answer spatial questions, yet the mechanisms connecting object grounding to spatial reasoning remain poorly understood. It is underexplored whether spatial reasoning internally requires precise objects localization, or can bypass explicit localization through global layout cues. In this work, we investigate two representative model families, LLaVA-1.5 and Qwen2.5-VL, using a suite of mechanistic interpretability tools, including token ablation, layer-wise probing, attention knockout, and causal mediation analysis. We find that spatial relation prediction follows a staged grounding-to-reasoning process in which object-aligned tokens establish coarse target-reference anchors, while precise bounding-box boundaries are not required. Positional information becomes decodable before relation decisions emerge, and a small set of attention heads mediates the causal effects of both localization and spatial reasoning. The two tasks share early grounding-related processing but ultimately rely on partially distinct specialized pathways. Through rigorous experiments, we provide a token-, layer-, and head-level account of how VLMs transform object grounding into spatial relations, showing that knowing where objects are is not equivalent to knowing how they relate.

# 《Grounding Isn't Knowing: Do VLMs Need Object Localization for Spatial Reasoning?》论文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉语言模型（VLM）在执行空间关系推理（如判断"书在杯子的左边"）时，内部是否**必须**先精确地定位（localize）出目标对象和参照对象的边界框？
- **背景与动机**：VLM虽能回答空间问题，但"能答对"并不等同于是基于对象的精确位置推导出答案——模型可能利用粗粒度场景布局、上下文规律或语言先验。学术界对"精确对象定位"与"空间推理"在内部机制上是**前提关系、并行能力、还是相关副产品**，仍不明确。
- **核心研究问题**：空间推理是否在内部严格要求精确的对象定位，还是可以绕过显式定位，通过粗粒度的全局布局线索（global layout cues）直接完成？

论文在标题中以口号式结论点题：**"Grounding isn't knowing"** ——知道物体在哪里（定位）并不等于知道物体如何关联（空间关系）。

## 2. 论文提出的方法论

论文采用了一套系统的**机制可解释性（mechanistic interpretability）**方法，在词元（token）、层（layer）和注意力头（attention head）三个尺度上逐级深入分析，核心方法如下：

### 2.1 视觉信息消融（Visual Information Ablation）

- **基本操作**：在LLM输入阶段（多模态投影之后、位置编码和自回归处理之前），将选定的视觉token嵌入替换为一个**全局平均视觉嵌入**（在ImageNet验证集上预先计算），从而移除图像特定内容但保留域一致的嵌入统计特征。
- **干预区域**：
  - **目标/参照对象token**：将分割掩膜（segmentation mask）栅格化到视觉token网格上，选择重叠至少一个像素的token。
  - **Padding变体**：对掩膜进行收缩（−1/ −2 token）或扩张（+1/ +2 token），以区分"对象内部""对象边界"和"周边上下文"的影响。
  - **随机token控制**：随机替换与对象token等量的视觉token，作为对照（3个随机种子取平均）。
- **用途**：检验对象内部证据是否为定位和空间关系预测所必需。

### 2.2 位置解码（Position Decoding）

- **逐层线性探针**：在解码器每一层训练独立的线性分类器，分别预测每个图像token的二维网格位置（x和y坐标分别预测，联合预测要求两者都正确）。分类器在50,000张ImageNet图像上训练10个epoch，在What's Up图像上评测。
- **Logit Lens**：无训练方法，将每一层最终prompt-token的表示通过最终层归一化和语言模型头，比较各答案选项的对数几率（logits），以追踪关系答案在哪些层开始形成。

### 2.3 注意力剔除（Attention Knockout）

- 阻止所有post-image token到对象对齐视觉token的注意力，在**分组层**（每4层一组）和**全局**（所有层）两种设置下进行。
- 测量定位和空间关系精度的变化，并对比**大小匹配的随机token控制**。
- 目的：确定对象信息在哪些层被实际提取和处理。

### 2.4 因果中介分析（Causal Mediation Analysis, CMA）

- **配对设计**：构建"源图（source）—基图（base）"对——源图包含目标对象，基图用LaMa修复技术将目标对象移除并修补背景。
- **激活修补**：将源图中某个注意力头的prompt-token激活，替换到基图的对应位置，观察修补是否恢复因对象移除而丢失的信息。
- **Mediation Fraction（MF）**：
  \[
  MF = \frac{L_{base} - L_{patched}}{L_{base} - L_{src}}
  \]
  其中 \( L_{src}, L_{base}, L_{patched} \) 分别为源图、基图和修补后的负对数似然（NLL）。MF≈1 表示该头部恢复了大部分性能差距；MF≈0 表示无贡献；MF<0 表示干扰。
- **评测对象**：定位任务只计算坐标数值token的NLL；空间关系任务只计算二分类答案token的NLL。
- 每种模型每种任务最多配50对源-基样本。

### 2.5 头部消融分析（Head Ablation Analysis）

- 按各注意力头的MF均值排序（定位和空间关系分别排序），并定义低重要性头（最小绝对MF）和负MF头作为对照。
- 逐步将一定比例的注意力头输出置零（cumulative ablation），绘制定位和关系精度曲线，用归一化AUC（nAUC）衡量敏感性。

## 3. 实验设计

### 3.1 数据集

- **来源**：基于What's Up benchmark（Kamath et al., 2023）构建，取Subset A和Subset B。
  - **Subset A**：物体位于桌子、椅子、扶手椅的上/下/左/右，论文仅保留"左/右"关系。
  - **Subset B**：家用物体两两之间为前/后/左/右关系，全部保留。
- **数据规模**：筛选后共**614张图像、1,228个对象标注**，其中Subset A有206张，Subset B有408张。
- **标注**：为目标和参照对象标注边界框和分割掩膜。
- **对象移除控制集**：用LaMa修复技术将目标对象移除并修补背景，仅保留"模型在原始图中正确识别对象、但在修复图中无法识别"的图像对，以确保后续实验依赖真实对象证据而非上下文线索。

### 3.2 评测任务

- **定位（Localization）**：提示模型分别预测目标和参照对象的边界框，与ground-truth框计算IoU，报告IoU阈值0.5/0.7/0.9下的平均成功率。
- **空间推理（Spatial Reasoning）**：使用What's Up原始的四选一（four-way multiple-choice）协议，报告与ground-truth关系匹配的准确率。

### 3.3 评估模型

- **LLaVA-1.5-7B**（学习式1D绝对位置编码）
- **LLaVA-1.5-13B**
- **Qwen2.5-VL-7B**（2D-RoPE动态分辨率位置编码）

这三个模型构成了对两种主流位置编码机制的代表性覆盖。论文没有与其他的VLM方法进行横向对比，而是主要做**自身内部机制下的对照实验**（基线vs各种干预条件）。

## 6. 论文的主要结论与发现

论文提出了四个主要发现：

1. **精确的定位并非空间推理的必要前提**：移除对象内部token会严重损害坐标恢复（定位精度大幅下降），但方向关系判断基本保持；准确的目标-参照边界框不是关系预测的必要中间步骤。

2. **空间推理更多地依赖粗略的对象布局，而非精确的边界几何**：消除精细边界证据（收缩掩膜）后关系精度仍然稳定，但当干预扩展到对象周边的上下文时关系精度才下降——表明"对象中心的粗略布局"比"精确几何边界"提供了更相关的空间信号。

3. **位置信息先于关系决策出现，但不构成严格的串行瓶颈**：中间层即可解码对象位置，而关系答案在更深的层才出现；即使定位失败，关系判断仍可能正确。

4. **定位与空间推理由稀疏、部分重叠的注意力回路中介**：少量共享头部承载对象接地（grounding）证据，但两任务主要通过各自特化的通路完成转换——**top-10头部中，两任务共享仅2~3个头部（top-50中仅共享3~7个）**；层级的表面重叠掩盖了头部级别的显著特化。

总的结论：**VLM需要对象接地（grounding），但不需要精确定位（precise localization）**。知道物体在哪 ≠ 知道物体如何关联。

## 7. 优点

- **方法系统性极强**：从token → layer → attention head三个粒度逐步深入，方法链完整且相互印证。
- **实验设计严谨**：多种对照（随机token、掩膜收缩/扩张、对象移除控制集）有效排除了混淆因素。

- **因果级证据**：通过激活修补和头部消融提供了因果性结论，而不仅是相关性观察。

## 8. 不足与局限

- **数据集单一且规模有限**：仅使用What's Up子集的614张图像，未在更多基准（如VSR、BLINK、OmniSpatial）上验证，结论的泛化能力存疑。
- **关系类型覆盖窄**：仅涉及平面二维拓扑关系（左/右/前/后），无法回答模型在3D关系、深度关系、遮挡关系、拥挤场景下的表现。
- **未报告资源信息**：缺少GPU型号/数量/运行时间等细节，可复现性受到限制。
- **模型家族有限**：上述结论是否适用于其他规模的VLM（如更大的70B级模型）或不同视觉编码器架构（如SigLIP、CoCa）尚不明确。
- **模型自身精度差异大**：LLaVA-1.5-7B的基线空间关系准确率仅约25%，远低于Qwen2.5-VL-7B的约96%。低性能模型的分析结果可能受"模型本就不会正确推理"的干扰，两模型间的对比解读需谨慎。
- **攻击性干预手法**：将对象token替换为全局平均嵌入是一种较强的非自然干预，可能引入非生理/非自然的表征偏移；虽然随机对照减轻了这一顾虑，但在解释自然推理过程时仍需保留余地。
- **任务提示不一致**：定位和空间关系使用了不同的prompt，无法完全排除提示差异对内部计算路径的影响。
- **对象移除配对样本量有限**：CMA分析每种模型每任务仅最多50对配对样本，统计功效有限。
