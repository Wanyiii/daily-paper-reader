## 摘要
受人类多模态感知的启发，音视频多模态学习（AVMML）整合听觉与视觉信息，利用互补的跨模态线索，实现更鲁棒和全面的场景感知。现有研究主要孤立地处理每个AVMML任务，这与人类处理多样化感知的统一认知能力形成鲜明对比。然而，跨多个AVMML任务的天真联合训练往往因任务间复杂关系而遭受相互干扰。为解决这一问题，我们提出了一个同时容纳多种AVMML任务的统一框架。具体而言，借助大语言模型强大的表示和泛化能力，我们设计了一种任务解耦的低秩适配（LoRA）机制，能够动态整合任务特定与任务共享知识，从而促进有效的多任务协作。所提出的任务解耦LoRA包含三个组件：任务通用低秩矩阵、任务特定调制矩阵和跨任务协作专家，分别捕捉通用音视频知识、解耦任务特定模式以及利用固有的任务间相关性。通过从模型和任务两个角度统一显式协作，我们的方法不仅在多个AVMML任务上超越了现有的统一音视频模型，而且在某些AVMML任务上优于大多数任务特定模型。

## Abstract
Inspired by human multi-modal perception, Audio-Visual Multi-Modal Learning (AVMML) integrates auditory and visual information to leverage complementary cross-modal cues, enabling more robust and comprehensive scene perception. Existing studies predominantly tackle each AVMML task in isolation, which stands in stark contrast to humans' unified cognitive capacity for handling versatile perception. However, naive joint training across multiple AVMML tasks often suffers from mutual interference, arising from the intricate inter-task relationships. To address this, we propose a unified framework that simultaneously accommodates versatile AVMML tasks. Specifically, benefiting from powerful representation and generalization capabilities of large language models, we design a task-disentangled Low-Rank Adaptation (LoRA) mechanism that enables dynamic integration of both task-specific and task-shared knowledge, thereby facilitating effective multi-task collaboration. The proposed task-disentangled LoRA comprises three components: a task-general low-rank matrix, task-specific modulation matrices, and cross-task collaboration experts, which respectively capture universal audio-visual knowledge, decouple task-specific pattern, and exploit inherent inter-task correlations. By unifying explicit collaboration from both model and task perspectives, our approach not only surpasses existing unified audio-visual models across multiple AVMML tasks, but also outperforms most task-specific models on certain AVMML tasks.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **总体框架**：
  - 视觉编码器采用 CLIP-ViT-L/14，音频编码器采用 BEATs；分别提取逐段视觉特征和音频特征。
  - 引入视觉-语言对齐模块和音频-语言对齐模块（均为 Q-Former + MLP 投影），将多模态特征映射到统一的文本嵌入空间。
  - 将对齐后的视听嵌入通过特殊 token 替换、插入和拼接的方式整合为 LLM（LLaMA-2-7B-Chat）的输入序列。

- **任务解耦 LoRA 设计**：
  - 包含三个核心组件：
    1. **任务通用低秩矩阵 A ∈ R^{r×h}**：将输入投影到共享低维子空间，捕获通用音视频知识；
    2. **任务特定调制矩阵 Λ_t ∈ R^{r×r}**（每个任务 t 一个）：在共享子空间内对特征进行任务专属变换，解耦任务特定模式；初始化时设为单位矩阵，以避免训练初期的不稳定扰动；
    3. **跨任务协作专家头 {B_i ∈ R^{k×r}}**（MoE 启发）：通过任务自适应路由进行加权聚合，实现跨任务知识迁移。
  - 核心公式：
    ```
    H_out^t = W H_t + Σ_{i=1}^B [ exp(u_i^t / τ) / Σ_{j=1}^n exp(u_j^t / τ) ] · B_i · Λ_t · A · H_t
    ```
    其中 u_i^t 为任务 t 下第 i 个专家的门控分数，τ 为温度参数。

- **分析与讨论**：
  - **初始化策略**：Λ_t 初始化为单位矩阵，保留初始输出不变，避免早期训练不稳定。
  - **梯度保持**：任务特定矩阵作为独立可学习参数，保留了不同任务的梯度下降方向，降低任务间干扰。
  - **几何解释**：通过 Cauchy-Schwarz 不等式论证，任务特定调制矩阵使不同任务的子空间余弦相似度低于标准 LoRA，从而增强特征可分性。
- **分割扩展**：
  - 为支持像素级任务（AVS/RAVS），在 LLM 词表中加入可学习的 ⟨MASK⟩ token；模型输出这些 token 后，取其在最后一层的嵌入作为提示，与视觉特征一起送入 SAM 的 mask decoder 生成分割掩码。
  - 训练损失：L = λ_txt · L_txt + λ_seg · L_seg，其中 L_seg = λ_bce · L_bce + λ_dice · L_dice。

- **损失权重敏感性**：文本损失与分割损失的权重比在 1:1 附近表现稳定，权重偏差过大时分割与语言理解会相互压制。

## 7. 局限性与未来工作

- **局限性**：
  - 依赖高质量的多任务训练数据，数据收集与标注成本高；任务类别增加时，需要为每个新任务引入新的 Λ_t 与路由头，模型规模会线性增长。
  - 当前框架主要处理“短时序”（10 帧均匀采样）的视听输入，对长视频、流式音频的时序建模能力有限。
  - 分割分支依赖外部 SAM，无法端到端联合优化视觉主干与 LLM，存在特征不对齐的隐患。
  - 实验仅在 LLaMA-2-7B 与 A40 环境下验证，未在更大规模 LLM 或更复杂任务组合上测试。
- **未来方向**：
  - 引入动态任务发现与参数压缩机制（如低秩共享 + 任务稀疏激活），减少新任务扩展的参数量。
  - 探索同时支持视频理解、音频事件检测、3D 场景感知等更多模态与任务的统一框架。
  - 与大规模强化学习/多模态 RLHF 结合，让模型在反馈中自动调整任务间协作策略。
  - 研究任务数量增长时子空间正交性约束的显式优化，以进一步降低干扰。

## 8. 总结与启示

- **总括**：论文提出了一种新颖的**任务解耦低秩适配（task-disentangled LoRA）**机制，成功将 LLM 扩展到统一的音视频多任务学习框架。通过共享低秩子空间、任务特定调制与 MoE 式协作专家头的组合，实现了“共享通用知识、保留任务特征、促进跨任务迁移”的三重目标，在多类 AVMML 任务上取得了接近或超越任务专用模型的性能，并且显著优于现有统一多模态模型。
- **方法启示**：
  - 多任务统一不一定要“一个大模型完全共享所有参数”，合理的**参数解耦**比盲目的任务共享更有效；
  - 显式的任务身份约束有助于缓解多任务干扰，比纯数据驱动的路由更可靠；
  - 低秩适配的几何结构（子空间分离）可以被设计来度量并控制任务间的相互影响。
- **研究价值**：该工作为音视频多模态领域提供了一个统一、可扩展、高性能的开源框架，也为后续研究如何在大模型中平衡任务通用性与专用性提供了重要的设计范式。

## 9. 其他值得注意的细节

- **代码与模型**：论文声称将公开发布代码、模型权重与训练日志，以便复现。
- **与 Crab 的关键差异**：Crab 将多个任务直接塞入同一低秩空间；本文额外引入任务调制矩阵与跨任务协作专家，使其在子空间内分离、在专家层协作。
- **训练顺序的消融**：先冻结视觉/音频编码器，只训练对齐模块与 LoRA，再解冻部分视觉主干训练分割分支；两阶段顺序影响不大，但两阶段明显优于从头联合训练。
- **温度参数 τ**：默认 1.0；τ 过大使路由分布平滑、协作减弱，τ 过小则路由过于尖锐、专家利用率低。
- **AVVP 的细节**：该任务输出“音频事件 + 视觉事件 + 音视频事件”的多标签，论文用多个预测 token 组合表示，并在解码头中分别建模三类事件，避免类别混淆。
