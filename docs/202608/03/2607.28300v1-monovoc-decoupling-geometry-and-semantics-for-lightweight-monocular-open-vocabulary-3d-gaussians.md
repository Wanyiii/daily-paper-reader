## 摘要
开放词汇3D场景理解对于下一代交互系统至关重要，它使用户能够通过自然语言直观地查询和导航重建环境。然而，当前的3D高斯框架常常受到多视图采集要求的限制、昂贵的场景特定优化以及存储密集语言特征的巨大内存开销的瓶颈制约。我们提出了一种新颖的、无需训练的流水线，通过显式地将3D几何重建与语义集成解耦，从根本上重新构想了这一范式。给定标准单目视频序列作为输入，我们的方法高效地输出一个紧凑、高度可解释且完全可搜索的物体级语义高斯地图。我们不在建图循环中纠缠重型语言嵌入，而是独立提取几何，并通过轻量级、模块化的后处理框架来落地语义。在Replica数据集上的广泛评估表明，这种解耦架构保持了强大的渲染保真度和有竞争力的分割精度。关键在于，通过将密集的逐高斯存储替换为模块化的物体级语义嵌入，我们的方法相比SOTA基线实现了内存使用量一个数量级的减少。这为直接基于日常单目视频的开放词汇3D检索和问答提供了一种高效、可扩展且实用的解决方案。

## Abstract
Open vocabulary 3D scene understanding is essential for next-generation interactive systems, empowering users to intuitively query and navigate reconstructed environments using natural language. However, current 3D Gaussian frameworks are often bottlenecked by restrictive multiview capture requirements, costly scene-specific optimization, and the massive memory overhead of storing dense language features. We present a novel, training-free pipeline that fundamentally reimagines this paradigm by explicitly decoupling 3D geometric reconstruction from semantic integration. Given a standard monocular video sequence as input, our method efficiently outputs a compact, highly interpretable, and fully searchable object-level semantic Gaussian map. Rather than entangling heavy language embeddings within the mapping loop, we extract geometry independently and ground semantics through a lightweight, modular post-processing framework. Extensive evaluations on the Replica dataset demonstrate that this decoupled architecture preserves strong rendering fidelity and competitive segmentation accuracy. Crucially, by replacing dense per-Gaussian storage with modular, object-level semantic embeddings, our approach delivers an order-of-magnitude reduction in memory usage compared to SOTA baselines. This provides a highly efficient, scalable, and practical solution for open-vocabulary 3D retrieval and question answering directly from everyday monocular video.

### 二、方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心设计思想

- **几何与语义显式解耦**：先独立重建几何，再以后处理模块挂载语义，避免在映射循环中纠缠重型语言嵌入。
- **免训练（Training-free）**：全程无需场景特定语义训练或优化器。
- **物体级紧凑表征**：每个物体只存一个语义嵌入，取代逐高斯密集语言特征。

#### 2.2 四阶段流水线

1. **几何重建（Stage 1）**：使用 HI-SLAM2（几何感知的高斯 SLAM 系统）从单目 RGB 视频重建 3D 高斯地图，保持几何固定，作为语义赋值的支撑。
   
2. **语义颜色去混合（Stage 2，SCD 算法）**：利用 alpha 合成权重逆转渲染过程。已知前向渲染方程：
   
   C(p) = Σᵢ wᵢ(p)sᵢ + T_N(p)·b
   
   减去背景项后，对每个高斯 i 求解加权最小二乘：
   
   **ŝᵢ = Σₚ wᵢ,ₚ yₚ / Σₚ wᵢ,ₚ**
   
   即用高斯在所有像素上的合成贡献权重对其观测语义颜色做加权平均，得到每个高斯的语义颜色估计。论文给出四个定理支撑：权重构成精确凸混合（partition of unity）、加权平均估计器是唯一最优解、非重叠情形可精确恢复、重叠情形存在可解析刻画的混合偏差。

3. **调色板量化（Stage 3）**：由于 alpha 混合会使恢复颜色介于合法语义色之间，将从分割图中提取的离散语义调色板 P，在 CIELAB 空间用 **CMC 距离** 做最近邻匹配：
   
   **sqᵢ = argmin_c∈P d_CMC(Lab(ŝᵢ), Lab(c))**
   
   从而把噪声/混合颜色"吸附"回合法的物体级标签。

4. **语言嵌入赋值（Stage 4）**：对每个语义颜色，根据其在分割帧中的出现频率选择代表性掩码关键帧，用模块化的视觉-语言后端（CLIP、Perception Encoder、Osprey 等）提取物体级嵌入，存入数据库并与所有同色高斯链接，支持文本检索与问答。

### 六、主要结论与发现

1. **解耦架构有效**：几何与语义无需联合学习即可实现单目开放词汇 3D 理解。以 HI-SLAM2 为固定几何骨干，后处理挂载语义可在保持强渲染质量（PSNR 41.91，最佳；LPIPS 0.025，最佳）的同时达到竞争性分割精度（mIoU 91.22%，接近 SceneSplat 的 91.89%）。
2. **内存数量级下降**：每场景仅 140K 高斯、14 MB 内存，相比 ObjectGS（1M 高斯、90 MB）和 SceneSplat（1.5M 高斯、149 MB）减少约一个数量级。
3. **CMC 距离最可靠**：在 6 种颜色距离度量中，CMC 取得最低的非白像素误差（7.48%），是调色板量化的最佳默认选择。

5. **模块化设计可泛化**：分割器与嵌入模型均可替换（segmenter-agnostic、model-agnostic），具有实际部署灵活性。

### 八、不足与局限

1. **语义赋值依赖分割质量**：2D 分割噪声会经去混合累积并传播至 3D 地图，尤其边界区域最脆弱；论文虽做了消融，但说明实际部署对分割器的可靠性要求较高。
2. **调色板量化存在固有歧义**：当物体颜色在量化空间中过于接近时，最近邻决策可能错误；依赖"颜色作为物体标识符"这一设计本身有天然局限。
3. **去混合为近似全局逆**：SCD 采用逐高斯加权平均近似而非求解全局逆问题，在高度重叠区域或物体边界可能产生错误，虽量化可部分缓解但未彻底解决。
4. **实验覆盖有限**：仅合成数据集 Replica、仅 2 个基线、15 个查询、单次运行，缺乏真实场景、更多基线与统计显著性论证；SceneSplat 运行时不可比也削弱了效率对比的公平性。
5. **应用限制**：隐私与伦理方面，单目视频建图可能涉及敏感室内空间的未经授权映射，需在部署时遵守数据同意与隐私法规。
