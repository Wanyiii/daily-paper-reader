## 摘要
多模态目标重识别（ReID）旨在利用跨模态的互补信息来检索目标实例。然而，现有方法面临两大挑战。首先，它们往往未能利用对齐良好且可靠的语义先验，使其易受背景杂乱和跨模态错位的影响。另一方面，它们通常依赖整体特征建模，忽视了全局与局部表征之间的协同作用。为克服这些局限，我们提出了一种具有双语义引导和全局-局部相互调制的鲁棒多模态重识别框架，主要由三个关键组件构成：文本语义注入器（TSI）、掩码全局-局部调制器（MGLM）和层次化专家混合融合（HMF）。TSI通过将干净且连贯的文本特征整合到视觉令牌中增强语义感知。MGLM通过软掩码和全局上下文的联合引导实现部分感知的跨模态交互，改善细粒度特征对齐。最后，HMF在局部语义监督下自适应聚合多光谱特征，生成判别性强且鲁棒的表征。在三个多模态重识别基准上的大量实验验证了所提方法的有效性。代码将在论文被接收后于https://github.com/zw-absin/DSGM公开提供。

## Abstract
Multi-modal object Re-Identification (ReID) aims to retrieve target instances by leveraging complementary information across modalities. However, existing methods suffer from two challenges. First, they often fail to exploit well-aligned and reliable semantic priors, making them vulnerable to background clutter and cross-modal misalignment. On the other hand, they typically rely on holistic feature modeling, overlooking the synergy between global and local representations. To overcome these limitations, we propose a robust multi-modal ReID framework with dual semantic guidance and global-local mutual modulation, which mainly consists of three key components, namely the Text-Semantic Injector (TSI), the Masked Global-Local Modulator (MGLM), and the Hierarchical MoE Fusion (HMF). The TSI enhances semantic awareness by integrating clean and coherent textual features into visual tokens. The MGLM enables part-aware cross-modal interaction through joint guidance from soft masks and global context, improving fine-grained feature alignment. Finally, the HMF adaptively aggregates multi-spectral features under local semantic supervision, yielding discriminative and robust representations. Extensive experiments on three multi-modal ReID benchmarks demonstrate the effectiveness of the proposed method. The code will be made publicly available at https://github.com/zw-absin/DSGM upon acceptance.

## 1. 核心问题与整体含义（研究动机和背景）

多模态目标重识别（Multi-modal Object Re-ID, ReID）旨在利用来自可见光（RGB）、近红外（NIR）、热红外（TIR）等异构模态的互补信息，在跨摄像机、复杂成像条件下检索目标实例。该任务在智能视频监控和多摄像机追踪系统中具有重要的实际应用价值。然而，现有方法面临两个关键挑战：

- **语义先验不可靠**：已有方法很难获得对齐良好、语义可靠的先验信息。例如基于 CLIP 的文本先验缺乏细粒度 ReID 所需的特异性；基于多模态大语言模型（MLLM）的方法虽然能生成更丰富的文本描述，但往往存在文本模糊、模态间描述不一致（如对热红外图像错误地使用颜色词）以及 padding 噪声干扰等问题，导致跨模态特征错位。
- **全局与局部建模割裂**：现有方法大多依赖整体（global）特征建模，忽视了全局与局部（local）表征间的协同作用，缺乏显式的部件级（part-level）跨模态对齐，容易在背景杂乱、遮挡和极端光照条件下丢失判别性细节。

本文提出了一种融合**双语义引导**（unified textual descriptions + soft semantic masks）与**全局-局部相互调制**（global-local mutual modulation）的多模态 ReID 框架 DSGM，旨在同时增强语义感知、抑制背景干扰、促进细粒度跨模态对齐，从而生成更具判别力和鲁棒性的多模态表征。

## 2. 方法论：核心思想、关键技术细节、算法流程

论文提出的 DSGM 框架以共享 CLIP 视觉编码器为骨干，包含三个核心模块，整体流程如下：

### 2.1 统一语义先验生成（Dual Semantic Guidance）

- 将 RGB 图像转换至 YCbCr 颜色空间，利用其亮度通道与 NIR、TIR 图像按固定权重进行融合，增强结构信息，同时保留原 RGB 的色度通道以保证颜色一致性。
- 将融合后的图像送入 SAM2 生成**软语义掩码** M，经最大池化下采样至视觉编码器的 token 网格尺寸。
- 使用统一的 MLLM 提示词策略（基于 GPT-4o）生成跨模态共享的**统一文本描述**，避免逐模态独立描述带来的语义不一致。

### 2.2 文本语义注入器（Text-Semantic Injector, TSI）

- 在冻结的 CLIP 文本编码器各层引入 **padding mask**，抑制 PAD token 在自注意力中的干扰，得到干净的 token 级文本表征。
- 采用 l 个带独立可学习指数的 **GeM Pooling** 提取多粒度全局文本特征，以增强语义表达的丰富性。
- 使用**超图特征精炼模块（HFR）**，将图像 token 与全局文本特征拼接后在共享的超图空间中实现高阶视觉-语言交互，从而突破传统双线性注意力的局限性。

### 2.3 掩码全局-局部调制器（Masked Global-Local Modulator, MGLM）

- 将各模态图像特征和软掩码划分为 k 个水平条带（part），并将三模态全局 token 融合得到的 `f_global` 作为全局上下文注入每个局部块。
- 每个局部块通过一个掩码感知编码器 `Φi` 进行调制，掩码与特征逐元素相乘，从而抑制背景区域、增强前景关键区域。
- 经过编码后，特征被拆分为三个模态对应的局部特征块并重新拼接，形成增强后的模态专属表示 `F_hat`。

### 2.4 层次化专家混合融合（Hierarchical MoE Fusion, HMF）

- 构建一个**上下文感知 MoE** 基本模块，门控 logits 由输入特征和上下文信号共同调制，训练时加入噪声门控与负载均衡损失。
- **Part-Aware MoE**：每个水平条带对应一个 MoE，对三模态局部特征进行融合，产生局部上下文向量 `c_part`。
- **Contextual Global MoE**：以 `c_part` 为调制信号，对三模态全局特征进行融合，实现由局部到全局的自适应聚合。
- 最终，全局融合结果通过残差连接增强各模态的全局特征，并拼接后用于分类。

### 2.5 优化目标

`L = Lg([f_R_class, f_N_class, f_T_class]) + Lg(hat_f) + L_aux`，其中 `Lg` 包含标签平滑交叉熵损失和三元组损失。

## 3. 实验设计

- 所提出的 DSGM 框架在 RGBNT201、RGBNT100、MSVR310 三个基准上均取得了**领先性能**（如 RGBNT201 mAP 82.6%、Rank-1 87.0%；MSVR310 mAP 64.6%、Rank-1 76.0%）。

## 7. 优点

- **显式局部对齐**：MGLM 结合软掩码实现部件级跨模态建模，是可解释且有效的机制，弥补了现有方法只关注全局特征的不足。
