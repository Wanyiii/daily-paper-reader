## 摘要
视觉问答中的答案定位旨在从给定的自然语言问题中定位与图像视觉内容相关的区域，因其实际应用而受到广泛关注。本文提出了用于视觉问答中答案定位的动态双层级视觉Transformer融合网络（DDVT）。具体而言，我们设计了一个问题引导的动态区域级模块（QGDR），通过ROI Align和文本内容融合互补的图像上下文，实现对文本相关视觉内容的精准定位。此外，我们提出了一种跨模态多尺度聚合模块（CMA），增强像素级与区域级特征之间的融合，促进与定位答案相关的视觉内容的有效定位。进一步地，我们将定位到的视觉内容与文本特征融合，以定位区域并为图像相关问题提供答案。实验结果表明，我们的DDVT在多个广泛使用的基准数据集上优于现有最先进方法。

## Abstract
Answer grounding in visual question answering aims to locate the region from a given natural language question associated with the visual content of an image, which has garnered significant attention due to its practical applications. In this paper, we introduce the Dynamic Dual-level Vision Transformer Fusion Network (DDVT) for answer grounding in visual question answering. Specifically, we propose a question-guided dynamic regional-level module (QGDR) that combines complementary image context through ROI Align and text content, enabling precise localization of text-related visual content. Moreover, we present a cross-modal multi-scale aggregation module (CMA) that enhances feature fusion between pixel-level and region-level features, facilitating the effective localization of visual content associated with grounded answers. Furthermore, we fuse the located visual content with text features to locate the region and provide answers to questions posed about the image. Experimental results demonstrate that our DDVT outperforms state-of-the-art methods on several widely-used benchmarks.

**研究动机：**
- 视觉问答中的**答案定位（Answer Grounding）**要求系统不仅给出正确的文本答案，还要在图像中**定位出支持该答案的视觉区域**（如分割掩码或边界框）。这是一个多模态推理任务，横跨计算机视觉与自然语言处理两个领域。
- 该任务具有重要的实际应用价值：辅助视障人士理解图像内容、辅助医生进行早期疾病诊断、增强人机交互的可解释性等。理想的 VQA 系统不仅应给出正确答案，还应帮助用户**验证答案是否基于正确的视觉证据**，避免因语言偏差等因素导致错误判断。

**现存问题：**
- 已有方法（如 MAC-Caps、LXMERT、SDCAM 等）虽然可以生成注意力图或边界框，但普遍存在两个局限：

  2. **忽略了像素级特征与区域级特征的聚合**，导致定位精度不足。
- 传统使用预训练目标检测器提取物体级特征的方法存在额外预处理开销，且泛化能力受限于已知类别。

**论文的整体含义与目标：**
- 提出一种 **动态双层级视觉 Transformer 融合网络（DDVT）**，同时预测文本答案并生成精准的定位掩码。通过问题引导的区域级选择策略与跨模态多尺度聚合机制，自适应融合像素级与区域级视觉信息，实现对与文本答案对应区域的有效定位。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体架构
- 视觉编码器：**Swin Transformer**（ImageNet-22K 预训练权重）提取层次化视觉特征。
- 语言编码器：**BERT** 模型获取问题特征。
- 在二者之间引入两个核心创新模块：**QGDR**（问题引导动态区域级模块）与 **CMA**（跨模态多尺度聚合模块），最后通过文本答案解码器（TAD）输出文本答案。

### 2.2 关键技术模块

**（1）像素-词注意力模块（PWAM）**
- 借鉴 LAVT 中的 PWAM 模块，通过像素级视觉特征与语言词向量之间的注意力操作，实现图像区域与文本描述的空间对齐，缩小跨模态语义鸿沟。

**（2）问题引导动态区域级模块（QGDR）**
- 核心作用：**基于问题动态定位区域级物体**，并为不同难度的目标自适应选择合适分辨率的掩码，以有效控制计算成本。
- 技术流程：
  - 利用 ROI Align 从 Swin Transformer 特征中得到区域特征 Z，经平均池化后与问题特征 K 进行跨模态注意力计算（公式1），获得带文本语义引导的区域特征；
  - 通过 SE-block 通道注意力模块对不同通道的视觉信息加权，再由卷积与全连接层分类，输出 4 种不同空间分辨率的候选区域层级特征 `{Ft, Fs, Fm, Fl}`；
  - 通过 **Gumbel-Softmax**（公式2）将软选择概率转化为近似 one-hot 的动态决策，实现端到端可训练的分辨率选择。

**（3）跨模态多尺度聚合模块（CMA）**
- 核心作用：**在语言指导下自适应融合像素级信息与区域级内容**，实现不同模态、不同层级特征的交互与融合。
- 技术流程：
  - 对 QGDR 输出特征 F 使用反卷积放大空间尺寸，与 PWAM 输出的像素级特征 P 拼接；
  - 用 3×3 卷积生成偏移映射，经 **可变形卷积** 对齐特征；
  - 将对齐后特征与 P 相加，经 1×1 卷积与 **CondConv**（动态条件卷积）增强对物体显著区域的关注。

**（4）损失函数**
- 总损失由四部分构成：掩码损失、边缘损失（拉普拉斯算子提取边界监督）、预算约束（控制动态分辨率选择的计算开销）和文本答案损失。

## 3. 实验设计：数据集、基准与对比方法

## 6. 主要结论与发现

- DDVT 在 **VizWizGround** 测试集上达到 **65.3%** IoU，相比 DDTN 提高约 **12%**，且超越大规模预训练的 UNIFIED 约 **11%**；
- 在 **VQS** 数据集上达到 **43.47%** IoU，显著优于既有方法；
- 消融实验表明：去掉 QGDR 使 IoU 下降 4.17；将 CMA 替换为简单拼接使 IoU 下降 3.57，验证了两个模块的有效性；
- 动态掩码分辨率选择能够以更低计算成本达到与最大分辨率接近的性能（如表 3 中 112×112 最高为 74.68，而动态方法与 56×56 的 73.71 接近但 FLOPs 更低）；
- 可视化表明，高层特征准确锁定语义位置，低层特征提供精细边界信息，双层级融合有效提升分割质量。
