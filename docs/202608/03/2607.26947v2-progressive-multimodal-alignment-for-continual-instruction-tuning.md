## 摘要
多模态大语言模型（MLLMs）依赖投影器将视觉表示与语言嵌入空间对齐，这使其成为跨模态理解的核心。然而，在多模态持续指令微调（MCIT）中，视觉分布的偏移和不断演化的指令语义会导致共享投影器发生漂移，从而引发投影器级别的遗忘，而这一主要聚焦于LLM主干的方法所忽视的问题尤为突出。我们提出了渐进式多模态对齐（PMA）框架，使投影器能够在保留先前学习到的对齐的同时持续适应。PMA通过轻量级表示描述符检测多模态分布偏移，并仅在需要时渐进式扩展投影器专家。一个可扩展路由器基于多模态特征整合专家输出，同时保留原始预训练投影器作为稳定的对齐锚点。该渐进机制在次线性参数增长下平衡了稳定性与可塑性，并可作为现有MCIT方法的通用即插即用模块。在两个最新MCIT基准上的大量实验表明，结合PMA时，缓解投影器级别的遗忘相较于先前最先进方法带来了一致的性能提升。此外，PMA可扩展至多种MLLM主干，展示了稳健且广泛适用的MCIT性能。

## Abstract
Multimodal Large Language Models (MLLMs) rely on a projector to align visual representations with the language embedding space, making it central to cross-modal understanding. In Multimodal Continual Instruction Tuning (MCIT), however, shifting visual distributions and evolving instruction semantics cause this shared projector to drift, leading to projector-level forgetting, an issue largely overlooked by methods that focus primarily on the LLM backbone. We introduce Progressive Multimodal Alignment (PMA), a framework that enables the projector to adapt continually while preserving previously learned alignment. PMA detects multimodal distribution shifts via a lightweight representation descriptor and progressively expands projector experts only when needed. An expandable router integrates expert outputs based on multimodal features, while the original pretrained projector is retained as a stable alignment anchor. This progressive mechanism balances stability and plasticity with sub-linear parameter growth and serves as a method-agnostic add-on to existing MCIT approaches. Extensive experiments on two recent MCIT benchmarks demonstrate that mitigating projector-level forgetting yields consistent gains over prior state-of-the-art methods when combined with PMA. Moreover, PMA scales across diverse MLLM backbones, demonstrating robust and broadly applicable MCIT performance.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：多模态大语言模型（MLLMs）依赖投影器（Projector）将视觉表示映射到语言嵌入空间，这一环节是跨模态对齐的核心。在多模态持续指令微调（MCIT）中，模型需要在不断变化的任务和指令风格中持续学习，同时保留已学知识。
- **核心问题**：现有MCIT方法（如MoELoRA、HiDE、DISCO等）主要聚焦于缓解LLM骨干中的灾难性遗忘（CF），但普遍忽视了一个关键瓶颈——**投影器级别的遗忘（Projector-level Forgetting）**。随着视觉分布偏移和指令语义的演化，共享投影器会发生漂移，导致先前任务学习到的跨模态对齐被覆盖或损坏。
- **具体表现**：以DISCO为例，在captioning任务上微调后，面对classification指令也可能输出caption风格的答案，说明投影器未能保持已有任务特定映射，引发跨模态对齐退化。
- **研究意义**：这也是多模态持续学习论文中所提的“cross-modal alignment策略”的典型代表之一。该论文首次系统地识别并形式化了这一问题，为MCIT研究补充了一个长期被忽视的视角。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出PMA（Progressive Multimodal Alignment）框架，使投影器在保持已有对齐能力的同时持续适应新任务，且不需要任务ID、以参数次线性增长实现。
- **整体架构**：包含三个关键组件：
  - **表示描述符（Representation Descriptor, RD）**：轻量级MLP自编码器，基于融合表示（视觉全局特征+指令文本嵌入）建模多模态分布，通过重建误差判断新任务是否引入分布偏移。
  - **可扩展投影器专家**：初始时仅有一个投影器专家P1；当检测到新任务分布无法被现有专家覆盖时，新增一个投影器专家P_t，旧专家保持冻结。
  - **可扩展路由器（Router R_t）**：基于融合表示计算各专家的软路由权重，无需任务ID即可实现任务无关推理。
- **关键流程**：
  - **第一任务初始化**：训练初始投影器P1、描述符RD1和路由器R1，计算重建误差的均值μ₁与标准差σ₁，作为后续检测的参考分布。
  - **后续任务展开判定**：对于每个输入样本，计算所有既有描述符RD_j的重建误差，并转换为z-score：
    - z = (r − μ_j) / σ_j
    - 若所有描述符对应的样本满足比例p_j < 60%（p_j为z ≤ τ的样本比例），则认为新任务分布未被覆盖，立即扩展新投影器专家及对应描述符、路由器权重列；否则复用最匹配的既有专家。
  - **最终投影计算**：
    - 最终映射= (P0输出 + Σ w_j P_j输出) / (1 + t′)，其中P0为冻结的预训练投影器锚点，t′为当前实例化的专家数量。
  - **训练目标**：L = L_LLM + L_RD，LLM损失只更新当前激活的投影器专家与路由器列；RD重建损失单独训练描述符，两者完全解耦。
- **设计特点**：方法无关（method-agnostic），可与现有PEFT-based MCIT方法无缝集成；通过z-score阈值τ控制展开灵敏度，实现次线性参数增长。

### 3. 实验设计

- **Benchmark与数据集**：采用MCITlib提供的两个持续学习基准：
  - **UCIT基准**：包含ImageNet-R（分类）、ArxivQA（VQA）、VizWiz-Caption（看图造句）、IconQA（多选推理）、CLEVR-Math（组合推理）、Flickr30k（描述生成），训练顺序固定。

### 6. 论文的主要结论与发现

- 投影器级别的遗忘是MCIT中真实且重要的性能瓶颈，但被现有方法系统性忽视。

- τ=1.4时以仅3个专家实现最佳MAA（83.98），验证了次线性增长的有效性。
