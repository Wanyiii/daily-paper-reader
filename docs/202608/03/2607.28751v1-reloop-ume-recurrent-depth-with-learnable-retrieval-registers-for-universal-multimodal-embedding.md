## 摘要
通用多模态嵌入（UME）将异构多模态输入映射到一个共享的嵌入空间。现有的UME模型要么通过单次前向编码形成嵌入，要么通过显式的理由令牌和潜在自回归状态来增加计算量。尽管令牌扩展可以改善复杂匹配，但串行生成增加了检索延迟，并使最终嵌入依赖于生成的中间状态。这提出了一个不同的问题：在保持令牌工作空间固定的情况下，能否沿着模型深度扩展有用的计算？我们分析了独立训练的UME模型每一层的正负相似度分离情况，并观察到一个共同的过程：早期层对多模态输入进行上下文化，一个连续的中后期阶段形成检索判别特征，最后的层将它们映射到嵌入空间。基于这一发现，我们提出了ReLoop-UME，它执行一次早期层，循环重用参数共享的检索形成块，并在最后一次循环后应用最终映射层。可学习的检索寄存器提供持久的检索特定状态，这些状态在循环中积累和交换证据，最终的寄存器作为嵌入读出。在MMEB-V2和MRMR上，ReLoop-UME在不同主干网络上持续改进检索，同时运行速度比UME-R1快44.9倍，比PLUME快1.5倍。

## Abstract
Universal multimodal embedding (UME) maps heterogeneous multimodal inputs into a shared embedding space. Existing UME models either form embeddings through single forward encoding or add computation through explicit rationale tokens and latent autoregressive states. Although token expansion can improve complex matching, serial generation increases retrieval latency and makes the final embedding depend on generated intermediate states. This raises a different question: can useful computation be expanded along model depth while keeping the token workspace fixed? We analyze positive-negative similarity separation at every layer of independently trained UME models and observe a shared progression: early layers contextualize multimodal inputs, a contiguous middle-to-late stage forms retrieval-discriminative features, and the final layers map them into the embedding space. Based on this finding, we propose ReLoop-UME, which executes the early layers once, recurrently reuses a parameter-shared retrieval-forming block, and applies the final mapping layers after the last loop. Learnable Retrieval Registers provide persistent retrieval-specific states that accumulate and exchange evidence across loops, with the final register serving as the embedding readout. On MMEB-V2 and MRMR, ReLoop-UME consistently improves retrieval across different backbones while running 44.9x faster than UME-R1 and 1.5x faster than PLUME.

## 2. 论文提出的方法论

**核心思想：**

在固定 token 工作区的前提下，通过循环重用参数共享的检索形成层来扩展有效计算深度。据此，模型可分为三段：前缀（Prefix）理解层执行一次、中间检索形成层循环复用 T 次、后缀（Suffix）映射层在最后一次循环后执行一次。

**关键技术细节：**

1. **逐层检索判别力分析（确定循环区间）**
   - 对独立训练的单次前向 UME 模型，逐层计算正负样本相似度分离度：
     - 正样本相似度 \(s^+_{i,l} = \hat{z}_l(q_i)^\top \hat{z}_l(c_i^+)\)
     - 负样本相似度取负样本池的 80 分位数 \(Q_{0.8}(s^-_{i,l})\)
     - 分离度 \(S_l = \frac{1}{N}\sum_{i=1}^{N}[s^+_{i,l} - Q_{0.8}(s^-_{i,l})]\)
   - 通过确定性的三段分段线性拟合（change-point fitting），识别出三个阶段：前缀理解阶段（低斜率）、检索形成阶段（持续上升区间）、嵌入映射阶段（末端饱和与映射）。
   - 实例化结果：Qwen2-VL/Qwen3-VL 为前缀 0–16 层、检索形成 17–26 层、映射 27 层；Qwen3.5-2B 为 0–11 / 12–22 / 23 层。边界对分位数选取不敏感。

2. **局部循环细化（Localized Recurrent Refinement）**
   - 定义映射：\(E = F_{0:a-1}\)（前缀）、\(G = F_{a:b}\)（循环块）、\(O = \text{FinalNorm} \circ F_{b+1:L-1}\)（后缀）。
   - 编码流程：
     - \(\tilde{X}(x) = [X(x); R]\)（拼接可学习检索寄存器）
     - \(H^{(0)}(x) = E(\tilde{X}(x))\)
     - \(H^{(t)}(x) = G(H^{(t-1)}(x))\), \(t = 1, \dots, T\)
     - \(z_T(x) = \text{norm}_2([O(H^{(T)}(x))]_{\rho_x})\)（读最终寄存器位置）
   - G 的参数在所有循环中共享，注意掩码、位置索引不变，序列长度固定为 \(n_x + M\)。

3. **可学习检索寄存器（Learnable Retrieval Registers）**
   - 在输入序列末尾追加 M 个可学习状态向量 \(R = [r_1, \dots, r_M]\)。
   - 在因果掩码下，每个寄存器可关注全部多模态输入；寄存器 m 可关注前 m-1 个寄存器；内容 token 也可以关注寄存器。
   - 作用：跨循环积累、保留和交换检索证据；循环块每轮精炼内容状态，寄存器从中反复读取改进后的多模态证据。
   - 最终只读最后一个寄存器作为嵌入输出，前 M-1 个寄存器仅为内部工作区。

4. **终端对比学习训练**
   - 使用 InfoNCE 损失，仅在最后一次循环后施加监督：
     - \(\mathcal{L}_{\text{NCE}} = -\frac{1}{B}\sum_{i=1}^{B} \log \frac{\exp(q_i^\top c_i / \tau)}{\sum_{j=1}^{B} \exp(q_i^\top c_j / \tau)}\)
   - 中间状态通过展开图获得梯度，但不要求形成独立可用的嵌入空间。

5. **理论效率分析**
   - 序列深度：\(D_{\text{loop}}(T) = L_p + T L_r + L_s\)
   - 额外深度仅为 \((T-1)L_r\)，集中在检索形成块；而 token 自回归方法约需 \((K+1)(L_p+L_r+L_s)\) 的串行深度。
   - 额外参数只有 M×d 的寄存器矩阵，无独立转换适配器。

## 6. 论文的主要结论与发现

1. **检索能力沿深度非均匀形成**：不同架构的 UME 模型均表现出三个功能阶段——前缀理解（正负纠缠）→ 检索形成（分离度持续上升）→ 嵌入映射（末端激增），且阶段边界对负样本分位数不敏感。

2. **局部循环优于全局循环**：循环目标应定位在检索形成阶段，而非整层、早层或仅最后一层。Layers 17–26 循环（58 次解码器应用）优于全层循环（112 次应用）1.9 分，说明"在哪加计算"比"加多少计算"更重要。

3. **寄存器的价值依赖于循环**：单独添加寄存器在 T=1 时无增益，但在 T=4 时带来 +1.4 分增益，说明寄存器的跨循环证据累积功能是循环深度的互补要素。

4. **循环深度存在最优区间**：T=4 达到最优（63.2），T=8 略降（62.8），收益在中等深度饱和而非随计算量单调增长。

5. **效率优势显著**：ReLoop-UME 比 UME-R1 快 44.9 倍、比 PLUME 快 1.5 倍，仅比 VLM2Vec-V2 慢 1.3 倍，同时 All 分数提升 5.2 分（63.2 vs. 58.0）。

6. **可迁移性**：同一训练方案在 Qwen2-VL、Qwen3-VL、Qwen3.5 三种主干上均带来一致增益（+2.2 至 +2.6 分），并能在 MMRM 上实现一定程度的零样本迁移（Avg. 48.6，领先 Ops-MM-Embedding 0.5 分）。

---

## 7. 优点

1. **问题视角新颖**：从 token 扩展计算转向深度扩展计算，并提供了详实的逐层证据支撑，而非仅凭直觉。

2. **方法设计优雅且高效**：固定 token 工作区 + 参数共享循环 + 微型寄存器（仅 7,680 参数），在保持模型大小不变的情况下提升计算深度，避免自回归生成的延迟和中间依赖。

3. **分析严谨**：采用确定性的分段拟合算法定位阶段边界，验证了分位数敏感性（q=0.5–0.8 结果一致）、运行间稳定性（不同随机种子）和跨架构一致性。

4. **消融设计系统性**：3 组核心消融（循环区间、寄存器数、循环深度）+ 2×2 因子实验，控制了计算变量，揭示了交互效应，证据链完整。

5. **效率测量规范**：多次独立采样取均值、报告标准差、设置 warm-up，并同时报告延迟、吞吐、加速比和相对开销，对比维度全面。

6. **诚实透明的局限报告**：明确承认视频模态是短板、MRMR 迁移增益有限、定性案例不可替代定量统计，并在附录中详细探讨失败机制和未来方向。

## 8. 不足与局限

1. **视频模态表现不佳**：2B 规模下视频平均分（40.5）落后于 PLUME（44.1）和 UME-R1（42.2）；7B 规模下（42.9 vs. UME-R1 的 47.5）差距更大。循环细化可能不足以保证采样帧间的时序信息。

2. **MRMR 迁移增益有限**：虽在 Knowledge（71.6）和 Theorem（39.1）领先，但在 Contradiction 组（30.7）落后于 Ops-MM-Embedding（36.6），Negation 仅 9.50 分，对极性敏感检索不擅长。

3. **消融覆盖较窄**：完整消融仅在 Qwen2-VL-2B 上进行，未扩展到 7B 或 Qwen3 系列；对不同基线的消融结论是否一致未经验证。

4. **训练流程统一但可能非最优**：所有模型固定 5,000 步训练，没有为每个基线/主干调整最佳训练配置；统一的超参数可能对某些模型不利。

5. **阶段定位缺乏因果验证**：分段拟合识别的是相关性而非因果性；论文也承认需要内部状态干预实验来确证各阶段的功能角色。

6. **定性分析的选择偏差风险**：失败案例是人为选取的，不能代表错误类型的真实频率分布；论文自己承认需要更大规模带机制标注的错误分析。

7. **训练成本较高**：循环展开增加了训练 FLOPs 和激活内存开销（虽然推理效率高）；论文未报告训练总耗时，也未系统对比训练成本。

8. **固定循环深度**：T=4 对所有输入一视同仁，未实现查询自适应的动态停止机制；简单查询可能浪费计算，复杂查询可能仍不够。

9. **未来方向重要但未验证**：论文提出的改进方案（自适应帧采样、视觉特征再注入、页面级寄存器、OCR 残差再注入等）均为推测，尚未有实验验证。
