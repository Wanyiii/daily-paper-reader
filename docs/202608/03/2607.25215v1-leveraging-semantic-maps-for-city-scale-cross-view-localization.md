## 摘要
我们希望机器人在未曾遍历的环境中，利用常见的先验数据进行定位。OpenStreetMap提供的丰富语义数据可用于此任务。然而，现有方法要么忽略此语义信息，直接匹配全景图像和俯视图像，要么大幅压缩语义信息，仅使用少量固定类别。要利用这些丰富的语义信息，需要克服两个挑战。首先，需要从机器人的自我中心观察中提取有用的语义信息。其次，观察到的信息必须快速与大型先验语义地图（例如，高达628平方公里）关联。我们展示了视觉语言模型（VLMs）在从全景图像中提取相关地标以及识别这些地标与先验俯视地标之间可行对应关系方面非常有效。然而，随着地图地标数量的增加，使用VLMs提出所有对应关系的扩展性较差。相反，我们提出从VLM中提炼一个轻量级匹配器，该匹配器可计算地图中所有实体的对应关系。我们利用该输出形成观测似然，并通过贝叶斯滤波器随时间融合，生成一系列位姿估计。为了支持对利用语义信息的可泛化跨视角方法的进一步研究，我们发布了一个数据集，包含提取的语义和跨越十一个环境的评估轨迹，包括我们在暴风雪中和波士顿夜间收集的全景图像。我们证明了我们的方法，在单一城市的晴好天气数据上训练，能够泛化到不同地点、光照、天气及其他挑战。代码和数据集可在 https://efahnestock.github.io/loci/ 获取。

## Abstract
We want robots to localize in previously untraversed environments against commonly available prior data. Rich semantic data available from OpenStreetMap can be useful in this task. However, existing methods either ignore this semantic information, directly matching panoramas and overhead imagery, or dramatically compress the semantic information, working with a small set of fixed classes. To leverage this rich semantic information, two challenges need to be overcome. First, useful semantic information needs to be extracted from the robot's egocentric observations. Second, the observed information must be quickly associated with the large prior semantic map (e.g., up to 628 km^2). We show that VLMs are effective at both extracting relevant landmarks from panoramas, and identifying feasible correspondences between these landmarks and prior overhead landmarks. However, using VLMs to propose all correspondences scales poorly as the number of mapped landmarks increases. Instead, we propose distilling a lightweight matcher from a VLM which computes correspondences for all entities in a map. We use this output to form an observation likelihood which is fused over time with a Bayes filter to create a time series of pose estimates. To support further investigation into generalizable cross-view methods that leverage semantic information, we release a dataset of extracted semantics and evaluation trajectories spanning eleven environments, including panoramas we collected in a snowstorm and at night in Boston. We demonstrate our method, trained on a single city's fair-weather data, generalizes across location, lighting, weather, and other challenges. Code and datasets are available at https://efahnestock.github.io/loci/.

  - 现有跨视角定位方法主要分为两类，均存在不足：

  - 作者希望利用OSM提供的丰富实例级语义信息来弥补图像检索的不足，同时解决将地面观测与大规模先验语义地图快速关联的挑战。
- **论文含义**：提出了一种名为 **LOCI（Landmark-Oriented Cross-view Inference）** 的框架，利用视觉语言模型（VLM）从全景图像中提取地标语义，并与OSM先验地图进行结构化匹配，在贝叶斯滤波框架下实现高效、可泛化的城市级跨视角定位。

## 二、论文提出的方法论

### 1. 总体框架：贝叶斯滤波 + 产品-of-专家

- 将定位问题建模为贝叶斯滤波：给定动作序列和观测序列，维护机器人位置的置信分布，通过预测（运动模型）和更新（观测模型）迭代更新。
- 观测似然采用**产品-of-专家（Product of Experts）** 框架分解：

$$p(o|x, I, M) \propto p(o|x, I) \cdot p(o|x, M)$$

其中 $p(o|x, I)$ 为基于俯视图像的似然（由现有方法WAG提供），$p(o|x, M)$ 为基于语义地图的似然（由LOCI提供）。

### 2. 三阶段流水线

**（1）全景地标提取（Landmark Extraction）**
- 使用VLM（Gemini 3 Flash）处理全景图像的四个90°视场角针孔投影，通过结构化提示词（任务指令、OSM本体示例、地标选择/排除标准、输出JSON模式），提取与OSM注释格式对齐的地标注释集合 $\hat{a}^o = \{\hat{a}^o_i\}$（如 `{building:tower, name:Eiffel Tower}`）。
- 提示中要求提取判别性强的地标（如街道名、品牌地点、独特建筑），忽略低信息量、远处、临时的地标。

**（2）注释对应关系（Annotation Correspondence）**
- **问题**：直接用VLM对所有全景地标与地图地标（数万至数十万）进行穷举匹配，计算成本不可接受。
- **方案**：使用VLM作为教师模型，离线生成正负匹配训练数据，**蒸馏出轻量级二分类器** $p(c_{ij}|\hat{a}^o_i, \ell^M_j)$ 用于在线推断。
  - 教师VLM对全景地标与附近地图地标对进行匹配，输出正样本和硬/易负样本（含评判标准和排除规则）。
  - 轻量分类器架构（如图3）：
    - 每个键值对（key-value pair）分别编码键（108个预定义键的学习嵌入）和值（Google text-embedding-005 → 128维投影）；
    - 拼接后经MLP得到64维标签嵌入，在注释集合内做mean/max池化；
    - 结合两组注释的Hadamard乘积和**交叉特征**（共享键的值余弦相似度、名称余弦相似度、门牌号兼容性等），最终由MLP输出匹配概率。

**（3）空间似然生成（Spatial Likelihood）**
- 对每个俯视图像块 $I_p$，取该块内的OSM地标 $M_p$，构建对应分数矩阵 $C_p$；
- 使用**匈牙利算法**做最优分配（含dummy行/列以拒绝低置信匹配）；
- 每个匹配分数用 $1/\log_2(1+\max(1, N_{matches,i}))$ 加权，使罕见地标权重更高；
- 最终通过高斯似然将分数转换为观测似然：

$$p(o|x_i, M) \propto \exp\left[-\frac{1}{\sigma_l^2}\left(1 - \frac{s_{o,i}}{\max_j s_{o,j}}\right)^2\right]$$

### 3. 滤器实现与后处理

- 使用**直方图滤波器**（约20m × 20m网格），预测步骤中加入高斯平滑；里程计噪音取自 $N(0, \sigma_n^2 d)$。
- 轨迹评估中，从均匀先验出发，逐步融合观测更新置信分布。

## 六、论文的主要结论与发现

- **实例级语义显著加速收敛**：在大多数环境中，LOCI的EDC₁₀₀比WAG降低3–10倍（如New York：184.5m vs 718.5m；Boston Snowy：92.3m vs 706.8m），最终定位误差与WAG相当或更优（在多数数据集中差距在一个网格单元内）。
- **鲁棒域偏移**：在夜间、暴雪、暴雨、飓风灾后等图像匹配易失稳的场景中，LOCI仍能保持较高的定位置信度；在Framingham混合日期的卫星拼接影像下，其他方法几乎完全失效，而LOCI仍保留了定位信号。
- **泛化能力强**：仅在Chicago（晴好天气城市）训练，即能推广到不同国家、气候、光照和地貌的11个环境。
- **WAG+OSM（粗语义栅格化）效果有限**：粗粒度语义在标志性稀疏或外观变化大的场景中甚至拖累性能（Fort Myers、Noordoostpolder、Veluwe），强化了保留实例级语义的必要性。
- **早期融合（LOCI-EF）劣于晚期融合（LOCI）**：说明地标语义与图像信息的结合方式至关重要；独立建模再乘积融合的归纳偏置更利于跨域泛化。
- **结构性注释优于联合嵌入**：将地标注释结构化（保留键值对）比简单嵌入语句更利于判别相似名称、不同类别的地标。

## 七、优点

1. **方法设计创新**：创造性地利用VLM的语义理解能力将全景图像转换为与OSM注释结构对齐的地标描述，直接弥合了表征鸿沟；利用知识蒸馏将高成本VLM匹配器转化为可实时的轻量分类器，兼顾性能与效率。
2. **产品-of-专家融合机制**：保留了图像和语义两条互补的证据路径，互为补充且在域偏移时仍能提供可靠似然。
3. **数据集丰富且开放**：构建了含11种环境、多种极端条件（雪、夜、雨、灾后）的跨视角定位数据集，并开源全部工具链和人类评估标注，对社区有较大贡献。
4. **消融设计合理**：通过LOCI-EF对照，清晰地论证了"何时融合"和"怎样融合"对泛化的重要性，深化了对跨模态融合的认识。
5. **实验严谨性**：有人类评估（双标注+裁决）、置信区间报告、多指标（误差+收敛距离）多维度评价，且所有方法在相同滤器框架下对比，公平性较好。

## 八、不足与局限

1. **处理远处/非本地地标的能力不足**：LOCI的观测模型假设地标位于机器人当前栅格附近，但VLM常提取远处地标（如高速公路上远处的城镇名称、地平线上高塔），这会造成似然偏移（Veluwe数据集上表现劣于WAG）。作者也承认未建模地标的**方位/距离**信息，丧失了远距离约束的潜力。
2. **VLM幻觉风险**：模型无内置不确定度校准，幻觉地标可能误导似然；文中未对VLM输出的置信度做系统校准或鲁棒化处理。
3. **部署依赖云API**：在线阶段使用了Gemini 3 Flash（云端），需要网络连接，尚未验证在机载端侧模型上的迁移。蒸馏分类器虽快，但语义提取部分仍是瓶颈（32.9s/帧）。
4. **人工标注与教师VLM同源性问题**：对应训练数据和验证标签均来自同一个VLM，虽然做了人工抽样验证，但模型可能对教师自身的错误模式形成系统性过拟合。
5. **对地图质量敏感**：在OSM标注稀疏或不一致（如Veluwe的通信塔）时，定位性能明显下降；方法对地图的完整性、注释一致性有较高要求。
6. **历史地图与图像时间对齐困难**：部分环境的OSM状态和卫星影像时相只能"大致对齐"，存在地标增删导致的不一致，这是一个实际部署中不可避免但尚未充分解决的挑战。
