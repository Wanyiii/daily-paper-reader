## 摘要
可控红外-可见光图像融合旨在通过灵活的区域感知调制整合互补的热信息和结构信息，生成能够适应多样化用户需求和下游任务的融合图像。然而，现有方法通常依赖于预定义的离散控制条件，导致稀疏的空间无法支持细粒度调制需求。为此，我们提出ConFusion，一种新颖的框架，通过高斯条件空间感知调制学习连续融合空间，实现实例级细粒度可控红外与可见光图像融合。ConFusion采用双分支架构，在联合重建和文本引导语义对齐下解耦模态不变和模态特定表示。高斯条件的实例调制变量与基于Grounded SAM的实例掩码相结合，通过掩码引导的特定特征调制器指导实例级细粒度调制，而文本驱动的不变特征增强器则改善语义一致性并增强融合效果。在推理过程中，多模态大语言模型将用户意图解析为实例级调制变量以指导图像融合。大量实验表明，ConFusion在融合质量和下游任务的多个指标上均达到最先进性能，同时支持细粒度可控图像融合。我们的代码可在https://github.com/HeyufeiAnto/Confusion获取。

## Abstract
Controllable infrared-visible image fusion aims to integrate complementary thermal and structural information with flexible region-aware modulation, producing fused images that adapt to diverse user requirements and downstream tasks. However, existing methods typically rely on predefined discrete control conditions, leading to a sparse space that fails to support fine-grained modulation demands. To address this, we propose ConFusion, a novel framework that learns the continuous fusion space via Gaussian-conditioned spatial-aware modulation, enabling instance-level fine-grained controllable infrared and visible image fusion. ConFusion employs a dual-branch architecture to disentangle modality-invariant and modality-specific representations under joint reconstruction and text-guided semantic alignment. Gaussian-conditioned instance modulation variables coupled with Grounded SAM-based instance masks guide instance-level fine-grained modulation through the Mask-Guided Specific Feature Modulator, while the Text-Driven Invariant Feature Enhancer improves semantic consistency and enhances fusion. During inference, the multimodal large language model parses user intents into instance-level modulation variables to guide image fusion. Extensive experiments show that ConFusion achieves state-of-the-art performance across multiple metrics in both fusion quality and downstream tasks, while supporting fine-grained controllable image fusion. Our code is available at https://github.com/HeyufeiAnto/Confusion

### 1. 论文的核心问题与整体含义

- **研究背景**：红外-可见光图像融合（IVIF）旨在整合红外图像的热辐射信息与可见光图像的纹理细节，广泛应用于辅助驾驶、遥感、监控和目标检测等场景。
- **核心问题**：现有IVIF方法可分为两类：
  - **非可控融合**：如CddFuse等，学习确定性的"一对一"映射，对每对输入只能生成固定的融合结果，无法满足用户多样化需求。
  - **粗粒度可控融合**：如TextFusion、RISFuse等，通过预定义的文本或视觉提示实现离散控制，导致控制空间稀疏，无法对语义相似但强度不同的用户意图（如"high thermal" vs. "extreme thermal"）做出可区分的响应。
- **核心任务**：本文提出 **ConFusion**，通过学习**连续融合空间**，实现**实例级（instance-level）细粒度可控**的红外-可见光图像融合，使用户能够对不同实例独立、精细地调节红外/可见信息的表达强度。

### 2. 论文提出的方法论

#### 2.1 核心思想

通过**高斯条件空间感知调制**将连续的调制变量映射到空间掩码上，注入潜在特征空间以调制模态特定表示，从而学习一个连续且稠密的融合空间。训练过程中通过密集采样的实例级调制变量，使模型支持实例级细粒度可控融合。

#### 2.2 两阶段训练框架

**训练阶段 I：解耦表示学习**

- **特征解耦与重建**：采用双分支架构，将输入图像解耦为模态不变特征（`F_in`）和模态特定特征（`F_sp`），通过自重建和交叉重建约束解耦质量。
- **解耦损失**：通过Frobenius范数约束跨协方差矩阵，鼓励不变特征与特定特征之间的统计独立性。
- **不变一致性损失**：用MSE约束红外和可见光的不变特征一致性，捕捉共享场景语义。
- **不变语义对齐**：利用Grounded SAM生成实例掩码，对不变特征进行掩码平均池化，并通过MLP投影到CLIP文本嵌入空间，与实例文本嵌入进行对齐，强化不变特征的模态无关语义。

**训练阶段 II：特征调制与增强融合**

- **掩码引导特定特征调制器（MGSM）**：
  - 对每个实例从截断高斯分布 `N[0,1](0.5, 0.2²)` 采样调制强度变量 `α_j`；
  - 结合Grounded SAM生成的实例掩码，构建空间感知调制掩码 `M(x,y) = Σ α_j·S_j(x,y) + α_bg·S_bg(x,y)`；
  - 红外分支使用掩码 `M` 调制，可见光分支使用互补掩码 `1−M` 调制，实现区域感知的模态特征增强/抑制；
  - 通过ROI约束损失确保实例区域内融合图像与指定模态的像素强度及梯度一致。
- **文本驱动不变特征增强器（TDIE）**：
  - 将融合后的不变特征与CLIP文本嵌入通过交叉注意力交互，突出与实例语义高度相关的特征点，增强语义一致性和融合质量；
  - 通过背景重建损失保持非实例区域的平衡融合。

**推理阶段：用户意图查询与融合图像生成**

- 多模态大语言模型（LLM）解析用户自然语言意图，输出结构化的**实例-强度（I-N）对**和实例文本；
- Grounded SAM根据实例文本生成空间调制掩码 `M`，CLIP文本编码器生成文本嵌入 `E`；
- 将 `M` 和 `E` 注入训练好的融合网络，生成与用户意图对齐的融合图像。

### 8. 不足与局限

#### 8.1 计算开销

- 调制是通过空间掩码标量实现的，对复杂语义关系（如实例间交互、遮挡关系）的表达能力有限。
