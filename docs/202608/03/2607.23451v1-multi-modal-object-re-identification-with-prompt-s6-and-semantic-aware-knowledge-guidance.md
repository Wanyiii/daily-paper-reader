## 摘要
多模态目标重识别（ReID）旨在通过整合来自多种模态的互补信息来检索特定目标。然而，现有的多模态重识别方法未能有效解决背景干扰抑制问题，也未实现三模态对齐，而是侧重于成对特征融合。此外，许多当前的聚合方法存在计算复杂度高的问题。为了解决这些局限性，我们提出了PRISM，一种基于Prompt-S6（PS6）和语义感知知识引导的新型多模态重识别框架。PS6在保持Mamba的线性复杂度和强大序列建模能力的同时，实现了高效的跨模态交互。利用这些优势，我们设计了两个关键组件：语义驱动的令牌剪枝（SDTP）和渐进式融合网络（PFN）。SDTP从分割基础模型中解析语义先验，然后利用这些先验进行动态令牌剪枝，以抑制背景噪声并细化特征表示。PFN逐步聚合多模态特征，以实现三模态对齐并充分利用模态互补性。通过所提出的模块，PRISM在复杂场景下生成更鲁棒的多模态表示。在四个多模态目标重识别基准上的大量实验证明了我们方法的有效性和效率。源代码可在https://github.com/zw-absin/PRISM获取。

## Abstract
Multi-modal object Re-Identification (ReID) aims to retrieve specific objects by integrating complementary information from multiple modalities. However, existing multi-modal ReID methods do not effectively address background interference suppression or achieve tri-modal alignment, instead focusing on pairwise feature fusion. Moreover, many current aggregation approaches suffer from high computational complexity. To address these limitations, we propose PRISM, a novel multi-modal ReID framework built upon Prompt-S6 (PS6) and semantic-aware knowledge guidance. PS6 maintains the linear complexity and strong sequence modeling capability of Mamba while enabling efficient cross-modal interaction. Leveraging these advantages, we design two key components: Semantic-Driven Token Pruning (SDTP) and Progressive Fusion Network (PFN). Parsing semantic priors from the segmentation foundation models, the SDTP then leverages these priors and applies dynamic token pruning to suppress background noise and refine feature representations. The PFN progressively aggregates multi-modal features to achieve tri-modal alignment and fully exploit modality complementarity. With the proposed modules, PRISM generates more robust multi-modal representations under complex scenarios. Extensive experiments on four multi-modal object ReID benchmarks demonstrate the effectiveness and efficiency of our approach. The source code is available at https://github.com/zw-absin/PRISM.

### 2. 方法论：核心思想、关键技术细节、公式或算法流程

论文提出的 PRISM 框架包含三个核心组件：

**（1）语义信息提取（Semantic Information Extraction）**
- 使用 OpenPifPaf（行人骨架关键点）和 SAM2（车辆分割）离线生成语义掩码，不增加训练和推理负担。

- 将语义掩码通过补丁嵌入操作转换成掩码令牌序列，与类令牌拼接形成掩码增强序列 `Mm`，如公式 (1)-(2) 所示。

**（2）语义驱动的令牌剪枝（Semantic-Driven Token Pruning, SDTP）**
- **Prompt-S6（PS6）**：核心创新算子，基于 Mamba 的选择性状态空间模型（SSM）。与传统 Mamba 不同，PS6 将 SSM 的输入矩阵 `B` 和输出矩阵 `C` 从外部辅助序列（如语义掩码或另一模态特征）独立生成，即 `B = Linear_B(t)`、`C = Linear_C(tp)`。这种解耦的提示条件机制让外部信号独立控制状态信息的写入（B）和读取（C），实现细粒度、非对称的跨模态调制，且保持线性复杂度。算法流程见 Algorithm 1。
- **目标感知特征增强（Target-Aware Feature Enhancement, TAFE）**：用共享的 PS6 模块将各模态特征与语义掩码进行令牌级交互，再通过残差连接和 FFN 输出增强表示，见公式 (3)-(4)。
- **尾部丢弃模块（Tail Drop Module, TDM）**：通过三个独立的打分器（scorer）对各模态补丁令牌评分，融合三模态的 top-k 索引（Cross-Modal Union），丢弃低分（背景/噪声区域）令牌，保留大部分前景令牌，实现跨模态一致性的令牌剪枝，见公式 (5)-(7)。

**（3）渐进式融合网络（Progressive Fusion Network, PFN）**
- 三阶段渐进融合策略：
  - **模态内建模（Intra-modal Modeling, IM）**：通过 MHSA + FFN 增强单模态特征。
  - **模态间交互（Inter-modal Interaction, IT）**：每个模态分别与另外两个模态通过 PS6 交互，输出取平均得到成对融合表示。
  - **三模态聚合（Tri-modal Aggregation, TA）**：通过 PS6 的循环排列（如 RN T 和 RT N）实现三模态同时交互，取平均得到最终融合特征。
- 总体损失由类令牌和融合特征的交叉熵损失 + 三元组损失组成，见公式 (18)-(19)。

**整体框架流程**：三模态图像经共享编码器提取特征 → 语义掩码经 TAFE 进行细粒度融合 → TDM 剪除背景令牌 → IM/IT/TA 渐进融合 → 得到最终表示 `ˆf = [ˆf_R, ˆf_N, ˆf_T] ∈ R^3D`，用于检索。

- **性能领先**：PRISM 在 RGBNT201 上达到 80.5% mAP（超过 IDEA 0.3%、DeMo 1.5%），在 RGBNT100 上达到 86.1% mAP（超过 DeMo、IDEA），在 MSVR310 上达到 47.6% mAP / 64.8% R-1（大幅超过 EDITOR 8.6% / 15.5%），在 WMVEID863 上达到 70.7% mAP / 78.1% R-1（均优于对比方法）。即使以较少参数量仍超越多个高参数量方法。

- **语义感知剪枝有效**：SDTP 在复杂场景（如低光照、遮挡、模糊）下显著提升了特征判别能力；语义掩码生成策略需根据目标结构选择（行人用骨骼关键点，车辆用 SAM2）。
- **鲁棒性优势明显**：在模态错位和遮挡加剧时，PRISM 的性能下降幅度明显小于对比方法；相比纯视觉方法，语义辅助信息增强了极端情况下的稳定性。
- **效率优势显著**：内存占用最低（1718 MiB），GFLOPs 和吞吐量有竞争力，证明了 PS6 的线性复杂度优势。

### 7. 优点（方法或实验设计的亮点）

1. **核心创新清晰且技术性较强**：PS6 通过解耦 SSM 的输入/输出矩阵生成，突破了现有 Mamba 系列仅做特征求和或拼接的局限性，实现了可控的跨模态状态调制。
2. **语义信息与多光谱特征深度融合**：不是简单二值掩码分割，而是利用 PS6 进行令牌级的细粒度语义-光谱交互，并能容忍掩码不完美（掩码只作粗粒度先验）。
3. **三模态对齐机械化实现**：通过循环排列策略在一个 PS6 中同时建模三模态关系，完成真正的三模态交互而非两两配对，这在 ReID 领域较为新颖。
4. **渐进式融合设计合理**：IM → IT → TA 的三阶段结构清晰且有层次感，避免了单步融合马太效应（信息冗余或流失）。
5. **计算效率和参数效率突出**：以 0.79M 参数、线性复杂度的 PS6 替代注意力机制，在保持性能提升的同时显著降低资源占用，利于实际部署。
6. **实验设计全面**：包含性能对比、消融、鲁棒性（错位/遮挡）、效率、可视化以及跨任务泛化（图像融合），实验链条完整，验证了方法的普适性。
7. **跨模态联合丢弃策略**：TDM 中的 Cross-Modal Union 联合三模态索引进行剪枝，保证跨模态一致性，避免单模态误判引起的有效信息损失。

### 8. 不足与局限（包括实验覆盖、偏差风险、应用限制）

1. **数据集的偏置与规模限制**：主要实验集中在 4 个中大规模数据集上，且都是特定场景（行人、车辆）；未在更大规模的野外多模态数据集上验证，泛化性和跨域迁移能力仍有待考证。
2. **三模态输入假设较理想化**：方法全面依赖 RGB、NIR、TIR 三种模态同时可用，在真实场景中可能存在模态缺失或部分模态失效（如夜间 NIR 不可用）等情况，论文未讨论此类缺失模态的处理方案。
3. **语义掩码生成依赖外部模型**：OpenPifPaf 和 SAM2 均为预训练模型，在极端退化条件下（如低光照、强遮挡）掩码质量可能不稳定，虽然论文表明其鲁棒性，但掩码错误带来的隐性风险未充分讨论。
4. **实验细节披露不充分**：未明确报告训练时长、具体推理环境配置、掩码生成时间开销的详细分解、以及多次运行的标准差等，可复现性和统计显著性信息不足。
5. **对比实验的公平性可进一步提高**：例如，推理时间对比未严格统一 Batch size、输入大小等超参数；参数分析中，不同方法的 backbone（ViT-S vs ViT-B）不一致可能对比较结果产生影响。
6. **轻微错位带来性能提升的解释稍显牵强**：作者将小像素偏移带来的 mAP 提高归因于隐式数据增强，但未做进一步控制变量验证（如加固定偏移而非随机偏移），解释力有限。
7. **缺少部分失败案例分析**：虽然给出了 token 剪枝可视化，但对剪枝失误或掩码失败（如图 5 中 Mask Failure Cases）对最终检索结果的影响缺乏定量分析。
