## 摘要
现有的前馈三维重建方法通常处理有限数量的图像，并在局部或内部归一化坐标系中恢复相机和几何结构。将它们扩展到大规模无人机测绘需要可扩展的多块处理与可靠的聚合，而完整的Sim(3)对齐在近似共线的轨迹上可能变得不稳定。我们提出了GeoFF3D，它结合了坐标锚定模型与空间大规模重建框架（SLRF）。该模型使用地理参照相机平移和可选的几何先验，直接在重力对齐的Z向上度量坐标系中预测相机姿态和稠密点图。SLRF将图像划分为空间重叠的块，传播共享视野先验，并分层聚合局部重建结果，同时适用于不同的有界视图模型。在九个航空测绘区块中，GeoFF3D达到了最佳的平均重建质量，将F@5从Pi3X + SLRF的0.829提升至0.877。在长序列UAVScenes上，它达到了0.848，而Pi3X + SLRF为0.687，最强评估的SLAM/流式基线为0.451。GeoFF3D在大约五分钟内重建2,000张图像，展示了可扩展且稳健的大规模无人机重建能力。代码可在https://github.com/yanxian-ll/GeoFF3D获取。

## Abstract
Existing feed-forward 3D reconstruction methods typically process a bounded number of images and recover cameras and geometry in local or internally normalized frames. Extending them to large-scale UAV mapping requires scalable multi-chunk processing and reliable aggregation, while full Sim(3) alignment can become unstable for near collinear trajectories. We present GeoFF3D, which combines a coordinate-anchored model with a spatial large-scale reconstruction framework (SLRF). The model uses georeferenced camera translations and optional geometric priors to predict camera poses and dense point maps directly in a gravity-aligned Z-up metric frame. SLRF partitions images into spatially overlapping chunks, propagates shared-view priors, and aggregates local reconstructions hierarchically, while remaining applicable to different bounded-view models. Across nine aerial mapping blocks, GeoFF3D achieves the best average reconstruction quality, improving F@5 from 0.829 for Pi3X + SLRF to 0.877. On long UAVScenes sequences, it reaches 0.848, compared with 0.687 for Pi3X + SLRF and 0.451 for the strongest evaluated SLAM/streaming baseline. GeoFF3D reconstructs 2,000 images in approximately five minutes, demonstrating scalable and robust large-scale UAV reconstruction.The code is available at https://github.com/yanxian-ll/GeoFF3D.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **现有前馈重建方法的局限**：当前主流的 feed-forward 三维重建模型（如 DUSt3R、MASt3R、VGGT、Pi3X 等）一次只能处理有限数量的图像（bounded views），且通常在参考相机坐标系或内部归一化的场景表示中输出结果。这使其难以直接应用于包含数百至数千张图像的大规模无人机（UAV）倾斜摄影测绘任务。
- **两大核心挑战**：
  1. **地理参考化困难**：将局部重建结果转换到统一的地理参考坐标系时，通常需要估计完整的 Sim(3) 变换。当无人机轨迹近似共线（near-collinear）时，roll 和 pitch 约束不足，Sim(3) 对齐可能不稳定，导致重建场景被错误倾斜，即使相机中心对齐看似准确。
  2. **大规模分块不一致**：大规模图像集合必须划分为多个重叠块。独立重建各块会导致相邻块之间的坐标系不一致、共享图像深度预测不一致，从而出现重复表面、垂直偏移和可见接缝等问题。多航带（multi-strip）无人机数据中，时间邻近不代表空间重叠，进一步加剧该问题。
- **核心见解**：应**利用地理参考先验直接定义预测坐标系**，而不是在内部坐标系中重建后再进行后处理对齐。
- **论文目标**：提出 GeoFF3D，将坐标锚定模型与空间大规模重建框架（SLRF）结合，实现大规模、鲁棒的无人机测绘重建，并保持重力对齐的 Z-up 度量坐标系。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体框架

- 输入：N 张无人机图像（N 可达数千），以及近似地理参考相机平移（必须有）、可选的旋转、内参和深度观测。
- 输出：所有相机的世界坐标系姿态和稠密点图。
- 整体流程形式化：
  - 通过足迹引导的空间分块（`Pfoot`）将图像集合划分为空间重叠的块（chunk），每块 ≤ M 个视图。
  - 对每个块，用坐标锚定模型 `fθ` 预测局部重建结果，并利用传播的先验 `Qk`。
  - 通过聚合模块 `AT`（重力保持的分层对齐）将各块结果合并为全局一致的重建。

### 2.2 坐标锚定前馈模型（Coordinate-Anchored Feed-Forward Model）

- **坐标系**：预测直接发生在局部地理参考笛卡尔坐标系中，Z 轴与重力方向相反（Z-up），XY 平面与局部水平面平行。使用平移中心 cT 和场景尺度 sT 进行归一化，推理后再恢复。
- **先验编码**：
  - 图像 patch 特征 F_I、光线方向特征 F_R、深度特征 F_D 为 patch 级；
  - 地理参考平移和旋转编码为 view 级嵌入，广播到所有 patch token；
  - 融合方式为加权求和，并通过掩码控制先验可用性；训练时随机 dropout 先验以增强鲁棒性。
- **预测头**：
  - 相机头预测每个视角的相机到世界变换 cWc→wi ∈ SE(3)；
  - 密集头预测每个像素的射线和 Z-depth，转换为世界坐标系中的三维点：
    - `bXwi(u) = sT * π3( cWc→wi * [ bdi(u)*bri(u), 1 ] ) + cT`
  - 另有置信度头用于抑制不可靠几何。
- **训练损失**：
  - `L = λ_local * L_local + λ_world * L_world + λ_pose * L_pose + λ_grav * L_grav`
  - `L_local`：相机坐标系点图、Z 深度、射线、相对姿态（Pi3 风格）；
  - `L_world` 和 `L_pose`：监督归一化地理参考坐标系中的稠密几何和绝对姿态，使模型学习由平移锚定义的坐标系；
  - `L_grav`：约束预测相机上方向与真实上方向的一致性，主要约束 roll 和 pitch，稳定 Z-up 方向。
- **训练过程**：先在 224 像素分辨率下训练 80 epoch，再在 518 像素下微调 10 epoch，期间随机丢弃并扰动几何先验。

### 2.3 空间大规模重建框架（SLRF）

- **足迹引导空间分块**：根据 GNSS 位置和 IMU 姿态估计每个图像的地面足迹，通过自适应二叉树递归划分，使叶子块的 core 视图数 ≤ ⌊0.7M⌋。每个块包含 core views 和从邻近区域选择的 seam views。
- **中心向外推理与先验传播**：
  - 构建块空间邻接图，从最接近场景中心的块开始广度优先处理；
  - 维护按图像索引的深度缓存；推理前将共享视图的缓存深度作为先验输入模型；
  - 推理后按置信度分位数（0.25）过滤低置信度区域，更新缓存；
  - 若无内参且所有图像来自同一相机，则用第一块预测的平均内参作为后续块的先验。
- **重力对齐分层聚合**：
  - 叶块先使用 GA-Sim（保留 roll/pitch 的相似变换：`T(x)=s*Rz(θ)*x + t`）锚定到地理参考平移先验；
  - 兄弟节点之间使用 GA-Rigid（只估计残余 yaw 和位移的刚性变换）；
  - 自底向上合并，最终仅融合置信度过滤后的 core-view 几何。
  - 相比完整 Sim(3)，GA-Sim/GA-Rigid 不改变重力方向，避免共线轨迹下的倾斜问题。

## 3. 实验设计

### 3.2 对比方法

### 3.3 评估指标

### 3.4 主要结果

## 6. 论文的主要结论与发现

1. **坐标锚定有效**：通过地理参考平移直接定义 Z-up 度量坐标系，避免了后验 Sim(3) 对齐在共线轨迹上的不稳定性，显著改善长序列重建。
2. **SLRF 可扩展**：足迹引导分块 + 中心向外先验传播 + 重力保持分层聚合，能处理数百到数千张图像，并减少跨块接缝误差。

4. **效率与鲁棒性**：2000 张图像约 5 分钟完成，且对姿态噪声具有一定鲁棒性，但过度依赖平移先验会在缺失旋转时性能下降。

## 7. 优点

- **问题定位准确**：准确指出现有前馈重建两个关键瓶颈（局部坐标系、大规模分块不一致），并针对近共线轨迹提出轻量级解决方案。
