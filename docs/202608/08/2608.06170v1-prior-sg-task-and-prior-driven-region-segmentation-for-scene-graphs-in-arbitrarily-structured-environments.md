## 摘要
分层3D场景图是自主移动平台高层空间推理的一种有前景的表示方法。然而，现有的提取框架通常依赖于纯局部视觉聚类或严格的几何启发式规则（如墙体分隔的房间），这无法适用于开放式平面或任意结构的环境。我们提出Prior-SG，一种任务与先验驱动的框架，从根本上将场景图生成转化为概率对齐问题。随着机器人的探索，它利用多尺度、开放词汇的特征融合策略，持续将输入的RGB-D传感器流聚合为物理 grounded 的实例图。随后，系统通过最大后验（MAP）估计推断该地图的高层功能语义，并由先验图引导——先验图是由大语言模型动态合成的对环境结构和任务相关词汇的逻辑预期。通过优化一个融合异构专家（视觉、几何和离散物体）与这些拓扑先验的马尔可夫随机场，系统解决了局部感知歧义。我们在多种模拟住宅数据集和大型开放式真实世界环境中验证了该方法。与最近的基线方法相比，Prior-SG在语义区域分割准确性上达到了最先进水平，在没有物理墙壁的情况下稳健地划分出远距离的功能边界，并独特地提供了零样本本体灵活性，使机器人能够根据给定的高层任务完全重构其空间划分。

## Abstract
Hierarchical 3D scene graphs are a promising representation for high-level spatial reasoning in autonomous mobile platforms. However, existing extraction frameworks typically rely on purely local visual clustering or strict geometric heuristics, such as wall-separated rooms, which fail in open-plan or arbitrarily-structured environments. We propose Prior-SG, a task- and prior-driven framework that casts scene graph generation fundamentally as a probabilistic alignment problem. As the robot explores, it continuously aggregates an incoming RGB-D sensor stream into a physically grounded Instance Graph utilizing a multi-scale, open-vocabulary feature fusion strategy. The system then infers the high-level functional semantics of this map through a Maximum A Posteriori (MAP) estimate, guided by a Prior Graph-a logical expectation of the environment's structure and task-relevant vocabulary synthesized dynamically by a Large Language Model. By optimizing a Markov Random Field that fuses heterogeneous experts (visual, geometric, and discrete objects) with these topological priors, the system resolves local perceptual ambiguities. We validate this approach across diverse simulated residential datasets and large, open-plan real-world environments. Prior-SG achieves state-of-the-art semantic region segmentation accuracy compared to recent baselines, robustly delineates distant functional boundaries in the absence of physical walls, and uniquely provides zero-shot ontological flexibility, enabling the robot to entirely restructure its spatial partitioning based on a given high-level task.

- 人类对空间的理解是**层次化**的（物体→区域→环境），而非仅由几何基元构成。现有自主移动机器人需要具备类似的空间智能，以进行高层语义推理和任务规划。
- 层次化 3D 场景图（Hierarchical 3D Scene Graphs）是一种理想的表示：它既保持稀疏性以实现大规模可扩展性，又能将语义序列化为自然语言，便于与大语言模型（LLM）集成。
- **现有方法的根本缺陷**：
  - **几何启发式依赖**：如 HOV-SG、Hydra 等依赖墙体分隔的房间结构提取区域，在开放式平面（open-plan）或任意结构环境中无法工作。

  - 两者都**缺乏高层拓扑先验**，无法利用环境结构的逻辑预期来辅助推断。

### 核心问题
- 如何在**任意结构环境**（包括无物理墙体的开放式空间）中，从 RGB-D 传感器流准确提取**任务相关的功能区域**，并构建完整的层次化场景图？

### 关键思路
- 受认知科学启发，人类不是仅靠局部几何或孤立视觉信号理解空间，而是利用**任务驱动的结构化先验**（如 "厨房通常连着餐厅、包含冰箱和灶台"）来解释观察结果。
- 因此，作者将场景图生成**重新定义为概率对齐问题**：将物理观察到的实例图（Instance Graph）与 LLM 生成的先验图（Prior Graph）进行最大后验概率（MAP）对齐。

### 2.2 数学形式化

将区域分割建模为寻找最优标注场 L∗：

$$L^\* = \arg\max\_L P(L \mid Z, E\_0, T)$$

通过引入先验图作为中介变量进行逐步近似：
- $(E\_0, T) \mapsto G\_P$：LLM 将抽象上下文映射为结构化先验图
- $Z \mapsto G\_I^{obs}$：传感器流聚合法为可观测实例图
- 最终：$P(L \mid Z, E\_0, T) \approx P(L \mid G\_I^{obs}, G\_P) \propto P(G\_I^{obs} \mid L, G\_P) P(L \mid G\_P)$

### 2.3 先验图生成（Section IV）

**（A）自顶向下的状态空间截断**：
- 基于环境 $E\_0$ 和任务 $T$，提示 LLM 枚举最可能的**功能区集合** $R\_P$
- 为每个区域生成任务相关或判别力强的**对象集合** $O\_P$
- 为每个区域实例化一个原型**位置节点** $p\_r \in P\_P$

**（B）固有节点属性**：
- **视觉外观描述符**：将对象和位置标签（如 "A picture of a kitchen"）通过 CLIP 文本编码器投影到联合视觉-语言嵌入空间
- **几何描述符**：LLM 输出预期局部几何（如平面度、倾角），解析为标准参数化形式（期望角度和方差）

**（C）概率结构边**：
- **包含先验（Containment Priors）**：LLM 估计条件似然矩阵 $P(o|r, E\_0)$，即对象出现在区域内的概率，采用软概率而非二元关联
- **拓扑先验（Topological Priors）**：LLM 估计区域之间转移似然矩阵 $P(r\_i \leftrightarrow r\_j | E\_0)$，编码逻辑上合理的空间布局
- **全局区域存在先验** $P(r | E\_0)$

### 2.4 实例图构建（Section V）

**物理骨架**：
- **对象层**：使用 GroundingDINO 开放词汇检测器，但用先验对象集 $O\_P$ 约束检测词汇，保证所有实例化对象都是任务相关的；通过 FastSAM 生成掩码，经 3D 关联和几何交集进行时间关联
- **位置层**：采用 Hydra 的拓扑自由空间提取（3D GVD 或 2D 占位提取），每个位置节点是锚定在 3D 中心的随机游走节点

**多尺度特征金字塔（核心创新）**：
- 将每个位置建模为 3D 高斯体，中心 $x\_p$，各向同性协方差半径 $r\_Q$（由先验图位置节点确定）
- 查询状态定义为 $s\_p = (u\_p, \sigma\_p)$，即投影的 2D 像素坐标和尺度（尺度由 $\sigma\_p = f \cdot r\_Q / z\_p$ 计算）
- **预计算金字塔**：对每帧图像构建 L 层滑动窗口金字塔，每层用 $S\_l \times S\_l$ 的均匀裁剪网格，逐层增大裁剪尺寸；相邻裁剪有重叠
- **物理筛选**：用深度图估计裁剪对应的 3D 物理面积 $A\_{3D} \approx (2\sigma\_l z\_i / f)^2$，丢弃 $A\_{3D} < A\_{min}$ 的裁剪（只看到微小物理碎片如一小块墙面）
- 每个裁剪经 CLIP 编码产生嵌入 $e\_{i,l}$，构成状态-特征对数据库 F

**语义集成核**：
- **空间亲和力**：2D 高斯响应 $w\_{spa} = \exp(-\|u\_p - u\_{i,l}\|^2\_2 / 2(\sigma^2\_p + \sigma^2\_l))$，**未归一化**以避免放大远处不相关裁剪的权重
- **尺度信任因子**：带通滤波器 $w\_{sca} = \exp(-(\log\sigma\_p - \log\sigma\_l)^2 / \gamma)$，惩罚金字塔层与先验期望尺度的偏差
- 最终的框架特征：$e\_p = \sum\_l \sum\_i W(s\_p, s\_{i,l}) e\_{i,l}$，置信度 $T(p) = \sum\_l w\_{sca}(\sigma\_p, \sigma\_l) \max\_i \{w\_{spa}(s\_p, s\_{i,l})\}$

**时间融合**：
- 位置节点：信任加权平均历史观测，偏好高质量尺度匹配
- 对象节点：基于中心性的加权平均，隔离最代表性的视觉原型，抵抗瞬态遮挡

**几何描述符提取**：在位置图上用最短路径邻域 $N(p)$ 提取局部空间结构的协方差矩阵，经特征分解得到局部倾角等参数化几何量。

### 2.5 全局推断：MRF 与图割（Section VI）

负对数后验转化为能量最小化：

$$E(L) = \sum\_{p \in P\_I} \psi\_U(p, L(p)) + \sum\_{(u,v) \in E\_I} \psi\_P(L(u), L(v))$$

**单元势能：置信度加权的对数线性池（Product of Experts）**：

$$\psi\_U(p, r) = -\sum\_{k \in K} \alpha\_k(p) \log P\_k(r|p)$$

关键设计：若某专家对某位置缺少数据，其置信度 $c\_k(p) = 0$，自动忽略该专家而不污染联合分布。共有四个专家：

**(1) 视觉专家**：
- 计算观测描述符与先验区域概念的余弦相似度
- 引入 **开放集 Null 类别** 作为背景噪声地板，用温度缩放 Softmax 在区域概念+Null 上分配概率质量
- 动态置信度 $c\_{vis}(p)$ = 成功分配给有效先验概念的总概率质量——若观察主要是分布外内容，质量流向 Null，置信度下降

**(2) 几何专家**：
- 用 von Mises 分布建模局部倾角与先验期望的匹配
- 置信度由邻域支持饱和度和局部形状各向异性共同决定
- 在非结构化或稀疏观测区域自动忽略

**(3) 对象专家**：
- 将观测对象通过 Softmax 映射到先验概念，再通过 LLM 包含先验 $P(r|c)$ 计算对象到区域的边际概率 $P(r|o) = \sum\_c P(r|c)P(c|o)$
- 构建**位置-对象二分邻近子图**，空间相关性随距离指数衰减（硬阈值 $d\_{max}$ 截断）
- 使用**邻近折扣的最大池化**聚合证据：$\tilde{P}\_{obj}(r|p) = \max\_{o \in O\_p} w(p,o) \cdot P(r|o)$——物理邻近性自然塑造了未归一化分布

**(4) 环境先验专家**：直接注入 LLM 生成的全局先验 $P(r|E\_0)$ 作为空间正则器。

**成对势能（拓扑正则化）**：Potts 模型变体，惩罚相邻位置被赋予不同区域标签，调制因子为距离衰减和 LLM 转移似然矩阵。

**优化算法**：由于 LLM 生成的拓扑规则**不满足度量性质**（如厨房直连走廊和走廊直连浴室代价都低，但厨房直连浴室代价高，违反三角不等式），使用 **α-β-swap 算法**（仅评估二元标签对）而非 α-expansion，严格保持非度量 LLM 拓扑。

**区域实例化**：对每个标签提取顶点诱导子图的连通分量，每个连通分量成为独立区域节点，并建立与位置、对象的层次边。

### 3.1 数据集（四个域，涵盖模拟与真实）

| 数据集 | 类型 | 内容 | 轨迹 |

### 3.2 基线方法
- **Clio [10]**：自底向上视觉聚类的代表，使用聚合信息瓶颈算法 + 全局 CLIP 特征投影；使用相同 Hydra 位置提取和相同的 CLIP ViT-H/14 编码器，隔离核心算法贡献
- **HOV-SG [5]**：几何启发式的代表，在 2D 欧氏距离场上用分水岭算法定义区域；仅限 HM3D 室内受约束场景评估（其算法无法分割无界室外或开放式平面）

### 3.3 评估指标
- 采用 Hughes 等人的体积度量：Precision、Recall、F1、mIoU，分别从**几何**（标签无关）和**语义**（标签严格匹配）两个轴评估

### 3.4 实现细节要点
- LLM：GPT-5.4（中等思维模式），生成先验图；量化基准中区域集合固定为 GT 类别，隔离 LLM 开放词汇方差；所有指标在 10 次独立先验生成上取平均
- CLIP ViT-H/14 视觉主干，GroundingDINO 检测器，FastSAM 分割
- 位置提取：结构化室内用 3D GVD，大型/无界环境用 2D place 提取 + 图滤波
- 查询半径 $r\_Q$ = 0.75m（火车站/HM3D/CODa），TartanGround 调整为 1.5m
- 裁剪丢弃阈值：3D 投影面积 < 2.25 m² 丢弃；最小裁剪分辨率 224×224
- MRF 权重全局固定：$\beta=2$，$\lambda\_{vis}=4$, $\lambda\_{obj}=1$, $\lambda\_{geo}=1$, $\lambda\_{env}=0.1$
- 专家激活依数据集能力配置（HM3D 用全部专家；Train Station 用视觉+几何+环境；TartanGround/CODa 用视觉+环境）
