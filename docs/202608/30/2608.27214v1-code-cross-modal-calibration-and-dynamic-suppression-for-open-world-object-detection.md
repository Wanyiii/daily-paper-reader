## 摘要
基于多模态基础模型的开放世界目标检测（OWOD）常因单向文本到视觉匹配而导致语义模糊，而刚性异常值惩罚可能过度抑制已知类决策边界附近的未知对象。我们提出CODE（跨模态校准与动态抑制），一种统一的推理时框架，包含三个互补组件。跨模态联合置信度校准注入全局视觉原型以校准文本驱动的已知类预测。不确定性引导的通用目标性增强通过局部视觉响应测量分类犹豫，以强化潜在未知对象。基于置信度裕度的动态异常值抑制以裕度感知调整替代刚性抑制，保留模糊的分布外实例。在真实世界检测基准上的实验表明，使用OWL-ViT L/14骨干网络，CODE在任务1中达到21.7 U-mAP和40.8 K-mAP，分别超过先前最先进方法2.6和2.3个百分点。

## Abstract
Open World Object Detection (OWOD) built on multimodal foundation models often suffers from semantic ambiguity caused by unidirectional text-to-vision matching, while rigid outlier penalties may over-suppress unknown objects near known-class decision boundaries. We propose CODE (Cross-Modal Calibration and Dynamic Suppression), a unified inference-time framework with three complementary components. Cross-Modal Joint Confidence Calibration injects global visual prototypes to calibrate text-driven known-class predictions. Uncertainty-Guided Universal Objectness Enhancement measures classification hesitation from local visual responses to strengthen potential unknown objects. Dynamic Outlier Suppression via Confidence Margin replaces rigid suppression with a margin-aware adjustment that preserves ambiguous out-of-distribution instances. Experiments on the Real-World Detection benchmark demonstrate that, with the OWL-ViT L/14 backbone, CODE achieves 21.7 U-mAP and 40.8 K-mAP in Task 1, surpassing the previous state of the art by 2.6 and 2.3 points, respectively.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：传统目标检测遵循“封闭世界”假设，只能识别训练时见过的类别。然而真实世界充满动态性和不确定性，经常出现超出预定义类别体系的新对象。开放世界目标检测（OWOD）要求模型在准确识别已知类别的同时，还能定位并标记未知对象，且不能将未知对象与背景或已知类别混淆。
- **技术演进**：CLIP、OWL-ViT等多模态基础模型的出现，为OWOD引入了丰富的开放词汇知识。近期的先进范式（如FOMO、PASS）通过大语言模型（LLM）将抽象类别分解为细粒度、类别无关的属性（如形状、纹理、材质），以这些属性作为中间语义表示来识别与已知类共享视觉或功能特征的未知对象。
- **识别出的三个关键问题**：
  1. **单向文本到视觉匹配的语义歧义**：现有方法独立编码测试图像和属性描述，缺乏直接视觉参考。在遮挡、模糊、视角变化、光照不良等情况下，判别性视觉属性可能变得不明显，导致分类困难。
  2. **通用目标性估计不可靠**：现有方法常以最大属性响应来估计通用目标性（objectness），无法可靠区分模糊未知对象与背景干扰物。
  3. **刚性异常值惩罚过度抑制**：最大概念匹配（MCM）机制依据最大已知类概率进行抑制，这会对与多个已知类共享属性的边界未知对象造成过度惩罚，导致它们被误判为背景。

## 2. 方法论：核心思想、关键技术与算法流程

论文提出**CODE（Cross-Modal Calibration and Dynamic Suppression）**框架，是一个统一的**推理时**框架，包含三个互补组件：

### 2.1 跨模态联合置信度校准（CMJCC）
- **核心目的**：解决单向文本-视觉匹配的语义歧义问题。
- **视觉原型构建**：使用冻结的OWL-ViT视觉编码器离线构建已知类别的视觉原型库。对每个已知类别，取其标注框的区域嵌入的归一化质心作为该类别的视觉原型。
- **视觉相似度与门控**：计算候选区域嵌入与所有已知类别原型的余弦相似度。通过候选特定的动态阈值（`τ = max(相似度均值 + 边界值m, 最小激活阈值)`）加ReLU门控得到视觉增强项，抑制背景和无关视觉响应。
- **联合校准**：将视觉增强项按照基础模型的内在温度倒数缩放后，与原始文本驱动的已知类逻辑值加权融合，得到校准后的已知类概率。视觉原型直接提供视觉到视觉的参考，弥补文本属性覆盖不足的缺陷。

### 2.2 不确定性引导的通用目标性增强（UGUOE）
- **核心目的**：解决通用目标性估计不可靠的问题，增强潜在未知对象的响应。
- **局部视觉响应聚合**：取候选区域与所有视觉原型相似度中Top-$K_u$个值，计算其均值 `μ` 作为基准视觉驱动的未知响应。高均值表示区域具有强物体性视觉特征。
- **不确定性建模**：计算Top-$K_u$个相似度的无偏方差 `σ²`。清晰的已知对象会高度集中在某个原型上（方差大），而未知对象在多个相关已知原型上呈现模糊、低方差的响应。通过指数衰减函数将方差映射为不确定性权重 `W_unc`，偏好低方差（模糊）的候选区域。
- **增强融合**：对基准未知响应进行ReLU阈值过滤后，乘以不确定性权重和缩放因子，注入到原始文本驱动的未知逻辑值中，增强“语义真空”中潜在未知对象的响应。

### 2.3 基于置信度裕度的动态异常值抑制（DOSCM）
- **核心目的**：解决刚性MCM机制对边界未知对象的过度抑制。
- **置信度裕度计算**：从校准后已知逻辑值的Softmax分布中提取Top-1和Top-2概率，定义裕度 `ΔS = P_top1 − P_top2`。大裕度表示对某个已知类的绝对排他性确信；小裕度表示边界模糊。
- **动态抑制**：用 `ΔS × P_top1` 替代原始MCM的 `P_top1` 作为有效抑制惩罚，得到动态OOD评分 `p_OOD = 1 − P_top1 × ΔS`。当模型在两个类之间犹豫时，抑制惩罚被显著缩小，从而保护边界未知对象免遭误杀。

### 2.4 整体推理流程
CMJCC提供视觉到视觉的已知类校准 → UGUOE增强潜在未知区域 → DOSCM动态保护边界目标。三个组件以级联方式协同工作，是一个**轻量级推理时增强框架**，不需要重新训练基础检测器。属性生成与原型构建均离线完成，不参与测试时推理。

## 6. 主要结论与发现

- **主结果**：使用OWL-ViT L/14骨干，CODE在Task 1上达到**21.7 U-mAP**和**40.8 K-mAP**，分别比SOTA（PASS）提升2.6和2.3点。Task 2的PK-mAP和CK-mAP分别为43.6和36.2，提升4.7和0.2点。B/16骨干上也有稳定提升。
- **UMGUOE对未知发现贡献最大**：移除UGUOE导致U-mAP从24.7/25.7骤降至9.1/2.3（Aquatic/Surgery），验证了不确定性引导对激活潜在未知对象的有效性。
- **CMJCC同时带来已知类和未知类性能提升**：移除CMJCC后，K-mAP和U-mAP均下降（Aquatic从24.7/62.7降至20.6/54.3），说明视觉原型校准能同时缓解已知类歧义和帮助未知发现。
- **DOSCM缓解已知-未知权衡**：增量消融表明，UGUOE提升U-mAP的同时会降低K-mAP，而DOSCM的加入在继续提升U-mAP的同时恢复了K-mAP，有效缓解了已知精度与未知发现之间的失衡。
- **局部视觉离散度优于全局逻辑统计**：基于局部视觉响应方差的不确定性建模（25.7 U-mAP）优于基于已知类逻辑值熵的方案（17.0 U-mAP）；基于置信度裕度的动态抑制（25.7 U-mAP）优于Energy（21.2）、MaxLogit（2.8）和全局熵（1.0）等替代方案。
- **泛化能力**：在M-OWODB上达到86.0 U-Recall和70.0 mAP，远超MAVL、DEUS等；在LVIS上AP_rare为32.0，优于GenerateU和Open-Det。

## 7. 优点

- **推理时轻量增强**：CODE不需要重新训练基础检测器，所有组件均在推理时动态计算，属性生成和原型构建离线完成，实际开销极小（FLOPs增加不到0.1%，延迟增加不到5%）。
- **三组件互补设计**：CMJCC（已知类校准）、UGUOE（未知激活）、DOSCM（边界保护）分别针对OWOD管线的不同阶段，从实验上看三者协同效果优于各自单独使用，并能缓解传统的已知-未知性能权衡。
- **严格的评估指标**：不同于早期OWOD方法只关注未知类Recall，CODE在RWD上严格采用mAP作为主要指标，同时关注已知类和未知类的准确率，评估更严谨。
- **跨域泛化验证**：在RWD（5个场景）之外还验证了M-OWODB和LVIS上的泛化性；在B/16和L/14两种骨干规模上都做了验证，实验覆盖较广。
- **直观的可视化分析**：附录中的对数分布演化分析、DOSCM决策边界散点图以及多场景定性对比，为方法的有效性提供了直观支撑。

## 8. 不足与局限

- **特定数据集的性能下降**：在Game数据集上CODE的U-mAP（−2.8）和K-mAP（−1.7）均低于PASS。论文将其归因于Game中极高的类间余弦相似度（0.82），说明高度重叠的细粒度类别仍对动态抑制机制构成挑战。
- **对视觉原型的依赖**：CODE依赖数据集特定的视觉原型，其代表性在极端数据稀缺（如10-shot场景）、长尾分布、噪声标注和跨域分布偏移下可能大幅下降。论文的少样本实验仅隔离了样本量稀缺这一因素，没有覆盖所有不利条件。
- **Surgery Task 2的K-mAP下降**：虽然Surgery Task 1的U-mAP大幅提升（+9.1），但Task 2的PK-mAP（−1.6）和CK-mAP（−7.7）均有下降。论文分析指出，大量激活模糊的未知外科工具可能对已建立的已知类决策边界产生干扰。
- **动态抑制的双刃剑效应**：DOSCM通过软化抑制边界来保护边界未知对象，但在类间相似度极高的合成域（如Game）中，也可能导致部分已知对象越界成为未知误报，本质上是精确率与召回率之间的固有权衡。
- **训练与推理信息未完全公开**：论文没有明确说明GPU数量、训练时间等算力细节，复现成本较难评估。
