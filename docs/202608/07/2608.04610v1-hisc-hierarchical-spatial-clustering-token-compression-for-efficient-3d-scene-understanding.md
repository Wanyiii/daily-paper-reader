## 摘要
3D视觉-语言模型（3D VLMs）能够对多视角场景进行空间推理，但由于重复观测和大量无信息区域而产生大量的标记冗余，导致计算成本高昂。尽管视觉标记压缩在加速2D VLMs方面显示出潜力，但它无法捕捉3D场景的结构化特性，导致空间覆盖不完整和细粒度细节丢失。在本文中，我们提出了HiSC，一种用于3D VLMs中分层空间聚类标记压缩的无训练框架。HiSC通过结合几何和语义线索，将标记组织为空间锚定的聚类，从而将标记压缩从标记级选择提升到聚类级处理。具体而言，我们首先引入了一种基于空间图的合并（SGraM）策略，该策略将跨视图冗余建模为空间连通性，并整合物理上一致的区域，在LLM推理之前有效合并极其相似的冗余标记。随后，我们在LLM推理中提出了一种基于空间聚类的剪枝（SCluP）范式，该范式在聚类间和聚类内执行分层压缩，在保留对象实例完整性的同时，保留重要区域的细粒度细节。在多个3D推理基准上的大量实验验证了HiSC的有效性，尤其是在高视觉标记剪枝比率下。此外，HiSC实现了超过90%的标记减少，且性能下降极小。代码可在 https://github.com/elecreak/HiSC 获取。

## Abstract
3D vision-language models (3D VLMs) enable spatial reasoning over multi-view scenes but suffer from substantial token redundancy due to duplicated observations and large uninformative regions, leading to high computational cost. Although visual token compression has shown promise in accelerating 2D VLMs, it fails to capture the structured nature of 3D scenes and leads to incomplete spatial coverage and loss of fine-grained details. In this paper, we propose \textbf{HiSC}, a training-free framework for hierarchical spatial clustering token compression in 3D VLMs. HiSC lifts token compression from token-level selection to cluster-level processing by organizing tokens into spatially grounded clusters using joint geometric and semantic cues. Specifically, we first introduce a \textbf{spatial graph-based merging (SGraM) strategy} that models cross-view redundancy as spatial connectivity and consolidates physically consistent regions, effectively merging extremely similar redundant tokens prior to LLM inference. We then propose a \textbf{spatial clustering-based pruning (SCluP) paradigm} within LLM inference, which performs hierarchical compression across clusters and within clusters, preserving object instance completeness while retaining fine-grained details for important regions. Extensive experiments on diverse 3D reasoning benchmarks show validate the effectiveness of HiSC, particularly under high visual token pruning ratios. Besides, HiSC achieves over 90\% token reduction with minimal performance degradation. Code is accessible at https://github.com/elecreak/HiSC.

### 问题背景
- **3D视觉-语言模型（3D VLMs）** 支持多视角场景的空间推理，在3D场景理解和具身机器人等领域展现出强大潜力。
- 主流方法采用**多视角RGB-D公式**，将2D图像token提升至3D空间，借助预训练的2D视觉表征实现空间推理（如Video-3D LLM、LLaVA-3D）。
- 然而，3D VLM面临**严重的token冗余问题**：单个3D场景可产生数千个视觉token，远超典型2D VLM。

### 核心问题
1. **结构化冗余**：
   - 多视角观测中，同一物理实体会被多个视角重复编码；
   - 大面积物理一致区域（如空白平面）产生大量近似重复的token。
2. **现有2D token压缩方法的不足**：
   - 基于注意力分数或特征多样性的token级独立选择，无法捕捉3D场景的**空间连通性与几何一致性**；
   - 缺乏对空间区域和对象实例的全覆盖保证，易导致**对象缺失**；
   - 重要性驱动的选择倾向于将token集中在少数高相关区域，**丢失上下文细节**，降低重要对象的表征保真度。

### 核心洞察
- 3D场景冗余具有**结构化模式**，与空间连接性和几何一致性密切相关；
- 有效的加速需要**超越独立token选择**，将token组织为空间分组，在不同层级实施定制化的压缩策略。

## 2. 论文提出的方法论

### 2.1 整体框架：HiSC

HiSC是一个**无训练**的分层空间聚类token压缩框架，核心思想为：

> 将token压缩从token级选择提升至**聚类级处理**——利用联合几何与语义线索，将token组织为空间锚定（spatially grounded）的簇，并在多个层级执行定制化压缩。

### 2.2 模块一：空间图合并（SGraM，LLM推理前）

**目标**：在LLM推理之前，消除跨视角重复和大面积均匀区域带来的结构化冗余。

**关键设计——几何-语义连通图**：

- **解耦几何接近度与语义相似度**分别构建邻接关系：
  - 几何邻接：\( A_{ij}^{geo} = \mathbb{I}(\|p_i - p_j\|_2 < \tau_{geo}) \)
  - 语义邻接：\( A_{ij}^{sem} = \mathbb{I}(\text{sim}(f_i, f_j) > \tau_{sem}) \)
  - 统一邻接：\( A_{ij} = A_{ij}^{geo} \odot A_{ij}^{sem} \)（仅当空间相邻且外观高度相似时，才建立边）

- **连通组件提取**：将邻接矩阵视为无向图，提取连通分量，每个分量对应物理一致的区域。
- **超级token合成**：对每个连通分量内的token进行特征与位置的平均聚合，形成紧凑的超级token。

**优势**：
- 利用连通性的**传递性质**，可将空间跨度大但局部一致的区域整合；
- 避免仅靠相似度聚类导致的跨对象错误合并或过度分割。

### 2.3 模块二：空间聚类剪枝（SCluP，LLM推理内）

**目标**：在LLM多层推理中，通过层次化压缩保持对象级完整性与重要区域细节。

**第一步：对象中心空间聚类**（Object-centric Spatial Clustering）

- 两阶段分解：
  1. **语义分组**：先将token划分为粗粒度语义集合；
  2. **空间实例分离**：在每个语义组内施加空间连通约束，分离物理上不同但视觉相似的实例。
- 公式化表达：\( \mathcal{C} = \bigcup_{m=1}^{K_{sem}} \text{ConnComp}(A^{(m)}) \)
- 优点：避免纯语义分组合并空间分离区域，也避免纯空间分区丢失语义身份。

**第二步：分层聚类token剪枝**

- **聚类级预算分配**：
  - 约束 \( n_k \geq 1 \)：确保每个聚类至少保留一个token，维持空间覆盖，防止对象消失；
  - 预算按重要性平方加权分配：\( n_k \propto (I_k)^2 \)。
- **聚类内token选择**：
  - 结合**重要性选择**与**多样性采样**；
  - 定义联合空间-语义距离：\( D_{ij}^{comb} = \lambda\|p_i - p_j\|_2 + (1-\lambda)\left(1 - \text{sim}(f_i, f_j)\right) \)，优先选择与已选token距离较远的token。

**设计价值**：
- 相较于纯token级剪枝（易产生碎片化表征），以及纯聚类级剪枝（可能完全删除低重要性聚类），层次化方案同时保证了**全局覆盖**与**局部细节保真**。

2. **在90%以上的token缩减下仅产生轻微性能下降**，证明结构化冗余可以被安全移除。

3. **SGraM阶段单独作用**可有效消除冗余并缓解注意力稀释；

   两者**互补结合**效果最佳。

4. **几何-语义解耦连通设计是必要的**：单一约束（纯几何或纯语义）或3D编码特征融合，在90%压缩率下性能显著下降。
