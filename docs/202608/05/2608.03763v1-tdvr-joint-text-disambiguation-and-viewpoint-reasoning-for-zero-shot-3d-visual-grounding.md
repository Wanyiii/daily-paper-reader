## 摘要
零样本3D视觉定位旨在基于文本描述和3D视觉输入来定位具体对象。然而，现有方法的效果常因查询文本的歧义和视角缺失而受到显著限制。为解决这些问题，我们提出了TDVR，一种免训练的推理框架，用于在零样本3D视觉定位中对输入文本进行消歧并推断准确视角。首先，我们从3D点云中检测到的实例构建语义3D场景图。随后，将原始查询、外观和空间关系描述输入大语言模型（LLM）进行融合，从而对初始输入进行消歧。我们利用思维链推理生成消歧后查询的结构化表示。然后，以场景图和结构化查询为输入，通过视角推理获得最优视角，以解决定位过程中视角缺失的问题。基于所得最优视角，我们进一步区分干扰对象，使模型具备区分相似实例的能力。之后，通过计算特征向量的相似度，将类别文本和外观图像与查询进行匹配。最后，通过整合视角分数、混淆分数、类别分数和外观分数来识别目标对象。与先前方法相比，我们的TDVR在视角推理、相似对象区分和歧义查询理解方面具有更强能力。在公开的ScanRefer数据集上的实验结果表明，我们的方法在Acc@0.25和Acc@0.5上分别比现有最优方法高出15.25%和14.46%，证明了TDVR在解决歧义查询文本和视角缺失问题上的有效性。

## Abstract
Zero-shot 3D visual grounding aims to localize specific objects based on textual descriptions and 3D visual input. However, the effectiveness of existing methods is significantly hindered by the ambiguous query text and deficient viewpoints. To address these issues, we propose TDVR, a training-free reasoning framework that disambiguates the input text and infers accurate viewpoints for zero-shot 3D visual grounding. First, we construct semantic 3D scene graph from the detected instances in the 3D point cloud. Subsequently, we put the original query, appearance and spatial relationship descriptions into the LLM for fusion, thereby disambiguating the initial input. We leverage chain-of-thought reasoning to generate the structured representation of disambiguated query. Then taking the scene graph and structured query as input, we get the optimal view via viewpoint reasoning to solve the problem of missing viewpoints during grounding. Based on the obtained optimal viewpoint, we further discriminate the distracting objects, enabling the model with the ability to distinguish similar instances. After that, we match the category text and appearance images with the query by computing the similarity of feature vectors. Finally, the target object was identified by integrating the viewpoint score, confusion score, category score, and appearance score. Compared with previous methods, our TDVR has stronger capabilities in viewpoint reasoning, similar object discrimination, and ambiguous query understanding. Experimental results on the public ScanRefer dataset show that our method outperforms the existing state-of-the-art methods by 15.25% and 14.46% in Acc@0.25 and Acc@0.5 respectively, demonstrating the effectiveness of our TDVR in addressing ambiguous query text and deficient viewpoints.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心任务**：零样本3D视觉定位（Zero-shot 3D Visual Grounding），即在没有针对该任务进行训练的情况下，仅凭自然语言描述和3D点云场景，定位出目标物体。该任务对具身智能、自动驾驶等领域具有重要意义。
- **面临的两大挑战**：
  - **空间歧义与未知视角**：如“左边”“后面”等方位词依赖于观察者视角。当描述者相机位姿未指定时，同一描述在不同视角下会指向不同物体，现有方法常常忽视视角影响，导致定位错误。
  - **相似实例干扰下的文本歧义**：室内场景中常存在同类别、相似外观且距离近的多个物体。当查询文本描述简略时，模型难以区分这些相似干扰物，只能随机猜测，缺乏鲁棒性。
- **整体意义**：论文提出TDVR，一个免训练（training-free）的推理框架，通过联合文本消歧和视角推理来提升零样本3D视觉定位的准确性和鲁棒性，缩小了零样本方法与全监督方法之间的性能差距。

## 2. 论文提出的方法论

TDVR框架主要包括以下几个模块，整体流程为：构建场景图 → 文本消歧 → 结构化关系提取 → 视角推理 → 相似物区分 → 类别/外观匹配 → 综合打分定目标。

- **语义3D场景图构建**
  - 使用预训练检测器（Mask3D）从3D点云中提取物体候选及其3D边界框、类别标签。
  - 对于每个实例，从多视角RGB图像中选择遮挡最小的2D裁剪图作为外观属性，通过深度一致性检查判断点是否可见，从而保证2D图像质量。
  - 构建场景图 G = (V, E, X_V)，节点包含3D边界框、类别标签和最优2D视图，边根据空间邻近性构建。

- **观察者中心协同消歧（Observer-Centric Synergetic Disambiguation）**
  - 生成三类增强描述：目标外观细节（颜色、纹理等，由MLLM从2D裁剪图提取）、多个锚点的方向描述（基于观察者视角的局部坐标系）、同类别实例间的相对位置描述。
  - 将原始查询与这些增强描述一起送入LLM进行融合，生成精确的消歧查询。

- **结构化关系提取**
  - 采用思维链（Chain-of-Thought）提示，将消歧后的查询分解为四个阶段：目标实体识别、锚点定位、空间关系标准化、类内细化。
  - 要求LLM对输出进行自检，确保结构化的语义表示（目标及其外观特征、锚点集合、二元关系元组、类内相对位置）格式正确，为后续几何推理提供确定性基础。

- **视角感知方向推理（Viewpoint-Aware Directional Reasoning）**
  - 论文从数学上证明物体间相对位移向量在固定旋转变换下与旋转中心无关，即空间关系具有旋转不变性；同时垂直方向可由Z轴直接判断，因此将6自由度视角推断降为1自由度水平旋转角估计。
  - 通过旋转整个点云（旋转单元为10°），对每个候选物体计算其与锚点的旋转相对向量与标准参考方向向量的对齐度，使用ReLU和max pooling选择最佳匹配锚点，遍历所有角度得到最优视角分数 S_v 和最优视角集合。

- **基于视角的相似性解耦推理（View-based Similarity Decoupled Reasoning）**
  - 针对同类别多个物体满足相同方向约束的问题，计算同类别物体的几何质心 M_C，然后衡量每个候选与该质心的相对位移是否与描述中的类内方向一致，得到混淆分数 S_c，从而区分目标与相似干扰物。

- **特征匹配的类别和外观评估**
  - 使用BERT计算物体类别标签与查询中类别文本的相似度，得到类别匹配分数 S_cat。
  - 使用CLIP将2D物体裁剪图与查询中的外观描述文本进行对齐，得到外观匹配分数 S_app。

- **目标接地**
  - 最终综合分数 S_total = S_cat · (αS_v + βS_c + γS_app)，其中权重 α=5，β=3，γ=1 为经验设定。
  - 选择总分最高的物体作为预测目标。

## 6. 论文的主要结论与发现

- TDVR通过文本消歧和视角推理，有效解决了零样本3D视觉定位中的查询歧义和视角缺失问题。
