## 摘要
空间关系问题要求模型在比较布局之前识别查询的主体和对象。然而，视觉语言模型（VLM）可以识别这两个实体，但仍然可能从错误的实例或模糊的全局视角作答。我们探究使查询特定证据显式化是否能缓解这一失败，并提出了SEER（实体-关系推理的自接地证据），一种用于冻结VLM的无训练推理时证据接口。SEER在成对定位期间隐藏候选关系，构建具有显式主语/宾语角色的查询特定视图，并保留完整图像和稀疏框几何作为补充证据。对于具有精确逆支持的关系选择协议，可选的细化会交换实体角色，并且仅在恰好一个视觉状态符合相应的逆关系时改变前向决策。在模型评分前冻结的图像不重叠的GQA-Train900测试中，SEER相对完整版本平均提升+3.94 [2.17, 5.72]；在标签无关的接地顺序平衡和实体名称唯一的535行上，增益保持为正。未改变的协议在三个模型的所有2,434个过滤后的EmbSpatial成对关系问题上产生+4.35到+11.79的提升。匹配对照将局部重聚焦与角色显式条件分离。这些结果确立了查询特定证据构建为主要干预手段，而互惠一致性作为较小且特定于协议的细化。

## Abstract
Spatial relation questions require a model to identify the queried subject and object before comparing their layout. Yet a VLM can recognize both entities and still answer from the wrong instance or an ambiguous global view. We ask whether making query-specific evidence explicit can mitigate this failure and propose SEER (Self-grounded Evidence for Entity-Relation Reasoning), a training-free inference-time evidence interface for frozen VLMs. SEER hides candidate relations during pair localization, constructs a query-specific view with explicit subject/object roles, and retains the full image and sparse box geometry as complementary evidence. For relation-choice protocols with exact inverse support, an optional refinement swaps the entity roles and changes the forward decision only when exactly one visual state obeys the corresponding inverse relation. On an image-disjoint GQA-Train900 test frozen before model scoring, SEER pools to +3.94 [2.17,5.72] over Full; the gain remains positive under label-independent grounding-order counterbalancing and on the 535 rows whose entity names are unique. The unchanged protocol yields +4.35 to +11.79 on all 2,434 filtered EmbSpatial pair-relation questions across three models. Matched controls separate local refocus from role-explicit conditioning. These results establish query-specific evidence construction as the principal intervention, with reciprocal consistency as a smaller protocol-specific refinement.

## 一、核心问题与研究动机

空间关系推理是视觉问答（VQA）、具身指令跟随、图表理解等任务的基础能力。然而，大量基准（如 VSR、GQA、ARO、What'sUp 等）反复表明，VLM 存在一个"悖论性"的失败模式：**模型能够正确识别图像中的各个实体，却在比较这些实体的空间位置关系时给出错误答案**。

作者将这一失败归因于"证据选择"层面的缺陷，而非单纯的识别能力不足：

- 模型可能定位到了错误的实例（如同一类别多个实体时选错对象）；
- 模型可能过度依赖语言先验而非视觉证据；
- 模型可能从整体模糊的全局视角作答，而非聚焦于查询所指向的具体实体对。

**核心研究问题**：如果显式地构造并暴露"查询特定证据"（query-specific evidence），即明确告诉模型"你要比较的是哪个实体与哪个实体、谁是谁的 subject/object"，是否能缓解上述失败？SEER 正是对这一问题的回答：一种无需训练、纯推理时的证据接口（evidence interface），它不修改 VLM 的任何参数，只改变模型在作答时"看见什么"。

## 二、方法论

### 2.1 核心思想

SEER（Self-grounded Evidence for Entity-Relation Reasoning）的出发点是：空间回答的质量取决于输入证据是否与查询对齐。因此，它通过**目标关系隐藏的自接地（target-relation-hidden self-grounding）**，将查询所指的实体对转化为显式的、角色明确的视觉证据，再交给同一个冻结 VLM 做最终判断。

### 2.2 关键技术细节

**（1）Stage 1：关系隐藏的实体定位（Self-Grounding）**

- 将原始问题中的候选答案和关系标签全部移除，仅保留图像、subject 和 object 的名称；
- 冻结 VLM 同时充当"定位器"（grounder），输出实体对的归一化边界框（bbox）；
- 框需通过有效性校验（正面积、在图像内、非退化坐标），无效则回退到完整图像；
- 关键约束：**定位阶段看不到候选关系**，防止定位器"看答案选框"。

**（2）Stage 2：构造三类互补证据状态**

| 证据类型 | 内容与特点 |
|---------|-----------|
| **Full Image** | 原始完整图像 + 原始问题，保留全局上下文，是最安全的回退选项 |
| **S/O Marker View** | 以实体框并集的带 padding 裁剪区域为底，用红色框 + "S" 标签标记 subject、蓝色框 + "O" 标签标记 object，并明确提示模型按 S-to-O 方向作答 |
| **Geometry Evidence** | 基于自接地框的中心位移与覆盖比例计算几何候选；仅在 left/right（水平位移）与 inside/contains（不对称覆盖率）上生效，对 above/below/on、front/behind 主动弃权，布局得分低于阈值 τ=0.5 时也弃权 |

**（3）Stage 3：状态级预测与决策规则**

- 对 Full 和 Marker 两种视觉-语言状态，计算每个候选答案的长度归一化对数概率（closed-set scoring），得到预测结果和选项得分差距（margin）；
- 前向决策（Forward）：
  - 若 Geometry 可用且得分 ≥τ，则直接采用几何候选；
  - 否则选择 margin 更大的视觉状态（Full 或 Marker）；平局偏向 Full；
  - 定位无效时直接使用 Full 预测。
- 互逆一致性修正（Reciprocal Consistency Refinement，可选）：
  - 仅适用于存在精确逆关系的协议（如 left-of ↔ right-of、inside ↔ contains）；
  - 当 Geometry 弃权、且 Full 与 Marker 冲突时，交换 subject/object 角色（Marker 中可见的 S/O 标记也互换），重新询问模型；
  - 若恰好只有一个状态在互换后满足逆关系一致性，则改用该状态的预测；否则保持 Forward 结果。

整体流程不训练任何参数，不引入外部检测器，固定阈值 τ=0.5 在所有模型/数据集上保持不变。

## 六、主要结论与发现

1. **SEER 在冻结的 GQA-Train900 上稳定提升**：池化增益 +3.94 [2.17, 5.72]（相对 Full）；在标签独立的 hash 平衡下仍保持 +2.56 [0.72, 4.39]。
2. **EmbSpatial 迁移显著**：Qwen3-I、Qwen3-T、InternVL3.5 分别提升 +4.35、+5.09、+11.79，且场景簇区间均排除零。
3. **证据构建是主要干预**：Full→Crop 增加 +1.25，Crop→Self-Marker 增加 +1.64；Oracle-Marker（使用标注框）比 Self-Marker 高出 +6.55–+6.17，说明自接地定位仍有较大提升空间。
4. **互逆一致性是较小的协议特定修正**：在完整开发池上相对 Forward 仅增加 +1.36 [1.17, 1.54]，触发率约 10%；且该修正并非通用可靠性证明（在 VSR 二分类和 SpatialSense 上增益不显著或为负）。
5. **局部重聚焦 + 角色显式绑定共同构成有效干预**，而非外部检测器、额外指令或特定标记样式。

## 七、优点

1. **训练免费**：完全推理时的接口设计，可在任意冻结 VLM 上即插即用，无需微调；
2. **问题定义清晰**：将"空间答错"重新定义为"证据选择"问题，而非单纯的能力缺失，切中要害；
3. **方法设计具有约束意识**：目标关系隐藏防止定位器信息泄漏；无效定位回退保证分母一致；阈值固定不做数据集级调参；
4. **实验分层严谨**：将"冻结确认"（GQA-Train900、EmbSpatial）与"事后机制分析"明确区分，避免选择偏差；
5. **消融设计精巧**：通过 Swapped/Random 破坏角色、SOP/Text-BBox 排除纯文本效应、同预算多提示集成排除计算量混淆，论证了到底是"看哪里"而非"怎么说"起作用；
6. **人工审计补充**：独立双标注人员审计样本有效性和接地质量，并将严格共识子集上的结果单独报告。

## 八、不足与局限

1. **接地质量依赖**：自接地框噪声大（平均 S/O IoU 约 0.33–0.46），Oracle-Marker 显示定位仍有约 6.5 个百分点的提升空间；
2. **关系覆盖面有限**：对 front/behind 等需要深度信息的关系，2D 几何不可判断；对 near/far 因标注稀疏直接排除；"on" 的关系语义模糊，多个审计中一致标记为最不干净的目标；
3. **顺序偏差未被根除**：关系隐藏不消除提示顺序偏差，subject-first 与 object-first 存在系统性差异，尽管 hash 平衡下增益仍为正；
4. **互逆一致性修正不是通用可靠性证书**：在二分类（VSR、SpatialSense）上增益不显著甚至为负，仅对受控的逆支持关系选择协议有效；
5. **计算成本高**：完整 SEER 约 7.12× Full 的延迟，自适应门控是事后设计而非冻结确认；
6. **预训练暴露无法排除**：虽然图像不重叠且协议冻结，但无法保证预训练语料中没有相关图像或标注信息；
7. **开放生成验证薄弱**：选项无关（option-free）的适配仅用 Qwen3-I 测试，范围有限；
8. **后验分析混杂风险**：部分机制分析与人工审计在方法确定后进行，作者虽明确标注，但读者需注意这属于解释性分析而非承诺性验证。
