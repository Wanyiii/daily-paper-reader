## 摘要
高精地图对于自动驾驶系统至关重要。在构建此类地图时，车载多视角摄像头图像、标准定义地图和卫星图像提供了关键信息。然而，由于这些数据源之间的模态和视角差异，现有方法往往难以有效地对齐和融合它们，使得在线高精地图构建仍然具有挑战性。为解决这些问题，我们提出了Driver2Map，一个受人类驾驶员启发的在线高精地图构建模型。与仅利用两种模态的现有高精地图构建模型不同，我们的Driver2Map能够同时利用三种模态。具体而言，我们提出了一种“两阶段对齐”策略，以减少不同模态之间的空间错位。此外，我们引入了“姿势引导的BEV融合”，这是一个BEV（鸟瞰图）生成模块，利用相机姿势信息自适应地加权多视角特征，从而在BEV生成过程中有效抑制跨视角特征重叠。我们还设计了一个“用于地图细化的预训练先验”模块，通过学习地图结构先验来细化初始预测，从而在动态遮挡下改进高精地图预测。大量实验表明，Driver2Map在IoU和AP指标上均优于现有方法。

## Abstract
High-definition (HD) maps are essential for autonomous driving systems. In constructing such maps, onboard multi-view camera images, standard-definition maps and satellite images provide crucial information. However, due to the modality and perspective differences among these data sources, existing methods often struggle to effectively align and fuse them, making online HD map construction still challenging. To address these issues, we propose Driver2Map, an online HD map construction model inspired by human drivers. Unlike existing HD map construction models that utilize only two modalities, our Driver2Map can simultaneously exploit three modalities. Specifically, we propose a "two-stage alignment" strategy to reduce spatial misalignment across different modalities. Additionally, we introduce "Pose-Guided BEV Fusion", a BEV (bird's-eye-view) generation module that leverages camera pose information to adaptively weight multi-view features, thereby effectively suppressing cross-view feature overlap during BEV generation. Also, we design a "Pretrained Prior for Map Refinement" module to refine the initial prediction by learning map structure priors, thus improving the HD map prediction under dynamic occlusions. Extensive experiments demonstrate that Driver2Map outperforms existing methods on both IoU and AP metrics.

## 1. 核心问题与研究动机

- **背景**：高精（HD）地图为自动驾驶提供车道分隔线、道路边界、人行横道等精细几何与语义信息，是定位和路径规划的关键先验。传统离线建图依赖人工标注，成本高、耗时长，且动态道路环境要求地图持续更新。因此近年研究倾向于利用低成本的车载摄像头进行在线高精地图构建。
- **核心问题**：
  - 现有方法通常只利用两种模态（相机 + SD map 或相机 + 卫星图），尚未有工作同时整合三种模态。SD map 提供道路拓扑结构但缺少道路细节；卫星图提供全局鸟瞰视角和纹理细节，但缺乏拓扑信息且易被建筑物遮挡。如何共同利用二者仍是一个开放挑战。
  - 多源数据（车载多视角图像、SD map、卫星图）之间不仅模态差异大，而且坐标系统不同，存在平移、旋转、缩放等几何错位，导致跨模态对齐与融合困难。
  - 已有的 BEV 生成方法在融合多相机特征时忽略了相机间位姿关系，导致跨视角特征干扰（如尾部相机特征可能误导前方 BEV 区域），造成细粒度信息丢失。
  - 行驶中动态物体（车辆、行人）造成的遮挡会导致地图构建不完整。
- **核心思想（受人类驾驶启发）**：人类驾驶员建图过程可概括为——先感知周围环境形成初步理解，再聚焦关键道路区域进行结构识别，最后利用驾驶经验在遮挡时推断缺失信息。Driver2Map 将这一过程建模为四个阶段：

  1. 环绕感知：用多视角图像生成初始 BEV 表示；
  2. 关键区域检测：用 SD map 的拓扑结构引导道路骨架识别；
  3. 细节观察：用卫星图像补充车道级精细几何；
  4. 经验推断：用预训练 HD map 结构先验恢复被动态遮挡的地图元素。

## 2. 方法论

### 2.1 总体框架

整体流程：多视角图像经 EfficientNet-B0 编码 → Pose-Guided BEV Fusion 模块生成初始 BEV 特征 → 与 ResNet 编码的 SD map 特征做交叉注意力（Topology Enhancement，结构增强）→ 再与 ResNet 编码的卫星图特征做交叉注意力并叠加细对齐（Detail Enhancement，细节增强）→ 分割头 H1 预测初始地图 P_init → 输入 PPMR 模块（分割头 H2）输出细化后的最终地图 P_final。语义类别为 3 类（divider、crossing、boundary），输出形状为 (3+1) × H × W。

### 2.2 Pose-Guided BEV Fusion（PGBF，位姿引导的 BEV 融合）

- **动机**：相机位于车辆不同方位，朝向和距离不同，不同相机对同一 BEV 位置的贡献应有差异。例如 BEV 前方区域应主要由前置相机主导，并平滑过渡地融合前左、前右相机的补充信息。
- **方法**：根据每个相机的朝向角度 θ_cam 和水平视场角 θ_view 将 BEV 空间划分为 6 个扇形区域后，对位置 (x,y) 计算每个相机的权重：
  - **距离权重**：W_dis(x,y) = 1 / d_i(x,y)，d_i 为到该相机扇区几何中心的欧氏距离；
  - **方向权重**：W_ori(x,y) = cos(δ_i(x,y))，当 δ_i ≤ ½θ_view 时；否则为 0，其中 δ_i = |θ(x,y) − θ_cam|，用于抑制视场角之外的区域；
  - **归一化融合权重**：W_cam = (α·W_dis + β·W_ori) / Σ_j(α·W_dis^j + β·W_ori^j)，α 和 β 为平衡系数（实验取 α:β = 1:2）；
  - 最终 BEV 特征为六个相机特征按权重加权求和：F_bev(x,y,c) = Σ_i W_cam^i(x,y)·F_cam^i(x,y,c)。
- **特点**：权重完全由相机几何标定参数决定，无需网络学习，可直接迁移至不同相机配置。

### 2.3 两阶段对齐策略（Two-Stage Alignment）

解决三类图（nuScenes 路网图、SD map、卫星图）坐标系不一致导致的错位问题：

- **粗对齐（数据准备阶段）**：以 nuScenes 路网图为参考坐标系，对每个城市区域人工选取 N=50 对同名地物关键点（道路交叉口、端点、桥梁、边界等），分别对 SD map 和卫星图用最小二乘法独立拟合仿射变换参数（x′ = ax + by + e; y′ = cx + dy + f），得到区域级映射。对每个样本，根据自车位姿 p_i = (x_i, y_i, θ_i)，将坐标变换后作为裁剪中心，按航向角旋转并裁剪出 100×200 像素的 SD 和卫星图局部图块。
- **细对齐（模型内可学习）**：在 Detail Enhancement 阶段，将交叉注意力特征 F_ca 与结构增强 BEV 特征 F_bev 拼接，经卷积层预测稠密 2D 光流场 Δ ∈ R^{H×W×2}，再用双线性采样对 F_ca 进行可微变形：F̃_ca(p) = F_ca(p + Δ(p))，以消除残余亚像素级错位。

### 2.4 预训练先验用于地图细化（Pretrained Prior for Map Refinement, PPMR）

- **动机**：动态物体遮挡导致初始预测不完整，人类驾驶员会依据长期驾驶经验推断被遮挡的道路结构。
- **方法**：采用掩码自编码器（MAE）+ 分割头 H2 的结构。
  - **预训练**：在 nuScenes 训练集的 GT HD map 上随机掩码以模拟动态遮挡；由于 divider、crossing、boundary 三类空间分布极不平衡，采用类别维度的 patch 掩码策略；若某个 patch 在全部三个语义类上被完全掩码，则替换为随机部分像素掩码以保留部分监督信号，防止训练信号完全丢失。
  - **动态类别权重**：为缓解类别不平衡，根据每个 epoch 后各类 IoU 动态调整下一轮语义损失的类别权重：w_i_loss = 3 · norm(exp(1 − IoU_i)) · exp(1 − mean(IoU))，使权重归一化到和为 3.0，且总的 IoU 低时损失绝对幅度增大以加速学习。
  - **微调**：预训练完成后将整个模块集成到主干网络中，冻结主干，仅微调 PPMR 模块。

### 2.5 训练策略

三阶段训练：① 训练不含 PPMR 的主干网络（学习率 1×10⁻³）；② 使用动态类别权重单独预训练 PPMR（学习率 8×10⁻⁴）；③ 将 PPMR 集成回主干、冻结主干微调（学习率 5×10⁻⁵）。优化器为 AdamW。

## 6. 主要结论与发现

- **三模态融合有效**：完整输入（C+SD+Sat）在两种 BEV 范围和两个指标上均取得最优结果，证明 SD map 的拓扑先验与卫星图的细节先验互补。
- **PGBF 贡献最大**：移除 PGBF 后 mIoU 下降 10.0（54.0→44.0）、mAP 下降 5.4（62.9→57.5）；对跨越类别（Crossing）影响尤其显著（IoU 53.4→38.7），验证了位姿引导融合能有效抑制跨视角重叠、提升实例一致性。
- **两个先验各有侧重**：去除卫星图导致 mIoU 下降更明显（54.0→49.2 vs 54.0→50.0），说明卫星图对像素级细节更重要；SD map 则对保持拓扑结构有不可替代的作用。
- **α:β = 1:2 最优**：方向权重比距离权重贡献更大，且模型在 1:2 附近对该超参数不敏感，具有一定鲁棒性。
- **PPMR 有效改善遮挡恢复**：去掉 PPMR 后 mIoU 下降 0.9、mAP 下降 0.8，并在夜间低照度场景中展现出较强的恢复能力

- **综合来看**：Driver2Map 通过将人类建图认知过程分解为“环绕感知—关键区域检测—细节观察—经验推断”四个阶段，成功融合了相机、SD map、卫星图三种模态，并通过位姿引导融合与两阶段对齐缓解了多源数据错位问题，在 nuScenes 上取得了竞争力强的结果。消融实验进一步验证了各模块的有效性，尤其是 PGBF 带来的大幅提升，体现出几何先验在多相机 BEV 融合中的关键作用。

## 7. 局限性与未来研究方向

- **数据集单一**：所有实验仅在 nuScenes（波士顿海港区域）上进行，该数据集场景相对固定，缺乏不同国家、不同交通规则、不同道路形态（如环岛、高速匝道）的验证。未来需要在 Argoverse 2、Waymo Open Dataset 等更大规模、更多样化的数据集上评估泛化能力。
- **输入依赖**：方法依赖高精度的车辆位姿（用于裁剪和旋转 SD 图/卫星图）以及区域级的粗对齐标定。在 GNSS 信号弱或地图偏移较大的场景下，粗对齐质量会直接影响后续细对齐的收敛效果，鲁棒性尚未验证。
- **动态物体处理有限**：PPMR 虽然能在一定程度上通过先验恢复被遮挡元素，但仅依赖语义类别先验，未显式建模动态物体的时空状态；对于长时间大面积遮挡（如前方卡车长期遮挡整个路口）可能仍会失效。
- **可拓展性**：当前框架针对 6 相机、固定 BEV 范围设计，若更换传感器配置（如 4 相机或 8 相机）虽可迁移权重公式，但需重新调节 α:β 超参数；卫星图与 SD map 的获取也依赖外部地图服务，实时在线更新时存在网络延迟和数据新鲜度问题。
- **未来方向**：可引入时序信息（如视频片段）增强动态遮挡下的时空一致性；利用多任务学习（如同时预测速度、可行驶区域）提升先验丰富度；探索端到端的三模态对齐网络以替代人工标定的粗对齐；以及在真实自动驾驶平台上进行闭环测试验证。

## 8. 总体评价

Driver2Map 在问题定义上具有新意，将认知建模引入在线高精地图构建，并通过工程上巧妙的设计（PGBF、两阶段对齐、MAE 预训练）解决了多模态融合的实际困难。论文写作结构清晰，实验对比充分，消融分析细致，具有较强的可复现性（权重公式明确、训练策略具体）。虽然存在数据集单一、对比不完全统一等不足，但整体上对在线高精地图领域贡献了有价值的多模态融合思路，尤其为“低成本视觉 + 公共导航地图”的组合提供了可行方案，值得后续研究者借鉴。
