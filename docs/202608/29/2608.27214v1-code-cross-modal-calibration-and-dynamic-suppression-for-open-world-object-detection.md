## 摘要
基于多模态基础模型的开放世界目标检测（OWOD）常因单向文本到视觉匹配而导致语义歧义，而刚性异常值惩罚可能过度抑制已知类别决策边界附近的未知对象。我们提出CODE（跨模态校准与动态抑制），一个统一的推理时框架，包含三个互补组件。跨模态联合置信度校准通过注入全局视觉原型来校准文本驱动的已知类别预测。不确定性引导的通用对象性增强通过衡量局部视觉响应中的分类犹豫来增强潜在未知对象。基于置信度裕度的动态异常值抑制以裕度感知调整替代刚性抑制，保留模糊的分布外实例。在真实世界检测基准上的实验表明，使用OWL-ViT L/14骨干网络，CODE在任务1中实现了21.7 U-mAP和40.8 K-mAP，分别超过先前最先进方法2.6和2.3个百分点。

## Abstract
Open World Object Detection (OWOD) built on multimodal foundation models often suffers from semantic ambiguity caused by unidirectional text-to-vision matching, while rigid outlier penalties may over-suppress unknown objects near known-class decision boundaries. We propose CODE (Cross-Modal Calibration and Dynamic Suppression), a unified inference-time framework with three complementary components. Cross-Modal Joint Confidence Calibration injects global visual prototypes to calibrate text-driven known-class predictions. Uncertainty-Guided Universal Objectness Enhancement measures classification hesitation from local visual responses to strengthen potential unknown objects. Dynamic Outlier Suppression via Confidence Margin replaces rigid suppression with a margin-aware adjustment that preserves ambiguous out-of-distribution instances. Experiments on the Real-World Detection benchmark demonstrate that, with the OWL-ViT L/14 backbone, CODE achieves 21.7 U-mAP and 40.8 K-mAP in Task 1, surpassing the previous state of the art by 2.6 and 2.3 points, respectively.

## 1. 核心问题与研究动机

- **背景**：传统的封闭世界目标检测假设推理时遇到的类别严格限定为训练时的已知类别，无法应对现实世界中不断涌现的新颖对象。开放世界目标检测（OWOD）要求模型在准确识别已知类别的同时，定位并标记未知对象，且不能将其与背景或已知类别混淆。
- **现有方案的不足**：基于多模态基础模型（如CLIP、OWL-ViT）的OWOD方法通常采用属性驱动的范式，即将抽象类别分解为细粒度、类无关的属性（形状、颜色、纹理等）作为中间语义表示。但该范式存在三个本质缺陷：
  1. **单向文本到视觉匹配导致的语义歧义**：当视觉属性受遮挡、模糊、视角变化或缺光影响时，纯文本属性难以区分困难对象与视觉相似的已知类别或背景区域。
  2. **通用目标性估计不可靠**：以最大属性响应作为目标性分数，无法可靠地将模糊的未知对象与背景干扰物区分开来。
  3. **刚性异常抑制（MCM）过度惩罚边界未知对象**：仅依据最大已知类概率确定的抑制项会错误地将与多个已知类共享属性的边界未知对象清除为背景。
- **核心意义**：提出一种轻量级、统一的推理时增强框架，在不重新训练检测器的情况下，同时改善已知类识别精度与未知类召回率，缓解已知/未知检测之间长期存在的权衡矛盾。

## 2. 方法论

### 2.1 整体框架

CODE 构建在属性驱动的 OWL-ViT 基线之上，包含三个互补组件：**CMJCC**（跨模态联合置信度校准）、**UGUOE**（不确定性引导的通用目标性增强）和 **DOSCM**（基于置信度裕度的动态异常抑制）。属性和视觉原型均离线预计算，推理阶段不调用 LLM。

### 2.2 基线：属性驱动 OWOD

- 利用 LLM 为每个已知类生成属性描述，通过文本编码器形成属性池。
- 通过优化损失（交叉熵 + 偏最优传输 + MSE + L1 正则）选择判别性属性并学习映射矩阵 W。
- 候选区域视觉嵌入 v 的 logits 计算为：Logit = sim(v, A)·W，其中前 K 列为已知类 logits，最后一列为未知类 logit。
- 未知概率由已知类 logit 经 Sigmoid 得到的 logit_U、任务相关性 p_ID 和 OOD 分数 p_OOD 三者乘积决定；p_OOD 采用标准 MCM 机制（1 − max Softmax(Known Logits)）。

### 2.3 CMJCC：跨模态联合置信度校准

- **视觉原型构造**（离线）：对每个已知类 k，从标注框提取的区域嵌入取归一化质心作为原型 p_k，组成视觉基矩阵 V_base = [p_1, …, p_K]⊤，推理过程中不更新。
- **视觉相似度与门控**：计算候选区域与原型的直接视觉相似度 Sim_vis，并通过候选特定动态阈值 τ_i（均值 + 裕度 m，最低下限 τ_min）和 ReLU 门控得到视觉增强项 Logit_boost。
- **联合校准**：校准后的已知 logits = 文本驱动已知 logits + α · S_scale · Logit_boost，其中 S_scale = 1/τ_OWL-ViT（≈14.28）为基于基础模型内在温度的反向缩放因子，α为调制系数。由此为文本预测注入鲁棒的视觉到视觉参考。

### 2.4 UGUOE：不确定性引导的通用目标性增强

- **局部视觉响应聚合**：取候选区域与视觉原型相似度的 Top-K_u 个值 S_local，计算平均值 μ_unk 作为基础视觉未知响应。
- **不确定性建模**：利用 S_local 的无偏方差 σ² 量化分类“犹豫”——已知对象的高方差响应集中在一个原型，而未知对象的低方差响应均匀分布，则表明语义真空中的候选。
- **不确定性权重**：采用指数衰减函数 W_unc = exp(−γ·σ²)，并将其裁剪至 [w_min, w_max]，高确定区域受罚，低方差模糊候选受青睐。
- **增强未知 logit**：Logit_enh_U = Logit_U + β · S_scale · W_unc · ReLU(μ_unk − τ_unk)，提升“语义真空”中潜在未知对象的响应。

### 2.5 DOSCM：基于置信度裕度的动态异常抑制

- **置信度裕度**：从校准已知 logits 的 Softmax 分布中取 Top-1 与 Top-2 概率，计算 ΔS = S_top1 − S_top2。大 ΔS 表示对单一已知类的排他性确信，小 ΔS 表示边界模糊。
- **动态抑制**：将 MCM 惩罚项改为 MCM_eff = S_top1 · ΔS，动态 OOD 分数 p_dyn_OOD = 1 − MCM_eff。
- **最终推理**：P_final_U(v) = σ(Logit_enh_U) · p_ID · p_dyn_OOD。该方法解耦了最大 Softmax 响应与惩罚机制，保护共享多类属性的边界未知对象。

## 3. 实验设计

## 6. 主要结论与发现

- **CODE 全面超越现有方法**：在 OWL-ViT L/14 下，Task 1 的 U-mAP 达 21.7（+2.6 vs PASS）、K-mAP 达 40.8（+2.3 vs PASS）；Task 2 的 PK-mAP 达 43.6（+4.7）、CK-mAP 达 36.2（+0.2）。B/16 下四项指标分别提升 +1.6、+0.6、+2.0、+2.4。
- **各场景提升不均**：最大改进在 Surgery Task 1（U-mAP +9.1）；Game 场景出现性能下降（U-mAP −2.8、K-mAP −1.7），归因于极高的类间余弦相似度（0.82）。
- **模块分工明确**：CMJCC 改善已知类判别（Surgery 上 K-mAP 从 43.0 提升至 45.0）；UGUOE 大幅提升未知召回但可能牺牲已知精度；DOSCM 在恢复已知精度的同时进一步改善未知发现。
- **替代方法验证**：DOSCM（25.7 U-mAP）优于 Energy（21.2）、MaxLogit（2.8）和全局熵（1.0）；UGUOE 的局部视觉方差优于已知 logit 熵（25.7 vs 17.0）。
- **原型效率**：50 个以上样本即可获得稳定的原型估计；N=25 属性在精度与效率间达到最佳平衡。

## 7. 优点

- **轻量级推理时增强**：无需重新训练检测器，且相较 Transformer 骨干额外开销低于0.1%的FLOPs和5%的延迟，实用性强。
- **模块设计逻辑清晰、互补性强**：三个组件分别针对“已知校准→未知激活→边界保护”三个环节，消融实验验证了其互补性而非简单叠加。
- **引入视觉原型弥补文本驱动局限**：CMJCC 以视觉到视觉的参考来校准单向文本到视觉匹配，是一种直观而有效的跨模态补全策略。
- **动态抑制机制设计精巧**：DOSCM 用 Top-1/Top-2 的置信度裕度衡量预测的排他性，把握住了“边界未知对象必然导致分类犹豫”这一关键现象。
- **实验体系较为完整**：涵盖增量与移除双协议消融、参数敏感性、替代方案对比、泛化验证和丰富的可视化，并坦诚报告了失败案例（Game、类混淆等）。
- **验证了“无需牺牲已知精度也可提升未知发现”的核心主张**：在多数场景中 U-mAP 和 K-mAP 同步提升。

## 8. 不足与局限

- **对数据稀缺和标注质量敏感**：视觉原型是数据集特定的质心估计，实验仅隔离了样本规模的影响（10-shot 时性能大幅下降），未覆盖长尾分布、噪声标注、跨域分布偏移等更复杂情形。
- **难以处理高类间相似度的细粒度场景**：Game（类间相似度 0.82）和 Surgery（0.87）中仍存在类别混淆；Surgery Task 2 的 CK-mAP 比 PASS 低 7.7 点，说明视觉校准在高度重叠类别的场景中效果有限。
- **对预训练基础模型的依赖**：CODE 作为冻结模型之上的校准层，其性能上界受限于 OWL-ViT 等的零样本泛化与判别能力。
- **原型表示粒度有限**：每类单质心可能无法捕捉视角变化、遮挡等导致的类内多样性。
- **动态抑制的双刃剑效应**：DOSCM 在保护边界未知对象的同时可能过度放松抑制界限，导致已知对象被误判为未知（Game 和 Aquatic 场景中均出现此问题）。
- **算力信息不透明**：未报告 GPU 数量、总训练时长、多次运行的标准差等信息，影响结果的可复现性评估。
- **基准覆盖仍有限**：主实验基于 RWD 基准（样本量最小的 Medical 仅182张图像），泛化实验相对简略，不同数据集间的差异较难归因于单一因素。
