## 摘要
计算机使用智能体在截图上将自然语言指令与界面元素对应起来以进行定位，然而现有基准测试并未检验模型能否将关系语言与正确元素绑定。我们引入了GUI-Primitives，这是一个包含994个对比指令对的基准测试，覆盖图形用户界面中七种空间关系（左/右、上/下、包含、对齐、邻近、列表序数、遮挡）。每个配对保持截图和锚点固定，仅改变关系表达式，因此正确的目标会在两个指定候选之间移动。五名标注者验证了一个包含196项的子集（κ=0.94表示结构良好性；κ=0.79表示目标选择）。十九个视觉语言模型在最严格的点入框准确率上最多达到32%。由于模型输出无约束的坐标，我们根据预测落入的候选区域对其进行分类。在60%至92%的项目中，预测落在两个候选区域之外。在落入候选区域的前提下，对于水平位置、垂直位置、邻近和列表序数，目标选择准确率达到0.82-0.90，但对于包含和遮挡，则与0.50无显著差异：大多数失败反映了候选定位问题，而非关系理解问题。在十个模型上，基准测试准确率与ScreenSpot-Pro准确率相关（Spearman ρ=+0.74），这在此样本量下属于探索性关联。标记两个指定候选可将选择准确率提高35至57个百分点，这是一种提供候选集的预言机诊断方法，而非可部署的方法。我们发布了该基准测试、预测结果和代码。

## Abstract
Computer-use agents ground natural-language instructions in screenshots to locate interface elements, yet existing benchmarks do not isolate whether models bind relational language to the correct element. We introduce GUI-Primitives, a 994-item benchmark of contrastive instruction pairs over seven spatial relations in graphical user interfaces (left/right, above/below, containment, alignment, proximity, list ordinal, occlusion). Each pair holds the screenshot and anchor fixed while changing the relation expression, so the correct target moves between two designated candidates. Five annotators validate a 196-item subset ($κ= 0.94$ well-formedness; $κ= 0.79$ target selection). Nineteen vision-language models reach at most $32\%$ strict point-in-box accuracy. Because models emit unconstrained coordinates, we classify each prediction by the candidate region it falls within. Predictions fall outside both candidates on $60-92\%$ of items. Conditional on falling within a candidate region, target selection reaches 0.82-0.90 for horizontal position, vertical position, proximity, and list ordinal, but does not differ significantly from 0.50 for containment and occlusion: most failures reflect candidate localization rather than relation understanding. Across ten models, benchmark accuracy correlates with ScreenSpot-Pro accuracy (Spearman $ρ= +0.74$), an exploratory association at this sample size. Marking the two designated candidates raises selection accuracy by 35--57 percentage points, an oracle diagnostic that supplies the candidate set rather than a deployable method. We release the benchmark, predictions, and code.

### 一、核心问题与整体含义（研究动机与背景）

- **问题背景**：计算机使用智能体（Computer-use Agents）依赖视觉语言模型（VLM）在截图上将自然语言指令与界面元素进行"接地"（GUI grounding），输出点击坐标或按键。然而，该能力已成为部署瓶颈，尤其在高分辨率真实软件截图中表现不佳。
- **现有不足**：已有端到端基准（如 OSWorld）将接地与规划、执行混合，无法单独度量"空间关系理解"这一基础技能；粗粒度接地基准（如 ScreenSpot、ScreenSpot-Pro）只测最终点击是否落在目标框内，也无法区分失败源自哪种空间技能。
- **核心缺口**：当智能体点击错误按钮时，我们不知道是哪一种基本空间技能出了问题——是分不清"左边/右边"、"上/下"，还是不理解"包含"、"遮挡"或"对齐"？
- **核心问题**：论文提出一个可控的诊断基准，将空间关系理解从整体任务中隔离出来，回答："当前 VLM 是否真的具备 GUI grounding 所需的基础空间关系技能？"
- **整体含义**：论文用最小对比对（minimal pairs）方式剥离了视觉显著性和固定答案偏好，提供了一种可泛化的诊断范式，不仅服务于 GUI agent 的安全部署，也为后续改进指明方向：**主要瓶颈在候选定位（candidate localization），而非关系词理解**。

### 二、方法论

1. **核心思想：最小对比对诊断**
   - 每个条目（item）是"对比对"（contrastive pair）的一半：**同一截图 + 同一锚点 + 仅改变关系表达式**（如 `left of ↔ right of`、`inside ↔ outside`）。
   - 正确目标在配对的另一候选元素间移动，因此利用视觉显著性、位置先验或常见标签分布的捷径（shortcut）模型，会在配对的两个孪生条目上各得一分、各失一分，配对得分恒为零，从而有效控制混淆因素。
   - 该方法借鉴语言学中的最小对比对评测（Linzen et al., 2016）与视觉-语言对比对评测（WHAT'S-UP, Kamath et al., 2023）。

2. **七个空间基元（Primitives）**
   - 分为三组：**方向**（水平相对位置、垂直相对位置）、**拓扑**（包含 containment）、**布局**（对齐、邻近、列表序数、遮挡）。
   - 每个基元均有 142 个条目（左右各 71 条），全部为二元对比对，因此参考水平统一为 0.50（表 1）。

3. **数据来源**
   - **真实桌面截图**（n=290）：来自 UI-Vision（Nayak et al., 2025），覆盖 Web、MacOS、VS Code、Office 及专业应用，涵盖水平/垂直位置、对齐、邻近，以及 24 条真实列表序数条目。
   - **合成截图**（n=704）：程序化渲染器生成，元素位置已知、干扰项受控，是唯一可干净获得包含、遮挡及剩余列表序数条目的途径。合成臂被视为受控刺激臂，报告时与真实臂分开。

4. **人类验证**
   - 5 名标注者独立判定 196 条分层抽样子集的两个问题：结构良好性与正确目标。
   - 一致度高：κQ1=0.942（几乎完美）、κQ2=0.787（实质性）；保留 185 条为"人类干净核心"，人类准确率 96.9%。

5. **评估协议**
   - 16 个模型采用贪心解码（T=0）、固定种子；所有模型使用统一的坐标解析器（支持像素、[0,1] 归一化、[0,1000] 等坐标约定）。
   - **封闭 API 坐标重缩放**：Anthropic、OpenAI、Gemini 会在服务端降采样大截图并返回降采样帧坐标；需要预先缩放到已知边长，再按比例映射回原像素空间。
   - 指标：严格点内准确率（point-in-box）为主指标；松指标（loose，2 倍目标对角线内）区分亚像素误差与元素误判；配对比较用 McNemar 检验 + Holm-Bonferroni 校正；置信区间为 bootstrap（2000 次重采样）。

6. **候选级分类与分析**
   - 每一条基线预测按其落入的候选区域被分类为：目标（target）、干扰项（distractor）、两者之外（neither）、无效（invalid）。
   - 进一步计算**区域内选择率**（within-region selection rate）以区分"候选定位失败"和"关系词理解失败"。

### 三、实验设计

1. **基准与数据集**
   - **GUI-Primitives**：994 条条目（497 对）× 7 个空间关系基元；包含真实（290）与合成（704）两个子集；发布与验证的核心为 185 条"人类干净核心"。
   - 同时还运行了 **ScreenSpot-Pro**（Li et al., 2025）作为下游接地的关联基准。

2. **模型规模与类型**
   - 共评估 **19 个视觉语言模型**：
     - 7 个封闭 API 模型：Claude Opus 4.7、Sonnet 4.6、Haiku 4.5、GPT-5、GPT-4.1、GPT-4o-mini、Gemini 3.1 Flash Lite。
     - 12 个开放权重模型：Qwen2.5-VL-7B、Qwen2-VL-7B、OS-Atlas-Base-7B、InternVL3-8B、Llama-3.2-11B-Vision、Gemma 3（4B/12B/27B，含 Ollama Q4 变体）、PaliGemma 2（3B/10B）、MiniCPM-V。
   - 排除 Pixtral-12B 和 Idefics3-8B（聊天模板与统一封装不兼容）。

3. **干预实验**
   - **Set-of-Mark（SoM）**：在目标与干扰项上叠加编号标记（oracle 条件），模型选择标记号而非回归坐标。属于"预言机诊断"，因为提供了候选集合，并非可部署方法。
   - **Primitive-aware CoT**：预置分解提示，显式命名空间关系并要求模型先推理再输出点击。
   - **激活引导（Activation Steering）**：基于 SteerVLM 框架，在 Qwen2.5-VL-7B 的第 12–19 层残差流中加入正确/错误样本的均值差向量，搜索 α ∈ {1, 2, 4, 6}。

4. **捷径控制（Shortcut Controls）**
   - 文本唯一（blank canvas）：准确率下降 -15.5 个百分点。
   - 截图打乱（shuffled）：准确率下降 -7.2 个百分点。
   - 重度高斯模糊（σ=12 px）：下降 -5.3 个百分点（显著但低于预设 10 点阈值）。

5. **关联分析**
   - 对 10 个同时有 GUI-Primitives 和 ScreenSpot-Pro 预测的模型计算 Spearman 相关（ρ=+0.736, p=0.015）；在真实子集与合成子集内部依然成立。
   - 条目级 logistic 回归（n=15,810，模型固定效应、log 目标面积控制、条目聚类标准误），pseudo-R²=0.404，仅报告模型级关联，不强调逐原始系数。

   - **优点**：控制了坐标框架歧义（封闭 API 重缩放），对每项结果给出 bootstrap 置信区间，并使用 Holm-Bonferroni 校正多重比较，统计上较严谨；配对设计与两级人工验证增加了数据可信度。
   - **不足**：样本量在若干处偏小——10 个模型的 Spearman 相关为探索性结果（置信区间宽，[+0.11, +0.98]），作者也明确声明；每个原始上仅 142 条，区域识别率在若干原始上因 p 高而变弱；干预实验仅覆盖 4 个模型，SoM 增益的普适性有限。
   - **总体**：作为一个诊断基准论文，实验的覆盖面充分、控制严格；但在跨模型相关和合成向真实泛化方面，证据强度有限，作者对此做了诚实披露。

### 六、主要结论与发现

1. **模型表现大幅低于人类**
   - 最强模型 Claude Opus 4.7 在人类干净核心上仅 32.4% 点内准确率，人类为 96.9%，**差距高达 65 个百分点**。
   - 模型排名在多个子集上稳定，差距不是噪声条目所致。

2. **失败主因是候选定位，而非关系理解**
   - 60–92% 的预测落在目标与干扰项两个候选区域之外。
   - 在落在候选区域之内的预测上，水平/垂直位置、邻近、列表序数的目标选择率达 0.89–0.90，说明模型一旦大致定位到区域，就可以正确解读关系词。
   - 唯一例外是**包含**（0.548）与**遮挡**（0.554）两个原始，区域内选择率与随机 0.50 无显著差异，说明这两个关系词几乎没有被利用。

3. **对关系词的使用存在方向性先验**
   - "左"条件下的区域内准确率（0.972）显著高于"右"（0.717）；"下"高于"上"。
   - 预测落在候选区域内的频率在目标任务为左侧元素时高 2.7 倍。
   - 作者将此解释为可能来自 Western GUI 中左侧元素更频繁的先验，不主张因果断言。

4. **原始技能与下游接地表现相关性**
   - GUI-Primitives 准确率与 ScreenSpot-Pro 准确率显著相关（Spearman ρ=+0.736, p=0.015，n=10）；该关联在真实/合成子集内均成立，且非单一模型驱动。

5. **SoM（oracle 标记候选）显著提升表现**
   - GPT-5：30%→87%（+57.1 点）；OS-Atlas：10%→52%（+42.1 点）；Qwen2.5-VL：22%→57%（+35.1 点）；Opus 4.7：31%→40%（+9.2 点，不显著）。
   - SoM 增益与基线准确率大致成反序；但 SoM 提供候选集合，因此是任务改造而非技能修复，为**预言机上限**，不是可部署方案。
   - 值得注意的是：在模型已饱和的列表序数上，SoM 反而带来 -32.4 点的回归（Qwen2.5-VL）。

6. **CoT 与激活引导无效**
   - Primitive-aware CoT：∆=+0.5 点，不显著。
   - 激活引导：∆=+1.5 点，不显著。
   - 模型在中间推理中已能正确说出关系词，但仍输出错误坐标；失败点更接近感知/跨模态绑定层，而非语言侧推理。

7. **捷径控制验证基准有效性**
   - 移除视觉信息或打乱截图均显著崩溃准确率，说明任务确实依赖截图与指令的匹配；模糊控制仅造成中等下降，提示模型更依赖全局布局而非精细 OCR。

### 七、优点

- **最小对比对设计**：在相同截图和锚点下仅改变一个关系表达式，强有力地消除了截图显著性、中心偏好和固定答案先验，让分数直接反映关系理解。
- **候选级分析**：将预测划分为目标/干扰项/两者之外，揭示了"主要失败在候选定位"这一关键结论，比简单准确率深刻得多。
- **人类验证机制**：5 名标注者独立双重验证（结构良好性与目标选择），并报告 Fleiss κ，数据质量可信。
- **多模型、多源覆盖**：19 个模型涵盖封闭/开放、不同规模与家族；真实 + 合成双数据集，且按源臂分开报告结果。
- **严格统计**：bootstrap 置信区间、Holm-Bonferroni 多重比较校正、集群鲁棒性重采样、留一模型敏感性分析，统计规范。
- **工程细节透明**：对封闭 API 坐标重缩放问题有专门附录（Appendix E），并建议社区后续按此处理，实用价值高。
- **负面结果如实报告**：CoT 与激活引导的无效结果被以与正面结果同等篇幅报告，避免发表偏倚。
- **资源开放**：基准、全部预测文件和代码全部开源。

### 八、不足与局限

- **两个原始仅合成源**：包含与遮挡缺乏真实 GUI 数据集中的父-子或覆盖层-目标元数据，因此只在合成臂出现；有限外部效度，作者明示这一限制。
- **列表序数数据混合**：142 条中仅 24 条来自真实截图，其余为合成；真实列表序数的代表性一般。
- **下游验证止步于 ScreenSpot-Pro**：未在 OSWorld 或 OSWorld-Verified 等端到端任务环境上验证，任务成功率相关性未知。
- **语言与动作范围有限**：v1 仅覆盖英文指令和点击目标，不包含拖拽、双向布局、CJK 场景及 OSWorld 行动前接地切片。
- **SoM 非直接可部署**：依赖上游检测器提供候选集；最多只叠加两个标记，真实场景的多候选项集的增益可能不成立。
- **点内准确率粗粒度**：漏 1 像素和点错整个元素分数相同；松指标仅部分缓解，未捕捉结构化空间误差（如锚点塌缩、方向反转）。
- **逐原始回归证据弱**：条目级回归中，各原始系数都很小且大部分不显著；作者只主张模型级关联，不主张因果。
- **小型样本相关的不确定性**：10 模型相关（Spearman）的窄样本置信区间极宽；作者自我描述为"探索性关联"，但该结论被引用于摘要核心位置，

### 九、未来工作展望

- **补充真实 GUI 数据中的难点原始**：针对包含与遮挡基元，可借助渲染工具或真实应用的可访问性树（accessibility tree）自动生成父-子与覆盖层标注，从而摆脱对合成数据的依赖，提升外部效度。
- **扩展下游端到端验证**：当前关联分析仅使用 ScreenSpot-Pro，未来应在 OSWorld 或其筛子集（OSWorld-Verified）上运行完整 agent，检验基础空间技能是否真实转化为任务成功率收益。
- **丰富语言与动作空间**：引入中文、阿拉伯语等非英语指令，覆盖 RTL 布局；加入拖拽、多指、双击等复杂动作，并增加跨分辨率的动态截图。
- **更细粒度的误差建模**：将点内二元准确率扩展为空间误差分解（如方向颠倒、锚点塌缩、对称误选等），为失败提供可操作的诊断信号。
- **探索候选定位的改进机制**：鉴于核心瓶颈是候选定位，可考虑将检测器/区域提案与空间关系理解解耦，或利用 SoM 标签作为训练时的辅助监督，而非纯推理时干预。
- **增大统计功效**：扩大模型数量与每个原始条目数，使逐原始分析和跨模型相关具有更小置信区间，从而支撑更稳健的结论。

### 十、总体评价

本论文构建了一个设计精巧、控制严格的 GUI 空间关系诊断基准，通过最小对比对将“关系词理解”从视觉显著性等混淆因素中剥离，并借助候选级分类揭示了当前 VLM 的失败主因——候选定位而非关系理解。这一发现比单纯的准确率排名更具价值，直接指引了后续研究应聚焦于感知/绑定层而非语言推理。同时，论文在统计规范、工程透明性、负面结果报告与开源发布方面均表现出较高的学术标准。局限性主要体现为真实数据覆盖不足、下游验证有限和部分统计功效偏弱，但作者对这些不足有清晰披露。总体而言，该基准为 GUI grounding 研究提供了可靠且可复用的诊断工具，也为构建更安全的 computer-use agent 铺设了基础评估阶梯。
