## 摘要
作为具身智能的关键能力，三维视觉定位（3DVG）主要在以RGB-D或点云为输入的室内场景中得到研究，而现有的室外扩展则大多仅依赖单目图像。这两种设置都无法满足真实世界的室外感知需求，因为在室外场景中，异构传感器捕获到的是互补但不同的物理属性，例如视觉纹理、三维几何和物体运动学，这些属性对于灵活稳健的查询自适应定位不可或缺，却仍未得到充分利用。为弥补这一差距，我们提出了Talk2Sensors，这是首个基于相机、激光雷达和4D雷达的多传感器三维视觉定位数据集。它包含8,682条语言指令和20,558个被引用对象，并带有与传感器特定物理线索明确对齐的多样化提示。此外，我们提出了TSFormer，一种用于自动驾驶中语言引导的三维视觉定位的统一Transformer框架。TSFormer采用由粗到细的属性感知融合策略：语言路由属性采样器首先通过使用查询级语言线索调制传感器采样权重来执行粗略的文本条件特征检索，而随后的稀疏保持模态仲裁器模块则进行细粒度的模态仲裁和文本引导细化，以确定精确的引用空间位置。这种设计能够根据每个提示的语义要求动态路由外观、几何和运动线索，防止密集模态淹没稀疏但关键的传感器信号。大量实验表明，TSFormer在多个基准上达到了最先进的性能：在Talk2Sensors上比最强基线提升了8.05 mAP，并在单目Mono3DRefer基准上以53.05%的Acc@0.5实现了迁移。

## Abstract
As a key capability for embodied intelligence, 3D visual grounding (3DVG) has been predominantly studied in indoor scenes with RGB-D or point-cloud inputs, while existing outdoor extensions largely rely on monocular images alone. Both settings fall short of real-world outdoor perception, where heterogeneous sensors capture complementary yet distinct physical properties, such as visual texture, 3D geometry, and object kinematics, that are indispensable for flexible and robust query-adaptive grounding but remain under-exploited. To bridge this gap, we introduce Talk2Sensors, the first multi-sensor 3D visual grounding dataset built upon camera, LiDAR, and 4D radar. It contains 8,682 language instructions and 20,558 referred objects, with diverse prompts explicitly aligned with sensor-specific physical cues. Furthermore, we propose TSFormer, a unified Transformer-based framework for language-guided 3D visual grounding in autonomous driving. TSFormer adopts a coarse-to-fine property-aware fusion strategy: the Language-Routed Property Sampler first performs coarse text-conditioned feature retrieval by modulating sensor sampling weights with query-level linguistic cues, while the subsequent Sparse-Preserving Modality Arbiter module conducts fine-grained modality arbitration and text-guided refinement to determine the precise referred spatial location. This design enables dynamic routing of appearance, geometry, and motion cues according to the semantic requirements of each prompt, preventing dense modalities from overwhelming sparse but critical sensor signals. Extensive experiments demonstrate that TSFormer achieves state-of-the-art performance across multiple benchmarks: it improves over the strongest baseline by 8.05 mAP on Talk2Sensors, and transfers to the monocular Mono3DRefer benchmark with 53.05\% Acc@0.5.

## 2. 方法论

### 2.1 整体架构（TSFormer）

TSFormer采用统一的端到端Transformer架构，包含四大组件：
- **多模态编码器**：ResNet-101+FPN（图像）、SparseEncoder-SECOND（LiDAR）、RadarFeatureNet+PointPillarsScatter（雷达）、CLIP ViT-B/32（文本）。
- **Language-Routed Property Sampler (LRPS)**：粗粒度文本条件特征采样。
- **Sparse-Preserving Modality Arbiter (SPMA)**：细粒度模态仲裁与文本细化融合。
- **Grounding Decoder**：DETR风格查询解码器，输出3D框。

### 2.2 Language-Routed Property Sampler (LRPS)

**核心思想**：避免依赖标定几何投影，将文本信息注入采样过程，让特征采样本身具备语言感知能力。

**关键步骤**：
1. **文本投影**：将全局文本特征 t 通过模态特定投影层映射到各传感器语义空间：$t_m = \phi_m(t)$。
2. **查询-文本相似度计算**：将投影后的文本特征与对象查询 Q 做通道级逐元素乘法并求和，得到查询级文本-传感器相似度图：$D_m = \sum_{c=1}^{C} (Q_{:,:,c} \odot t_{m,:,c})$。
3. **调制因子生成**：通过 sigmoid 和可学习的温度参数 $\tau_m$ 将相似度转换为有界调制因子：$G_m = \sigma(\tau_m D_m)$。
4. **注意力调制**：将调制因子广播到采样注意力权重上，在 Softmax 归一化前完成调制：$\tilde{A}_m = \text{Softmax}(A_m \odot E_{H,LP}(G_m))$。
5. **多尺度可变形采样**：采样点由参考点加偏移得到，最终通过可变形注意力聚合传感器特征：$O_m = \text{MSDeformAttn}(V_m, S_m, \tilde{A}_m)$。

**设计要点**：文本提示通过查询级调制因子动态调整不同空间位置的采样权重，使模型优先从与文本描述相关的区域提取特征。

### 2.3 Sparse-Preserving Modality Arbiter (SPMA)

**核心思想**：解决密集模态（相机）淹没稀疏但关键模态（雷达）的问题，进行语言引导下的模态级仲裁。

**关键步骤**：
1. **全局文本向量**：对文本token特征做平均池化并投影，得到全局语义向量 $t_g$。
2. **模态门控网络**：通过线性层+激活+LayerNorm生成模态门控 logits：$z = \eta_g(t_g)$。
3. **可选 Top-K 稀疏路由**：将门控 logits 与 Top-K 掩码 $m_{topk}$ 相乘，强制稀疏化，鼓励仅在少数关键模态上分配高权重。
4. **门控加权融合**：经 Softmax 归一化后，门控系数对各模态采样特征做加权求和：$F_s = \sum_{m \in M} \alpha_m O_m$。
5. **文本引导交叉注意力**：以融合特征为查询，文本token为键/值，进行多头交叉注意力细化，得到最终仲裁输出 $F_{SPMA}$。

### 2.4 Grounding Decoder 与训练目标

- 查询特征经多层Transformer解码器迭代精细化，最终由分类分支预测**指代置信度**（二分类：是否为文本所指对象）和回归分支预测**3D包围框**（中心坐标+尺寸+偏航角）。
- 采用 DETR 风格二分图匹配（匈牙利算法）进行集合预测训练，匹配代价融合指代置信度、L1回归损失和3D GIoU损失。
- 损失函数：最终层损失 + 各中间解码层的辅助监督损失。

## 6. 主要结论与发现

1. **多传感器融合有效的前提是语言引导的路由**：TSFormer 随模态增加性能单调提升（LiDAR-only: 46.18 → L+R: 48.28 → C+L+R: 51.00 EAA mAP），而 FUTR3D 在加入相机后反而下降（42.95），说明无语言引导的朴素融合会被密集相机特征主导，无法有效利用稀疏雷达信号。
2. **感知线索必须按查询动态路由**：TSFormer 的最大增益出现在雷达相关和全三传感器提示上（Camera+LiDAR+Radar 提示 +10.83 mAP），验证了属性感知融合的设计动机。
3. **LiDAR 是几何骨干**：在模态丢弃实验中，所有方法在移除 LiDAR 时都崩溃，验证了 LiDAR 在几何定位中的不可替代性。
4. **跨数据集泛化能力**：TSFormer 在 Mono3DRefer 上达到 53.05% Acc@0.5，超越专用单目方法 Mono3DVG-TR（44.25%），说明属性感知设计具有通用性。
5. **SPMA 有效保护稀疏关键信号**：BEV 特征热图可视化显示，尽管相机激活密集、雷达激活稀疏（数量级差异），融合结果仍能集中在被引对象上。

## 7. 方法亮点与实验设计优点

### 方法创新
1. **任务定义创新**：首个将4D雷达纳入3DVG的数据集，使“速度”“运动方向”等运动学属性成为可查询的语言线索。
2. **注释流程严谨**：采用“量化-标注-验证”闭环：将隐式传感器属性可视化为可量化的线索（如逐点速度、RCS投影、5米间隔同心圆），并由三位专家三重验证，确保事实准确性和多传感器一致性。
3. **无需标定的统一传感器采样**：LRPS 在统一查询空间中完成文本调制采样，规避了传统融合中依赖标定的脆弱几何投影。
4. **从检测到指代的概念转变**：预测头不预测语义类别，仅输出“是否为文本所指对象”的置信度，语义完全由提示承载，更符合视觉定位的本质。
5. **粗到细的递进融合逻辑**：先由 LRPS 做查询级粗定位，再由 SPMA 做模态仲裁与文本精细对齐，逻辑层次清晰。

### 实验设计亮点
- 通过 **提示类别分组分析**（图8c）证明增益来源的针对性。
- 通过 **模态丢弃测试** 验证系统鲁棒性与模块降级行为。
- 不仅报告 EAA 整体区域，还报告 DCA 驾驶走廊区域，更贴近实际自动驾驶的安全关键场景。
- mAOS（方向相似度）指标的引入，对运动学相关查询的评估具有重要意义。

## 8. 不足与局限

### 数据层面
- **数据规模有限**：8,682条指令、20,558个对象远小于室内数据集（如 ScanRefer 51K），可能限制模型学习复杂跨模态关系的上限。
- **单一数据源**：仅基于 View-of-Delft 数据集构建，场景地理范围（荷兰代尔夫特）、交通模式、天气条件单一，缺乏跨地区、跨环境多样性。
- **类别覆盖有限**：主要集中在 Car、Pedestrian、Cyclist 三类，虽然包含其他类别，但数量很少。
- **传感器分布不均衡**：标注中的相机、LiDAR、雷达点云数量差异巨大（如 Car 的 LiDAR 平均368.3点 vs Radar平均9.3点），可能引入模态偏差。

### 方法与评估层面
- **雷达单独性能极低**（EAA mAP仅1.463），虽然论文将其归因于属性路由的合理性，但也表明纯雷达特征的表达能力严重不足。
- **统计验证缺失**：未报告多次运行的均值/方差，也没有进行显著性检验。
- **推理速度**：全三传感器配置下推理速度约 9.2 FPS，未达到实时标准（通常需要 ≥30 FPS）。
- **未覆盖恶劣天气**：论文涉及了 4D 雷达在恶劣天气中的穿透性优势，但实验仅在正常天气条件下进行，没有验证这一核心优势。

### 技术与应用层面
- **文本编码器限制**：使用 CLIP ViT-B/32 且最大token数77，对长度超过77 tokens的复杂描述会被截断。
- **仅支持单阶段查询**：每个样本只有一个提示，不支持多轮对话或同时引用多个不同语义对象。
- **零样本能力未验证**：论文展示的是监督学习下的性能，未评估在全新类别或未见场景下的零样本/少样本表现。
- **对比方法中缺少最新的基于大语言模型的方法**：未与 VLM-Grounder 等更先进的零样本方案进行对比。
