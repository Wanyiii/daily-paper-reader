## 摘要
3D视觉语言模型（3D VLMs）能够对多视图场景进行空间推理，但由于重复观测和大量无信息区域的存在，会遭受严重的令牌冗余问题，导致计算成本高昂。尽管视觉令牌压缩在加速2D VLMs方面已展现出潜力，但它无法捕捉3D场景的结构化特性，导致空间覆盖不完整和细粒度细节丢失。在本文中，我们提出HiSC，一种用于3D VLMs中分层空间聚类令牌压缩的无训练框架。HiSC通过利用几何与语义联合线索，将令牌组织为空间接地聚类，从而将令牌压缩从令牌级选择提升到聚类级处理。具体而言，我们首先引入一种**基于空间图的合并（SGraM）策略**，将跨视图冗余建模为空间连通性，并整合物理一致区域，从而在LLM推理之前有效合并极度相似的冗余令牌。然后，我们在LLM推理过程中提出一种**基于空间聚类的剪枝（SCluP）范式**，在聚类间和聚类内执行分层压缩，在保留重要区域细粒度细节的同时保持对象实例完整性。在多种3D推理基准上的大量实验验证了HiSC的有效性，尤其是在高视觉令牌剪枝比率下。此外，HiSC实现了超过90%的令牌减少，且性能下降极小。代码可在https://github.com/elecreak/HiSC获取。

## Abstract
3D vision-language models (3D VLMs) enable spatial reasoning over multi-view scenes but suffer from substantial token redundancy due to duplicated observations and large uninformative regions, leading to high computational cost. Although visual token compression has shown promise in accelerating 2D VLMs, it fails to capture the structured nature of 3D scenes and leads to incomplete spatial coverage and loss of fine-grained details. In this paper, we propose \textbf{HiSC}, a training-free framework for hierarchical spatial clustering token compression in 3D VLMs. HiSC lifts token compression from token-level selection to cluster-level processing by organizing tokens into spatially grounded clusters using joint geometric and semantic cues. Specifically, we first introduce a \textbf{spatial graph-based merging (SGraM) strategy} that models cross-view redundancy as spatial connectivity and consolidates physically consistent regions, effectively merging extremely similar redundant tokens prior to LLM inference. We then propose a \textbf{spatial clustering-based pruning (SCluP) paradigm} within LLM inference, which performs hierarchical compression across clusters and within clusters, preserving object instance completeness while retaining fine-grained details for important regions. Extensive experiments on diverse 3D reasoning benchmarks show validate the effectiveness of HiSC, particularly under high visual token pruning ratios. Besides, HiSC achieves over 90\% token reduction with minimal performance degradation. Code is accessible at https://github.com/elecreak/HiSC.

# 论文总结：HiSC——用于高效3D场景理解的分层空间聚类令牌压缩

## 1. 核心问题与研究动机
- **问题背景**：多视图 3D 视觉语言模型（3D VLMs）能够进行空间推理，但一个场景常产生数千个视觉 token，远多于 2D VLM。由于多视图之间的重复观测、大块无信息区域等因素，视觉 token 存在大量**结构化冗余**，导致 LLM 推理计算成本高昂。
- **现有方法的不足**：已有的训练无关 token 剪枝方法大多面向 2D 图像，在 1D token 序列上做独立选择，忽略了 3D 场景中的空间连通性、对象完整性和跨视图一致性。这类方法容易导致：空间覆盖不完整、重要对象细节丢失、同类对象被错误合并或遗漏。
- **论文目标**：提出一个无训练、即插即用的框架，将 token 压缩从“令牌级选择”提升到“聚类级处理”，在显著降低计算开销的同时，保持 3D 推理所需的对象级空间完整性和关键区域细粒度信息。

## 2. 方法论
### 2.1 总体框架
- HiSC 包含两个核心模块：
  1. **SGraM（Spatial Graph-based Merging）**：在 LLM 推理之前，基于空间连通性合并冗余令牌；
  2. **SCluP（Spatial Clustering-based Pruning）**：在 LLM 推理过程中，利用空间语义聚类进行分层次剪枝。
- 整体输入为多视图 RGB-D 图像和相机参数；每个图像 patch 被提升为带 3D 坐标的空间化视觉 token：`v_i = f_proj(f_i, p_i)`，其中 `f_i` 为视觉特征，`p_i` 为 3D 坐标。
- LLM 输入序列为 `X = [T_prompt; V; T_query]`，其中视觉 token 数量 `L_v` 远大于文本 token 数量，是计算开销的主要来源。

### 2.2 空间图合并（SGraM）
- 动机：同一物理表面或跨视图重复观测的 token 具有空间连通性和语义一致性，只靠全局特征相似度无法建模这种**传递性连通关系**。
- 方法：
  - 分别定义几何邻接和语义邻接：
    - `A_geo_ij = I(||p_i - p_j|| < τ_geo)`
    - `A_sem_ij = I(sim(f_i, f_j) > τ_sem)`
  - 统一邻接矩阵：`A_ij = A_geo_ij ⊙ A_sem_ij`，确保边只存在于“空间上相邻且语义高度一致”的 token 之间。
  - 以 A 构造无向图 `G = (V, E)`，提取连通分量 `C = {C_k}`；每个连通分量近似一个物理一致区域。
  - 将每个连通分量内的 token 聚合为一个代表“超级 token”（如特征和位置的平均），从而在 LLM 之前安全移除冗余。

### 2.3 空间聚类剪枝（SCluP）
- 动机：LLM 多层推理中仍存在冗余，且 token-level 独立剪枝会导致对象级信息失衡。
- 方法分两步：
  1. **对象中心空间聚类**：先做粗粒度语义分组，再在每个语义组内用空间邻接关系提取连通分量，得到最终聚类 `C = {C_k}`。这样可区分“视觉相似但物理分离”的不同实例，避免语义混淆。
  2. **层次化剪枝**：
     - **跨聚类层**：为每个聚类分配 token 预算 `n_k`，要求 `n_k ≥ 1`（保证每个对象至少保留一个 token），且 `n_k ∝ (I_k)^2`，其中 `I_k` 是聚类重要性得分；总预算 `∑n_k = N^(l)`。
     - **聚类内层**：同时考虑重要性和多样性，使用联合空间-语义距离：
       `D_comb_ij = λ||p_i - p_j|| + (1-λ)(1 - sim(f_i, f_j))`，优先选择与已选 token 距离较远的 token，以保持结构多样性。
- 该设计使模型在压缩时既保留全局对象覆盖，又保留重要区域的细节。

## 6. 主要结论与发现
- HiSC 在三种压缩强度下均优于所有基线，尤其在高压缩比下优势明显。
  - Light 压缩（约 50% token）：相对得分 98.87%，接近无损。
  - Medium 压缩（约 25% token）：相对得分 97.14%，仍显著高于其他方法。
  - Extreme 压缩（约 10% token）：相对得分 92.46%，而最好基线约 89.43%。
- SGraM 和 SCluP 互补：前者在 LLM 前安全移除结构化冗余，后者在 LLM 中做自适应、对象感知的剪枝；二者结合可同时保持空间完整性和细节保真度。
- 空间连通性对区分外观相似但物理不同的对象至关重要，能避免相似度聚类导致的错分。

## 7. 优点
- **训练无关、即插即用**：无需重新训练或微调，可直接部署到现有 3D VLM。

- **解耦几何与语义邻接**：建模传递性连接，准确合并冗余区域，避免错误合并。
