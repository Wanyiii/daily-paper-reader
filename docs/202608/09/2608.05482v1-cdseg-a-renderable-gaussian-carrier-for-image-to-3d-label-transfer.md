## 摘要
现代图像模型提供了关于每个视图中应分割什么（\emph{what}）的强线索，但其掩码本身并不能确定这些标签在三维中应保留在何处（\emph{where}）。我们提出了跨域分割高斯溅射（CDSeg），一种无需任务特定三维分割训练的标签转移接口，利用高斯原语作为可渲染的标签载体。外部掩码源提供标签，而由渲染器派生的可见性决定哪些三维原语接收这些标签。该载体通过将每个输入点补全为一个高斯（保留其索引）或复用优化后的高斯场景的原始原语来实例化。CDSeg在渲染过程中记录像素-原语关联，并通过投票和局部滤波器融合多视图掩码。所得标签可返回到原始点、保留在原始高斯场景上，或渲染到其他视图中。CDSeg涵盖可提示、自动实例、语义和LiDAR设置，并能在数秒内处理具有数百万原语的场景。在DesktopObjects-360上获得92.35%的mIoU，在NeRDS-360上获得95.89%，在使用提供的2D语义标注的完整ScanNet-v2验证集上获得65.77%。因此，CDSeg提供了一种统一接口，可在点云、高斯场景和图像视图之间复用2D掩码，而无需任务特定的三维分割网络。

## Abstract
Modern image models provide strong cues about \emph{what} should be segmented in each view, but their masks do not by themselves determine \emph{where} those labels should persist in 3D. We present Cross-Domain Segmentation via Gaussian Splatting (CDSeg), a label-transfer interface that requires no task-specific 3D segmentation training and uses Gaussian primitives as a renderable label carrier. An external mask source supplies the labels, while renderer-derived visibility determines which 3D primitives receive them. The carrier is instantiated either by completing each input point into one Gaussian, preserving its index, or by reusing the native primitives of an optimized Gaussian scene. CDSeg records pixel--primitive associations during rendering and fuses multi-view masks through voting and a local filter. The resulting labels can be returned to the original points, retained on the native Gaussian scene, or rendered into other views. CDSeg covers promptable, automatic instance, semantic, and LiDAR settings and processes scenes with millions of primitives in seconds. It obtains 92.35\% mIoU on DesktopObjects-360, 95.89\% on NeRDS-360, and 65.77\% on the full ScanNet-v2 validation split using the provided 2D semantic annotations. CDSeg thereby provides one interface for reusing 2D masks across point clouds, Gaussian scenes, and image views without a task-specific 3D segmentation network.

- **问题本质**：现代图像基础模型（如 SAM 等）能够为每个 2D 视图提供高质量的掩码，回答"图像中**什么**（what）应该被分割"的问题；然而，这些 2D 掩码本身无法确定对应的标签在三维空间中应该**保留在何处**（where），即如何将图像的 2D 分割结果可靠地映射到 3D 场景（点云、高斯场景或其他视图）。
- **现有挑战**：传统的 3D 分割方法通常需要**任务特定的 3D 分割网络**进行训练，成本高昂且泛化受限；而已有的 2D-3D 标签转移方法往往缺乏一个统一、高效且可渲染的标签载体。
- **核心动机**：是否可以利用高斯溅射（Gaussian Splatting）的可渲染性质，构建一种**无需 3D 分割训练**的通用标签转移接口，从而将 2D 掩码灵活地复用到多种 3D 表示中？

## 2. 方法论：CDSeg 的核心思想与关键技术

- **整体思路**：CDSeg 使用**高斯原语作为可渲染的标签载体**。外部掩码源提供语义/实例标签，而由**渲染器推导出的可见性**决定哪些 3D 原语接收这些标签。该过程无需训练任务特定的 3D 分割网络。
- **载体实例化方式**（两种路径）：
  - **路径 A（从点云）**：将每个输入点补全为一个高斯原语，同时**保留其原始索引**，便于后续将标签返回点云。
  - **路径 B（复用高斯场景）**：直接复用已优化高斯场景中的原生原语，不改变场景本身的几何与外观表示。
- **像素-原语关联记录**：在可微渲染的前向过程中，记录每个像素与哪些高斯原语相关联（即渲染可见性关系），建立 2D 掩码与 3D 原语之间的桥梁。
- **多视图标签融合**：
  - **投票机制**：多个视图的掩码通过投票聚合到同一组 3D 原语上，消除单视图遮挡和噪声。
  - **局部滤波器**：在原语局部邻域内进行滤波，平滑标签的空间一致性，减少噪点和不一致。
- **标签输出形式**（灵活可逆）：
  1. 返回到原始点云；
  2. 保留在原生高斯场景上；
  3. 渲染到其他任意视图中。
- **覆盖的任务设置**：可提示分割（promptable）、自动实例分割、语义分割以及 LiDAR 点云设置。
- **算法流程概要**：
  1. 输入 3D 场景（点云或高斯场景）和外部 2D 掩码源；
  2. 实例化高斯载体；
  3. 从多个视角渲染场景，记录像素-原语关联；
  4. 将外部 2D 掩码通过可见性关联"沉积"到 3D 原语；
  5. 跨视图投票 + 局部滤波融合；
  6. 输出 3D 标签（可返回点云、保留于高斯场景或渲染到新视图）。
