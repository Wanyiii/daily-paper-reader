## 摘要
3D视觉定位旨在从自然语言查询中定位3D场景中的目标对象，需要细粒度的语义理解和依赖视角的空间推理。现有方法通常将语义理解表述为辅助的闭集对象分类任务，并依赖多视角特征聚合进行视角推理，这限制了语义泛化并削弱了视角特定的证据。我们观察到，视觉语言模型通过开放词汇语义理解和全局场景感知自然地提供了互补能力。基于这一见解，我们提出了GuideGround，一个VLM引导的框架，通过利用VLM进行语义增强和视角特定的假设验证，来补充而非取代特定任务的定位模型。具体来说，我们用VLM生成的对象语义描述取代辅助的闭集对象分类，以增强语义理解。同时，我们不直接聚合多视角表示，而是通过逐视角定位保留视角特定的定位假设，并使用VLM在候选视角间显式验证它们。在ReferIt3D基准上的大量实验表明，GuideGround持续优于之前的最先进方法。全面的消融研究进一步证实了所提出的语义理解和视角推理策略的有效性。

## Abstract
3D visual grounding aims to localize the target object in a 3D scene from a natural language query, requiring both fine-grained semantic understanding and viewpoint-dependent spatial reasoning. Existing methods typically formulate semantic understanding as an auxiliary closed-set object classification task and rely on multi-view feature aggregation for viewpoint reasoning, limiting semantic generalization and weakening viewpoint-specific evidence. We observe that vision-language models naturally provide complementary capabilities through open-vocabulary semantic understanding and global scene perception. Based on this insight, we propose GuideGround, a VLM-guided framework that complements rather than replaces task-specific grounding models by leveraging VLMs for semantic enhancement and viewpoint-specific hypothesis verification. Specifically, we replace auxiliary closed-set object classification with VLM-generated object semantic descriptions to enhance semantic understanding. Meanwhile, instead of directly aggregating multi-view representations, we preserve viewpoint-specific grounding hypotheses through per-view grounding and explicitly verify them using VLMs across candidate viewpoints. Extensive experiments on the ReferIt3D benchmark demonstrate that GuideGround consistently outperforms previous state-of-the-art methods. Comprehensive ablation studies further confirm the effectiveness of both the proposed semantic understanding and viewpoint reasoning strategies.

## 1. 核心问题与整体含义（研究动机与背景）

- 3D视觉定位（3DVG）任务目标：根据自然语言查询，在3D场景中精确定位目标对象，是具身智能（Embodied AI）的核心基础能力之一。
- 任务面临两大核心挑战：
  - **语义理解挑战**：需从视觉或类别上相似的对象中区分目标，且真实室内场景包含超过400个细粒度类别、长尾分布、未见类别以及由遮挡导致的不完整点云。现有方法普遍将语义理解建模为**闭集对象分类**的辅助任务（如基于PointNet++、CLIP特征），这种范式限制了语义泛化能力。
  - **视角相关空间推理挑战**：需正确解读如"左边""后面"等依赖视角的关系。现有方法采用两种策略——直接预测观察视角（存在歧义）或多视角特征聚合（会模糊视角特有证据，导致即使某个视角已有足够证据仍可能定位失败）。
- 核心观察：视觉语言模型（VLM）天然具备**开放词汇语义理解**与**全局场景感知**能力，可作为任务专用3D定位模型的互补力量。
- 关键问题：①3DVG中的语义理解能否超越辅助对象分类范式？②不同视角的定位结果能否被有效利用来提升视角相关空间推理？

## 2. 方法论

### 2.1 核心思想
**GuideGround是VLM引导的辅助框架**，不取代任务专用定位模型，而是形成互补：VLM提供开放词汇语义知识与场景级视觉证据，任务专用模型负责结构化空间推理。

### 2.2 技术架构与关键细节

**阶段一：VLM引导的语义理解模块**
- **对象语义表示**：将3D点云投影至RGB图像，通过对象感知的关键帧选择策略（综合投影覆盖率、可见率、投影面积三个质量指标，并分段选取Nf=4个时域分散的关键帧）构建2×2拼接图Co，输入冻结VLM生成简短对象描述to与详细语义描述co。
- **查询语义解析**：使用LLM Mpar将语言查询Q解析为目标描述tQ与锚点描述集A={a₁,...,a_K}，目标描述用于语义匹配，锚点描述用于空间推理引导。
- **语义先验构建**：通过句子嵌入模型计算详细描述co与目标描述tQ的余弦相似度：

  **s_sem_o = (e_o^T · e_t) / (‖e_o‖ · ‖e_t‖)**

**阶段二：视角感知空间推理模块**（将视角推理分解为逐视角定位+假设验证）

- **逐视角定位**（每个候选视角独立执行）：
  - **QFM（查询感知融合模块）**：基于MiKASA的语言-空间融合设计，但用语义理解模块生成的对象描述语言嵌入替换PointNet++点云特征。
  - **ARM（锚点感知精化模块）**：
    - 锚点定位：计算锚点短语e_ak与对象表征f_vi的相似度l_vk,i = (e_ak^T·f_vi)/(τ‖e_ak‖‖f_vi‖)，通过softmax得到锚点-对象对应概率p_vk,i。
    - 锚点感知消息构建：综合相对几何编码r_ij、对象特征与锚点短语表示，m_vk,i = ϕ(Σp_vk,j·r_ij, Σp_vk,j·f_vj, e_ak)。
    - 特征聚合与门控残差注入：ˆf_vi = f_vi + γΔf_vi。
  - **GHG（定位假设生成）**：融合三类分数——语义一致性s_sem、粗定位分数s_coarse、关系感知分数s_rel，即 s_vi = λs·s_sem_i + λc·s_coarse,vi + λr·s_rel,vi。
- **VLM假设验证**：
  - 触发条件：所有视角预测一致时直接接受；最高与次高分数差>δ时直接接受；仅模糊样本调用验证VLM。
  - 为每个视角构建验证假设Hv = {顶视图可视化、视角定位预测、上下文对象语义描述}，交由VLM Mver比较各候选假设与语言查询的一致性，选出最合理的指代对象。
- **训练策略**：训练时聚合多视角得分 s_agg = (1/V)Σs_vi，避免不一致的优化信号；推理时保留各视角假设供VLM验证。总损失 L = L_ref + λa·L_anchor + λd·L_dis（交叉熵定位损失 + 多正锚点损失 + 难负样本排序损失）。

## 6. 主要结论与发现

- 在Nr3D上取得68.1%整体准确率，较此前最优的65.2%提升2.9个百分点；在Hard子集（61.8%）和VD子集（66.6%）上有显著改进；在Sr3D上取得76.5%准确率（VD子集79.6%）。
- 相比零样本/少样本方法（最佳53.2%），GuideGround提升近15个百分点，表明**基础模型作为辅助组件比直接端到端使用更有效**。
- 用VLM生成的语义先验替代辅助闭集分类，将整体精度从64.4%提升至68.1%，验证了开放词汇语义优于传统监督范式。
- 保留逐视角定位假设并验证（68.1%）优于直接多视角特征聚合（64.7%），说明**关键不在生成多个视角，而在于显式选择信息量最大的视角**。
- 仅用VLM直接推理（文本+图像，54.6%）远不如GuideGround完整框架，证明提升来自**基础模型与专用结构化空间推理的有机整合**。
- 4个候选视角是最优折中（8视角因引入冗余假设而性能下降）。
- 验证模块的修正中，空间修正（189/275）多于语义修正（86/275），验证核心价值在于解决视角相关的空间歧义。

- **计算开销**：依赖多个大型冻结模型（DeepSeek-V3、Qwen3.5、GPT-5.6、MPNet），训练与推断的计算成本显著高于纯PCD方法，文中未评估"验证阶段为模糊样本需要多少次VLM调用"的额外成本，未报告推理时延。

- **性能上界**：在目标缺失（不含目标对象的场景）或模糊查询等恶意场景下，VLM验证可能产生误导性修正；文中未讨论验证模块产生错误修正的失败案例及频率。
