## 摘要
随着大规模图像-文本预训练模型（如CLIP）的出现，文本-视频检索近年来取得了实质性进展。现有性能最佳的方法涉及同时在个体、局部和全局层面对齐跨模态语义，这引发了对简洁文本与丰富视频之间固有语义不匹配的担忧。一种典型的方法是将多个语言-视频注意力模块整合到分层框架中，但该范式仅优化视觉表示，且计算成本高昂。在本文中，我们提出了一种新的基于原型的分层对齐网络（PHA-Net），以跨模态对齐个体/局部/全局级别的表示。具体而言，我们引入了多个模态共享原型作为桥梁，以高效优化用于跨模态对齐的文本和视频表示。然后，我们认为聚类标记中的不平衡语义分布可能会损害检索性能，因为语义较弱的标记不太重要。为了减少这些标记的影响，我们提出了一种原型支持的标记合并模块，通过原型语义指导来增强具有强语义的标记并抑制具有弱语义的标记。此外，我们设计了一种原型对比损失，以鼓励文本和视觉原型关注不同的语义信息。这种辅助损失的思想是确保来自同一原型的文本和视觉原型之间的相似度高于来自不同原型的相似度。在四个基准上的大量实验证实了我们PHA-Net的有效性，其在MSR-VTT（8.8%）、ActivityNet（19.2%）、VATEX（0.7%）和Charades（4.9%）上的所有召回率之和取得了显著提升。代码可在 https://github.com/JingXiaolun/PHA-Net 获取。

## Abstract
With the emergence of large-scale image-text pre-training models, e.g., CLIP, text-video retrieval has experienced substantial advances in recent years. Existing best-performing methods involve aligning cross-modal semantics at individual, local, and global levels simultaneously, raising concerns about the intrinsic semantic mismatch between concise texts and rich videos. A canonical approach is to integrate multiple language-video attention modules into the hierarchical framework while this paradigm only optimizes visual representations with prohibitive computational costs. In this paper, we propose a new prototype-based hierarchical alignment network (PHA-Net) to align individual/local/global level representations across modalities. Concretely, we introduce multiple modality-shared prototypes as the bridge to efficiently optimize text and video representations for cross-modal alignment. Then, we argue that the imbalanced semantic distribution in clustered tokens may undermine retrieval performance, as tokens with weak semantics are of little interest. To reduce the impact of these tokens, a proposed prototype-supported token merge module is responsible for enhancing tokens with strong semantics and suppressing others with weak semantics via prototype semantics guidance. Moreover, we devise a prototype contrastive loss to encourage textual and visual prototypes to focus on different semantic information. The idea of this auxiliary loss is to ensure higher similarity between textual and visual prototypes from the same prototype than those from different prototypes. Extensive experiments on four benchmarks confirm the effectiveness of our PHA-Net, which achieves significant improvements in the sum of all recalls on MSR-VTT (8.8%), ActivityNet (19.2%), VATEX (0.7%), and Charades (4.9%). Code is available at https://github.com/JingXiaolun/PHA-Net.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：文本-视频检索（TVR）旨在通过文本查询检索相关视频，是多媒体检索领域的基础任务。近年来，基于大规模图像-文本预训练模型（如 CLIP）的方法取得了显著进展，主流范式将 CLIP 迁移至视频领域并设计多种时序聚合或跨模态注意力机制进行语义对齐。
- **核心问题**：简洁的文本与内容丰富的视频之间存在**固有不匹配**——一个文本通常只描述视频中较少的语义，而视频帧包含大量与文本无关或弱相关的信息。此外，现有分层对齐方法（如 HCMI、HBI）在构建个体/局部/全局三级对齐时存在两大痛点：
  1. **仅优化视觉表示**：典型跨注意力模块仅利用文本引导权重生成语义相关视频特征，而不优化文本侧表示，导致对多义词或复杂语义的建模能力不足；
  2. **计算开销高昂**：需要多个跨模态注意力模块参与分层交互，显著降低训练与推理效率。
- **研究意义**：如何以相对高效的方式**联合优化文本和视频的分层表示**，是 TVR 领域亟待解决的问题。论文提出的 PHA-Net 以模态共享原型（prototype）为桥梁，在保证性能的同时大幅降低训练成本。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 2.1 整体框架
PHA-Net 基于 CLIP 双编码器构建，在 CLIP 输出特征基础上引入**模态共享原型**（modality-shared prototypes），在**个体（individual）→ 局部（local）→ 全局（global）**三个层级逐步对齐文本与视频表示，并通过多任务损失联合优化。

### 2.2 核心技术：三个关键设计

**（1）模态共享原型（Modality-Shared Prototypes）**
- 在个体层级设置 $N_p^I$ 个可学习原型，在局部层级设置 $N_p^L$ 个可学习原型（实验默认 $N_p^I=3$, $N_p^L=1$）。
- 将单词/帧 tokens 与可学习原型拼接，经轻量 Transformer Block（TB）建模原型与 token 之间的交互，实现文本和视频的联合优化，弥合模态鸿沟。
- 原型带来的额外计算开销可接受，同时能加速训练收敛。

**（2）原型支持的 Token 合并模块（Prototype-Supported Token Merge Module）**
- 用于个体→局部、局部→全局的 token 聚合过程。
- 首先使用 **DPC-KNN**（基于 K 近邻的密度峰值聚类）算法对 token 进行聚类，得到短语（phrase）和片段（clip）token；
- 由于直接聚类会导致共享原型语义分配不均，部分 token 强语义、部分弱语义，该模块将**平均且复制后的原型 tokens 作为查询 Q**，将聚类后的加权平均 tokens 作为键 K 和值 V，送入交叉注意力层，从而以原型语义为指导**增强强语义 token、抑制弱语义 token**；
- 上图中（正文 Figure 2）清晰展示了该模块的内部结构。

**（3）原型对比损失（Prototype Contrastive Loss, PCL）**
- 为防止不同原型关注相同语义区域、确保原型语义多样性，PCL 约束同一原型的文本侧与视频侧输出更相似、不同原型之间更疏远。
- 损失函数采用 InfoNCE 形式，在批级别对原型相似度矩阵进行对比学习。

### 2.3 多层级对齐与训练目标
- **个体对齐**：词-帧相似度采用加权 token 交互（WTI）机制计算。
- **局部对齐**：经过 token 合并模块得到短语和片段 tokens，再拼接局部原型经 TB 增强，用 WTI 计算相似度。
- **全局对齐**：再经合并模块得到句向量和视频向量，用余弦相似度计算。
- **总损失**包含三部分：
  $$ \mathcal{L}_{\text{all}} = \mathcal{L}_{\text{HCL}} + \lambda \mathcal{L}_{\text{DL}} + \mu \mathcal{L}_{\text{PCL}} $$
  其中 $\mathcal{L}_{\text{HCL}}$ 为三级对比损失之和，$\mathcal{L}_{\text{DL}}$ 为层级间自蒸馏损失（I2L、L2G、I2G），$\mathcal{L}_{\text{PCL}}$ 为原型对比损失。
- **推理**：三个层级的相似度加权求和作为最终匹配分数。

## 7. 优点

- **方法创新性强**：将原型学习引入 TVR 分层对齐，用模态共享原型作“桥梁”同时优化双模态，替代传统多重跨注意力模块，思路新颖、合理；
- **计算高效**：训练时间明显缩短，推理开销在可接受范围，兼顾效果与效率；
- **模块设计精细**：原型支持 token 合并模块有效解决了聚类 token 语义分布不均的问题，增强了关键 token 的语义表达；
- **损失设计完备**：原型对比损失促进原型特化、自蒸馏损失增强层级一致性，与分层对比损失形成完整的多任务学习框架；
- **实验规范且全面**：四个标准数据集、多组消融实验、定性与定量结合，对比充分，证据扎实；
- **可复现性好**：公开代码、提供超参数设置、数据集划分方式和具体实现细节。

## 8. 不足与局限

- **原型数量为静态超参**：当前 $N_p^I=3, N_p^L=1$ 的固定配置难以适应视频内容复杂度的变化。论文在失败分析中也指出，有限的原型无法兼顾“数量属性”等微观语义，跨场景泛化受限；
- **对高动态视频语义捕捉不足**：1D-Conv 会平滑场景切换带来的高频时序线索，导致 DPC-KNN 聚类后语义信息被稀释，影响判别力；
- **VATEX 上增益较小**：由于 VATEX 描述多样性强，静态原型数量难以充分覆盖多变语义，性能提升有限；
- **Charades 上绝对性能仍偏低**：虽然相对提升 4.9%，但 R@1 仅 13.6（t2v），说明对单句-短视频场景的语义匹配仍有较大提升空间；
- **原型增加带来衰减**：当 $N_p^I$ 或 $N_p^L$ 超过一定值后，性能不升反降，说明多原型可能引入冗余或过拟合风险；
- **主观偏差风险**：论文选择性地展示了有利于方法效果的检索可视化结果，对失败案例的讨论较为有限；
- **未扩展至更多模态场景**：论文只在文本-视频检索上验证，跨模态检索（如文本-音频、图文匹配）以及多模态医学影像分析等适用性尚待探索。
