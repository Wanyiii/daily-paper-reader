## 摘要
视觉-语言模型（VLMs）在处理高分辨率图像时面临严重计算瓶颈，因为Softmax多头注意力（MHA）具有$O(N^2)$的内存复杂度。虽然将MHA替换为独立的多层感知器（MLP）可实现$O(N)$缩放，但这种方法削弱了架构的空间序列路由能力，严重损害了全局场景理解和物体永续性。本文提出线性多时间尺度保留（LIA-MTR）模块，一种内存高效的跨模态桥接方法。通过将基于ELU的正特征映射与自适应写门控和对数线性分布的循环衰减相结合，LIA-MTR在数学上将连续视觉序列压缩为有界记忆状态。理论分析证明该架构具有严格的$O(N)$序列交互复杂度。实证中，合成检索评估表明LIA-MTR能在16,000个标记间完美路由上下文，消除了朴素线性注意力典型的“中间迷失”退化问题。硬件基准测试展示了无限上下文缩放能力，在11.2 GB显存占用下原生处理262,144个视觉块，而标准MHA在16,384个块时即遭遇内存不足失败。此外，在665K对话样本上进行指令微调后，LIA-MTR在MME基准上显著优于行业标准MLP基线（71.00%对比68.11%），这得益于物体永续性绝对提升10%以及更优的全局语义提取。这项工作为无限上下文视觉-语言集成奠定了数学严谨、计算平坦的基础。

## Abstract
Vision-Language Models (VLMs) face a critical computational bottleneck when processing high-resolution imagery due to the $O(N^2)$ memory complexity of Softmax Multi-Head Attention (MHA). While substituting MHA with independent Multi-Layer Perceptrons (MLPs) achieves $O(N)$ scaling, it strips the architecture of spatial sequence routing, severely degrading global scene understanding and object permanence. In this paper, we propose the Linear Multi-Timescale Retention (LIA-MTR) module, a memory-efficient cross-modal bridge. By integrating an ELU-based positive feature mapping with adaptive write-gating and log-linearly distributed recurrent decays, LIA-MTR mathematically compresses continuous visual sequences into bounded memory states. Theoretical analysis proves the architecture operates with strict $O(N)$ sequence-interaction complexity. Empirically, synthetic retrieval evaluations demonstrate that LIA-MTR flawlessly routes context across 16,000 tokens, eliminating the "Lost in the Middle" degradation typical of naive linear attention. Hardware benchmarking reveals infinite-context scaling capabilities, natively processing 262,144 visual patches within an 11.2 GB VRAM footprint, whereas standard MHA suffers out-of-memory failure at 16,384 patches. Furthermore, following instruction tuning on 665K conversational samples, LIA-MTR significantly outperforms an industry-standard MLP baseline on the MME benchmark (71.00% vs. 68.11%), driven by a 10% absolute improvement in object permanence and superior global semantic extraction. This work establishes a mathematically rigorous, computationally flat foundation for infinite-context Vision-Language integration.

- **科学问题**：视觉-语言模型（VLM）处理高分辨率图像时，Softmax 多头注意力（MHA）的 $O(N^2)$ 内存复杂度构成严重计算瓶颈，无法应对视觉 token 序列长度指数级增长的现实需求。
- **已有方案的困境**：
  - **MHA 路线**（如 Flamingo、InstructBLIP 中的 Q-Former）：全局语义路由能力强，但显存随序列长度呈二次方膨胀。即便有 FlashAttention 等优化，标准硬件上超过 16,000 个视觉 token 仍会出现灾难性显存耗尽（OOM）失败。
  - **MLP 路线**（如 LLaVA）：复杂度降至 $O(N)$，但每个视觉 patch 被独立映射，完全丧失序列路由能力，导致全局场景理解下降和物体永续性（object permanence）退化。
- **核心矛盾**：需要在**线性复杂度**与**序列路由能力**之间取得兼顾，目前尚无理想的跨模态桥接方案。
- **研究意义**：解决这一矛盾是实现无限上下文视觉-语言集成的基础性前提。

## 2. 方法论：LIA-MTR 模块

### 2.1 核心设计思想

LIA-MTR 摒弃了二次方的两两注意力计算，转而采用**门控的、固定大小的循环记忆状态**，以 $O(N)$ 复杂度实现视觉序列的上下文混合。其核心是三条技术路线的融合：

1. **ELU 正特征映射**：确保 key 表示非负，避免递归累积中出现分母塌缩。
2. **自适应写门控**：逐 token 动态调节信息写入记忆的强度，抑制空间冗余造成的噪声累积。
3. **多时间尺度递归衰减**：以 $S$ 个对数线性分布的衰减常数并行维持不同尺度的记忆，同时捕捉短期空间细节与长期全局语义。

### 2.2 关键公式与技术细节

**（1）投影与正特征映射**

$$q_t = W_q x_t, \quad k_t = \varphi(W_k x_t), \quad v_t = W_v x_t$$

其中 $\varphi(z) = \text{ELU}(z) + 1$ 保证 key 特征的非负性。

**（2）自适应门控与尺度混合**

$$g_t = \sigma(W_g x_t^{\text{conv}^\top}), \quad \alpha_t = \text{softmax}(W_{\text{mix}} x_t^{\text{conv}^\top})$$

- $g_t$：sigmoid 写门控，控制信息注入量（内部分析显示激活均值稳定在约 0.5053）；
- $\alpha_t$：token 相关的尺度混合权重，动态调整记忆视界。

**（3）多时间尺度记忆更新**

$$M_{t,s} = \lambda_s M_{t-1,s} + u_t, \quad u_t = g_t \odot (k_t \odot v_t)$$

- $S$ 个并行记忆状态，各由固定衰减常数 $\lambda_s \in (0,1)$ 控制；
- $\lambda_s$ 在对数线性区间 $[0.70, 0.995]$ 内分布，对应有效半衰期从 $t_{1/2}=1.94$ 步到 $t_{1/2}=138.28$ 步，实现短期细节与长期语义的兼容。

**（4）输出读入**

$$m_t = \sum_{s=1}^{S} \alpha_{t,s} \odot M_{t,s}, \quad o_t = q_t \odot m_t, \quad y_t = W_o o_t$$

### 2.3 理论保证

- **定理 1**：序列交互复杂度严格为 $O(N)$；
- **定理 2**：记忆状态在无限上下文中严格有界，不产生梯度爆炸；
- **引理 2**：在 $S=1$、$\alpha_t=1$、$g_t=1$ 的约束下，LIA-MTR 可退化为标准一阶线性注意力，即它是线性注意力的严格推广；
- **定理 3**：实现了序列长度上的阶最优性（与理论下界 $\Omega(N)$ 匹配）。
