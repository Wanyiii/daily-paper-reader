## 摘要
以往的RGB-D语义分割方法通常采用双编码器分别处理RGB和深度输入，并随后使用专用模块进行跨模态特征融合。然而，此类设计往往未能充分捕捉深度表示，从而限制了有效的跨模态交互，同时额外的编码器分支引入了冗余计算，阻碍了轻量化部署。为应对这些挑战，我们提出了URNet，一种统一的重参数化RGB-D网络，在单一编码器内同时进行多模态特征提取与跨模态融合。具体而言，我们采用重参数化策略来精简网络架构并促进快速推理。在每个重参数化块（RepBlock）中，引入了线性门控注意力（LGA）模块，以充分利用不同特征尺度上的互补RGB与深度线索。此外，考虑到现有RGB-D分割模型中解码器设计相对未被充分探索，我们开发了一种简洁而有效的通用解码器，称为金字塔融合解码器（PMD）。在多个RGB-D分割基准上的大量实验表明，URNet在保持高效率的同时实现了最先进的性能。代码将在https://github.com/Wild-Stephen/URNet提供。

## Abstract
Previous RGB-D semantic segmentation methods commonly employ dual encoders to separately process RGB and depth inputs, followed by dedicated modules for cross-modal feature fusion. However, such designs often inadequately capture depth representations and consequently limit effective cross-modal interaction, while the additional encoder branch introduces redundant computation that hinders lightweight execution. To tackle these challenges, we propose URNet, a Unified Reparameterized RGB-D Network that performs simultaneous multi-modal feature extraction and cross-modal fusion within a single encoder. Specifically, we adopt a reparameterization strategy to compact the network architecture and facilitate fast inference. Within each Reparameterized Block (RepBlock), a Linear Gated Attention (LGA) module is introduced to fully exploit complementary RGB and depth cues across different feature scales. Furthermore, considering that decoder design has been relatively underexplored in existing RGB-D segmentation models, we develop a concise yet effective universal decoder, termed the Pyramid Merging Decoder (PMD). Extensive experiments on multiple RGB-D segmentation benchmarks demonstrate that URNet achieves state-of-the-art performance while maintaining high efficiency. Code will be available at https://github.com/Wild-Stephen/URNet.

# URNet论文中文总结

## 1. 核心问题与整体含义

- **背景**：RGB-D语义分割通过联合利用RGB图像（颜色、纹理）和深度图（几何结构、空间关系）实现像素级场景解析。在低光照、运动模糊、纹理歧义等不利条件下，深度信息是RGB的重要补充。
- **现存问题**：主流方法普遍采用**双编码器架构**（RGB与深度各自独立编码，后再融合），存在三大局限：
  - **深度特征建模不足**：深度编码器使用ImageNet RGB预训练权重初始化，与深度模态存在分布偏移，难以提取高质量的深度特征；
  - **跨模态交互受限**：融合模块仅部署在少量编码器阶段，模态间信息交换不充分；
  - **计算冗余严重**：双编码器分支带来大量重复计算，不利于轻量化与实时部署。
- **核心含义**：论文提出URNet，将多模态特征提取与跨模态融合**统一到单一编码器**中，配合重参数化策略和轻量解码器，在保证高精度的同时显著降低计算开销。

## 2. 方法论

- **核心思想**：受DFormer/DFormer-v2启发的RGB-D统一预训练 + 重参数化单编码器结构 + 线性门控跨模态融合 + 轻量金字塔解码器。
- **整体流程（两阶段训练）**：
  - **Phase I**：在ImageNet-1k的RGB-D配对数据上进行大规模预训练，学习跨模态表示；
  - **Phase II**：在NYUDepth V2、SUN-RGBD等下游分割数据集上微调。
- **统一层级编码器（Unified Hierarchical Encoder）**：
  - RGB与深度分别经并行Stem层（4个3×3卷积，stride=2）处理；
  - 后接四个层级阶段，每个阶段由堆叠的**RepBlock**组成，输出分辨率分别为输入的1/4、1/8、1/16、1/32；
  - 提供T/S/B/L四种规模（URNet-T/S/B/L），参数量为9.2M/19.8M/44.1M/62.2M。
- **重参数化块（RepBlock）**：
  - 受RepViT启发，采用并行多分支Token Mixer：3×3深度卷积 + 1×1深度卷积 + （1×7 + 7×1）分解卷积 + 恒等连接；
  - 相比RepViT额外引入了7×7等效感受野，提升空间信息聚合能力；
  - 训练时的分支和跳跃连接在**推理阶段可重参数化合并**，消除额外计算与内存开销，加速推理。
- **线性门控注意力（LGA）模块**：
  - 位于RepBlock中间，实现RGB与深度特征的双向交互；
  - 对两模态特征分别进行池化+3×3卷积，经sigmoid生成门控信号；
  - 门控信号对**对侧模态**进行逐元素乘法调制：
    - $\hat{x}_{rgb} = x_{rgb} + g_{depth} \odot x_{rgb}$
    - $\hat{x}_{depth} = x_{depth} + g_{rgb} \odot x_{depth}$
  - 交互后分别经Squeeze-and-Excitation（SE）模块重标定通道响应，再沿通道维拼接得到融合特征；
  - 仅使用线性元素级操作，避免了注意力机制的二次复杂度，开销可忽略不计。
- **金字塔合并解码器（PMD）**：
  - 针对现有RGB-D模型解码器设计不足的问题提出；
  - 以自顶向下金字塔方式逐级融合多尺度特征：对低层特征下采样后与相邻高层特征相加，再上采样传播；
  - 中间融合阶段插入池化操作抑制冗余、缓解尺度不匹配；
  - 最后通过金字塔池化（P-Pooling）捕获多感受野上下文，并与聚合特征残差相加；
  - 仅含上/下采样、池化、逐元素加法等轻量操作，参数开销极小。

## 6. 主要结论与发现

- **统一RGB-D预训练优于RGB-only预训练**：相同微调设置下，RGB-D预训练比RGB-only预训练mIoU高1.2%（56.1% vs 54.9%），证实配对RGB-D预训练有助于跨模态对齐。
- **重参数化Token Mixer效率显著**：与自注意力相比，Rep Token Mixer精度几乎持平（53.17% vs 53.45% mIoU），但参数量减少49.7%（18.40M→9.26M）、FLOPs减少26.5%（20.89G→15.35G），推理速度提升5.5倍（100.35 vs 18.23 FPS）。
- **LGA融合有效且轻量**：LGA比简单加法融合mIoU提升1.34%（53.17% vs 51.83%），比Concat提升0.85%（53.17% vs 52.32%）且FLOPs更低（15.35G vs 16.06G）。
- **PMD解码器优于MLP和HAM**：PMD取得53.17% mIoU，优于MLP（51.74%）和HAM（52.78%），同时比HAM节省约17%的计算量。
- **总体SOTA性能**：URNet-L在NYUDepth V2达58.8% mIoU、SUN-RGBD达53.4% mIoU，均在相近参数量下优于对应规模的DFormer/DFormerV2，且FLOPs显著更低。
- **可泛化性**：在RGB-D SOD五个基准上，URNet-L以62.0M参数量/22.3G FLOPs超越HiDANet（130.6M/71.5G），说明统一RGB-D表示具有跨任务迁移能力。

## 7. 优点

- **方法创新与工程化并重**：

## 8. 不足与局限

- **实验覆盖有限**：
