## 摘要
前馈3D高斯泼溅（3DGS）实现了高效且可泛化的3D重建，但当前用于场景理解的前馈3DGS方法仍主要面向类别。相比之下，实例感知的3DGS方法通常依赖逐场景优化，且往往将重建与实例和语义学习解耦，限制了它们之间的相互促进。我们提出了InstanceSplat，一个统一的前馈3DGS框架，用于从无位姿多视图图像进行可泛化3D重建和实例感知场景理解。在单次前向传播中，InstanceSplat构建了一个实例感知的高斯表示，联合编码外观、几何、实例身份和语言对齐的语义。共享的3D高斯跨视图绑定实例身份，产生可渲染且跨视图一致的实例特征。为使重建和场景理解相互受益，我们进一步设计了一种以实例为中心的学习策略，通过共享实例结构连接重建、实例学习和语义学习。具体而言，实例线索引导重建，语言对齐的语义增强对易混淆同类实例的判别，实例区域将语义证据聚合成连贯的对象级预测。在可变输入视图设置和未见数据集上的新视图合成、实例分割和开放词汇语义理解实验表明，该方法达到了最先进的性能、实用效率和强泛化能力。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) enables efficient and generalizable 3D reconstruction, but current feed-forward 3DGS methods for scene understanding remain largely category-oriented. In contrast, instance-aware 3DGS methods typically rely on per-scene optimization and often decouple reconstruction from instance and semantic learning, limiting reciprocal interactions among them. We present InstanceSplat, a unified feed-forward 3DGS framework for generalizable 3D reconstruction and instance-aware scene understanding from pose-free multi-view images. In a single forward pass, InstanceSplat constructs an instance-aware Gaussian representation that jointly encodes appearance, geometry, instance identity, and language-aligned semantics. Shared 3D Gaussians ground instance identities across views, producing renderable and cross-view-consistent instance features. To allow reconstruction and scene understanding to benefit from each other, we further design an instance-centric learning strategy that connects reconstruction, instance learning, and semantic learning through shared instance structure. Specifically, instance cues guide reconstruction, language-aligned semantics strengthen the discrimination of confusing same-category instances, and instance regions aggregate semantic evidence into coherent object-level predictions. Experiments on novel-view synthesis, instance segmentation, and open-vocabulary semantic understanding under varying input-view settings and on an unseen dataset demonstrate state-of-the-art performance, practical efficiency, and strong generalization.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：3D高斯泼溅（3DGS）因其高保真新视图合成和高效渲染而成为极具吸引力的3D表示。然而，标准3DGS主要面向视觉重建，不显式编码实例结构或语义信息。现有的面向场景理解的3DGS方法主要分为两条路线：
  - **逐场景优化方法**（如Gaussian Grouping、OpenGaussian、InstanceGaussian）：通过逐场景优化将语义或实例特征附加到高斯场景中，支持语义查询和实例分割，但依赖逐场景优化、效率低，且通常将重建与实例学习分为独立阶段，限制了两者的相互促进。
  - **前馈3DGS方法**（如AnySplat、LSM、Uni3R、C3G）：直接从图像重建未见场景，部分方法已引入语言对齐语义特征，但其表示仍是类别导向的，难以区分对象实例并保持清晰的对象边界。
- **核心问题**：现有方法要么提供高效可泛化的重建但缺乏显式实例建模，要么通过昂贵的逐场景优化实现实例感知理解。一个统一的前馈框架，能够联合学习重建、实例结构和语义，仍然缺失。
- **本文贡献**：提出 **InstanceSplat**，一个统一的前馈3DGS框架，从无位姿多视图图像中构建实例感知的高斯表示，在单次前向传播中联合编码外观、几何、实例身份和语言对齐的语义，实现重建与实例级场景理解的互相促进。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
InstanceSplat将实例身份视为3D高斯的内在属性而非重建后附加的特征，通过共享3D高斯作为统一载体，将重建、实例学习和语义学习耦合在一个前馈框架中。实例结构作为重建与语义理解之间的共享接口，实现双向交互。

### 2.2 整体架构（三阶段）

**阶段一：实例感知高斯表示（Instance-Aware Gaussian Representation）**

- 给定N张无位姿输入图像 {I_i}，前馈网络 F 联合预测相机参数、深度图、点图和稠密高斯集。
- 骨干网络：使用预训练DINOv2骨干 + 24层Transformer（交替进行视图内和跨视图注意力），DPT风格解码器预测几何属性，第二个DPT解码器回归剩余高斯属性与紧凑语义特征。
- 实例解码器（沿用IGGT）：从多级Transformer特征预测像素对齐的8维实例特征图，通过滑动窗口交叉注意力融入局部几何线索。
- 每个像素生成一个高斯原语，包含位置 μ、旋转 R、尺度 s、颜色 c、不透明度 α、置信度 c、实例嵌入 S、语义特征 L。
- 采用置信度感知体素化（confidence-aware voxelization，沿用AnySplat）合并冗余原语，获得紧凑的体素对齐3DGS集，同时融合实例嵌入与语义特征。

**阶段二：3D一致实例锚定（3D-Consistent Instance Grounding）**

- 使用与RGB渲染相同的alpha合成过程，将实例嵌入可微渲染到监督视图：S̃_i = R_ins(G′, t_i)。
- 不同视角的观测通过同一组3D原语耦合，使图像空间监督能在3D中建立一致的实例身份。
- 基于原型的对比学习目标：
  - **Pulling项**（L_pull）：使像素特征靠近其所在实例的原型，保证实例内部紧凑性。
  - **Pushing项**（L_push）：拉开不同实例原型之间的距离，保证实例间分离（η为语义相似度权重）。
  - **交叉视图项**（L_cross）：对齐同一实例在不同视角下的原型，保证跨视图一致性。
- 总实例损失：L_ins = λ_pull·L_pull + λ_push·L_push + λ_cross·L_cross。

**阶段三：实例中心耦合（Instance-Centric Coupling）**

三个良性循环的交互机制：
- **边界感知重建（Boundary-Aware Reconstruction）**：从像素对齐实例特征图计算边界分数（4邻域最大余弦距离），映射为软边界权重 b(p)。边界权重引导RGB损失聚焦于实例边界区域，改善深度不连续处的高斯几何精度。
- **语义引导的实例判别（Semantic-Guided Instance Discrimination）**：渲染语义特征并投影到语言对齐空间，与教师特征对齐（L_sem）。构建实例级语义原型，用语义相似度动态加权pushing项：语义相似（易混淆）的同类实例获得更大的分离权重。
- **实例锚定的语义聚合（Instance-Grounded Semantic Aggregation）**：推理时用HDBSCAN对渲染的实例嵌入聚类，得到对象区域；在每个预测实例内聚合语义特征形成对象级原型，与文本嵌入比较分配开放词汇标签，抑制局部语义噪声，保持对象边界。

**总训练目标**：L = L_rgb + L_distill + λ_ins·L_ins + λ_sem·L_sem + λ_bd·L_bd-rgb，其中L_rgb为MSE + 感知损失，L_distill用于与几何基础模型的伪监督保持一致。

## 6. 论文的主要结论与发现

1. **共享高斯表示实现实例锚定**：将实例特征附着在共享3D高斯上并通过可微渲染监督，相比IGGT（无渲染）显著提升跨视图实例一致性（T-mIoU 64.03 vs 61.99，T-SR 51.04 vs 45.15）。
2. **双向交互有效**：实例线索改善边界处重建几何（RMSE从0.2375降至0.1985）；语义线索提升同类实例判别（消融显示加入困难负样本后mIoU在各视图设置下均有提升）；实例区域聚合语义证据提升对象级一致预测。
3. **前馈效率优势显著**：相比逐场景优化方法，推理时间从分钟级降至秒级（~3s），同时跨数据集泛化性能更优。
4. **跨视图一致性提升**：显式的交叉视图原型对齐（L_cross）和3DGS联合优化都对时序/跨视图一致性有正贡献。
5. **总体验证**：在无位姿输入、多视图设置和未见数据集上，InstanceSplat在NVS、实例分割和开放词汇语义理解上均达到SOTA。

## 7. 优点

- **统一框架创新性强**：首个将重建、实例学习和语义学习统一在前馈3DGS中的工作，三个任务共享同一个显式3D表示，实现了真正的端到端联合学习。
- **设计巧妙**：
  - 实例身份作为高斯的内在属性（而非后处理），天然具备可渲染性和跨视图一致性。
  - 边界感知损失仅依赖学习到的实例特征，不需要GT边界或透明度门控。
  - 语义相似度动态加权pushing项是\"语义帮助实例\"的优雅实现。
  - 实例锚定语义聚合在推理时零额外训练成本即可提升语义一致性。
- **实验全面且对比公平**：与两类方法分别对比，统一分辨率、统一协议；消融实验逐一验证每个模块的必要性。
- **效率与泛化兼顾**：训练仅约21小时（2×A800），推理约3秒，在未见数据集上仍能保持领先，实用价值突出。

## 8. 不足与局限

- **计算开销随规模增长**：论文自述\"特征聚类随着视图和高斯数量增加而变得更昂贵\"，HDBSCAN聚类在稠密场景或大规模输入时可能成为瓶颈。
- **域迁移下的性能退化**：LERF数据集的实验显示8视图→16视图时性能下降（mIoU从63.22降至53.85），论文归因于域偏移导致的位姿精度恶化，说明模型对跨域多视图对齐的鲁棒性有待提升。
- **类别不平衡问题**：4视图设置下mAcc偏低，暴露了模型对罕见类别的敏感性，但论文仅给出了定性解释，缺乏针对性的解决策略或深入分析。
- **边界重建收益有限**：边界感知重建对深度指标改善显著（RMSE↓16.4%），但对渲染质量的提升很微小（PSNR仅+0.02），实际视觉收益有待验证。
- **外部泛化验证范围有限**：仅使用LERF一个未见数据集评估，且对比的逐场景方法在输入视图数量和评估粒度上存在差异，泛化性结论的支撑略显单薄。
- **文本编码空间受限**：语义特征先渲染到紧凑空间再投影到教师空间，课程语义（如颜色/材质等属性）的表达可能受限于紧凑特征的容量。
