## 摘要
联合嵌入预测架构通过预测缺失观测的潜在表示来进行学习，然而许多掩码JEPA主要通过它们产生的编码器来评估。我们探究，当原生3D场景中整个实体缺失时，训练后的预测通路本身会推断出什么。我们引入SR-JEPA，一种面向场景级点云的点原生JEPA，其原始冻结预测通路可在指定位置进行查询。在评估时，编码前移除一个物体的所有点，并在其质心处替换为相同的、无形状的32点查询。训练仅使用自包含的3D EMA目标：不涉及重建、语义标签、语言或提升的2D特征。在5,953个保留的ARKitScenes物体上，估算的潜在表示达到43.13%的语义身份宏平均准确率，比最强基线高出22.18个百分点。随机化预测路径会使准确率下降9.78个百分点，而替换匹配的供体上下文则会下降21.98个百分点。在8,570对Sr3D支持对上，完整潜在表示达到41.15 AP；从缺失物体潜在表示解码出的身份，结合锚点身份和几何信息，达到39.37 AP，留下1.78个百分点的未解决残差。这些结果揭示了可查询、可组合的3D预测状态：模型完成依赖于上下文的实体内容，下游计算将其与度量几何相结合。

## Abstract
Joint-embedding predictive architectures learn by predicting latent representations of missing observations, yet many masked JEPAs are evaluated primarily through the encoders they produce. We ask what a trained predictive pathway itself infers when an entire entity is absent from a native 3D scene. We introduce SR-JEPA, a point-native JEPA for scene-scale point clouds whose original frozen predictive pathway can be queried at a supplied location. At evaluation, every point of one object is removed before encoding and replaced by the same shape-free 32-point query at its centroid. Training uses only self-contained 3D EMA targets: no reconstruction, semantic labels, language, or lifted 2D features. On 5,953 held-out ARKitScenes objects, the imputed latent reaches 43.13% semantic-identity macro accuracy, 22.18 points above the strongest floor. Randomizing the prediction path removes 9.78 points, while substituting matched donor context removes 21.98 points. On 8,570 Sr3D support pairs, the full latent reaches 41.15 AP; identity decoded from the missing-object latent, combined with anchor identity and geometry, reaches 39.37 AP, leaving an unresolved 1.78-point residual. These results reveal a queryable, compositional 3D predictive state: the model completes context-dependent entity content, which downstream computation combines with metric geometry.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：现有 JEPA（联合嵌入预测架构）类方法（如 I-JEPA、V-JEPA）虽然通过"预测缺失观测的潜在表示"进行自监督学习，但绝大多数评估聚焦于**编码器**的下游迁移质量，预测通路本身的推理能力鲜少被研究。作者主张预测器应该成为独立的科学对象，而非仅仅作为训练附属物。
- **核心问题**：当一个**完整实体**（而非部分掩码块）从原生 3D 场景中完全移除时，训练好的冻结预测通路能否在指定查询位置推断出该缺失实体的语义内容？这种推断出的状态是否能与度量几何相结合，支持下游结构化决策？
- **整体含义**：论文试图揭示一种"可查询、可组合"的 3D 预测状态——预测通路补全与上下文兼容的实体信息，下游计算再将"是什么"与"在哪里"相结合，推导出空间关系。该工作将 JEPA 的预测器从"训练工具"提升为"推理接口"。

## 2. 论文提出的方法论

- **核心框架**：SR-JEPA（Self-supervised Representation JEPA）是面向**场景级点云**（scene-scale point cloud）的点原生（point-native）JEPA。
- **双分支结构**：
  - **上下文编码器**：Point Transformer V3（PT-v3m2），处理可见占用区域，5 阶段深度 (3, 3, 3, 12, 3)，宽度 (48, 96, 192, 384, 512)，输出各阶段上采样拼接后得到 1232 维逐点特征。
  - **目标编码器**：与上下文编码器同架构，通过 EMA（动量从 0.994 线性增至 1.0）更新，观察完整场景，无梯度。
  - **预测器**：窄而小的稀疏 PT-v3（宽 192、深 6、6 头注意力），输入侧由 1232→192 线性映射，输出侧 192→1232 投影，辅以可学习的 mask token 指定查询位置。
- **损失函数**：五阶段加权 L1 潜在预测损失：
  \[
  \mathcal{L}_{\text{mask}} = \frac{1}{5}\sum_{\ell=1}^{5} \frac{1}{|M| d_\ell} \sum_{i \in M} \left\| \hat{z}_i^\ell - \operatorname{sg}(z_i^\ell) \right\|_1
  \]
  另加权重 λ=0.1 的可见 token 预测项。目标完全由 3D EMA 编码器自生成——**无输入重建、无语义标签、无语言嵌入、无 2D 基础模型特征**。
- **掩码策略**：仅对占用 3D 格（occupied cells）采样连续立方体块，避免在空体积上浪费目标；掩码块大小 0.1→0.4 m，掩码比例 0.3→0.7。
- **训练设置**：在 ScanNet 1,201 个训练场景上预训练 100 epochs，AdamW、base LR 0.002、OneCycle 调度、weight decay 0.04→0.2。
- **评估协议（deletion-first prediction）**：
  1. 在编码前删除目标物体全部点；
  2. 在标注质心处插入固定模板：32 点球面（半径 0.15 m），**无类别、尺寸、朝向、轮廓信息**；
  3. 输入上下文编码器+冻结预测通路，输出 1232 维逐查询点潜在表示，平均后作为"imputed latent"；
  4. 下游 MLP 探针消费该向量做身份识别或支持关系判断。
- **可控对比框架**：通过四种干预（随机模型/随机预测器嫁接/匹配供体上下文/联合身份-几何控制）区分信号来源，辨别"可解码性、学习补全、上下文依赖、下游组合"。

## 6. 论文的主要结论与发现

1. **实体身份可补全**：冻结预测通路从完全缺失的物体位置能解码出 43.13% 的语义身份宏准确率，显著高于所有捷径基线，且跨两种训练配方稳定。
2. **补全依赖上下文与预测路径**：随机化预测器降低 9.78 点；替换为匹配供体场景降低 21.98 点——说明输出来自学习的预测路径和正确的场景上下文，而非先验或随机特征。
3. **预测状态具有组合性**：在支持关系上，身份+几何联合控制（39.37 AP）几乎复制了完整潜在表示的效用（41.15 AP），残差 1.78 点不显著——表明预测状态为下游提供"实体内容"，下游再结合"度量几何"完成结构决策。
4. **分工简单清晰**：预测通路估计"该位置有什么"，度量坐标提供"在哪儿"，二者结合即可计算关系——无需在状态中为每个关系显式建模独立 token。

## 7. 优点

- **问题设定独特**：将 JEPA 的预测器提升为可查询的推理接口，而非仅关注编码器迁移；"完整物体删除"比部分掩码更严格地测试了预测能力。
- **查询模板干净**：固定 32 点球形查询完全不含目标类、尺寸、方向、轮廓，杜绝了查询位置本身的泄漏；
- **控制实验设计严谨**：
  - 随机预测器嫁接（保留训练编码器）与匹配供体上下文（保留探针）分别隔离了"预测路径训练"与"正确上下文"的贡献；
  - 联合身份-几何 oracle 有效区分任务敏感度与模型能力；
  - 配对供体构造（union-hole）防止通过删除边界形状识别实验臂。
- **自包含训练目标**：无需语义标签、语言、2D 基础模型特征，显示原生 3D 自监督的潜力；
- **统计严谨**：100k 场景聚类 bootstrap、多 checkpoint × 多 head、场景分离划分、交叉拟合选择，逻辑链完整。

  - 模型为静态场景设计，不涉及动力学、行动条件化、规划、多步 rollout。
- **资源透明性不足**：没有提供 GPU 数量、型号、训练实际耗时等算力信息。

## 总结

SR-JEPA 通过"删除完整物体、插入形状无关查询、读取冻结预测通路输出"的实验范式，令人信服地展示了场景级点原生 JEPA 的预测器能够补全依赖于上下文的实体身份，并与度量几何组合以支持结构化空间关系决策。控制实验的严谨性（配对供体、随机预测器、联合 oracle）是方法论上的突出亮点。但受限于支持任务样本量小、空间感知范围未决、缺少与其他目标函数的严格对比以及算力细节不透明，其推广性和因果归因仍有待后续验证。
