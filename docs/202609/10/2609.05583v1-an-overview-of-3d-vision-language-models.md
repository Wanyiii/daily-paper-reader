## 摘要
视觉-语言模型（VLMs）通过对齐视觉与文本嵌入正在重塑计算机视觉，使模型能够识别视觉概念并利用自然语言对其进行推理。然而，传统的 3D 深度学习模型通常针对特定任务（如分类、分割或检测）进行训练，不能自然地支持以其嵌入空间进行跨模态检索，即以文本或图像作为查询。为了解决这一问题，基于对比语言-图像预训练（CLIP）的方法将 3D 嵌入与预训练的图像和文本表示对齐，催生了支持零样本分类、跨模态检索以及 3D 形状开放词汇识别的 3D 视觉-语言模型（3D VLMs）。本教程对 3D VLMs 进行概述，内容从 3D 表示的基本定义及其编码为嵌入，到跨模态对比对齐、现代多模态框架以及 3D 视觉-大语言模型（3D VLLMs）。我们介绍用于多模态嵌入对齐的对比学习的主要定义，并重点介绍语言引导的 3D 高斯泼溅、3D 形状生成以及面向机器人学的具身 AI 方面的最新进展。

## Abstract
Vision-Language Models (VLMs) are reshaping computer vision by aligning visual and textual embeddings, allowing models to recognize visual concepts and reason about them using natural language. Traditional 3D deep-learning models, however, are typically trained for specific tasks, such as classification, segmentation, or detection, and do not naturally support cross-modal retrieval from their embedding spaces using text or images as queries. To address this issue, Contrastive Language-Image Pretraining (CLIP)-based methods align 3D embeddings with pretrained image and text representations, giving rise to 3D Vision-Language Models (3D VLMs) that support zero-shot classification, cross-modal retrieval, and open-vocabulary recognition of 3D shapes. This tutorial provides an overview of 3D VLMs, ranging from basic definitions of 3D representations and their encoding into embeddings to cross-modal contrastive alignment, modern multimodal frameworks, and 3D Vision-Large Language Models (3D VLLMs). We present the main definitions of contrastive learning for multimodal embedding alignment and highlight recent advances in language-guided 3D Gaussian splatting, 3D shape generation, and embodied AI for robotics.

## 2. 方法论：核心思想与关键技术细节

本文"方法论"实为**综述的组织框架 + 对比对齐的数学表述**，可分为三块。

### 2.1 问题设定与统一符号

- 给定 **N 个三元组** $\{(S_i, I_i, T_i)\}_{i=1}^N$：$S$ 为 3D 表示，$I$ 为 2D 图像（可由 3D 表示在任意视角渲染得到），$T$ 为文本描述。
- 三种专用编码器 $E_S, E_I, E_T$ 分别处理 3D、图像、文本；$E_S$ 的结构**取决于几何表示类型**。
- 在 CLIP 式方法中，$E_I$ 与 $E_T$ 通常从预训练 VLM（如 CLIP）初始化并**保持冻结**，只优化 $E_S$ 去匹配其视觉–语义空间。
- 特征经投影层 $P_S, P_I, P_T$ 映射为**ℓ2 归一化**的嵌入 $z_S, z_I, z_T$，位于公共空间 $\mathbb{R}^d$。
- 文本语义可表现为类别名、物体描述、caption、问题、指代表达或指令（动作）。

### 2.2 3D 表示与编码器（决定 $E_S$ 架构）

| 表示 | 特点 | 代表编码器 |
|---|---|---|
| 多视图图像 | 2D 渲染 $x_i = \{v_i^{(1)},…,v_i^{(V)}\}$，共享 2D 编码器后聚合为物体级表示，可复用 2D 基础模型 | MVCNN、ViT |
| 点云 | $\{p_i \in \mathbb{R}^3\}$，可带法向/颜色；LiDAR 与深度传感器的原生输出；**无序、置换不变** | PointNet、DGCNN、Point-BERT、Point-MAE、Point Transformer（向量自注意力 + 可训练 3D 相对位置编码）、SparseConv/Minkowski（广义稀疏张量卷积）；新近方法把点云分解为紧凑可解释基元（SuperFlex 可变形超二次曲面） |
| 网格 Mesh | 顶点/边/面定义的三角网格，是图形学标准表示，但**连接性给学习算子带来困难** | MeshCNN（在边上定义卷积与任务驱动池化，保持拓扑）、MeshNet（面级公式化） |
| 隐式场 | 连续占据场或 SDF | Occupancy Networks、DeepSDF 等；Michelangelo 用 CLIP 把隐式表示与图像/语言嵌入对齐 |
| 3D 高斯泼溅 3DGS | 各向异性 3D 高斯集合 $(\mu_i, \Sigma_i, \sigma_i, c_i)$，可微 splatting 实现实时逼真渲染，且本质是点云，可复用点云编码器 | 点云编码器；TRELLIS 可将高斯 splat 编解码到适合 3D 内容生成的嵌入空间 |

### 2.3 对比对齐的几何直觉与损失

- **几何直觉**：几何、图像、语言可描述同一物体却结构上不可比，各编码器初始特征空间中的距离由编码器特性而非语义对应主导。对比学习把所有模态映射到**按语义兼容性组织的共享嵌入空间**，类比为"语义地图"：同物体表示彼此靠近，无关物体彼此远离。
- **单位球视角**：嵌入 ℓ2 归一化后落在单位球面上，内积即余弦相似度，**对齐等价于减小表示间的夹角 θ**。
- **对齐前后**：对齐前 3D 锚点 $a$ 可能比其正样本更接近某个负样本；对比优化提高正样本相对 batch 内其余候选的相似度（图 3 的 pull closer / push apart）。
- **公式体系**：
  - 温度缩放余弦相似度：$s^{a,b}_{ij} = (z^{M_a}_i)^\top z^{M_b}_j / \tau$，$\tau>0$ 控制相似度分布集中度。
  - **方向性 InfoNCE**（以 $M_a$ 为锚点，在 $M_b$ 全部候选中识别配对）：
    $$\mathcal{L}_{M_a \to M_b} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(s^{a,b}_{ii})}{\sum_{j=1}^{N}\exp(s^{a,b}_{ij})}$$
    可理解为 N 路跨模态匹配目标；相似度矩阵**对角线为匹配正对，非对角线为 batch 内负候选**。
  - **双向对称**（遵循 CLIP）：$\mathcal{L}_{M_a \leftrightarrow M_b} = \frac{1}{2}(\mathcal{L}_{M_a \to M_b} + \mathcal{L}_{M_b \to M_a})$
  - **三模态 3D VLM 目标**：$\mathcal{L}_{\text{3D-VLM}} = \mathcal{L}_{S \leftrightarrow I} + \mathcal{L}_{S \leftrightarrow T}$，即 3D 表示**独立地与图像、文本分别对齐**；当图像/文本编码器继承自 CLIP 时，该目标把其视觉–语义结构迁移给 3D 编码器。
  - 现有方法的差异主要体现在：3D 表示、骨干网络、监督信号、配对构造、可训练组件。

### 2.4 五阶段分类法（Taxonomy）

1. **闭集 3D 识别**：MVCNN（多视图）、PointNet（点集）→ DGCNN（动态局部图）→ transformer 预训练（Point-MAE 等）；输出空间仍由任务标签定义。
2. **基于投影的 VLM 适配**：PointCLIP（点云渲染为多视图深度图，与文本类别嵌入比对）、PointCLIP V2（更真实的投影 + 3D 专用 prompt）、EPCL（冻结 CLIP 特征做点云理解）。优点是与预训练 2D 模型的接口简单，常无需学专用 3D 编码器；**缺点**是依赖视角选择、渲染质量与投影保留的几何信息。
3. **联合嵌入空间**：训练专用 3D 编码器产出与预训练图像/文本兼容的特征。CG3D、CLIP2Point 做早期 2D→3D 迁移；**ULIP 确立被广泛采用的三模态范式**；后续在数据、监督、架构规模上推进——OpenShape（大规模多样 3D 数据，如 Objaverse/Objaverse-XL，面向开放世界识别）、Uni3D（可扩展 ViT 骨干）、ULIP-2（自动生成描述替代人工 caption）、Sculpting（多模态增强）、OpenDLIGN（深度对齐图像监督）、3D-MRL（嵌套 Matryoshka 表示）、DuoDuo-CLIP（多视图建模模态鸿沟）、TAMM（轻量 adapter）；更近的 Concerto（3D 自蒸馏 + 2D–3D 联合嵌入，经线性 translator 映射进 CLIP 语言空间）、Utonia（跨异构点云域的统一自监督编码器，特征也利于多模态空间推理与具身策略）。**局限**：需大规模配对数据、多模态监督有限或含噪、对比预训练成本高。
4. **3DGS 与 VLM 结合**：点云几何明确但外观信息有限，3DGS 的基元联合编码位置、协方差、不透明度与颜色，与 VLM 处理的 2D 图像天然衔接。UniGS（高斯感知特征与图像/语言嵌入三模态对齐）、TIGaussian（把高斯属性分解为专用隐分支 + 多视图融合实现空间一致对齐）、CLIP-GS（高效高斯 tokenization + 视角感知监督，面向跨模态检索）。相较点云，高斯表示**几何–外观–图像监督耦合更紧**，但依赖重建质量并带来显著存储或逐场景成本。
5. **3D VLLM**：架构 = 3D 编码器/分词器 + 学习到的 projector + 预训练语言骨干（如 Qwen3-VL）。PointLLM、ShapeLLM 确立通用架构；PointAlign 引入特征正则以在语言建模中保几何信息；Multi-3DLLM 扩展到多物体关系推理；SAGE 直接把点云转为离散 token；N3D-VLM 结合原生 3D grounding 与语言空间推理。**学习目标从跨模态比较变为语言生成**，带来幻觉、几何保真度、token 效率、3D 指令数据稀缺等挑战。

### 2.5 应用维度（图 5 的八类任务）

零样本分类、跨模态检索、视觉 grounding、问答、场景理解、空间推理、3D 生成、具身 AI。

## 6. 主要结论与发现

- **演进主线**：3D 视觉–语言学习正从 **2D 投影适配 → 原生联合嵌入 → 3DGS 对齐 → 3D VLLM** 逐步演进，即**从固定任务特定输出，走向开放词汇表示，再走向生成式语言接口**。
- **范式分工**：
