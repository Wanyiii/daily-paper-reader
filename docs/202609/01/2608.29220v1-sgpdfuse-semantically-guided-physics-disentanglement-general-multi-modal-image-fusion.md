## 摘要
多模态图像融合（MMIF）旨在将互补的传感器数据集成到单一表示中，在消除环境干扰的同时保留内在场景真实感。大多数现有方法依赖盲特征聚合，这擅长信号累积，但无法区分本质内容与物理退化。我们提出SGPDFuse，通过构建在预训练视觉基础模型上的语义-物理参数桥（SPPB），利用内在-变化原理将输入映射到物理解缠的结构表示，从而弥合这一差距，将不变场景属性与瞬态环境因素解耦。为引导这种分解，我们引入了语义对齐机制：通过余弦相似度将融合表示显式锚定到同一基础模型特征空间中的显著语义特征，以保留关键目标，同时通过Gram矩阵正则化强制物理纹理保真度，以严格消除不自然伪影。大量实验表明，SGPDFuse使用单一架构在红外-可见光、多焦点和多曝光基准上均实现了最先进的性能。

## Abstract
Multimodal image fusion (MMIF) aims to integrate complementary sensor data into a single representation that preserves intrinsic scene reality while eliminating environmental interferences. Most existing approaches rely on blind feature aggregation, which excels at signal accumulation but fails to distinguish essential content from physical degradations. We propose SGPDFuse, which bridges this gap by mapping inputs into a physics-disentangled structural representation via a Semantic-Physical Parametric Bridge (SPPB) built on pretrained vision foundation models, utilizing the Intrinsic-Variation principle to decouple invariant scene attributes from transient environmental factors. To guide this decomposition, we introduce a Semantic Alignment mechanism: we explicitly anchor the fused representation to salient semantic features in the same foundation model feature space via cosine similarity to preserve critical targets, while enforcing physical texture fidelity through Gram-matrix regularization to strictly eliminate unnatural artifacts. Extensive experiments demonstrate that SGPDFuse achieves state-of-the-art performance across infrared-visible, multi-focus, and multi-exposure benchmarks using a single architecture.

- 多模态图像融合（MMIF）的目标是将不同传感器（如红外与可见光、不同曝光、不同焦点）捕获的互补信息整合为一张图像，在保留场景真实内容的同时抑制环境干扰。
- 现有主流方法大多采用“盲特征聚合”范式：将融合视为信号加权求和或特征拼接问题，缺乏对“本质内容”与“物理退化”的区分能力。
- 论文观察到，不同物理成像过程（如红外热辐射模型 `L = εB(T) + (1-ε)L_env`、Retinex 模型 `I = R·L`、散焦模型 `I = S⊗K`）具有统一结构 `I = G(Intrinsic, Variation)`，即观测是“本质成分”和“变化成分”的混合。
- 然而现有融合方法直接对纠缠信号操作，无法彻底消除伪影（如反射面上的热鬼影、曝光失衡的色偏、失焦纹理丢失等）。
- 为此论文提出**SGPDFuse**，将融合问题重新定义为“物理量解缠”：先分离内在场景属性（Φ）与环境干扰（Ψ），再仅对内在成分进行融合，并借助预训练视觉基础模型（DINOv3）的语义能力来估计物理变化参数，实现单一架构下的通用多模态融合。

### 2. 论文提出的方法论

#### 核心思想

- 遵循“内在-变化”（Intrinsic-Variation）原则，将每种模态观测建模为 `I^(m) = G(Φ^(m), Ψ^(m))`，其中 Φ 为跨模态不变的本质成分，Ψ 为需抑制的环境/传感器变化成分。
- 论文论证了在纠缠信号上直接加权融合（`w⊙I_A + (1-w)⊙I_B = Φ + w⊙Ψ_A + (1-w)⊙Ψ_B`）无法消除残余 Ψ，因此必须先估计 Φ 和 Ψ。
- 提出“尺度对齐分解”：将每个源图像分解为低频基础（Base）和高频细节（Detail），并在每个频带上独立进行内在-变化解缠，形成 `I = G_b(Φ_b, Ψ_b) + G_d(Φ_d, Ψ_d)` 的四阶段流程。

#### 关键技术细节

1. **双分支统一编码器**：共享编码器 `E_θ` 从每个源图像提取基础特征 `F_base` 和细节特征 `F_detail`；细节分支通过交叉注意力注入 DINOv3 语义 token，基础分支保持纯卷积，避免语义污染低频成分。
2. **语义-物理参数桥（SPPB）**：
   - 使用 LoRA 微调的 DINOv3 提取空间语义 token `Z^(m)`，编码与物理变化无关的材料/结构信息。
   - 通过“材料库”进行软最近邻回归：`φ̂_ij = Σ_k softmax(-||Z_ij - e_k||/τ) · φ_k`，得到逐像素物理参数（发射率、曝光最优性、聚焦概率）。
   - 最终变化置信图 `W = σ(f_θ(F_A, F_B) + g(φ̂))`，其中 `f_θ` 聚合编码器特征，`g` 为可学习标量投影。
3. **内在-变化解缠**：
   - 通过 `F_Φ = W⊙F + R_Φ(W⊙F)`、`F_Ψ = (1-W)⊙F + R_Ψ((1-W)⊙F)` 将特征分解为 Φ 与 Ψ；`R_Φ`、`R_Ψ` 为残差网络用于补偿非正交。
   - 加入一致性约束 `F_Φ + F_Ψ ≈ F`，正则化残差网络行为。
   - 互补源分配：`W_A = W`，`W_B = 1-W`，以编码物理互补性。
   - 融合前**直接丢弃所有 Ψ 成分**，只使用 Φ 进行融合。
4. **物理引导融合**：
   - 基础层：使用 SE 通道注意力按物理置信度加权融合；
   - 细节层：采用 L1 活动度权重选择更清晰的源。
5. **损失函数**：
   - 两阶段训练：阶段1为重建预训练（L1+SSIM），阶段2为端到端融合训练。
   - 总损失 `L_total = L_IG + λ_decomp L_decomp + λ_RecA L_RecA + λ_tv L_tv`，其中 `L_IG` 为像素/梯度保真损失，`L_decomp` 包含交叉相关与一致性项，`L_tv` 为 W 的平滑正则。
   - **重建对齐损失 `L_RecA`**：在 DINOv3 特征空间中对融合结果进行双监督——余弦内容对齐（保持语义显著特征）和 Gram 矩阵风格正则（消除纹理伪影）。
