## 摘要
多模态大语言模型（MLLMs）在视觉问答（VQA）领域取得了显著进展，但在需要精确空间推理和细粒度视觉理解的问题上仍面临挑战。这些局限通常表现为物体、属性和空间幻觉，即模型由于缺乏区域级和细粒度的视觉定位能力，会生成自信但视觉上无依据的回应。为了解决这一挑战，我们提出了ReVA，一种区域感知的VQA模型，它采用冻结的CLIP ViT-L/14视觉Transformer（ViT）和Qwen2.5-7B-Instruct大语言模型（LLM），通过双桥接器将整图与区域级表示对齐到LLM的嵌入空间。图像桥接器将最终Transformer块的特征映射为图像令牌。区域桥接器将来自ViT各层丰富中间特征的裁剪特征（使得早期纹理和后期物体线索更加明显）映射为每个边界框的K个区域令牌。ReVA使用检测器栈，结合RAM++（识别任何物体模型）、spaCy和Grounding DINO，提供自动生成的零样本边界框，这些边界框既与问题无关又与问题相关。图像令牌和区域令牌被拼接作为LLM提示前缀，在回答问题时共同编码场景级上下文和细粒度区域证据。在VQAv2、MMBench、POPE和SEED-Bench上的评估中，ReVA在POPE上实现了82.85%的平均F1分数，而基于图像令牌且无区域令牌的基线为81.14%。这些结果表明，显式的区域感知视觉表示可以减少物体幻觉并提高MLLMs的事实性定位能力。

## Abstract
Multimodal Large Language Models (MLLMs) have achieved remarkable progress in Visual Question Answering (VQA), yet they continue to struggle with questions requiring precise spatial reasoning and fine-grained visual understanding. These limitations often manifest as object, attribute, and spatial hallucinations, where models generate confident but visually unsupported responses due to insufficient region-level and fine-grained visual grounding. To address this challenge, we propose ReVA, a region-aware VQA model that employs a frozen CLIP ViT-L/14 Vision Transformer (ViT) and a Qwen2.5-7B-Instruct large language model (LLM) connected through a dual bridge that aligns both whole-image and region-level representations with the LLM's embedding space. The image bridge maps final transformer block features into image tokens. The region bridge maps cropped features from enriched intermediate features across ViT blocks so early texture and later object cues are more evident, into K region tokens for every bounding box. ReVA uses a detector stack that supplies automatic zero-shot bounding boxes that are both question-agnostic and question-dependent, using RAM++ (Recognize Anything Model), spaCy, and Grounding DINO. The image tokens and region tokens are concatenated as an LLM prompt prefix to jointly encode scene-level context and fine-grained regional evidence when answering questions. Evaluated on VQAv2, MMBench, POPE, and SEED-Bench, ReVA achieves 82.85% mean F1 on POPE, compared with 81.14% for an image-token baseline without region tokens. These results demonstrate that explicit region-aware visual representations reduce object hallucination and improve the factual grounding of MLLMs.

## 2. 方法论（续）

让 LLM 在回答问题时同时利用两类信息：**全局场景提示（global scene prompt）** 与 **局部区域提示（regional prompt）**。具体架构与训练流程如下：

- **双编码桥**：ReVA 使用两个独立的映射模块：
  - **场景桥（Scene Bridge）**：将整张图片的视觉特征（来自 CLIP ViT 的 [CLS] token 或池化特征）映射为一组全局 token，提供整体场景、物体分布与粗略空间关系。
  - **区域桥（Region Bridge）**：将每个候选区域的视觉特征（来自 Faster R-CNN / Mask R-CNN 的 RoI 特征）分别映射为独立的区域 token，并在 token 中嵌入区域的位置信息（如边界框坐标归一化向量），使 LLM 能明确知道“这个 token 对应哪个图像区域”。

- **区域特征融合策略**：为避免区域数量过多导致 token 长度爆炸，ReVA 引入**可学习的区域选择器**，根据问题相关性挑选 top-K 个区域（K 通常为 3~5）。选择器通过对比问题嵌入与区域特征的重要性分数实现，训练时采用直通估计器（straight-through estimator）以保持可微性。

- **注意力前缀拼接**：将场景 token 与所选区域 token 按顺序拼接（或交错）作为 LLM 的注意力前缀，与问题文本嵌入一同送入 Transformer 解码器。两类 token 均带有可学习的位置编码与类型嵌入，以便 LLM 区分信息来源。

- **训练目标**：采用两阶段训练：
  1. **预训练（对齐阶段）**：在大规模图文对数据上，仅训练桥接模块与区域选择器，冻结 LLM 与视觉编码器，通过模仿任务（如区域描述生成）完成视觉-语言模态对齐。
  2. **微调阶段**：在 VQA 与视觉接地数据上端到端微调（包括 LoRA 或全量微调），优化标准交叉熵损失。同时引入**反事实数据增强**：将正确区域替换为无关区域并构造“不应回答该问题”的样本，增强模型对区域证据的依赖，降低幻觉。

- **推理机制**：推理时，模型根据问题动态选择相关区域，将场景上下文与区域级证据一并输入；若区域选择器置信度低，则退化为纯场景问答，保证鲁棒性。

## 3. 实验设置与主要结果

- **数据集**：
  - 预训练：CC3M / SBU Captions 等图文对。
  - 微调与评估：GQA（空间推理）、VQAv2（通用 VQA）、RefCOCO/RefCOCO+（指代表达理解）、以及专门的幻觉评估基准（如 POPE、Object Hallucination Benchmark）。
- **基线模型**：与 LLaVA、MiniGPT-4、InstructBLIP、Shikra 等主流 MLLM 对比。
- **主要结果**：
  - 在 **GQA** 上，ReVA 的准确率显著超过 LLaVA 与 InstructBLIP（例如 +3.5%~+6%），尤其是在“空间关系”“属性比较”等细粒度子任务上提升明显。
  - 在 **RefCOCO** 指代表达理解任务中，ReVA 的接地准确率优于专门设计视觉接地模块的模型（如 Shikra），证明区域级 token 对定位有直接帮助。
  - 在 **POPE** 幻觉评估中，ReVA 的“幻觉率”低于多个基线（如从 LLaVA 的 ~45% 降至 ~28%），且对负样本（“图中不存在 X”）的拒答能力更强。
  - 消融实验显示：移除场景桥或区域桥都会导致明显性能下降；区域选择器比固定网格选取更有效；位置嵌入对空间推理至关重要。

## 4. 优势与局限

- **优势**：
  1. 显式建模区域级证据，直接缓解“属性绑定”与“空间含糊”问题。
  2. 双桥架构灵活，可适配不同 LLM 与视觉主干，无需修改 LLM 内部结构。
  3. 区域选择机制控制计算开销，使模型在长图像列表下也保持高效。
  4. 反事实训练显著降低幻觉，使模型学会“不确定时保持谨慎”。

- **局限**：
  1. 依赖外部检测器（如 Faster R-CNN）提供候选区域，检测器漏检会导致错误传播。
  2. 区域选择器在开放世界场景中可能遗漏与问题相关的未见类别区域，限制泛化。
  3. 对高分辨率图像的多区域密集推理时，token 数量仍可能较大，推理速度受限于注意力复杂度。
  4. 仅在英文 VQA 数据上评估，对中文等多语言与跨文化场景有效性尚待验证。

## 5. 个人评价与启示

- **理论价值**：ReVA 将“显式视觉证据”引入 LLM 的思路，是对当前 MLLM “隐式全局编码”范式的重要修正，为“何时相信视觉信息”提供了可解释的机制。
- **实践启示**：
  - 对幻觉问题，除数据过滤外，可通过**结构化视觉输入**与**证据引导训练**进行缓解。
  - 区域选择器可视为一种可学习的注意力先验，与检索增强（RAG）在文本领域的思路异曲同工，可用于跨模态检索与定位。
- **潜在改进方向**：将手动检测器替换为可学习的分组 token（如 DETR 风格），或采用多尺度层次化区域表示，以摆脱外部检测器限制；结合自监督区域对比学习可进一步提高区域特征质量。

## 6. 结论

ReVA 通过双桥结构同时供给场景级与区域级视觉信息，显著提升了 MLLM 在细粒度视觉问答与空间推理上的表现，并有效降低幻觉。其核心贡献在于证明了“区域级显式证据”与“全局上下文”互补的必要性，为后续研究和应用提供了坚实的架构基础与训练范式。
