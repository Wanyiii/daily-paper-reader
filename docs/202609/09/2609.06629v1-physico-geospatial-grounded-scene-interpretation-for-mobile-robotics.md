## 摘要
深度学习的最新进展使机器人代理能够与动态和非结构化环境进行交互。特别值得关注的是将物理-地理空间世界知识整合到此类系统中，可以通过物理感知的机器学习模型、用于建模关系的知识图谱或时空与逻辑推理来实现。在本研究中，我们引入了一种方法，通过整合语义描述、OpenStreetMap建筑数据和街道信息，以及从传感器系统获得的位置、时间和度量信息，利用LLM进行信息融合，从而增强用于场景解释的预训练、未修改的VLM的输出。我们将此概念应用于大学校园内的室外记录，在建筑接地任务中实现了0.83的F1分数，在路径表面接地任务中实现了0.64的F1分数（基于我们的试点评估集）。结果表明，所提出的解决方案在能力上能够提供物理-地理空间接地的自然语言描述。代码和结果可在 https://datahub.rz.rptu.de/hstr-csrl-public/publications/physico-geospatial-grounded-scene-interpretation 获取。

## Abstract
Recent advancements in deep learning allow robotic agents to interact with dynamic and unstructured environments. Of special interest is the integration of physico-geospatial world knowledge into such systems, either by using physics-aware machine learning models, knowledge graphs to model relationships or spatio-temporal and logical reasoning. In the present work, we introduce an approach to augment the output of pre-trained, unmodified VLMs used for scene interpretation by integrating semantic descriptions, OpenStreetMap building data and street information with positional, temporal and metric information obtained from our sensory systems, fusing this information using LLMs. We apply this concept to an outdoor recording within a university campus, achieving an F1-Score of 0.83 in the task of grounding buildings and 0.64 for path surface grounding on our pilot evaluation set. The results demonstrate the conceptual capability of the proposed solution to deliver physico-geospatial grounded natural language descriptions. Code and results are available at https://datahub.rz.rptu.de/hstr-csrl-public/publications/physico-geospatial-grounded-scene-interpretation

# 《面向移动机器人的物理-地理空间接地场景解释》论文总结

## 1. 核心问题与研究动机

- 移动机器人在动态非结构化环境中执行任务时，需要对其所处环境进行“场景解释”，这涉及目标检测与分割、行人重识别、自然语言描述、场景图生成等多类子任务。
- 当前主流方案依赖 LLM 和 VLM，它们能够生成通顺、语义丰富的场景描述，但其输出往往缺乏**与真实物理世界和地理空间的可靠对应关系**，可能出现幻觉、错误指称和不精确的定量信息（例如只说“一栋建筑”而无法给出建筑名称，只说“一条小路”而无法说明路面材质）。
- 已有工作要么聚焦于局部空间推理（如深度、几何关系），要么聚焦于纯遥感/卫星数据的“地理空间推理”，鲜有同时将**本地多模态传感数据（视觉、LiDAR、GNSS/INS）**、**物理量（如行人速度 km/h）**和**全局地理空间数据库（如 OpenStreetMap）** 融合起来、并对预训练 VLM 输出的场景描述进行“接地”的系统。
- 因此，本文提出一个模块化流水线，在不修改、不重训 VLM 的前提下，为其生成的场景描述注入经过物理与地理空间验证的事实性信息，从而得到更强的“经验现实接地”的自然语言场景解释。

## 2. 方法论

### 2.1 总体思想

- 保持预训练 VLM（如 Cosmos-Reason2-8B）完全不变，利用其生成的单句场景描述作为**基线文本**。
- 通过额外的视觉感知模块（目标检测、分割、跟踪、重识别）、立体视觉/LiDAR 深度、GNSS/INS 定位，以及 OSM 数据库，为场景中相关实体（建筑、路径、行人、车辆等）计算物理和地理空间属性。
- 最后使用一个本地运行的 LLM 作为“融合器”，将附加上下文信息与基线描述整合为一条新的、经过物理-地理空间接地的场景描述。

### 2.2 流水线步骤

1. **数据记录与标定**  
   - 使用多种自研移动平台（人形机器人 Unitree G1、四足机器人 Unitree Go1、电动轮椅、车辆、三脚架等），均配备定制模块化传感系统。
   - 记录 RGB 立体图像、LiDAR 点云、GNSS/INS 位置数据。
   - 本文聚焦离线后处理，而非实时机上运行。

2. **语义信息提取**  
   - 每 3 秒生成一条基线描述：每秒取一帧 RGB 图像，使用 Cosmos-Reason2-8B 输出一句话描述。
   - 开放词汇检测/分割：Grounding DINO + SAM，可检测预设类别和文本相关动态类别。
   - 行人重识别：自研自训练的 OSNet 跟踪模型；其余目标用 ByteTrack。

3. **3D 场景投影**  
   - 使用 Fast-FoundationStereo 从立体图像估计深度（也可用 LiDAR 深度）。
   - 将检测框中心或分割掩膜质心投影到 ECEF 坐标系的 3D 世界点。

4. **物理与地理空间接地**  
   - 对跟踪行人施加 Kalman 滤波和 RTS-Smoother，估计其行走速度（km/h）。
   - OSM 目标匹配：针对相关对象（建筑、路径）在世界坐标附近的候选 OSM 元素，计算距离；将多次观测输入**时序贝叶斯滤波**，对候选对象的似然建模为高斯距离模型：  
     \( L(d_i) = \exp(-d_i^2 / (2\sigma^2)) \)，其中 \(\sigma = 10\) 米（由距离噪声假设确定）。
   - 随时间累积每个轨迹对各 OSM 候选对象的置信度，最终选出最可能的建筑/路径实例。

5. **LLM 融合并生成接地描述**  
   - 将基线描述、OSM 匹配结果（建筑名称、路径表面等）、目标计数（如车辆数）、行人身份与速度等结构化信息一次性提供给 LLM，要求其生成增强后的场景描述。
   - 实验中使用的融合模型是 Llama4:16x17b 和 Llama4:128x17b，temperature = 0.0，4-bit 量化，通过本地 Open WebUI 服务调用。

### 2.3 关键技术细节

- 分层误差分析：将流水线分为“检测质量”、“OSM 匹配质量”和“端到端接地质量”三个环节，分别用 GT vs Detection、OSM vs Detection、OSM vs GT 衡量。
- 无需微调任何生成模型，仅将附加信息通过提示词交给 LLM，属于“模块化增强”思路。

## 3. 实验设计与评测

### 3.1 数据集/场景

- 录制约 8464 帧、20 Hz，总时长 7 分钟。

### 3.2 Benchmark 与指标

- 车辆计数：Mean Absolute Error (MAE)。
- LLM 最终增强描述质量：人工定义 8 类错误，其中 4 类由两名独立标注者评定（幻觉、错误实体、错误关系、遗漏输入描述），4 类可从文本自动判定（是否完整包含所有给定对象/建筑/路径/人员）；报告 Wilson 95% CI 及 Cohen's κ。

### 3.4 主要量化结果

- **建筑接地（端到端 OSM vs GT）**：Subset Accuracy = 0.56，F1 = 0.83。
- **路径接地（端到端 OSM vs GT）**：Subset Accuracy = 0.40，F1 = 0.64。
- 建筑 GT vs Detection：F1 = 0.92；路径 GT vs Detection：F1 = 0.90；OSM vs Detection 相对端到端有提升，说明检测环节非唯一瓶颈。
- **人员重识别**：GT vs Detection F1 = 0.84。
- **车辆计数**：MAE = 3.04，而 GT 中每 3 秒平均有 8.17 辆（中位数 5）。
- LLM 增强文本错误率：Llama4:128x17b 在 30% 的描述中至少含一种错误，Llama4:16x17b 为 52%；两类模型最主要的错误均为“Wrong Entities”（0.13 vs 0.15）。
- 标注一致性：多数类别的 Cohen's κ 处于中等至较高水平，个别类别（如幻觉）因默认值 0 占比过大导致 κ 接近 0。

## 6. 主要结论与发现

- **概念可行**：提出的模块化流水线确实能够把 OpenStreetMap 建筑/路径信息、行人速度、目标计数等经验事实注入到预训练 VLM 生成的场景描述中，且端到端建筑接地 F1 为 0.83，路径接地 F1 为 0.64，初步说明能够输出在物理-地理空间上“接地”的自然语言描述。
- **误差来源主要在检测与深度投影**：远处建筑、遮挡、深度估计噪声（尤其是立体视觉）导致物体投影位置不准，从而降低 OSM 匹配准确率。
- **路径 OSM 匹配比建筑更困难**：路径是连续线状实体且缺乏明确边界，OSM 中路径表达为无体积的“中心线”，投影点与之最近的几何关系会产生歧义。
- **大型 LLM 融合效果更优**：Llama4:128x17b 在整体错误率上明显低于 Llama4:16x17b；两模型常见错误是把正确输入关联到错误描述中实体，原因是没有足够相对位置/关系线索供模型映射。
- **保留原始 VLM 不做微调的路线可行**，但直接将额外数据加入 VLM 输入不会提升效果（文中提到初步测试无改善），需要额外用 LLM 后处理或未来做针对性微调。

## 7. 优点与亮点

- **方法论简洁且模块化**：不依赖修改/重训大型生成模型，外部知识以结构化信息形式注入，便于替换不同 VLM、LLM、分割模型、传感器。
- 深度整合了多源异构信息：视觉语义、物理量（速度）、地理数据库 OSM、时序贝叶斯滤波，实现了从像素到地理实体的完整链接。
- 评价设计较细致：同时报告 F1、Subset Accuracy、MAE、置信区间；将误差分解为检测、匹配和端到端三段，有助于定位问题。
- 对文本输出质量进行了结构化的人工错误分类，给出了置信区间和标注者一致性指标，增强评估透明度。
- 在实验室自有多种移动平台上有较广适用性（人形、四足、轮椅、车辆等），并公开了代码、结果、人工标注数据便于复现。
- 实际示例中可以看到，同一描述从模糊的“sand footway near buildings”被增强为“sandy footpath near Building O, speed 5 km/h, ~16 cars”，效果直观且具有应用价值。

## 8. 不足与局限

- **实验规模较小且单一**：仅一个校园场景、142 条短描述、七八分钟数据，难以证明通用性；缺少不同城市、类型区域和季节/天气变化测试。
- **深度估计与远距离投影误差大**：建筑在 >100 m 时匹配准确率明显下降，立体视觉在遮挡和半透明物体（如栏杆/树）场景中引入显著噪声。
- **OSM 路径匹配的内在缺陷**：路径“中心线”表示方式和人类/车辆可通行区域不一致，导致紧邻停车位、复杂路口或连续路径时的匹配错误。
- **LLM 融合层仍会引入错误**：正确实体被关联到错误对象；小模型遗漏信息更严重；且由于缺少相对位置、朝向、视觉邻接关系等提示，这类错误无法依靠现有输入可靠消除。
- **评估中对基线描述缺陷采取“不作为错误”的策略**，这意味着 VLM 自身幻觉/错误会被带入最终增强描述，实际输出中错误的可能性可能被低估。
- **速度等物理量没有真值验证**，只有基于 Kalman/RTS 的估计值，因而物理量部分的“真实性”仅停留在演示层面。
- 人工评价存在主观偏差，少数类别 Cohen's κ 很低甚至等于 0，影响对相关错误率的解释力。
- 目前是后处理流水线，未实现实时处理或端到端边缘部署；直接给 VLM 添加额外数据也难以见效，离实用机器人系统还有距离。
