## 摘要
无位姿前馈3D高斯泼溅使得从未标定的多视角图像中进行新视角合成成为可能。尽管更多视角应能提升性能，现有方法在稠密视角输入下往往会退化，因为全局注意力将关注分散到大量令牌上，而朴素的体素融合将众多高斯平均成过度平滑的表示。我们提出AVSplat，一个将额外视角转化为聚合与表示可靠信号的框架。在全局注意力之前，每个视角与一组基于相关性和多样性选择的辅助视图进行单次轻量交互，缓存的特征提供了聚焦的场景上下文，从而稳定对应关系。在表示方面，我们采用自适应温度感知体素融合，在高占用率下锐化归属，并由占用率和点置信度引导。关键在于，AVSplat恢复了正向视角缩放，即随着输入视角数量的增加，性能保持稳定或提升，而非在稠密视角范围内退化。消融实验表明，辅助视图预条件主要防止稠密视角退化，而占用引导的体素融合贡献了单点图像质量提升的大部分。

## Abstract
Pose-free feed-forward 3D Gaussian Splatting enables novel view synthesis from uncalibrated multi-view images. Although more views should improve performance, existing methods often degrade with dense-view inputs because global aggregation spreads attention over many tokens, and naive voxel fusion averages many Gaussians into overly smooth representations. We present AVSplat, a framework that turns additional views into reliable signals for both aggregation and representation. Before global attention, each view performs a single lightweight interaction with a small set of Assist Views chosen for relevance and diversity, and the cached features provide a focused scene context that stabilizes correspondence. For representation, we use adaptive temperature-aware voxel fusion that sharpens attribution under high occupancy, guided by occupancy and point confidence. Crucially, AVSplat restores positive view scaling where performance remains stable or improves as more input views are added, instead of degrading in the dense-view regime. Ablations show that Assist View Preconditioning is primarily responsible for preventing dense-view degradation, while Occupancy-guided Voxel Fusion contributes most of the single-point image-quality gains.

## 1. 核心问题与整体含义

- **研究背景与问题**：无位姿（pose-free）前馈3D高斯泼溅（3DGS）方法旨在直接从多张未标定图像中完成新视角合成，无需针对每个场景进行单独优化。理论上，**输入视角越多，重建质量应该越好**；但在实际中，现有方法（如AnySplat）在稠密视角输入下性能反而会退化。
- **退化原因**：作者将其归纳为两个关键设计缺陷：
  1. **全局注意力分散**：在无位姿情形下，骨干网络的全局聚合依赖softmax注意力来寻找跨视角对应关系。随着序列长度增长（输入视角变多），注意力质量分散到大量候选令牌上，正确匹配的权重被稀释，跨视角一致性被削弱。
  2. **朴素体素融合导致过度平滑**：在将逐像素高斯聚合到体素网格时，若大量高斯落入同一体素，归一化平均相当低通滤波器，被少数强贡献者被大量弱贡献者稀释，高频细节丢失。
- **核心论点**：如果能同时改善全局对应推理和体素表示这两个环节，就能把额外视角转化为可靠的信号，从而在稠密视角下恢复“视角越多性能越好”的正向缩放特性。

## 2. 方法论

AVSplat在现有前馈高斯预测管道（基于VGGT风格几何编码器）中引入了两个新模块。

### 2.1 辅助视图预条件（Assist View Preconditioning, AVP）

该模块的目标是：在任意全局注意力之前，让每个视角先从一组小而精的“辅助视图”中获得聚焦的场景上下文，从而减少后续全局匹配的搜索负担。

具体流程为：

- **视图描述子计算**：对每个视角 \(s\) 的patch tokens进行平均池化得到视图描述子 \(z_s\)。
- **候选池构建**：通过余弦相似度找出当前视角的 \(M\) 个最近邻作为候选池。
- **覆盖驱动选取**：从候选池中**贪心**选出 \(K\) 个辅助视角，其目标函数权衡了：
  - **令牌覆盖度**：辅助视角对当前视角各patch token的最大匹配得分总和；
  - **可靠性**：辅助视角的内部token方差（方差大则更不可靠）；
  - **多样性惩罚**：辅助视角之间的相似度越低越好（避免重复）。
- **轻量交互**：用当前视角的token做查询，以辅助视角的token为键/值做一次**单层多头交叉注意力**，通过门控残差（gating residual）注入上下文。门控系数从训练初期接近0逐步增至1，稳定优化。

该模块的关键思想在于：**将“发现对应关系”的负担从事后全局注意力转移到事前的显式视角筛选阶段**。

### 2.2 占用引导的体素融合（Occupancy-guided Voxel Fusion, OVF）

该模块在解码器产出高斯基元后取代均匀/朴素融合，对落入同一体素的高斯进行更精细的加权平均。

核心公式逻辑为：

- 定义体素 \(v\) 的占用数 \(n_v\)。
- 体素温度：
  \[
  \tau_v = \mathrm{clip}\left(\tau_{\min},\ \tau_0 \left(\frac{n_v}{n_{\mathrm{ref}}}\right)^{-\alpha}\cdot \psi_v,\ \tau_{\max}\right)
  \]
- 其中可靠性因子 \(\psi_v\) 由体素内3D点的几何方差决定：
  \[
  \psi_v = \frac{1}{1+\lambda\sigma_v^2}
  \]
  若体素内点越一致，\(\psi_v\) 越大。
- 对体素内每个高斯候选，以其置信度除以温度为logits做softmax得到权重。高占用 → 温度低 → 权重分布更尖锐 → 高置信度/高几何一致性的高斯主导融合结果；低占用 → 温度高 → 权重更平滑，避免单点独断。
- 用一个累积质量阈值（如0.8）截断尾部弱贡献者，降低离群点影响。

直观来说，这一机制避免了多数弱贡献者稀释少数强贡献者的问题，从而在高占用体素中仍能保持高频细节。

### 2.3 整体流程

输入多个未标定图像 → 编码器生成各视角patch tokens → **AVP**（每个视角先与辅助视角交互得到上下文）→ 全局聚合注意力 → 解码头预测位姿、深度和高斯参数 → **OVF** 占用引导的体素融合 → 可微光栅化 → 渲染输出。

## 3. 实验设计

### 3.1 数据集与Benchmark

- **训练集**：DL3DV（超过10k个训练场景）。
- **评测集**：
  - Mip-NeRF 360（4个场景：bonsai, counter, kitchen, room）
  - VR-NeRF（4个室内场景：apartment, kitchen, raffurnishedroom, workshop）
  - DL3DV测试集（140个场景）
- **视角设置**：
  - 稀疏视角：3、6、16个输入视角，2个目标视角。
  - 稠密视角：32、48、64个输入视角，目标视角分别为4、6、8个。
  - DL3DV固定协议中每个场景采样75个候选视角，固定3个目标视角，从剩余视角中按需选取上下文视角。

### 3.2 对比方法

- 稠密视角：主要对比**AnySplat**（因为其他无位姿基线如NoPoSplat、Flare在稠密视角下发生OOM内存溢出）。
- 稀疏视角：对比**NoPoSplat**、**FLARE**、**AnySplat**。
- 为保证公平，在Mip-NeRF 360和VR-NeRF的零样本评测中，使用公开实现和推荐配置在DL3DV上重训了AnySplat，确保所有方法训练数据一致。

### 3.3 指标

PSNR ↑、SSIM ↑、LPIPS ↓，每个场景内先对目标视角平均再在场景间平均。

## 6. 主要结论与发现

- AVSplat在稠密视角（32、48、64视角）下，在DL3DV上的PSNR分别领先AnySplat约0.49、0.56、0.53 dB，且自身性能保持增长（21.54→21.67 dB），而AnySplat趋于饱和甚至震荡。
- 在高度重叠输入的ACID压力测试中：AnySplat从48视角的23.12 dB降至72视角的22.45 dB，而AVSplat反而从23.15升至23.24 dB，在72视角处形成0.79 dB的优势。
- 注意力诊断显示：AVSplat有效降低Attention的归一化熵（0.693→0.642），并将几何相关频带内的注意力量GeoMass@1patch从0.286提升到0.374（相对提升30.8%）。
- 消融结果表明：OVF在64视角内贡献主要的单点图像质量提升（PSNR从21.14提升至21.57），AVP则主要负责稳定全局匹配、防止稠密退化的发生。

## 7. 优点与亮点

- **问题定位清晰**：精准指出稠密视角下性能退化的两个机制性原因（注意力分散与体素平均过度平滑），而不是简单堆叠技巧。
- **设计轻量高效**：AVP只是单层交叉注意力且每次只选少量辅助视角，计算负担相对小；辅助选取基于贪心近似（submodular目标函数），有理论保证。
- **门控残差与梯度过策略**等工程细节提升了训练稳定性（前1500步冻结辅助分支梯度、gating从0逐步到1）。
- **机制验证充分**：不仅做了端到端指标，还通过注意力矩阵可视化和GeoMass量化诊断，直接检验了内部机制是否按预期生效。
- **稀疏与稠密统一框架**：通过实验确认了稀疏视角下AVP并不可用（无可选辅助集），诚实且合理地划分了模块适用范围。
- 论文写作结构清晰，说明逻辑前后呼应，读者能快速理解“什么导致了退化”和“如何修复退化”。

## 8. 不足与局限

- **对比方法数量有限**：在稠密视角模式下，其他基线（NoPoSplat、Flare）均OOM，无法提供更全面的横向对比；没有和其他稠密扩展方法（如ZPressor）比较。
- **稀疏视角性能不稳定**：在DL3DV 3视角下AVSplat的PSNR（14.41）明显低于AnySplat（15.04），SSIM也偏低（0.341 vs 0.387），说明当视角极少时AVSplat存在可用性和稳定性短板。
- **自适应辅助视图选择属于不可微的启发式选择**，最优性缺乏严格保证（论文用贪心近似的次模性说明接近最优，但实际误差界并不严格清晰）。
- **评测数据有限**：Mip-NeRF 360和VR-NeRF各只用了4个场景，DL3DV测试集是140个场景，但真实大场景/室外开放场景覆盖仍然有限。
- **未报告训练总时长或吞吐量**，无法严格对比训练/推理效率；稠密设置下虽然声称“可承受的计算/内存”，但没有提供具体的显存占用/运行时间对比数据。
- **模型只能处理有限的视角范围**（主实验为3-64，ACID压力测试到72），论文声称的“正向缩放”还没有在100+乃至数百视角的真实极限条件下得到验证。
