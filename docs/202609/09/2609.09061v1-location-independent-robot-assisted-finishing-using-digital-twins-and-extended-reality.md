## 摘要
本文提出了一种用于位置无关编程、监督、训练和远程操作机器人辅助精加工（RAF）系统的信息物理系统（CPS），该系统用于对金属增材制造（AM）部件进行后处理。在Unity中构建的数字孪生（DT）以WebGL应用的形式交付给操作员，该应用通过支持WebXR的设备同时支持桌面和沉浸式模式。此外，它通过消息队列遥测传输（MQTT）代理与协作机器人交换机器人状态和位姿命令。在将位姿发布到物理机器人之前，DT强制执行运动学和碰撞约束，并用表面形貌的彩色图谱增强虚拟部件，以支持操作员在部件重新定位或过程终止方面的决策。该架构在专门设计的物理RAF系统上进行了验证。测量得到稳态关节同步误差为0.12度，平均往返延迟为563毫秒，这对于监督编程和间歇性远程操作是足够的。

## Abstract
This paper presents a cyber-physical system (CPS) for location-independent programming, supervision, training, and teleoperation of a Robot-Assisted Finishing (RAF) system used to post-process metal additive-manufactured (AM) components. A digital twin (DT) built in Unity is delivered to the operator as a WebGL application that supports both desktop and immersive modes through WebXR-compatible devices. Moreover, it exchanges robot state and pose commands with a collaborative robot through a Message Queuing Telemetry Transport (MQTT) broker. The DT enforces kinematic and collision constraints before a pose is released to the physical robot, and augments the virtual component with a color map of the surface topography that supports operator decisions on part repositioning or process termination. The architecture was validated on a specially designed physical RAF system. A steady-state joint synchronization error of 0.12 deg and a mean round-trip latency of 563 ms were measured, which is adequate for supervisory programming and intermittent teleoperation.

## 一、核心问题与研究动机

- **背景**：增材制造（AM）在小批量及单件生产中具有节材、缩短设计周期和分布式制造优势，但生产后的**精加工环节**高度依赖人工，存在噪声（约85 dB(A)）、振动、粉尘和工作区可视性差等问题，长期现场作业对操作员不友好。
- **核心痛点**：小批量AM零件形状多样、加工过程需人工判断，**完全自动化的精加工方案不经济**；传统示教器编程要求操作员具备机器人专业知识且需现场值守，离线编程又无法根据零件实际表面状态实时调整策略。
- **总体目标**：设计一种人在回路的网络物理系统（CPS），借助数字孪生（DT）与扩展现实（XR），实现**位置无关**的机器人辅助精加工——即操作员在异地即可完成编程、监督、训练与间歇性遥操作，减少现场暴露的同时保留人类对加工过程的判断力。
- **两个研究问题**：
  - RQ1：基于浏览器DT + 云MQTT中介的延迟与同步表现能否满足RAF系统远程遥操作需求？
  - RQ2：除机器人运动学状态外，DT还需携带哪些过程信息，以便操作员远程监控和控制RAF系统？

## 二、方法论

**1. 系统总体架构**

- 系统由UNCC的UR30协作机器人（六自由度、臂展1.3m、负载30kg、配三指气动夹爪）与Mass Finishing RF-50离心盘精加工机组成。
- DT在Unity中构建，机器人模型使用ROS industrial UR包导出，经Blender贴图后导入Unity，关节由Unity Articulation对象连接并按真实关节角度限位。
- 交付方式：编译为WebGL运行时托管在云服务器上，用户在浏览器中打开即可使用，兼容桌面与WebXR沉浸式设备（VR/MR头显+手持控制器）。

**2. 通信机制（MQTT）**

- 采用MQTT发布/订阅协议：DT发布到 `raf/robot/cmd` 话题，订阅 `raf/robot/state` 话题；消息JSON载荷携带机器人的位姿（roboPose）、夹爪状态、processBusy等字段。
- 每条消息带有**单调递增序号与发布者时间戳**，便于接收方丢弃过期/乱序指令。
- 机器人控制器通过第三方软件 MQTT Connector Professional 实现MQTT发布/订阅；控制器内部的循环程序**周期轮询**期望位姿与工具变量并执行运动或夹爪动作。

**3. 运动学与碰撞安全验证**

- 逆运动学采用**阻尼最小二乘（DLS）**求解器推算关节增量：

  Δq = Jᵀ(JJᵀ + λ²I)⁻¹·Δx

  其中J为操作臂雅可比矩阵，Δx为笛卡尔空间误差，λ为阻尼因子（用于在奇异位形附近平滑降级）。无需封闭解，对XR自由空间中操作员随意指定的路径目标有良好容错性。
- 关节限位由Unity Articulation关节对象强制约束；夹爪、机械臂、基座、离心碗、工件及研磨介质均定义了碰撞体。
- **分层安全架构**：
  - DT层：非法或碰撞位姿无法记录/发送，防止操作员误操作；
  - 控制器层：循环程序独立拒绝超出关节限位与笛卡尔安全平面的指令，防止伪造/重放消息造成事故；
  - 物理层：设置光幕（light curtain），本地人员进入安全围栏时禁止远程指令执行；
  - 符合ISO 10218-1/2与ISO/TS 15066协作安全要求。

**4. 过程感知可视化（Process-Awareness Visualization）**

- DT不仅呈现机器人运动，还展示零件表面**高度彩色图谱（height map）**：精加工过程按固定时间间隔离线测量表面形貌（Zygo ZeGage 3D干涉显微镜），测量结果同步至DT。
- 操作员据此判断零件是否充分打磨、是否需要重新定位/旋转以均衡介质接触，或是否达到目标粗糙度可终止过程——支撑了远程决策而非盲目执行固定程序。

**5. 网络安全**

- HTTPS托管DT运行时，MQTT broker位于端口8883，防火墙封禁其余端口；全部TLS-encrypted连接使用大学签发的证书；broker要求逐用户认证并限制发布权限；机器人控制器主动出站连接broker，不接受任何入站TCP连接。

## 六、主要结论

1. **RQ1的回答**：系统支持的稳态关节同步误差（0.12°）和平均往返延迟（563 ms）对于**离线编程和间歇性遥操作是够用的**（一次记录一个位姿、在DT验证后再执行）；但**不适用于连续运动流或实时手动导引**——使用者的操作方式受限于“move-and-wait”（移动—等待）模式。
2. **延迟瓶颈定位**：延迟的主导因素并非网络或MQTT协议，而是机器人控制器循环程序的**轮询间隔**——平均563ms比已有文献中MQTT约几十毫秒的通信延迟高一个数量级。最有效的改进方向是把控制器侧轮询改为事件驱动。
3. **RQ2的回答**：仅凭机器人运动学状态无法完成远程精加工监督，**必须叠加过程级信息**（如表面形貌/粗糙度图）供操作员决策零件重定位与终止时机；这正是区别于一般通用机器人遥操作DT的关键。
4. 系统展示了人在回路的混合工作流的技术可行性和经济合理性：不替代操作员而是让人类决策与机器人执行互补。

## 七、优点

1. **真实工业场景验证**：使用真实UR30协作机器人和离心盘精加工机构建系统，而非仿真环境中的玩具任务；
2. **端到端完整性**：从XR人机交互、数字孪生安全验证、云MQTT通信到物理机器人控制形成闭环，且考虑了网络安全隐患；
3. **分层安全设计**：DT验证 + 控制器独立校验 + 光幕物理防护构成纵深防御（defense-in-depth），处理了“操作者在浏览器内执行、物理机器人属信任边界外”的安全悖论；
4. **过程感知可视化创新**：将离线表面形貌测量数据映射到DT虚拟工件上，赋予了DT超越纯运动学仿真的制造过程价值；
5. **系统性位置无关能力**：兼有远程操作、位置无关、沉浸式、跨平台、过程感知五项能力，是表I中首个完整实现全部能力的系统；
6. **开源/可复用的选型**：WebGL免安装、Unity MQTT Bundle等选型降低了部署门槛。

## 八、不足与局限

1. **延迟性能不足于连续遥操作**：563ms平均往返延迟超过作者此前CPMT工作所设定的250ms可用阈值，无法支持实时的触觉/力觉交互式导引；对突发事件反应慢于一个往返周期。
2. **实验覆盖不足**：仅验证了一个拾放/加工任务场景；没有跨地域（真正的远程）、跨不同AM零件几何、跨多种粗表面处理阶段场景的大规模试验证据。
3. **过程信息仍然滞后且离线**：表面形貌通过离线CSI测量，零件需从加工环境取出，属于间歇性离散采样，没有实现过程的实时原位监控。
4. **评价证据不足**：宣称的“适用于训练和教育”的可用性没有设计用户研究（作者在Future Work中承认需补充非专家用户研究）；性能指标统计不完整（RMS、分布、丢包率等遗漏）。
5. **离心碗未被完全仪表化**：按照Kritzinger分类法，机器人层级是完整DT，但加工工艺层级（碗中力、振动、声音等信号）尚未完全实现自动化数据回传，本质上是“部分数字孪生”。
6. **系统的安全设计局限**：依赖光幕检测本地人员但未提及光幕失效、多用户并发控制、或MQTT凭据泄露等更复杂威胁模型下的行为。
7. **经济性主张未经实证**：论文称该方案可提升小批量AM精加工的“经济可行性”，但缺少与人工加工在时间、成本维度的量化对比。
