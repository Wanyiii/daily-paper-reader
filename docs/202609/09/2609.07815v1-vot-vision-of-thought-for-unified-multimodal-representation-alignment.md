## 摘要
当前的文本到图像系统通常采用“文本编码器加扩散解码器”的范式，其中文本语义直接调制连续潜在噪声。尽管这些方法取得了成功，但它们缺乏一种显式的、可解释的中间表示，来有效桥接高层语言语义和低层视觉信号。在本文中，我们提出了思维视觉（VoT），一个在视觉语言模型（VLM）和扩散变换器（DiT）之间引入离散视觉思维层的框架。我们不再将VLM仅视为文本编码器，而是将其用作多模态规划器，在渲染像素之前生成表示高层视觉计划（如对象和布局）的离散VoT标记。我们在VLM语义空间中训练了一个专门的VoT分词器，其闭环目标结合了VLM对齐、特征重建和向量量化损失。这些目标使得标记在语义上可被VLM读取，同时保留了生成所需的视觉信息。实验结果表明，VoT改善了语义对齐，并为可解释和可控生成提供了结构化接口。

## Abstract
Current text-to-image systems typically employ a "text encoder plus diffusion decoder" paradigm, in which text semantics directly modulate continuous latent noise. Despite their success, these methods lack an explicit, interpretable intermediate representation that effectively bridges high-level linguistic semantics and low-level visual signals. In this paper, we propose Vision-of-Thought (VoT), a framework that introduces a discrete visual-thinking layer between vision-language models (VLMs) and diffusion transformers (DiTs). Instead of treating VLMs merely as text encoders, we use them as multimodal planners that generate discrete VoT tokens representing high-level visual plans, such as objects and layouts, before rendering pixels. We train a specialized VoT tokenizer in the VLM semantic space with a closed-loop objective that combines VLM alignment, feature reconstruction, and vector-quantization losses. These objectives make the tokens semantically readable by the VLM while preserving the visual information needed for generation. Experimental results demonstrate that VoT improves semantic alignment and provides a structured interface for interpretable and controllable generation.

## 1. 论文的核心问题与整体含义
- **研究背景**：当前最主流的文本到图像（Text-to-Image）生成系统普遍采用"文本编码器 + 扩散解码器"（如 DiT）的范式。在这一范式中，文本语义被直接编码为条件信息，用于调制扩散过程的连续潜在噪声。
- **核心问题**：这种直接的"文本-像素"调制方式缺乏一个**显式的、可解释的中间表示**。高层语言语义（如对象类别、布局关系）与低层视觉信号（如纹理、色彩、空间细节）之间缺少桥接层，导致生成模型在语义对齐的精细度、生成过程的可解释性和可控性上仍有较大局限。
- **整体意义**：VoT 试图回答一个关键问题——是否可以在语言规划与像素渲染之间引入一个"视觉思维"层，使模型先"想清楚"视觉上要画什么（对象、布局），再动手去画，从而统一多模态表示的对齐过程。该研究为文生图模型的**可解释性与可控生成**提供了新思路。

## 2. 论文提出的方法论：VoT 框架
### 核心思想
- 不再将视觉语言模型（VLM）仅仅当作文本编码器，而是将其视为**多模态规划器**。
- 在 VLM 与扩散 Transformer（DiT）之间，引入一个**离散视觉思维层**（VoT token）。
- 该离散 token 用于表示文本背后隐含的高层视觉计划（如有哪些对象、各自的空间位置与交互布局），在生成任何像素以前先产生结构化的视觉中间表征，再送入 DiT 渲染像素。

### 关键技术细节
1. **VoT 分词器（tokenizer）**：专为 VLM 语义空间设计的离散分词器，负责把视觉计划量化成语义可读的离散 token。
2. **闭环训练目标（closed-loop objective）**：分词器的训练不是单独进行，而是与生成系统衔接，包含三类损失的加权组合：
   - **VLM 对齐损失**：让 VoT 离散 token 能被 VLM 语义空间正确读取，保证 token 具有语义可读性。
   - **特征重建损失**：保证离散 token 仍包含足够的视觉细节信息，使得下游 DiT 能据此重建高质量图像。
   - **向量量化（VQ）损失**：保证离散化的稳定性，并使码本（codebook）得到良好学习。
3. **信息流**：文本 → VLM 生成高层视觉计划 → VoT 分词器将计划映射为离散视觉思维 token → DiT 逐层感知这些 token 并渲染像素。

### 流程简述（文字表示）
- 输入：一段文本 prompt
- 步骤 1：VLM 以文本为输入，结合多模态能力生成对象与布局层面的高层视觉规划
- 步骤 2：该视觉计划被映射到离散的 VoT token 序列（通过 Vocab 中挑选特定码字表达语义/结构信息）
- 步骤 3：VoT token 被送入扩散 Transformer 中，作为显式的条件信号参与噪声预测
- 输出：最终解码得到生成图像
- 训练阶段：VLM（可冻结或微调）、VoT 分词器、DiT 联合/分阶段优化，并以 VLM 对齐、特征重建、VQ 三类损失联合约束
