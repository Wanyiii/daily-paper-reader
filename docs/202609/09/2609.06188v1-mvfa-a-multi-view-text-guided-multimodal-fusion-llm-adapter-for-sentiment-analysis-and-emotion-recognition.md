## 摘要
对话中的多模态情感分析和情绪识别需要对文本、声学和视觉模态之间的异构交互进行有效建模。尽管大型语言模型（LLM）提供了强大的语言理解能力，但将其适应于多模态情感计算仍然具有挑战性：全模型微调在计算上代价高昂，而许多现有的轻量级适配器在跨模态融合过程中未能保留丰富的文本线索。为解决这些局限性，我们提出了多视图文本引导多模态融合适配器（MVFA），这是一种参数高效的框架，可为冻结的LLM增强强大的多模态推理能力。MVFA首先通过最大池化、均值池化和注意力池化构建互补的文本视图；这些视图随后引导与音频和视觉特征的跨模态交互。融合后的多模态表示随后通过增强型Q-Former融合模块压缩为一组紧凑的可学习伪令牌。以ChatGLM3-6B-base作为主要主干，我们还在LLaMA2-7B和Qwen3-8B上进一步验证了MVFA，以检验其跨多个冻结LLM主干的可移植性。MVFA在三个具有挑战性的数据集上进行了评估：CH-SIMS V2.0、MELD和CHERMA。实验结果表明，MVFA在仅更新一小部分参数的情况下，在关键指标上达到了最先进的性能。具体而言，它在CH-SIMS V2.0上达到了84.62%的Acc2和84.59%的F1，在MELD上达到了67.36%的Acc和66.03%的WF1，在CHERMA上达到了74.66%的Acc。这些发现确立了多视图文本引导融合作为一种有效且可扩展的范式，用于情感计算中参数高效的多模态LLM适应。代码可在https://github.com/Overwhelm1208/MVFA公开获取。

## Abstract
Multimodal sentiment analysis and emotion recognition in conversations demand effective modeling of heterogeneous interactions across textual, acoustic, and visual modalities. Although large language models (LLMs) offer powerful language understanding, adapting them to multimodal affective computing remains challenging: full-model fine-tuning is computationally prohibitive, while many existing lightweight adapters fail to preserve rich textual cues during cross-modal fusion. To address these limitations, we propose the multi-view text-guided multimodal fusion adapter (MVFA), a parameter-efficient framework that augments frozen LLMs with strong multimodal reasoning capability. MVFA first constructs complementary text views via max pooling, mean pooling, and attention pooling; these views then guide cross-modal interactions with audio and visual features. The fused multimodal representations are subsequently compressed into a compact set of learnable pseudo-tokens through an Enhanced Q-Former Fusion Module. Using ChatGLM3-6B-base as the primary backbone, we further validate MVFA on LLaMA2-7B and Qwen3-8B to examine its portability across multiple frozen LLM backbones. MVFA is evaluated on three challenging datasets: CH-SIMS V2.0, MELD, and CHERMA. Experimental results demonstrate that MVFA achieves state-of-the-art performance on key metrics while updating only a small fraction of parameters. Specifically, it attains 84.62\% Acc2 and 84.59\% F1 on CH-SIMS V2.0, 67.36\% Acc and 66.03\% WF1 on MELD, and 74.66\% Acc on CHERMA. These findings establish multi-view text-guided fusion as an effective and scalable paradigm for parameter-efficient multimodal LLM adaptation in affective computing. The code is publicly available at https://github.com/Overwhelm1208/MVFA.

## 1. 论文的核心问题与整体含义

- **研究背景**：人类交流天然是多模态的，情感与意图通过语言、声学韵律和视觉线索协同传递。多模态情感分析（MSA）与对话情绪识别（ERC）需要融合文本、音频、视觉三种异构信号。
- **核心问题**：将大语言模型（LLM）应用于多模态情感计算时存在两难：
  - 全模型微调计算成本过高；
  - 现有轻量级适配器（如 MSE-Adapter）在跨模态融合时通常只使用单一的压缩文本视图，容易丢失互补性文本线索，如显著情感词、语篇级对比、语境相关词等。
- **本文主张**：提供一种参数高效的冻结 LLM 适配范式，通过**多视图文本引导**的跨模态融合，在更新极少参数的前提下增强 LLM 的多模态情感推理能力。

## 2. 论文提出的方法论

### 核心思想
- 不使用单一压缩文本向量，而是通过**最大池化、均值池化、注意力池化**构造三个互补的文本视图；
- 用这些文本视图作为查询（Query），引导音频和视觉特征的跨模态交互；
- 将融合后的多模态表示通过**增强型 Q-Former 融合模块（ENQF）** 压缩为少量可学习的伪令牌（pseudo-tokens）；
- 将伪令牌与原始文本嵌入、提示增强文本嵌入共同输入**冻结的 LLM**，进行自回归式情感/情绪标签生成。

### 关键技术细节与流程
1. **输入表示**：
   - 文本：任务提示 + 原始话语拼接，经 LLM 分词器与嵌入层得到 `T` 和 `Tp`；
   - 音频/视觉：使用预提取的标准化特征，经单向 LSTM 建模，再线性映射为全局摘要 `Ã` 和 `V˜`。

2. **多视图文本建模（MTF）**：
   - Max-pooling 视图：`Fmax = max(MLP_max(T))`，捕获显著局部线索；
   - Mean-pooling 视图：`Fmean = AvgPool(MLP_mean(T))`，概括整体语义倾向；
   - Attention-pooling 视图：`Fattn = aᵀ MLP_attn(T)`，参数无关注意力加权；
   - 渐进融合：两阶段带残差的 MLP 融合，得到融合文本特征 `Ftext`。

3. **文本引导跨模态交互**：
   - 将 `Ftext` 作为查询，音频特征 `Ã` 和视觉特征 `V˜` 分别作为键/值，进行两个独立的多头交叉注意力；
   - 输出拼接后经两层 MLP 投影回 `Fcross`。

4. **增强型 Q-Former 融合模块（ENQF）**：
   - 对 `Fcross` 做投影与 LayerNorm；
   - 引入轻量级特征增强子网络，通过 sigmoid 门控生成增强特征，并以系数 α（默认 0.3）叠加；
   - 用 n 个可学习查询（默认 4）与融合特征做交叉注意力；
   - 输出经投影头得到伪令牌 `P`。

5. **LLM 推理与损失**：
   - 输入序列：`X_input = [P; T; Tp]`；
   - 损失：自回归交叉熵，仅 MVFA 模块参数可更新，LLM 主干完全冻结。

## 6. 论文的主要结论与发现

- MVFA 在三个数据集上均取得最优或极具竞争力的结果：
  - CH-SIMS V2.0：Acc2 84.62%、F1 84.59%、Acc2-Weak 77.27%、Corr 0.736、MAE 0.284；
  - MELD：Acc 67.36%、WF1 66.03%；
  - CHERMA：Acc 74.66%，在 7 类情绪中 6 类 F1 最优。
- 相比复现的 MSE-ChatGLM3-6B，MVFA 提升显著（CH-SIMS V2.0: +1.76 Acc2, +1.87 F1, +2.58 Acc2-Weak；MELD: +1.48 Acc, +1.36 WF1；CHERMA: +1.25 Acc）。
- 多视图文本引导优于单一压缩文本视图；三个池化分支互补，缺一不可。
- 文本模态主导 ERC，但音频和视觉确能提供互补增益，三者联合最优。
- ENQF 中 4 个伪令牌与 α=0.3 是较优配置；伪令牌过多或增强过强会造成性能下降。
- MVFA 可移植至不同冻结 LLM 骨干，但性能依赖骨干选择，ChatGLM3-6B-base 在其实验中整体最强。

## 7. 优点

- **方法层面**：
  - 提出多视图文本建模（max/mean/attention pooling），有效保留互补文本线索的机制创新性强；
  - 以文本为查询引导音频、视觉交叉注意力，符合情感语义主要由语言承载的直觉；
  - ENQF 大幅简化传统 Q-Former，既降低参数开销又通过显式特征增强提升表征能力；
  - 冻结 LLM + 少量可训练参数，解决了全模型微调不可行的问题。
- **实验层面**：
  - 数据集覆盖中英双语、MSA/ERC 两种任务，维度全面；
  - 同时验证 3 种不同规模/架构的 LLM 骨干，展示可迁移性；
  - 消融设计系统化，从模块级到分支级再到模态级，层层递进；
  - 提供可视化混淆矩阵与定性案例，增强结果可解释性；
  - 代码开源，利于复现。
