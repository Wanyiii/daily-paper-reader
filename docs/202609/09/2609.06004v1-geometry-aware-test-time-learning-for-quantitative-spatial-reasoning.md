## 摘要
视觉-语言模型（VLMs）中的定量空间推理旨在从二维图像和自然语言查询中推断三维空间中物体之间的空间距离和方向关系。尽管近期取得了进展，但在分布变化下，VLM的空间推理仍然脆弱，这主要归因于三维监督的高成本。因此，当面对新颖的物体配置或改写后的空间查询时，模型常常产生不一致或矛盾的预测，揭示出学习表示与底层几何之间的错位。为解决此问题，我们提出TTL-SR，一种用于定量空间推理的几何感知测试时学习框架，利用几何一致性约束和未标记的测试数据来使模型适应目标域。具体而言，TTL-SR通过几何耦合的辅助查询增强输入查询，通过自适应几何触发过滤不可靠的预测以构建结构化的token级伪标签，并仅使用测试数据在几何感知的多目标损失下更新模型参数。实验结果表明，TTL-SR显著提升了空间推理性能，在Q-Spatial-ScanNet数据集上，对Qwen3-VL-4B-Instruct和SpatialRGPT-VILA-1.5-8B分别带来了6.47%和9.41%的准确率提升。

## Abstract
Quantitative spatial reasoning in visual-language models (VLMs) aims to infer spatial distances and directional relationships among objects in 3D space from a 2D image and a natural language query. Despite recent progress, VLM spatial reasoning remains brittle under distribution shifts, largely due to the high cost of 3D supervision. As a result, models often produce inconsistent or contradictory predictions when faced with novel object configurations or rephrased spatial queries, revealing a misalignment between learned representations and underlying geometry. To address this, we propose TTL-SR, a geometry-aware Test-Time Learning framework for quantitative Spatial Reasoning that leverages geometric consistency constraints and unlabeled test data to adapt models to target domains. Specifically, TTL-SR augments the input query with geometrically coupled auxiliary queries, filters unreliable predictions via adaptive geometric triggering to construct structured token-level pseudo-labels, and updates model parameters under a geometry-aware multi-objective loss using only test data. Experimental results demonstrate that TTL-SR significantly boosts spatial reasoning performance, yielding 6.47% and 9.41% accuracy gains for Qwen3-VL-4B-Instruct and SpatialRGPT-VILA-1.5-8B on Q-Spatial-ScanNet dataset, respectively.

## 核心问题与整体含义

定量空间推理旨在让视觉-语言模型（VLM）从单张二维图像及自然语言查询中推断三维空间中物体间的距离与方向关系。作者指出，尽管现有 VLM 在空间问答上有所进展，但其空间知识高度依赖高成本的 3D 标注，训练域与现实场景之间存在分布偏移。这导致模型在遇到新颖物体配置或语义改写后的空间查询时，常给出物理上不成立或自相矛盾的输出——例如 "直接距离" 与其 "水平/垂直距离" 分量无法满足勾股关系。因此，文中引入一种全新的、几何感知的测试时学习（Test-Time Learning, TTL）范式，利用 **无标注测试数据** 在推理阶段完成模型的自适应优化，使预测结果与底层几何规律对齐。

## 提出的方法论

### 1. 核心思想
- 不直接利用置信度或熵最小化等传统 TTL 目标（这类目标会导致表征同质化与特征塌缩，损害连续数值预测精度）。
- 基于固有的几何属性（如勾股定理）在不同空间查询预测之间构造一致性约束，将离散的语言模型输出空间与连续的物理几何关系桥接起来。

### 2. 具体技术环节

1. **空间查询增强（Spatial Query Augmentation）**：
   - 将原始查询（如"咖啡磨豆机到咖啡杯的直接距离"）扩展为几何耦合辅助查询集合，包括同类属性的不同表述、"垂直/水平距离"、"物体宽度与高度"。
   - 所有辅助查询均基于模板自动生成，无需额外标注。

2. **自适应几何一致性建模（Adaptive Geometric Consistency Modeling）**：
   - **自适应几何触发**：利用勾股定理一致性、宽高比稳定性、语义一致性等准则计算相对误差 RE_a，仅当其小于容差阈值 τ 时才触发优化，防止在预测不可靠时更新参数导致误差放大。
   - **结构化 Token 级伪标签**：将数值目标分解为结构化 token 序列（整数部分 / 小数点 / 小数部分 / 单位）。对结构化 token 采用 one-hot 锚定；对数值 token 则将概率质量均匀分配到数值邻域内的候选 token 上，以建模估计不确定性、提升优化稳定性。

3. **测试时优化（Test-Time Optimization）**：
   - 总损失为 Ltotal = Lgeo + λ_kl L_kl + λ_ent L_ent：
     - **几何一致性损失（Lgeo）**：基于 MLE 的正向学习 + 对高置信但几何无效的 token 进行 Unlikelihood 惩罚；
     - **KL 散度损失（Lkl）**：约束当前模型与初始预训练模型的输出分布，防止灾难性遗忘；
     - **熵最小化损失（Lent）**：仅在几何相关位置应用，辅助锐化分布。
   - 仅更新注入骨干网络的低秩 LoRA 适配器，冻结原始权重，保持高效且适应增量式更新。

## 主要结论与发现
1. TTL-SR 在 Q-Spatial-ScanNet 上使 Qwen3-VL-4B-Instruct 平均准确率提升 **6.47%**，SpatialRGPT-VILA-1.5-8B 提升 **9.41%**。
2. 传统置信度驱动式 TTL（Tent、TLM）在定量空间推理中可能**降低性能**（如表中的 40.00% → 38.24%），说明几何一致性目标对数值推断至关重要。
3. 联合优化所有空间属性比单独优化某属性更有效——单独优化"直接距离"会导致"垂直距离"指标恶化，而全量正则化能绕开属性间的负迁移。
4. 轻量开源模型（4B）+TTL-SR 可以在部分类别（如直接距离达到 63.9%）超过 Gemini-3-Flash 等大容量闭源模型。

## 主要优点
1. **方法创新性**：首次提出将物理几何规律——而非置信度/熵——作为 TTL 的自监督信号，直接回应了定量空间推理任务"连续数值精确性"与"多属性一致性"的本质需求。
2. **即插即用**：TTL-SR 是模型无关、无需任何 3D 地面真值标注的框架，可附加于预训练 VLM 之上，同时只更新 LoRA 参数、资源开销有限。
3. **稳健的去噪机制**：自适应几何触发 + 软伪标签 + Unlikelihood 三重过滤，兼顾对几何有效信号的利用和对无意义梯度/高置信错误预测的抑制。
4. **实验严谨性好**：通过分类别（直接、水平、垂直、宽、高、方向）逐项报告准确率与 MARE，而非仅报平均数，能清楚观察优化过程对各维度的具体影响。

## 不足与局限
1. **依赖几何耦合查询模板**：当前辅助查询依赖人工设计模板生成，对未定义的复杂物体关系（如"在…之上""面向…"）覆盖不充分。
2. **物理约束的适用范围有限**：目前只利用勾股定理和宽高比等基础几何规律，尚未推及更复杂的多物体空间交叠、遮挡、透视投影以及方向/角度推理（角度仅在 SpatialRGPT-Bench 上有一项验证）。
3. **需要调节较多超参数**：如触发阈值 τ、软标签容差 τ_label、负例采样 k、λ_kl、λ_ent 等。论文虽做了敏感性分析，但如何针对不同模型自适应设定这些阈值仍缺乏自适应的推导方法。
