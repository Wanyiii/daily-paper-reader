## 摘要
从稀疏输入进行新视角合成既需要来自观测视角的几何基础，也需要对未观测区域的生成先验，这促使了近期结合重建与生成的混合方法。然而，现有方法通过渲染图像或显式3D表示（如点图或3D高斯）来连接两者。因此，生成过程以有损且不完美的场景投影为条件，继承了其误差，而重建过程则无法从生成中获得纠正这些误差的信号。我们提出RoGe，一种去除这种显式桥梁的端到端统一重建与生成框架。它针对由稀疏视图锚定的场景内漫游：给定少量带位姿的图像和一条相机轨迹，沿该轨迹合成时间上连贯的视频。从稀疏输入视图出发，RoGe利用前馈重建模型构建隐式场景表示，并用目标相机光线查询该表示以获取逐视角几何特征。这些特征被注入视频扩散模型作为条件，无需任何3D中间表示。两个模块联合训练，因而生成目标直接塑造其自身的几何条件。我们在DL3DV上进行实验，RoGe在图像级指标和视频级时间一致性上均优于基于重建、基于生成及混合基线。消融实验证实，光线查询的隐式特征作为条件优于原始重建标记和渲染RGB，且联合训练带来进一步提升。

## Abstract
Novel view synthesis from sparse inputs requires both geometric grounding from the observed views and generative priors of unobserved regions, motivating recent hybrid methods that combine reconstruction and generation. However, existing methods bridge the two with rendered images or explicit 3D representations such as point maps or 3D Gaussians. Generation is thus conditioned on a lossy and imperfect projection of the scene, inheriting its errors, and reconstruction receives no signal from generation to correct them. We present RoGe, an end-to-end unified reconstruction and generation framework that removes this explicit bridge. It targets roaming within a scene anchored by sparse views: given a few posed images and a camera trajectory, it synthesizes a temporally coherent video along that trajectory. From the sparse input views, RoGe builds an implicit scene representation with a feed-forward reconstruction model, and queries it with target camera rays to obtain per-view geometric features. These features are injected into a video diffusion model as conditioning, without any 3D intermediate. Both modules are trained jointly, so the generation objective directly shapes its own geometric conditioning. We conduct experiments on DL3DV, where RoGe outperforms reconstruction-based, generation-based, and hybrid baselines on image-level metrics and video-level temporal consistency. Ablations confirm that ray-queried implicit features outperform both raw reconstruction tokens and rendered RGB as conditioning, and that joint training brings further gains.

## 2. 方法论

### 核心思想
从稀疏观测构建“显式3D模型不存在”的**隐式场景表示**，用目标相机光线查询该表示以得到逐视角几何特征，再将其注入视频扩散模型（以DiT为骨干）的条件通道中。整个流程**端到端可微分**，重建与生成共享同一优化目标进行训练。

### 整体流程（重要步骤串联）
1. **输入构建**——稀疏观测图 Ii、内参 Ki、外参 Ti 输入前馈重建网络；目标轨迹以 Plücker 射线图 P 表示。
2. **隐式重建**——先通过相机条件化的 VGGT 重建网络获得场景 token Zi。
3. **射线查询**——对所有视图（观测+目标）的射线图进行 token 化，经过 12 层“射线-场景”交叉注意力模块，得到逐视角几何特征 Fr。
4. **条件注入**——通过 latent-aligned geometry adapter 将 Fr 对齐到 VAE 潜在空间维度，作为隐式几何条件 G。
5. **视频生成**——将目标帧噪声 token 与三种条件（外观 Y、射线信息 P、几何特征 G）相加融合，送入预训练的视频 DiT 进行去噪。

### 关键技术细节

**(a) Plücker 射线表示**——兼作重建和生成的统一相机表示，相比单向量相机参数更稠密、保持几何对应关系。

**(b) 相机条件化 VGGT 重建网络**
- 每个相机的内外参通过两层MLP投影为 1024 维 token。
- 关键意义在于把 VGGT 的特征构建在给定的世界系下，解决了其原生特征内坐标系与给定轨迹不一致的问题。
- 不显式生成深度点云或3D高斯，而是输出 token 集构成“隐式场景”，通过射线直接查询。

**(c) 双向往返式 Ray–Scene Transformer**
- 对每个射线 token 首先做**自注意力**；
- 再把射线 token 作为 Query，场景 token 作为 Key/Value 做**交叉注意力**（射线→场景）；
- 反向执行场景→射线交叉注意力以实现隐式场景的**双向信息更新与特征细化**（文中称双向交叉注意力），最终层仅保留射线→场景方向。
- 这种“双向信息流动”是几何条件能同时服务于重建与生成的关键。

**(d) 混合VAE表示**
- 稀疏观测视图采用**逐帧独立编码**，保持排列不变性；
- 目标轨迹视频采用**联合因果编码**（Wan 的 3D causal VAE），保留时间连续性。

**(e) 几何条件注入设计**
- 重建特征 Fr 需对齐到 VAE 维度、空间分辨率与时间轴，利用 1×1 卷积+双线性重采样+Pack 4（时间维度重排）完成。
- DiT 输入的融合方式为：`3D卷积Patch嵌入`分别嵌入噪声+外观、相机光线、几何条件，然后三路相加融合。

**(f) 联合训练目标**
- **Flow Matching Loss（主损失）**：仅在目标轨迹槽上计算，衡量预测速度场与目标速度场之间的差。
- **Rendering Loss（辅助）**：用重建头把几何特征 Fr 解码回 RGB 图像作为监督，使得特征非纯抽象，始终锚定观测场景。

## 6. 主要结论与发现

1. **整体性能领先**：RoGe 在 DL3DV 的**图像级所有指标（PSNR、SSIM、LPIPS、DreamSim）**以及视频级指标的 **TSED (0.9977)、FID (23)、FVD (58)** 是最优方案之一（与 SEVA 的 FID 并列最优），说明其图像/视频两个维度的能力同时达到榜首，优于纯重建、纯生成与松耦合混合方法
2. **具体定量亮点**：
   - PSNR 达 20.92 dB，比纯生成法（SEVA）高2.29 dB，与纯重建/重建生成混合方法中最佳 LagerNVS 相近且更高；而 LPIPS 从 LagerNVS 的 0.193 大幅降到 0.124，说明它在保留重建精度的同时显著提升了感知质量
   - TransAPE 从 LagerNVS 的 0.033 略劣（同值0.0403，与NeoVerse并列），RotAPE 2.5121 为全局最低，说明在长轨迹中保持较好的相机跟随能力
3. **消融的核心推理**：
   - VGGT 原始 token 无法与相机轨迹对齐，直接把原始 token 注入生成模型反而**伤害性能**（低于不做几何条件的基线 #1），证明几何条件设计中的**坐标系对齐至关重要**
   - 渲染 RGB 作为条件表现可敬，但仍然不如射线查询的隐式特征（表中的 #4 vs. #5/#6），验证隐式特征提供了对渲染有损投影而言的更高保真度
   - 端到端联合训练整体带来提升（#5→#6对比），验证“双向信息流动”的实际有效性。

## 7. 优点

1. **概念创新**——放弃显式3D中间体（点云、3D高斯、RGB渲染），让生成模型直接消化自身的几何条件，实现真正紧耦合
2. **模块设计的周全性**：
   - 引入“相机条件化的 VGGT”解决了几何特征坐标系与给定相机轨迹的固有偏差，实为被许多方法忽略的关键痛点
   - “双向最近邻式”的 Ray-Scene Transformer 让隐式场景和射线特征相互更新，是几何条件提取的重要催化
3. **精心设计的混合编码方案**——在“观测视图排列不变性”和“生成视频时间连贯性”之间保持平衡
4. **实验设计具有说服力**：消融实验设计不仅覆盖行为端（条件类型），更覆盖训练端（是否联合），交叉验证层次高
5. **视频级评测全面**：不仅报序列 FVD/TSED，还增加 MEt3R 与轨迹估计对比，涵盖了视觉真实感、时序稳定性、几何一致性和相机可控性四个不同视角
6. **通用生成性**——以 14B 重量级生成器为骨干，强调在大量多源真实数据上的鲁棒性。

## 8. 不足与局限

1. **评测覆盖的窄化**：
   - 量化比较只在 DL3DV 上进行，单测试集带来的鲁棒性问题仍待观察
   - 外推验证（ScanNet）以定性展示为主，缺少量化跨数据集数据
2. **计算资源负担很大**：
   - 14B 规模 DiT + VGGT 联合训练，输入端直接需要 16×H20 数十万步计算，相比于 3DGS 类方法，在一般学术环境中的复现门槛较高
   - 训练中固定了单 batch=1，未讨论较大 batch 的可扩展性及对最终性能的影响
3. **对比公平性局限**：
   - 对重建类方法（3DGS、YoNoSplat等）或优化型方法统一要求其输出与 81 帧生成模型一致的轨迹视频，但它们的推理机制本质上只是为了逐帧输出，在如此长的时间范围内可能出现系统性的轨迹漂移；衡量方式上可能有倾斜于视频生成方法的偏差；
   - 不同基线的分辨率和生成条件可能不完全一致（虽写明默认推理），但并未在测试中统一各个方法的分辨率条件
4. **隐式表示带来的不可解释性**——没有可视化/量化层面分析“隐式场景表示”的几何质量本身（如在未观测深度区域的误差），只能从最终视频效果来反证其合理性
5. **缺少极限条件分析**——针对极端稀疏（只有 1-2 张参考图）、极端轨迹偏移（长时间漫游 180°+）、以及大遮挡物体等，均无专门的误差分析或失败案例分析
6. **未讨论推理速度**——基于 14B 参数模型，推理的速度和部署成本值得审视；同时没有与轻量化基线在此维度上比较。
