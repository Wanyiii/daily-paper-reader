## 摘要
地球观测表示学习的最新进展通常通过更大的架构来容纳异构传感器和缺失观测。我们提出了MEOX（多模态地球观测专家混合模型），一种多模态掩码自编码器，其编码器参数量为293.9万，总参数量为311.5万。传感器自适应适配器、显式有效信号和共享稀疏专家块在学习的逐块融合之前保留模态依赖处理。四个元数据标记随后伴随单一空间序列经过另外十四个编码器块。共享专家投影与私有低秩残差约束参数增长，而旋转注意力支持与预训练不同的下游空间网格。该模型在122.8万个MMEarth64样本上进行了预训练，使用模态平衡掩码重建和结构化传感器丢弃。冻结迁移在六个GEO-Bench任务上以64和224像素进行评估。该模型在64像素的腰果分割任务上达到64.42%的平均交并比，在224像素的EuroSAT上达到90.56%的平均准确率，超过了相应报道的CSMoE结果。BigEarthNet微调达到72.95%的微平均精确度。路由诊断区分专家参与、空间依赖、模态关联和功能贡献。一个留出的WorldCover探针测量了元数据带来的0.64个百分点的收益，而检索将同传感器语义与跨传感器对齐区分开来。这些结果表明，使用紧凑的参数预算可以实现传感器灵活表示学习和强任务迁移。

## Abstract
Recent advances in Earth Observation representation learning accommodate heterogeneous sensors and missing observations, often through larger architectures. We present MEOX (Multimodal Earth Observation with eXperts), a multimodal masked autoencoder with a 2.939 million-parameter encoder and 3.115 million parameters in total. Sensor-specific adapters, explicit validity signals, and a shared sparse-expert block preserve modality-dependent processing before a learned patch-wise fusion. Four metadata tokens then accompany a single spatial sequence through fourteen further encoder blocks. Shared expert projections with private low-rank residuals constrain parameter growth, while rotary attention supports downstream spatial grids different from pretraining. The model is pretrained on 1.228 million MMEarth64 samples using modality-balanced masked reconstruction and structured sensor dropout. Frozen transfer is evaluated on six GEO-Bench tasks at both 64 and 224 pixels. The model reaches 64.42% mean intersection-over-union on cashew segmentation at 64 pixels and 90.56% average accuracy on EuroSAT at 224 pixels, exceeding the corresponding reported CSMoE results. BigEarthNet finetuning reaches 72.95% micro-average precision. Routing diagnostics distinguish expert participation, spatial dependence, modality association, and functional contribution. A held-out WorldCover probe measures a 0.64-percentage-point benefit from metadata, while retrieval separates same-sensor semantics from cross-sensor alignment. These results demonstrate sensor-flexible representation learning and strong task transfer using a compact parameter budget.

## 2. 方法论

### 2.1 核心思想
- **延迟、有效性感知融合**：先让每个可用传感器独立通过共享的 Transformer-MoE 块，再通过逐 patch 的软门控融合为一个空间序列，避免在整个编码器中携带多份模态序列。
- **显式缺失建模**：对每个像素/波段维护有效性掩码，缺失值不会与归一化均值混淆；元数据也有显式缺失嵌入。
- **紧凑专家设计**：共享专家投影 + 私有低秩残差（rank-8），以少量参数保留专家差异化。
- **旋转位置编码（RoPE）**：支持下游可变空间网格（64/224像素），而非依赖绝对位置加性注入。

### 2.2 关键技术与公式（文字描述）

- **分块融合**（式 3–4）：对每个 patch，计算各传感器的融合分数 = 学习向量对归一化表示的打分 + 传感器偏置 + log(有效比例)，再经 softmax 得到权重，加权求和得到融合表示。
- **稀疏专家路由**：
  - 路由器生成 logits，并加入随输入相关的噪声（训练时）；每个 token 选择 Top-2 专家并归一化权重（式 5）。
  - 每个专家是 SwiGLU 前馈网络（式 7–8），其中 value 和 output 投影在同一层内跨专家共享，每个专家额外有 rank-8 私有残差路径，且 U 矩阵初始化为零。
- **预训练目标**：

## 6. 主要结论与发现

- **紧凑模型有效性**：总参数量 3.115M（编码器 2.939M），在 64 像素下 EuroSAT 平均准确率 89.70%（超过 CSMoE 最高变体 1.40 点），cashew mIoU 64.42%（超过 5.02 点）；在 224 像素下 EuroSAT 90.56%，同样超过 CSMoE。
- **分辨率影响任务依赖**：224 像素总体提升分类/分割（如 crop type +4.68 点），但 So2Sat 反而下降 2.43 点，cashew 基本不变。
- **BigEarthNet 微调增益明显**：从冻结 55.16%→67.78%（64px），57.22%→72.95%（224px）micro-mAP，说明模型具备任务适配容量。
- **路由可解释性**：所有专家均被激活，路由全局均衡但对单个 token 有选择性；位置关联微弱，但传感器和语义类别存在关联（尤其动态世界类别的 NMI 显著高于置换基线）；专家影响并不均匀。模型可提供可检查的稀疏计算路径。
- **元数据有用但非必须**：移除全部元数据仅损失约 0.64 点 mIoU（匹配设置），ERA5 贡献最大，月份几乎无单独贡献。
- **跨传感器检索仍有不足**：同传感器检索接近或部分超过 CSMoE 小/中变体，但跨传感器检索低于最强基准，说明模型没有完全对齐雷达-光学语义空间。

## 7. 优点

- **参数预算极小，性能有竞争力**：以不到 CSMoE 1/87 的参数达到部分超越，验证“紧凑”派路线潜力。
- **架构设计结合成熟技术而并非单纯堆叠**：有效性感知融合、共享稀疏专家 + 私有低秩残差、模态均衡重构、延迟融合等组合具有明确的设计动机。
- **实验规范细致**：统一固定预训练、用验证集选择 checkpoint；报告多头均值±标准差；给出多种 pooling/归一化/位置编码的单独评估；区分“冻结”和“微调”协议。
- **深入测量路由行为**：将执行率、门控占比、top-1 选择、熵、NMI、抑制实验、传感器条件门控等多角度结合，避免仅凭“专家激活”下结论。
- **变量分离明确**：将“表示池化选择”与“嵌入几何”“输入归一化”分别评估；对比时保持任务、主要指标等对齐。
- **开源承诺**：公布代码和实验 notebook（GitHub），利于复现。

## 8. 不足与局限

- **对比实验的匹配性不完全**：与其他模型的比较并非所有输入设置都一致（如 SAR 方向、波段数量、下游负载等），且部分对比值来自图表数字化，存在误差；没有重新运行竞争模型。
- **缺乏组件级消融**：论文没有系统地去掉每个贡献（例如 gated fusion、meta tokens、低秩 residual、噪声 router、模态均衡损失等）并测量对下游的影响，因此结论只能说明“整个系统有效”，不能精确归属于每个部件。
- **元数据消融范围有限**：只在 MMEarth 自身的预训练验证集上做 WordCover 探针，不是独立基准；未评估“元数据在预训练时是否存在”的影响（预训练一直接收元数据）。
- **检索上跨模态对齐不足**：跨传感器检索指标低于最先进的 CSMoE 变体，模型并不能为所有任务提供完美的模态无关空间。
- **路由分析样本太少**：仅 128 个样本，且是同一预训练语料，并不能代表全局路由模式；没有覆盖长尾地理位置。
- **计算比较不全面**：FLOPs 只算 S2 提取和编码器，不含下游头或 UPerNet 整体开销；224 像素下注意力复杂度导致 compute 相对 CSMoE 无优势，论文承认了“存储优势”与“计算效率”的非等同性。
- **部分实验设置缺乏深度**：如随机波段移除鲁棒性、多尺度/大场景重叠窗口推理、以及元数据缺失训练与下游缺失条件之间的匹配性均未验证。
- **损失数值不可直接跨模型比较**：重建 loss 依赖目标尺度归一化，不能用于跨方法对比 。
