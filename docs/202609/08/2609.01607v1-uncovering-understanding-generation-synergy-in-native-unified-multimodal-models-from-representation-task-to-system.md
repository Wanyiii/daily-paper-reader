## 摘要
虽然统一多模态模型（UMMs）在单一模型内联合执行视觉理解与生成，但功能上的统一并不保证学习上的协同：这两个目标可能相互增强、争夺能力，或仅仅共存。我们在一个受控的、结构上原生且无预训练视觉先验的环境下，从表示、任务和系统层面探究它们的关系。在表示层面，我们发现每个目标都为对方提供有用信号：生成丰富了用于理解的视觉特征，而理解则加强了用于生成的视觉-语言对齐。然而，当两个目标被迫经由同一条计算路径时，往往会出现一方主导的情况。一种将冲突的视觉计算专门化同时保留语义交互的任务解耦架构能够避免这种不对称退化。在任务层面，通过三个案例研究，我们发现当理解与生成任务依赖共享知识时，存在积极的双向迁移。在系统层面，我们展示了一个端到端UMM在明确要求同时进行图像理解与生成的复杂任务上胜过了匹配的规划器-执行器流水线。综合这些结果表明，UMM的价值超越了统一接口：适当的专门化、共享的任务知识以及端到端优化可以将共存转化为协同。

## Abstract
While unified multimodal models (UMMs) jointly perform visual understanding and generation within a single model, functional unification does not guarantee learning synergy: the two objectives may reinforce each other, compete for capacity, or merely coexist. We investigate their relationship at the representation, task, and system levels in a controlled, structurally native setting without pretrained vision priors. At the representation level, we find that each objective provides useful signal to the other: generation enriches the visual features learned for understanding, while understanding strengthens vision--language alignment for generation. However, when both objectives are forced through the same computation path, one tends to dominate. A task-decoupled architecture that specializes conflicting visual computation while preserving semantic interaction avoids this asymmetric degradation. At the task level, through three case studies, we find positive bidirectional transfer when understanding and generation tasks rely on shared knowledge. At the system level, we show that an end-to-end UMM outperforms a matched planner--executor pipeline on complex tasks that explicitly require both image understanding and generation. Together, these results show that the value of UMMs extends beyond a unified interface: appropriate specialization, shared task knowledge, and end-to-end optimization can turn coexistence into synergy.

## 二、论文提出的方法论：核心思想、关键技术细节

### 2.1 建模选择与原生视觉接口
- 采用**自回归文本建模（离散）+ 流匹配（Flow Matching）视觉生成（连续）**的混合范式，这是当前联合支撑语言理解与高质量图像生成的主流经验选择。
- 多模态上下文按因果方式建模；每张生成图像内的视觉token按双向方式建模。
- "原生"指视觉信息直接以**像素空间输入和输出**：图像patch由两层卷积（patch size=32）转为token进入模型，生成图像无需图像tokenizer或VAE，以避免外部视觉先验掩盖理解与生成联合训练的真实影响。
- 基于预训练语言模型 **Qwen3-1.7B**，前方增补随机初始化的16层pre-buffer层，使用MRoPE-I编码多模态位置，保留2D空间结构及预训练LLM的位置先验。

### 2.2 三种受控路由架构（核心方法）
**（a）Dense Sharing（密集共享）**：文本、无噪理解视觉token、带噪生成视觉token全部通过同一个LLM decoder层，最大化参数共享。训练匹配三种变体：仅理解（UND）、仅生成（GEN）、联合（UND+GEN）。

**（b）Modality-decoupled MoT（模态解耦）**：预训练分支只处理文本；从零初始化的并行分支处理所有视觉token（包括理解token与生成token），两个分支对交错序列保持全局注意力。用于将视觉表示学习与预训练语言骨干隔离。

**（c）Task-decoupled MoT（任务解耦，论文提出的新设计）**：文本与干净图像token（理解或上下文）走预训练LLM分支；带噪图像token（生成）走生成专用视觉分支。两个分支的视觉表示通过两种方式软对齐：
1. 与同一文本特征做注意力交互，提供共享语义上下文；
2. 图像编辑与交错样本中，理解分支的上下文图像经逐层共享注意力成为生成分支的条件。

另外，训练混合中额外分配20%比例的图像重建任务（以图像编辑形式，随机遮盖50%下文图像的视觉token），加强两分支连接。

### 2.3 任务层面的训练协议
各案例研究中，50%混合为移除相关域样例后的通用表示层数据，剩余50%为任务针对性数据，避免任务数据与辅助数据重叠混淆比较。

### 2.4 系统层面的受控比较
将同一推理型图像编辑数据转化为三种训练格式：
1. **端到端**：接受源图与隐含指令，推理出显式编辑指令并生成目标图；
2. **规划（理解）**：只输出显式编辑指令；
3. **执行（生成）**：在源图、隐含指令和显式指令条件下生成目标图。

推理时，端到端（格式1）与"规划器→执行器"（格式2+3组合）在同一基座、同一任务数据下直接公平对比。

  5. 原生训练仅针对视觉部分增量进行，全文承认并不是从头原生预训练完整模型；
  6. 生成评估选用的自动指标（GenEval2原子级、DPG、HPSv3、Aesthetic）对语义忠实度与高级视觉质量反映有限。
- **综合来看**：实验设计在同规模、同数据、同基座下是相当客观、公平的内部受控体系；但作为对UMM协同效应的通用规律断言，其外部效度（更大模型、其他架构、其他数据分布）仍有限。

## 六、论文的主要结论与发现

**发现1（表示层面）**：视觉理解与生成能互相提供有益的学习信号，但能否转化为相互增益**依赖架构选择**。核心机制：
- 生成监督**丰富用于理解的视觉特征**：冻结探针实验显示联合训练在ImageNet、ADE20K、NYUv2多层内部提升，PCA可视化显现更连贯目标区域与清晰空间结构；
- 理解监督**改善面向生成的视觉-语言对齐**：联合训练的生成特征与文本特征层间CKA一致高于纯生成训练；
- 但在Dense共享中，LLM的强语义锚定让理解占据主导，生成能力受损；在Modality-decoupled MoT中，从零初始化的视觉分支由生成主导，理解能力下降。两种失败模式均可被**任务解耦MoT**克服——它将冲突视觉计算特化、同时保留语义交互路径，消除不对称退化，使理解与生成指标都未明显受损；
- 结论："不是统一本身产生干扰，而是目标沿路径分离后可同时改善"。

**发现2（任务层面）**：当理解和生成任务依赖**共享领域知识/底层能力**时，存在**双向正迁移**。三个案例中几何（生成图形提升几何推理与泛化数学）、SVG（两方向俱增，盲VQA诊断证实"从代码到视觉的心理执行"能力增强，且早熟生成结构的代码可视化能力更强）、3D空间智能（理解侧8/9提升、平均57.15→59.01；生成侧误差下降与重建质量提升）均一致复现该模式。且几何案例中，生成目标比将同一数据转化为文本理解目标更有效——证明增益主要由学习生成图本身带来，而非单纯增加数据量。

**发现3（系统层面）

**发现3（系统层面)**：在需要理解与生成紧密协同的复杂视觉任务中，端到端统一模型显著优于分离式流水线，但前提是其内部具备任务解耦结构。在推理型图像编辑上，Task-decoupled MoT的端到端训练在RISEBench上平均约提升14.1分、KRIS-Bench上提升8.6分，相对“规划器→执行器”流水线有统计显著优势；而Dense Sharing架构的端到端模型优势大幅缩小甚至消失。这证明强语义耦合的密集共享无法充分利用端到端信号，而任务解耦使两个方向在底层共享、在计算上保持自主，才能真正受益于端到端优化。

**观察4（扩展性观察）**：全文中联合模型的文本token与生成token量级保持同量级——210K步中理解文本约70.8%的token占比，而生成任务在较高增强倍率下的总token数量最高达到理解token的84.8%。即便从较低生成token比例起步，生成能力也可随训练稳定攀升，说明性能改善并非来自简单增加某一个方向的训练量，而是来自目标结构与路由设计本身。

## 七、局限性与可改进方向

该研究的核心局限主要有六点：

1. **规模有限**：仅在Qwen3-1.7B单一规模上完成全部分析，没有更大LLM规模的验证，无法排除更大模型上Dense Sharing的任务冲突显著弱化的可能性；未来可在7B/32B（或MoE）上重跑关键实验；
2. **单基座依赖**：不同语言模型家族的语义锚定强度不同，可能对“理解主导Dense共享”现象有显著影响；未来可跨多个LLM家族做复制验证；
3. **未进行完整视觉单元预训练**：作者承认“原生”主要体现于增量阶段的无视觉先验输入输出，没有完整地从头预训练整个多模态栈，部分初始视觉模式仍可能遗留了预训练LLM语料中的间接知识；
4. **任务层面的因果机制多为间接证据**：对共享知识的解释主要来自实验模式推论；未来可通过更直接的能力扰动或表示编辑实验加以验证；
5. **超参数敏感性未扫描**：图像重建20%比例、流匹配噪声尺度、双分支注意力结构等关键设计均未做敏感性分析，最优结构未必全局最优；
6. **视觉生成侧自动指标的语义覆盖有限**：缺少人工评估或更细粒度的语义保真度量，生成质量结论仍应谨慎解释。

## 八、对后续研究的启发与参考价值

对本领域最重要启发是：**多模态统一建模的核心问题并不是“保留多少参数给生成”，而是“如何在模型内部划出正确的分工边界”**。论文展示了一条可迁移的设计路线——利用预训练LLM长上下文的强先验处理语言和视觉语义理解，同时为像素生成设置带软对齐的专用计算路径，既不放弃共享语义知识，也避开视觉生成与语言语义锚定之间的暴力冲突。这一“任务特化+跨层语义交互”的模板，也可推广至统一模型内部的音频、3D、视频生成与理解协调设计；同时其利用同一任务生成数据改写为理解任务数据的对照方法，也为后续做数据与目标任务效应分离提供了可复用的实验范式。

## 九、结论

本文通过受控、分层（表示/任务/系统）的大规模实验体系，明确回答了核心问题：统一视觉理解与生成不一定互相干扰，也并非自动协同——它取决于目标在模型内部的路径设置与共享方式。Dense Sharing结构中理解因语言模型语义锚定而压制生成，Modality解耦结构中生成反向压制理解；而任务解耦MoT（文本-理解走预训练路径、生成走并行视觉专用路径、以逐层交叉注意力保持文本与图像语义联系）不但消除了单方向能力的不对称退化，还在几何、SVG、3D空间智能等需要共享领域知识的任务中催生出双向互惠、且端到端优于分离式流水线的系统级增益。走出“仅共存”的关键方法是在保持共享知识交互的同时、理解与生成在计算路径上获得适度自主性。
