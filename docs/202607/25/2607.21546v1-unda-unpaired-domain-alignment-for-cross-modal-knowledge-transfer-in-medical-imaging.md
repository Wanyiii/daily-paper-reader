## 摘要
多模态方法在下游任务中通常优于单模态方法，因为不同模态提供互补信息，但在现实场景中获取配对的临床数据仍然是一个重大挑战。虽然跨模态知识蒸馏解决了这一问题，但现有方法往往难以应对大的模态间隙以及来自不确定源域预测的噪声传播。为了克服这些挑战，我们提出了UnDA，一种用于无配对跨模态蒸馏的锚点引导框架。我们的方法引入了一个主干无关的对齐模块，该模块通过基于注意力的池化机制提取语义结构化的类标记。为了确保鲁棒的知识迁移，我们提出了不确定性加权最优传输（UCT-OT），它根据预测置信度动态调整特征级对齐的权重，有效抑制噪声监督。此外，每个类的ProtoNCE目标维持稳定的原型记忆，以在无配对批次间强制执行全局判别性。在严格无配对设置下的代表性分割任务评估显示，目标模态的准确性和边界精度得到一致提升，这表明在无需配对数据集的情况下，有意义的 structural 知识可以在异质数据源之间迁移。

## Abstract
Multimodal based approaches often outperform single modality approaches in downstream tasks as the different modalities provide complementary information, yet acquiring paired clinical data remains a significant challenge in real world scenarios. While cross-modal knowledge distillation addresses this, existing methods often struggle with large modality gaps and the propagation of noise from uncertain source-domain predictions. To overcome these challenges, we propose UnDA, an anchor-guided framework for unpaired cross-modal distillation. Our approach introduces a backbone-agnostic Alignment Module that extracts semantically structured class tokens via an attention based pooling mechanism. To ensure robust knowledge transfer, we propose Uncertainty-Weighted Optimal Transport (UCT-OT), which dynamically weights feature-level alignment based on prediction confidence, effectively suppressing noisy supervision. Furthermore, a per-class ProtoNCE objective maintains stable prototype memories to enforce global discriminability across unpaired batches. Evaluations on representative segmentation tasks under strictly unpaired settings show consistent improvements in accuracy and boundary precision in the target modality, demonstrating that meaningful structural knowledge can be transferred across heterogeneous data sources without paired datasets.

## 2. 论文提出的方法论

### 核心思想
- 采用两阶段训练：第一阶段在标记的源域（锚点域）上训练锚点模型，学习可靠的结构表示和类令牌；第二阶段冻结锚点模型，利用其生成参考令牌和更新原型统计量，指导目标域网络训练。
- 通过**主干无关的对齐模块**，将编码器瓶颈特征映射到共享的类令牌空间；该模块在训练后移除，推理时零开销。

### 关键技术细节
1. **类令牌池（Class Token Pool）**  
   - 在编码器瓶颈处，通过可学习的空间注意力权重将特征图聚合成K个紧凑的类令牌（每个令牌代表一个语义类）。
   - 锚点训练时，使用类别存在辅助损失（L_token）监督令牌判别性；目标域令牌经轻量残差MLP适配器（秩r=16）调整后用于对齐。

2. **原型记忆（Prototype Memory）**  
   - 维护一个动量更新的运行原型记忆M（大小为K×d），存储锚点域类级表示。
   - 每次迭代用锚点批次令牌以指数移动平均（β=0.9）更新原型，提供稳定的对齐目标。

3. **不确定性加权最优传输（UCT-OT）**  
   - 替代原始最优传输（OT），对锚点令牌的可靠性进行加权。利用预测熵估计每个令牌的不确定性u_i，转化为可靠性权重w_i = exp(-α u_i)，归一化后作为源边际分布a；目标边际保持均匀。
   - 通过Sinkhorn迭代求解熵正则化的OT问题，得到传输计划P*，其中不确定性高的锚点令牌携带更少质量，从而抑制噪声监督。
   - 对齐损失L_UCT-OT = Σ P*_ij * C_ij（C_ij为令牌间L2距离）。

4. **训练目标**  
   - **锚点阶段**：L_anchor = L_seg + λ_token L_token，其中L_seg = Dice + BCE。
   - **目标阶段**：L_target = L_seg + λ_OT L_UCT-OT + λ_P ProtoNCE。ProtoNCE损失使目标令牌聚拢在动量更新的类原型周围，增强全局判别性。默认λ_OT=0.2，λ_P=0.5。

## 6. 主要结论与发现

- UnDA在严格无配对设置下，**显著提升了目标模态的分割Dice和边界HD95**。例如BraTS上TC HD95从29.12mm降至10.10mm，ET HD95甚至超过锚点（T2-FLAIR），表明T1-native能更好捕捉增强肿瘤边界。
- 在MM-WHS上，UnDA达到**平均Dice 82.71%**（比CT基线+11.12点），平均HD95 **13.94mm**（优于所有对比方法，比UMMKD低9.19mm）。
- **不确定性加权OT**比普通OT更重要：普通OT甚至可能降低性能（PA下降6.56 Dice），UCT-OT恢复并显著提升小结构（如PA）。
- **ProtoNCE与UCT-OT互补**：两者结合在RA和PA上获得最佳效果，验证了不确定性感知分布对齐与类原型判别性的协同作用。
