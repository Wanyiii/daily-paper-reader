## 摘要
将仿真模型与历史输出数据进行验证对于其在数字孪生环境中的成功部署至关重要。我们提出了一种统计验证框架，在该框架中，仿真模型从观测到的系统状态反复初始化，并通过将来自随机输入模型子集的原语固定为其观测实现，同时模拟剩余原语，从而获得条件输出分布。然后，这些条件输出分布被用于拟合优度检验，以验证仿真模型相对于输入模型组合的正确性。我们还开发了诊断工具，以识别对仿真模型输出与实际结果之间任何观察到的偏差贡献最大的输入模型。在M/M/1排队系统和支持数字孪生的串联排队系统仿真上的数值实验表明，所提出的框架能够检测到输入模型中的错误设定，而这些错误设定可能被仅验证边际输出分布的现有方法所忽略。

## Abstract
Validating simulation models against historical output data is essential for their successful deployment in digital-twin environments. We propose a statistical validation framework in which a simulation model is repeatedly initialized from observed system states, and conditional output distributions are obtained by fixing the random primitives from a subset of stochastic input models to their observed realizations while simulating the remaining primitives. These conditional output distributions are then used in goodness-of-fit tests to validate the simulation model with respect to combinations of input models. We also develop diagnostic tools to identify the input models that most contribute to any observed misalignment between a simulation model's outputs and reality. Numerical experiments on an M/M/1 queueing system and a digital-twin-enabled simulation of a tandem queueing system demonstrate that the proposed framework can detect misspecifications in input models that may be missed by existing approaches that validate only the marginal output distribution.

### 1. 核心问题与整体含义（研究动机和背景）
- **背景**：仿真模型在数字孪生环境中部署前，必须通过历史输出数据进行验证。现有统计验证方法（如Rhodes-Leader & Nelson, 2023）仅检验仿真输出的**边际分布**与真实数据的对齐程度。
- **问题**：边际验证方法可能因多个错误输入模型的偏差相互抵消而**遗漏**模型误设。例如，在M/M/1排队系统中，服务率和到达率同时被高估但差值不变时，边际输出分布可能看似一致，掩盖了底层输入模型的错误。此外，现有方法无法定位导致偏差的具体输入模型。
- **研究目标**：提出一个**更全面的统计验证框架**，不仅验证边际输出分布，还验证**条件于部分历史轨迹（子轨迹）的条件输出分布**，从而检测出边际验证无法发现的误设，并诊断哪些输入模型是偏差的主要来源。

### 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：
  - 假设系统动力学映射H正确，误差仅来自输入模型误设。
  - 给定历史轨迹数据（包含状态ψ_t、随机原语ξ_t、输出y_t），对于输入模型索引的子集A，定义**子轨迹条件输出分布**：固定A中的原语为历史值ξ_t,A，对剩余原语（Ac）进行采样，得到输出分布F_t,A。
  - 利用**概率积分变换（PIT）** 将不同时间段的输出标准化为均匀分布U(0,1)的样本，从而合并所有时间段进行拟合优度检验。
- **关键技术细节**：
  - **PIT转换**：对每个时间段t和子集A，计算U_t,A = F_t,A(y_t)，若模型正确，则{U_t,A}~i.i.d. U(0,1)。实际中F_t,A通过R次模拟逼近，得到经验CDF，进而计算估计值\hat{U}_t,A。
  - **假设检验**：零假设为{U_t,A}服从U(0,1)。使用**Wasserstein-1距离**作为检验统计量，其闭式解为W_A = (1/T)∑|û_{(t),A} - (2t-1)/(2T)|。通过bootstrap计算p值，并采用Bonferroni校正控制族系错误率。
  - **诊断方法**：
    - **实验设计（DoE）**：将2^S种配置（每个输入模型模拟=0或固定历史=1）全部或部分执行，得到W_A值。采用全因子/部分因子设计，配合ANOVA分析主效应和交互效应。
    - **Bootstrap增强**：对每个配置的R次模拟输出进行B次重采样，生成更大数据集，用于后续回归或树模型推断。
    - **子集选择**：使用线性回归（含交互项），结合前向/后向逐步选择，识别显著影响WA的输入模型。
    - **回归树**：训练回归树预测WA，根据分裂时RSS减少量计算变量重要性得分，分解各输入模型的贡献。
- **算法流程**（文字说明）：
  1. 获取历史轨迹E = {(ψ_t, ξ_t, y_t)}。
  2. 对于每个子集A（设计集D），对每个时间段t：
     - 固定子轨迹ξ_t,A，从估计的输入模型中采样R次剩余原语，运行仿真得到R个输出Y^r_t,A。
     - 构建经验CDF \hat{F}_t,A，计算\hat{U}_t,A = \hat{F}_t,A(y_t)。
  3. 对所有t合并\hat{U}_t,A，计算Wasserstein距离W_A，并通过bootstrap获取p值。
  4. 对全部分组进行多重假设检验（Bonferroni校正）。
  5. 若拒绝某些零假设，使用DoE数据库（W_A及编码z_A）进行回归树或子集选择，识别关键输入模型。

### 3. 实验设计
- **实验场景1：M/M/1排队系统**

  - 数据：40个独立复制（每个复制得到一个平均等待时间），共40个历史观测。
  - 设计点：3种配置——(到达模拟,服务模拟)、(到达历史,服务模拟)、(到达模拟,服务历史)。R=40次模拟复制。
  - 对比方法：边际验证（对应配置(模拟,模拟)）与条件验证（后两种配置）。
- **实验场景2：串联排队系统（数字孪生环境）**
  - 场景：3个服务站，有限缓冲区（10,15,15），阻塞机制，非平稳泊松到达（24个30分钟区间，速率不同），服务时间指数分布（站1:1min,站2:1min,站3:2min）。误设：站2的服务时间均值被错误估计为2（真实为1）。其他输入模型正确。
  - 数据：单个12小时复制的**24个区间**输出（拒收比例），每个区间开始时使用历史状态ψ_t。

### 6. 主要结论与发现
- 边际验证可能因多个输入模型误差抵消而无法检测到误设（如M/M/1实验中λ和μ同时高估），而**条件验证能有效暴露这些隐藏偏差**。
