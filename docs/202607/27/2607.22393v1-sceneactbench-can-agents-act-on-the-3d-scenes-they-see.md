## 摘要
视觉语言模型（VLM）智能体越来越多地使用工具来作用于3D场景，而不仅仅是描述它们。现有的3D基准测试对文本响应或单物体操作进行评分，而智能体在完整多物体3D场景上的操作仍缺乏评估。我们提出SceneActBench，一个在统一智能体-环境循环下跨五个3D任务进行视觉条件动作的基准测试。给定PNG图像或采样视频帧，以及（如适用）提供的3D资产，智能体对3D环境执行操作。我们针对每个最终输出，使用任务特定的几何指标与隐藏的真实值进行对比评估。SceneActBench包含来自210个源实例构建的五个任务，共产生520个任务案例（包括配对输入条件）。每个任务通过一个固定的智能体循环运行以保持公平比较。在11种专有VLM配置中，总体得分范围在38.6到50.2之间，且没有一种配置在所有任务上表现一致良好。我们进一步分析了失败发生的位置和方式。

## Abstract
Vision-language model (VLM) agents increasingly use tools to act on 3D scenes rather than only describe them. Existing 3D benchmarks score textual responses or single-object operations, leaving agent action on complete multi-object 3D scenes under evaluated. We present SceneActBench, a benchmark for visually conditioned action across five 3D tasks under a unified agent-environment loop. Given PNG images or sampled video frames and, where applicable, supplied 3D assets, an agent acts on a 3D environment. We evaluate each final output against hidden ground truth with task-specific geometric metrics. SceneActBench comprises five tasks built from 210 source instances, yielding 520 task cases including paired input conditions. Every task runs through one fixed agent loop to keep the comparison fair. Across eleven proprietary VLM configurations, Overall scores span 38.6-50.2, and none performs consistently well across tasks. We further analyse where and how failures manifest.

- **研究动机**：现有视觉语言模型（VLM）智能体越来越多地使用工具在3D场景中执行操作（而不仅仅是描述场景），但现有3D基准仅评估文本回答或单物体操作，缺乏对智能体在**完整多物体3D场景**中执行动作能力的整体评估。
- **核心问题**：“一个看到场景的智能体，能否在3D环境中执行操作以匹配该场景？”——即**视觉条件的3D动作**能力是否真正具备。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将3D理解转化为可执行的评估——智能体观察参考图像或视频帧，通过统一工具接口控制Blender（无需图形界面），在固定智能体-环境循环中执行操作，最终输出与隐藏3D真实值进行任务特定的几何指标对比。
- **关键技术细节**：
  - **统一智能体循环**：所有任务共享相同流程：输入（图像/视频帧+可选3D资产）→ 智能体通过MCP接口调用Blender工具（检查场景、执行Python代码、渲染）→ 输出最终产物（GLB文件、动画GLB、JSON相机位姿等）→ 隐藏评估器计算几何指标。循环允许智能体在预算步数内反复检查、修改。
  - **任务定义**：
    - **Layout（布局）**：给定室内图像和标准化家具GLB（位于原点），智能体设置每个物体的世界位置和绕Y轴的旋转。度量：ADD-S（平均表面距离）。
    - **Camera（相机）**：给定固定场景图像和已知视场角，智能体推断6自由度相机位姿。度量：位置误差（PE）和角度误差（AE）。
    - **Articulated（铰接）**：给定闭合铰接物体GLB和32帧开合视频，智能体找到可动部分、推断关节参数并重现运动。度量：最大零件误差（MPE）。
    - **Reconstruction（重建）**：给定多视点房间图像和空的Blender场景，智能体重建每个家具的网格、位置和基本颜色。度量：F@5%（对象级表面匹配）。
    - **Dynamic（动态）**：给定采样视频帧和组件GLB库，智能体重建静态布局、每个移动物体的起始位置和关键帧轨迹，输出动画GLB。度量：最大移动体误差（MME）+ 布局误差（LE）。
  - **后处理**：标准化所有3D资产（中心化、中性偏航、匿名标识符），防止信息泄露。
  - **总体得分**：将每个任务的主要指标映射到0-100分（误差用q↓，F@5%用q↑），然后平均五个任务得分。只使用单视图Layout和低多边形Dynamic作为总体得分基准。

## 3. 实验设计
- **数据集/场景**：
  - 室内场景：100个3D-FRONT房间（3-7件家具，27个类别），每房间11个校准视图。
  - 铰接物体：100个S2O Articulated Containers Dataset (ACD)物体，每物体32帧开合视频。

## 6. 主要结论与发现
- **表现水平**：11个配置总体得分范围38.6–50.2，最高为Doubao Seed 2.0 Pro High（50.2），其次Claude Opus 4.6 High（48.9）和GPT 5.4 Medium（48.7）。三者仅差1.5分，但各自领先不同任务。

## 7. 优点
- **统一可执行评估**：将3D理解转化为实际动作评估，提供几何指标与隐藏真实值对比，避免主观评分。
- **多任务覆盖**：同时评估空间定位、自我中心推理、运动学推理、形状想象和动态推理五种能力，覆盖面远超现有基准。
- **标准化工具接口**：通过MCP控制Blender，所有配置使用完全相同工具和环境，保证公平比较。
- **丰富诊断信息**：除主要指标外，提供详细的阶段诊断（零件移动、类型方向、匹配率、表面覆盖等），帮助定位失败原因。
- **严格的防泄露处理**：标准化资产、匿名标识符、隐藏真实值，迫使智能体从图像重建而非利用命名/坐标信息。
- **公开代码、项目页面和数据集**：便于复现和扩展。

## 8. 不足与局限
- **运行次数有限**：每个配置-案例对仅一次运行，无法估计重复运行变异，总体得分不应视为统计差异证据。
- **动态场景规模小**：仅10个动态场景，作为压力测试而非广泛评估，结论可能受特定场景选择影响。
- **归一化常数依赖**：总体得分取决于q↓/q↑的固定参考值（如4m、90°等），不同选择可能导致不同排名。
- **仅限专有VLM**：未评估开源模型或专业3D管线（如布局生成器、图像转3D重建器、相机估计器等），这些方法可能表现更好。
- **任务刚性**：固定预算步数、单一工具集，可能限制某些智能体的部分优势（如用官方CLI栈时某些任务得分更高，但总体效果变化不大）。
- **无语言/交互复杂度分析**：未深入分析智能体生成了多少代码、是否涉及复杂推理等，仅用步数和调用量粗略表征互动。
- **应用限制**：基准使用Blender作为唯一环境，且仅关注几何匹配，不涉及物理真实感、光照、纹理等更丰富的3D场景属性。
