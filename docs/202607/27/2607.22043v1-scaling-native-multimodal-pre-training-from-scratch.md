## 摘要
尽管大型语言模型（LLMs）展现出卓越的推理能力，但其依赖纯文本预训练限制了其对多模态物理世界的感知。原生多模态预训练通过在多模态输入上从头开始训练模型，避免了这一限制，从而实现深度跨模态集成，并缓解了传统后期融合架构固有的优化不对称性。尽管有这些优势，该范式的扩展特性仍缺乏系统性的描述。为弥补这一空白，我们研究了在固定计算预算下训练基于Transformer的视觉语言模型时，最优模型大小和标记数量。我们证明，最小目标损失遵循可预测的计算律，而计算最优的模型大小和标记数量以幂律形式扩展。值得注意的是，语言和多模态目标表现出不同的扩展行为。语言分配律在很大程度上与数据组成无关，表明无论多模态数据比例如何，语言学习都是稳定的。相反，多模态分配律对此组成高度敏感。具体来说，只有在大模型规模下，文本密集的混合数据才会变得计算高效，从而将最优资源分配转向更大的模型容量。此外，通过对数据组成对计算律和分配指数的影响进行建模，我们推导出一个效率前沿，指定了模型大小、标记数量和数据混合的精确配置。下游评估进一步揭示，原生多模态预训练引发了正向的跨模态迁移，从而增强了纯文本空间推理，并实现了稳健的多模态上下文学习。总之，这项实证研究为可预测地扩展多模态基础模型奠定了必要的基础。

## Abstract
Although large language models (LLMs) exhibit remarkable reasoning capabilities, their reliance on text-only pre-training restricts the perception of the multimodal physical world. Native multimodal pre-training avoids this limitation by training models from scratch on multimodal inputs, thereby achieving deep cross-modal integration and mitigating optimization asymmetries inherent to traditional late-fusion architectures. Despite these advantages, the scaling properties of this paradigm remain systematically uncharacterized. To address this gap, we investigate the optimal model size and token count for training a transformer-based vision-language model under a fixed computational budget. We demonstrate that minimal objective loss adheres to a predictable compute law, whereas compute-optimal model sizes and token counts scale as power laws. Notably, language and multimodal objectives manifest distinct scaling behaviors. The language allocation law is largely invariant to the composition of the data, indicating stable language learning regardless of the multimodal data ratio. Conversely, the multimodal allocation law is highly sensitive to this composition. Specifically, text-heavy mixtures become compute-efficient only at larger model scales, shifting the optimal resource allocation toward greater model capacity. Additionally, by modeling the influence of data composition on compute laws and allocation exponents, we derive an efficiency frontier specifying precise configurations of model size, token count, and data mixture. Downstream evaluations further reveal that native multimodal pre-training induces positive cross-modal transfer, thereby enhancing pure-text spatial reasoning and enabling robust multimodal in-context learning. In summary, this empirical research establishes the essential groundwork for predictably scaling multimodal foundation models.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：当前大语言模型（LLMs）主要依赖纯文本预训练，限制了模型对多模态物理世界的感知能力。现有的多模态预训练主流范式是“后期融合”（late fusion），即预训练好的语言模型与视觉编码器通过投影层对接，再在多模态数据上继续训练。这种方式虽然高效，但引入了本质不对称性：视觉和语言表示是从不同数据分布和不同优化目标独立学习而来，难以实现深度跨模态集成。
- **研究动机**：原生多模态预训练（native multimodal pre-training）从零开始在混合多模态数据上训练单一模型，能够避免上述不对称性，但其计算缩放规律（compute-optimal scaling laws）尚未被系统刻画。本文旨在解决以下核心问题：在固定计算预算下，如何最优分配模型参数量（N）和训练 token 数（D）？语言目标与多模态目标各自的缩放行为是否一致？数据组成（多模态 token 占比 r）对最优分配有何影响？
- **整体含义**：这项工作为从零开始构建大规模原生多模态基础模型提供了理论指导和实证基础，揭示了语言与多模态目标截然不同的缩放特性，并给出了可操作的效率前沿配置。

## 2. 论文提出的方法论

### 核心思想
- 将原生多模态预训练的总目标解耦为语言目标（L<sub>text</sub>）和多模态目标（L<sub>mm</sub>），分别分析其计算最优分配。
- 基于计算预算 C = 6ND（标准近似），寻求使损失最小化的 (N, D) 组合。
- 拟合幂律关系：N<sub>opt</sub> ∝ C<sup>a</sup>，D<sub>opt</sub> ∝ C<sup>b</sup>，且 a + b = 1。
- 引入数据混合比率 r = (多模态 token 数) / (文本 token 数)，考察 r 对缩放行为的影响。

### 关键技术细节
1. **两个独立估计器**：
   - **IsoFLOP 曲线**：在同一计算预算下，固定 FLOPs，调整模型大小 N 并绘制损失曲线，通过抛物线拟合找到最小损失对应的 N<sub>opt</sub>，进而得到 D<sub>opt</sub>。
   - **训练曲线包络（training-curve envelope）**：汇集所有规模模型的损失-计算量轨迹，取下包络线，包络上的每个点对应 (N, D) 配置，用于交叉验证 IsoFLOP 结果。
2. **计算前沿（Compute Frontier）**：
   - 沿包络线的损失满足幂律：L(C) = E + (C<sub>c</sub> / C)<sup>β</sup>，其中 E 为不可约损失，C<sub>c</sub> 为临界计算量，β 为衰减指数。
3. **联合帕累托前沿（Joint Pareto Frontier）**：
   - 在统一计算预算 C<sub>total</sub> 下，通过扫掠 r 得到语言损失与多模态损失之间的帕累托曲线；再基于不对称建模（语言分配律对 r 不敏感，多模态分配律对 r 敏感）投影出全局最优分配指数 a(r) 和 b(r)。

### 算法流程（文字说明）
1. 选择 6 种不同规模的模型（71M~3B 激活参数）。
2. 针对每个 r 值（0, 0.1, 0.2, 0.3），使用多个计算预算 C 进行训练，分别生成 IsoFLOP 曲线和训练曲线包络。
3. 通过 IsoFLOP 曲线拟合出每个计算预算下的 N<sub>opt</sub> 和 D<sub>opt</sub>，再对 log N<sub>opt</sub> 与 log C 做线性回归得到指数 a、b。
4. 用训练曲线包络独立重复上述回归，验证结果一致性。
5. 对语言目标和多模态目标分别执行以上步骤，观察 a、b 随 r 的变化。
6. 最后，在联合预算 C<sub>total</sub> 下，通过帕累托分析给出最优的 (N, D, r) 配置。

## 6. 主要结论与发现

1. **语言目标缩放对数据组成不敏感**：语言目标的分配律（a, b）几乎不随 r 变化，表明语言学习从每个 token 中获取的信息一致，不受多模态 token 影响。
2. **多模态目标缩放高度依赖数据组成**：随着 r 增大（多模态 token 占比提高），最优分配指数 a 显著下降（参数扩展变缓），b 上升（需要更多数据）。说明跨模态对齐本质上是“数据饥饿”的，需要更多 token 来支撑。
3. **联合帕累托前沿驱动资源倾斜**：在统一预算下，高 r 配置要求模型参数量扩展更保守，token 数扩展更激进；例如 r=0.3 时 N<sub>opt</sub> ∝ C<sub>total</sub><sup>0.66</sup>，而 r=0.1 时为 C<sub>total</sub><sup>0.69</sup>。
4. **原生多模态预训练保持语言能力**：在 250B 文本 token 基础上引入 25B~75B 多模态 token 后，15 个文本基准的平均准确率与纯文本基线几乎无差别（<1%）。
5. **跨模态迁移增强纯文本空间推理**：在 SpatialEval 的抽象空间推理子任务（MazeNav, SpatialMap）上，多模态模型（r=0.3）显著优于纯文本模型，且差距随模型增大而扩大。
6. **多模态上下文学习随规模涌现**：模型在较大规模（≥874M）时，少样本（1-shot, 3-shot）提示带来显著增益（最大 +2.43%），类似 LLM 的上下文学习；增益主要集中在空间推理类任务，对 OCR/识别类获益有限。
7. **少样本增益随训练数据增加而上升**：在 A3B 模型训练过程中，少样本优势逐步显现，表明该能力是通过大量数据学习获得的。

## 7. 优点

- **方法创新**：首次系统解耦分析原生多模态预训练的语言与多模态目标缩放行为，揭示了其截然不同的分配律；引入数据组成 r 作为关键变量，填补了以往规模律研究只考虑单一模态的空白。
- **双估计器校验**：同时使用 IsoFLOP 曲线和训练曲线包络，结果高度一致，增强了结论的可靠性，避免了对特定函数形式的过拟合。
- **实践指导价值**：通过联合帕累托前沿给出了模型大小、token 数和数据配比的明确配置公式，对实际部署原生多模态模型有直接指导意义。
- **全面的下游验证**：大规模基准评测（39 个）覆盖了语言、多模态多个维度，且通过 r 消融实验证实多模态预训练不损害语言能力且带来正向迁移。

## 8. 不足与局限

- **模型规模限制**：实验最大模型为 3B 激活参数（总参数量可能更大，但为 MoE，激活参数严格为 3B）。在当代大规模模型实践中（如 100B+ 级别），缩放律是否完全成立仍未验证，需要后续扩展到更大规模。
- **数据多样性不足**：仅使用单一图像-文本对/交错文档数据族，未涉及其他模态（音频、视频、3D 等），也未考虑数据质量或噪声的影响，结论在其他多模态场景下的泛化性有待检验。
- **以训练损失代理评估**：缩放分析基于训练损失（平滑后的），虽然对标语言建模任务中“每个 token 只看到一次”的惯例，但多模态评估更复杂，训练损失与下游任务指标的相关性未完全建立。
- **架构特定性**：实验基于 MoE decoder-only Transformer，且使用辅助损失无关训练；其他架构（如 dense 模型、视觉编码器+语言解码器等）的缩放律可能不同，结论推广需谨慎。
- **未报告算力细节**：缺少 GPU 型号、数量、训练时长等关键信息，不利于其他团队复现或估算成本。
- **拟合误差**：虽然双估计器一致，但语言目标的 a 值随 r 略有波动（在置信区间内），可能暗示存在微弱依赖，当前定性为“不变”是一种近似。
